# 编辑器目录职责

根 `index.tsx` 负责编辑工作区装配，`index.module.scss` 保留宿主布局样式。业务实现与对应 SCSS 就近放置，通常只分一层目录。

- `workspace`：标题栏、工具栏、状态、历史反馈、侧栏框架、宿主宽度与覆盖层布局。
- `session`：会话装配、运行时、草稿协调、命令适配、模态框和对象交互协调。
- `tools`：拍、小节、音符、技巧与连音的工具入口、目标解析、状态及参数面板。
- `score`：谱面图层、焦点提示、视图缩放、文字度量与画布渲染。
- `output`：文件读写、图片生成及任务生命周期、成品分页与打印。
- `music-text`：共享音乐文字侧栏、任务上下文、草稿、编辑目标及浮窗定位；拍映射预览由简谱和歌词共同使用。
- `numbered`：简谱输入、音高节奏字段、预览与提交依赖。
- `lyrics`：歌词表单及其样式。
- `chords`：和弦编辑、预设、曲库、指法图、偏好及和弦目标。
- `settings`：歌曲/小节设置表单、设置草稿与输入法组合状态。
- `shared`：已有跨模块消费者的表单、工具面板、选中任务样式，以及最小输入按键判断。

## 引用约定

网站内部使用指向真实实现的明确相对路径；核心包能力从 `@liuxianmao/lxm-editor` 公共入口引用。模块内直接引用具体文件，不增加转发入口或旧路径兼容副本。子模块不得通过根 `index.tsx` 获取业务能力；`session/EditorSession.tsx` 是会话入口装配器，唯一负责从根挂载宿主。

移动文件时一并核对外部消费者、动态导入、测试 mock、源码读取路径和浏览器 Vite 的 alias/resolve 匹配。SCSS 文件名与类名保持稳定，资源相对路径按真实位置解析。共享样式只在已有多个消费者时放入 `shared`，业务专用样式留在所属模块，避免建立泛化工具杂物目录。

吉他进阶教学谱例复用 `score/ScoreMusicLayer` 作为只读 SVG 图层，场景数据仍通过核心包公共出口构建。跨产品入口由宿主检查会话草稿、模态框及输出状态；头部只请求导航，不创建第二套草稿协调器。全局打印隔离只作用于存在成品打印层的编辑器页面。
