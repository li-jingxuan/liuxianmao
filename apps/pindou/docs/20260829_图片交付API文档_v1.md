# 图片交付 API 文档

> 状态：已实现  
> 目标版本：MVP  
> 方案日期：2026-08-29  
> 适用范围：`apps/api` 的 `image-deliveries` 接口，兼容现有 `apps/web` 交付预览页

## 1. 接口说明

`image-deliveries` 用于管理员临时上传完整拼豆施工图，并生成公开的预览、查看和下载地址。

- API 前缀：`/api/v1/image-deliveries`
- 上传格式：PNG
- 默认有效期：7 天
- 默认文件上限：15 MiB
- 默认图片上限：5000 万像素
- 上传接口需要管理员密钥；查询、预览和下载接口公开访问
- 文件名、上传 MIME 类型不会被直接采用，服务端会校验真实 PNG 内容

## 2. 鉴权方式

上传接口通过请求头传递管理员密钥：

```http
X-Admin-API-Key: <KEY_ISSUER_API_KEY>
```

密钥缺失、为空或错误时返回 `401 ADMIN_API_KEY_INVALID`。

## 3. 响应模型

上传成功和查询元数据使用相同的 JSON 结构：

```json
{
  "token": "随机生成的 43 位访问令牌",
  "image_url": "/api/v1/image-deliveries/{token}/image",
  "download_url": "/api/v1/image-deliveries/{token}/download",
  "expires_at": "2026-09-05T10:30:00Z"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | `string` | URL-safe 随机令牌，用于访问当前交付图 |
| `image_url` | `string` | 原图内联预览的 API 相对路径 |
| `download_url` | `string` | 原图附件下载的 API 相对路径 |
| `expires_at` | `string` | 带时区的 ISO 8601 过期时间 |

## 4. 接口列表

### 4.1 上传交付图

```http
POST /api/v1/image-deliveries
Content-Type: multipart/form-data
X-Admin-API-Key: <管理员密钥>
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | 文件 | 是 | 完整且有效的 PNG 图纸 |

请求示例：

```bash
curl -X POST 'https://<api-domain>/api/v1/image-deliveries' \
  -H 'X-Admin-API-Key: <管理员密钥>' \
  -F 'file=@pindou-pattern.png;type=image/png'
```

成功响应：`201 Created`，响应体为[响应模型](#3-响应模型)，并返回：

```http
Cache-Control: no-store
```

### 4.2 查询交付图元数据

```http
GET /api/v1/image-deliveries/{token}
```

无需鉴权。成功响应为 `200 OK`，响应体为[响应模型](#3-响应模型)，并返回 `Cache-Control: no-store`。

### 4.3 预览原图

```http
GET /api/v1/image-deliveries/{token}/image
```

无需鉴权。成功时返回原始 PNG 二进制内容：

```http
HTTP/1.1 200 OK
Content-Type: image/png
Content-Disposition: inline; filename="pindou-pattern.png"
Cache-Control: private, max-age=<剩余有效秒数>
X-Content-Type-Options: nosniff
```

该接口适合浏览器展示和移动端长按保存。

### 4.4 下载原图

```http
GET /api/v1/image-deliveries/{token}/download
```

无需鉴权。返回内容与预览接口相同，但使用附件下载方式：

```http
Content-Type: image/png
Content-Disposition: attachment; filename="pindou-pattern.png"
```

## 5. 错误响应

业务错误统一使用以下结构：

```json
{
  "error": {
    "code": "DELIVERY_IMAGE_NOT_FOUND",
    "message": "图纸链接不存在或已过期",
    "request_id": "req_xxx"
  }
}
```

| HTTP 状态码 | 错误码 | 说明 |
| --- | --- | --- |
| `400` | `DELIVERY_IMAGE_INVALID` | 文件不是有效 PNG，或 PNG 内容损坏 |
| `401` | `ADMIN_API_KEY_INVALID` | 管理员密钥缺失或错误，仅上传接口可能返回 |
| `404` | `DELIVERY_IMAGE_NOT_FOUND` | token 格式非法、文件不存在或链接已过期 |
| `413` | `DELIVERY_IMAGE_TOO_LARGE` | 文件体积或解码后的像素数超过限制 |
| `422` | FastAPI 参数校验错误 | 未提交必填的 `file` 表单字段等请求格式问题 |
| `507` | `DELIVERY_STORAGE_UNAVAILABLE` | 服务端交付目录暂时无法写入 |

为避免泄漏历史状态，非法 token、不存在的 token 和已过期 token 均返回相同的 `404` 错误。

## 6. 生命周期与配置

交付图保存在 API 本机目录中，不写入数据库。文件修改时间作为创建时间，达到 TTL 后首次访问会立即删除；后台任务也会定期清理过期文件。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `IMAGE_DELIVERY_DIR` | `apps/api/src/pindou/assets/image-deliveries` | 交付图保存目录 |
| `IMAGE_DELIVERY_TTL_SECONDS` | `604800` | 有效期，默认 7 天，可配置为 1 小时至 30 天 |
| `IMAGE_DELIVERY_MAX_BYTES` | `15728640` | 单张 PNG 最大字节数，默认 15 MiB |
| `IMAGE_DELIVERY_MAX_PIXELS` | `50000000` | 图片最大解码像素数 |
| `IMAGE_DELIVERY_CLEANUP_INTERVAL_SECONDS` | `259200` | 后台清理间隔，默认 3 天 |

部署时应将 `IMAGE_DELIVERY_DIR` 挂载到持久化卷；多实例部署若不共享该目录，同一 token 可能无法在其他实例访问。
