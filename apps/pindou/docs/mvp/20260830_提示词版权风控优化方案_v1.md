# 提示词版权风控优化方案

> 状态：待确认  
> 目标版本：MVP2 量化增强版  
> 方案日期：2026-08-30  
> 适用范围：`apps/api` Seedream 图片增强提示词；兼容现有 `apps/web` 转换接口

## 1. 背景与目标

当前提示词强调“保留主体身份、标志性轮廓、关键身份色”和背景语义，能够提升拼豆图的识别度，但也会促使模型高保真重现原图中的品牌标识、Logo、可读文字、知名角色特征和第三方作品细节，增加输入/输出版权审核命中概率。

本方案只调整提示词表达，不宣称用户拥有素材权利，也不将生成结果认定为可商用或免版权。目标是：

1. 保留拼豆转换所需的一般类别、数量、姿态、构图和主要色块关系。
2. 将品牌化、文字化和作品专属细节主动抽象为普通几何色块。
3. 降低背景保留模式对海报、包装、商标和第三方作品的复刻倾向。
4. 保持现有网格、颜色预算、透明背景和无新增物体约束。

## 2. 方案概要

### 2.1 基础内容依据改写

将“以输入图为唯一内容依据”“保留主体身份、标志性轮廓”改为：

```text
以输入图作为构图和内容参考，仅保留主体的一般类别、数量、姿态方向、主要色块关系和整体构图语义。
输出应是经过重新归纳的通用平面插画，不追求逐像素还原或复制原图的独特表达。
```

“身份”保留范围收窄为一般类别和必要结构，避免把 IP 专属外观当作必须复制的内容。

### 2.2 非品牌化约束

在统一输出约束中增加：

```text
将可识别的品牌标识、商标、Logo、角色专属徽记、可读文字、签名、二维码和包装标签，简化为无文字的普通几何色块或非品牌化装饰。
不要生成或强化知名影视、动漫、游戏角色及其专属服饰、道具和徽记。
不要模仿特定艺术家、工作室或现有作品的独特风格。
```

采用“替换为可执行的普通图形”而不是单纯写“禁止版权内容”，减少模型无替代目标导致的失控。

### 2.3 背景模式差异化

- `simplify`：保持现有策略，并明确删除/抽象背景中的文字、品牌元素和装饰性作品细节。
- `keep`：仍保留背景物体的类别、数量、位置和遮挡关系，但背景中的文字、Logo、商标、海报和包装信息必须抽象化，不得原样重现。
- `solid`：沿用当前透明背景要求；主体上的文字、Logo 和专属徽记也遵循非品牌化约束。

### 2.4 风格词约束

现有 `Q 版 / Chibi`、贴纸、简约插画、剪纸风属于通用描述，继续保留；不新增艺术家、工作室、品牌或具体 IP 名称。后续若开放用户自定义描述，应在进入 Seedream 前将此类名称归一化为通用风格描述。

## 3. 修改范围

预计只修改：

- `apps/api/src/pindou/services/seedream_prompt.py`
  - `SEEDREAM_PROMPT_VERSION` 升级到 v14。
  - `BASE_PROMPT` 改写为“通用语义保留 + 非逐像素复刻”。
  - `KEEP_BACKGROUND_PROMPT` 增加背景文字/品牌/作品抽象化约束。
  - `OUTPUT_GUARD_PROMPT` 增加品牌、商标、Logo、文字、签名、二维码和特定 IP/艺术家风格约束。
- `apps/api/tests/test_seedream.py`
  - 增加新约束存在性断言。
  - 保留现有网格、背景、风格隔离和透明 PNG 断言。

不修改 API Schema、前端接口、图像量化算法和 Ark 错误映射。

## 4. 兼容性与风险

提示词变更可能降低 Logo、角色专属服饰、包装文字等内容的保真度，这是有意的合规取舍。主体类别、数量、姿态、主要配色和网格可制作性仍作为高优先级约束。

提示词不能替代权利确认、OCR/Logo/人脸检测或人工审核，也不能保证供应商一定放行。`OutputImageSensitiveContentDetected` 仍按现有策略不自动重试。

## 5. 验收标准

1. 所有现有 `test_seedream.py` 测试通过。
2. 生成的 Prompt 包含“通用平面插画/非逐像素还原”约束。
3. 生成的 Prompt 包含文字、Logo、商标、签名、二维码和特定 IP/艺术家风格的抽象化约束。
4. `keep`、`simplify`、`solid` 三种背景模式均保留各自原有语义，不出现互相污染。
5. Prompt 版本与实现同步更新，转换响应中的 `enhancer_prompt_version` 可追踪到 v14。
