# Seedream 三档激进化提示词方案

> 状态：Prompt v6 已实施后撤回，由 Prompt v7 主体优先策略替代  
> 当前版本：MVP3 / Prompt v7（由 v6 实测修订）  
> 方案日期：2026-08-14  
> 影响范围：`apps/api/src/pindou/services/seedream_prompt.py`、提示词版本、单元测试与效果评估  
> 前置方案：[按网格大小优化提示词](./seedream-grid-aware-prompt-optimization.md) · [色彩预算感知提示词](./color-budget-aware-prompt-and-max-colors-policy.md)

> 2026-08-14 实测修订：v6 对局部特征的放大、强化和重构授权过多，导致主体与背景细节一起增长。当前实现已调整为 `seedream-pindou-v7-subject-first`：小于 `104×104` 时按“主体轮廓与姿态 > 主要结构 > 少量身份特征 > 背景与装饰”分配视觉预算，并统一压低背景细节；`104×104` 档改为克制保留，不再主动放大局部。

## 1. 结论

同意把 `52×52 / 78×78 / 104×104` 三档提示词再做得激进一些。

当前提示词已经能按网格删除低价值纹理，但整体仍偏向“忠实保留并克制简化”。这会让 Seedream 把大量能力用于复刻原图，而不是主动为最终拼豆图做视觉设计。尤其 `52×52`，仅删除发丝、反光和小装饰还不够，模型还需要被明确授权：

- 放大真正决定识别度的五官、花色、配件和功能结构；
- 加粗缩小后容易断裂的轮廓、肢体和连接结构；
- 分离颜色接近、互相粘连的前后区域；
- 合并、移动或重塑局部小结构，使其成为连续且可量化的色块；
- 主动提高主体内部、主体与背景之间的明度或色相对比。

这里的“激进”不是继续减少内容，也不是让模型直接画像素画，而是给予它**受约束的视觉重设计权**。推荐三档目标为：

| 预设 | 新目标 | 激进程度 | 主要动作 |
| --- | --- | --- | --- |
| `52×52` | 强图标化重设计 | 最高 | 夸张身份特征、加粗细结构、主动分离粘连区域、大幅合并低价值细节 |
| `78×78` | 主动插画化重构 | 中高 | 优化局部比例、强化表情和配件、整理遮挡关系、建立清晰色块层级 |
| `104×104` | 精修式可读性增强 | 中等 | 保留丰富结构，同时清理摄影噪声、强化边缘转折、扩大关键细节的视觉权重 |

首轮只调整 Prompt，不同时修改颜色预算、量化算法、网格采样或背景后处理。这样才能判断最终效果提升是否确实来自新的重设计指令。

## 2. 当前提示词为什么显得保守

当前 `small / medium / large` 三档主要使用以下表达：

- “保持”“保留”“允许有限细节”；
- “合并纹理”“移除噪点”“不要恢复照片级纹理”；
- “轮廓优先于纹理”“确保边界清楚”。

这些约束能阻止结果变乱，却没有要求模型主动解决下游网格化中的结构问题。模型可以通过“稍微磨皮、减少纹理、维持原比例”满足提示词，但这种中间图缩小后仍可能出现：

- 人脸五官面积太小，量化后只剩随机色点；
- 细肢体、发梢、眼镜腿、动物尾巴或物体把手发生断裂；
- 主体相邻区域颜色接近，缩格后粘成一片；
- 原图中重要配件被忠实保留，却因为尺寸太小而不可辨识；
- `104×104` 虽然细节更多，但仍保留过多摄影式渐变，没有转化为可制作的平面结构。

根因是 Prompt 目前只定义了“允许保留多少”，没有清楚定义“允许怎样改造”。

## 3. 激进化边界

### 3.1 必须锁定的语义不变量

无论网格大小，以下内容不能因激进化而改变：

- 主体身份、类别、数量；
- 主体姿态和朝向的主方向；
- 标志性轮廓、主要配色和关键身份色；
- 主要物体之间的相对位置与遮挡关系；
- 背景模式的产品语义；
- 原图不存在的角色、肢体、物体、文字、标志、边框和水印不能被添加。

### 3.2 明确允许的视觉重设计

在不改变上述语义的前提下，允许模型：

- 适度调整局部比例，让关键特征在缩小后仍有足够面积；
- 放大、加粗或重塑五官、花纹、配件、把手、耳朵、尾巴等识别结构；
- 将过细、过碎或互相粘连的结构重组为更连续的形状；
- 拉开相邻区域的明度、冷暖或色相差异；
- 把摄影式光影重构为少量、边界明确的形体明暗；
- 删除无识别价值的微小结构，并把其视觉作用合并到相邻主色块；
- 轻微整理局部遮挡边界，但不能改变物体前后关系。

### 3.3 仍然禁止的方向

- 不直接生成像素格、马赛克、拼豆颗粒、珠子或网格线；
- 不把“激进”理解为任意卡通化、Q 版化或改变画风；
- 不为了增强识别而新增原图没有的眼睛、手指、配饰或图案；
- 不擅自裁掉主体、改变主体数量或大幅改变构图；
- 不为了提高对比而改变主体的身份色；
- 不要求 Seedream 精确输出某个颜色数量或直接匹配 MARD 色号。

## 4. 三档提示词策略

后端仍沿用现有档位映射，使自定义尺寸不会在预设附近出现行为突变：

| 网格档位 | 范围 | 代表预设 | 新策略 |
| --- | ---: | ---: | --- |
| `small` | 32–63 | 52 | 强图标化重设计 |
| `medium` | 64–95 | 78 | 主动插画化重构 |
| `large` | 96–156 | 104 | 精修式可读性增强 |

`micro` 的 8–31 档暂不跟随本方案修改。它已经是极低分辨率图标化策略，是否进一步激进应单独验证，避免把主体压缩成通用符号。

### 4.1 `52×52`：强图标化重设计

目标不是“更空”，而是让每个保留下来的结构更大、更稳、更像一个经过设计的图标。

建议替换 `GridDetailBand.SMALL` 片段：

```text
细节策略：面向 52×52 级别的强图标化重设计。
不要机械复刻原图的局部比例。以主体身份和姿态为边界，主动放大最能识别主体的五官、发型大形、动物花色、服饰分区、配件或物体功能结构，并提高它们的视觉权重。
将细肢体、发梢、眼镜腿、尾巴、把手和连接结构加粗、缩短或重塑为缩小后仍连续的形状；将相互粘连且颜色接近的区域主动分离。
预计缩小后只能形成单个零散采样点的特征，应删除、并入相邻结构，或扩大为稳定且有意义的色块。不要保留仅仅因为原图中存在、但缩小后无法辨识的细节。
使用清楚有力的外轮廓、较大的内部结构分区和少量高辨识度特征。光影压缩为固有色、主要亮面和主要暗面，允许为了可读性强化必要的明暗或色相对比。
结果应像经过专业图标设计师重新归纳的平面插画，而不是原图的轻度滤镜版本。
```

该档允许三档中最大的局部比例调整，但不能改变主体类别、数量、姿态主方向和标志性配色。

### 4.2 `78×78`：主动插画化重构

`78×78` 已能承载主要表情和配件，但当前提示词容易把预算花在低价值纹理上。新目标是建立清晰的视觉层级。

建议替换 `GridDetailBand.MEDIUM` 片段：

```text
细节策略：面向 78×78 级别的主动插画化重构。
保留主体的关键内部结构、表情关系、服饰层次、材质分区和有语义价值的配件，同时主动优化这些特征的局部比例、边缘清晰度和相互间距，使其在缩小后仍能独立辨识。
允许适度放大眼睛、嘴部表情、花色边界、徽记外形、衣领、配件和物体功能结构；允许加粗容易断裂的线性结构，并整理不清楚的遮挡边界，但不得创造新内容或改变前后关系。
将摄影纹理、细碎反光、随机噪点、重复图案和柔和渐变重构为边界明确的连续色块。使用两到三层主要明暗，必要时主动拉开相邻区域的明度、冷暖或色相差异。
结果应具有明确的主体层级、稳定轮廓和经过设计的局部重点，不要只做忠实但保守的平面化处理。
```

该档比 `52×52` 保留更多关系细节，但同样要求模型主动改造，而不是被动删减。

### 4.3 `104×104`：精修式可读性增强

`104×104` 的激进化不应表现为大幅减细节，而应表现为更果断地整理结构、边缘和对比。

建议替换 `GridDetailBand.LARGE` 片段：

```text
细节策略：面向 104×104 及更高网格的精修式可读性增强。
保留完整主体结构、主要五官和表情、服饰或物体的关键构造、识别性图案、重要材质分区和主要空间层次，但不要原样复制摄影画面的全部频率。
主动强化关键轮廓的转折、重要配件的外形和主要结构之间的分界；对面积过小、对比不足或容易粘连的身份特征，可以适度放大、加粗、分离或提高对比。
将毛孔、颗粒、杂乱发丝、细碎反光、无规律纹理和连续渐变重构为有方向、有层级的平面形体。允许保留三到四层有意义的明暗或材质变化，但每一层都应形成面积足够、边界稳定的区域。
结果应比普通平面化更有设计感和结构判断：重要细节更醒目，次要细节更安静，不能因为网格较大就退回照片式复刻。
```

该档要避免两个极端：既不能沿用当前的保守复刻，也不能套用 `52×52` 的强图标化导致细节预算浪费。

## 5. 公共提示词调整

只替换三个档位片段仍可能被当前公共提示词中的“保留整体构图”解释为禁止局部调整。建议同时把公共片段改为“语义保真、表达可重构”。

建议公共片段：

```text
以输入图为唯一内容依据。锁定主体身份、类别、数量、姿态主方向、朝向、标志性轮廓、主要配色、关键身份色和整体场景语义，不改变原图的核心内容。
允许为了最终网格中的可识别性，重新设计局部比例、轮廓粗细、结构间距、色块边界和明暗关系；这种调整只能强化原图已有特征，不能创造新特征或改变主体身份。
将图像重构为边界清晰、色块连续、视觉层级明确、适合后续缩小和有限色卡量化的平面插画中间图。
优先解决缩小后会断裂、粘连、消失或失去辨识度的结构，再处理次要装饰。
```

建议增加一段统一的“重设计执行规则”，放在网格档位之后、颜色预算之前：

```text
对每个局部特征做缩小后的可读性判断：保留且强化有识别价值的结构；合并、扩大或删除无法稳定表达的结构；分离容易粘连的相邻区域。
所有调整都必须能从输入图中找到依据。宁可做少量清晰、果断的形状决定，也不要保留大量模糊、细碎、相互冲突的细节。
```

## 6. 与颜色预算和背景模式的组合

### 6.1 颜色预算

颜色档位继续负责“可以有多丰富”，网格档位负责“结构可以有多复杂”。本轮不提高颜色预算：

- `52×52` 仍使用 `balanced`，通过更大的色块、更强的对比和更少的近似色获得识别度；
- `78×78` 与 `104×104` 仍使用 `rich`，但新增颜色必须服务于原图已有的材质、身份色或明暗层次；
- 不把“激进”误解为更高饱和度、更多强调色或用满颜色上限。

### 6.2 背景模式

| 模式 | 激进化允许范围 | 不可突破的边界 |
| --- | --- | --- |
| `simplify` | 可更积极地删除低价值背景物体、扩大背景主区域、拉开主体边缘对比 | 不能把背景直接换成纯色，不能改变场景类型 |
| `keep` | 可整理背景物体内部纹理和边界，降低其视觉权重 | 不能移动、删除、替换有语义的背景物体 |
| `transparent` | 可更积极地修整和加粗主体外轮廓、闭合小缺口 | 主体外必须保持真实透明，不能添加投影、底色或地面 |

冲突优先级保持：主体身份与数量 > 背景模式 > 网格可读性 > 颜色丰富度 > 装饰细节。

## 7. 工程实现建议

### 7.1 保持正交组装

继续使用：

```text
公共语义不变量
+ 下游网格上下文
+ 网格档位重设计策略
+ 统一重设计执行规则
+ 颜色预算上下文
+ 颜色预算策略
+ 背景模式
+ 输出禁止项
```

不要为 `52 / 78 / 104 × 颜色档位 × 背景模式` 建立完整提示词矩阵。现有纯函数和静态片段结构足以承载本次调整。

### 7.2 版本

建议将提示词版本升级为：

```text
seedream-pindou-v6-bold-grid
```

版本只代表 Prompt 文本变化，不绑定量化策略版本。响应继续返回 `meta.enhancer_prompt_version`，评估记录至少包含：

```text
prompt_version
grid_size
grid_detail_band
color_budget_band
background_mode
```

### 7.3 单元测试

在现有测试基础上补充：

- `52 / 78 / 104` 各自只命中一个新档位片段；
- 三档均包含“允许局部比例、粗细、间距和对比重设计”的授权；
- 三档均包含“调整必须来自输入图”的约束；
- `52` 包含加粗、分离、扩大或删除单点特征等强动作；
- `78` 包含局部比例、遮挡边界和两到三层明暗；
- `104` 包含三到四层有效层次，且明确禁止退回照片式复刻；
- 统一禁止项仍包含新增内容、像素格、网格线、拼豆和水印；
- 三种背景模式仍严格隔离，激进片段不能覆盖背景语义；
- `micro` 文本和档位边界在本轮保持不变。

## 8. 效果验证方案

生成模型有随机性，不能用单张样例决定上线。建议分两轮验证。

### 8.1 快速筛选

固定 12 张授权测试图：人物 4 张、动物 3 张、物体 3 张、复杂场景 2 张。先只使用 `simplify` 背景模式：

```text
12 张 × 3 个预设 × v5/v6 × 每组 2 次 = 144 次生成
```

比较对象必须是最终完成量化的拼豆图，而不只是 Seedream 中间图。

### 8.2 背景回归

从快速筛选中选 6 张代表图，对 `simplify / keep / transparent` 做回归，重点检查背景删除、位移、透明边缘和幻觉，不再大范围调文案。

### 8.3 评估维度

| 维度 | 关注问题 |
| --- | --- |
| 一眼识别度 | 不看原图时能否快速认出主体类别和姿态 |
| 身份特征 | 人脸、花色、服饰、配件或功能结构是否更清楚 |
| 轮廓连续性 | 肢体、尾巴、把手、眼镜等是否减少断裂 |
| 区域分离度 | 相邻同明度区域是否减少粘连 |
| 碎片率 | 最终网格中的单格、小孤岛和无意义杂色是否下降 |
| 设计感 | 是否从轻度滤镜提升为有明确取舍的平面插画 |
| 语义漂移 | 身份、数量、姿态、配色、背景内容是否被改变 |
| 幻觉 | 是否新增物体、肢体、文字、花纹或投影 |

### 8.4 建议验收门槛

- `52×52`：v6 成对盲评偏好率至少 70%，小孤岛占比较 v5 下降至少 25%；
- `78×78`：v6 成对盲评偏好率至少 65%，关键特征可辨识率提高且碎片不增加；
- `104×104`：v6 成对盲评偏好率至少 60%，不能因过度简化导致关键细节明显减少；
- 三档严重语义漂移率均不高于 5%，且不得高于 v5；
- 背景模式严重违约率、额外肢体和新增物体次数不得高于 v5；
- 延迟、错误率和生成成本不因 Prompt 增长出现明显回归。

门槛是第一轮实验提案，可根据 v5 基线校准，但调整时必须记录原因，不能看完结果后任意改变统计口径。

## 9. 上线与回滚

1. 完成 Prompt v6 文本和单元测试；
2. 固定量化策略与颜色预算，执行 144 次快速筛选；
3. 每次只调整一个档位片段，避免同时重写公共、颜色和背景片段；
4. 通过背景回归后，在内部或小比例流量启用 v6；
5. 观察用户重试率、导出率、三档选择分布和人工抽检结果；
6. 未达到门槛时通过配置恢复 v5，不回滚其他转换链路。

不建议在线请求同时生成 v5 和 v6，两次模型调用会直接增加延迟和成本。A/B 应保证一次用户请求只命中一个 Prompt 版本。

## 11. 最终建议

优先把 `52×52` 做得最激进，因为它当前最容易出现“中间图看起来不错，最终拼豆图却过于普通或丢特征”的问题。`78×78` 应明显增加主动设计动作，`104×104` 则以结构强化和纹理重构为主，不应简单复制 52 档的强简化。
