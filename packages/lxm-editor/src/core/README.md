# 核心领域目录

- `document`：文档加载、版本升级入口、结构与语义校验、调弦和调性。
- `commands`：跨领域命令主调度、提交前校验与命令效果收集。
- `rhythm`：TAB 拍结构、剪贴板、时值与小节容量规划、连音及其具体命令。
- `numbered`：简谱事件、节奏索引、输入区间、标记、复制与具体命令。
- `lyrics`：歌词位置与连续歌词规划。
- `chords`：和弦图校验、编辑、预设与目录查询。
- `music-text`：歌词与和弦共用的文字规范、锚点收集及具体命令。
- `techniques`：技巧校验、等价比较、受保护拍索引与复制。

根目录只保留通用领域类型、常量和文档级 ID 工厂。具体命令随所属领域维护，跨领域编排集中在 `commands`。

包内引用明确的相对文件路径，不增加转发文件或目录 barrel；包外通过 `@liuxianmao/lxm-editor` 的公共入口使用。迁移或新增文件时同步检查测试、示例与生成器中的路径，保持 `src/index.ts` 的公共导出稳定。
