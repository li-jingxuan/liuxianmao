# 布局目录

- `structure`：页、谱行、小节、谱头、拍号与小节线的结构布局，以及小节间距编排。
- `music-text`：歌词、和弦与简谱的测量请求、布局、输入位置和标记。
- `rhythm`：共享时间网格、时值连梁、休止、连音、节奏层对齐及拍单元范围。
- `techniques`：技巧间距、几何范围、曲线避让与轨道布局。

根目录保留布局入口、共享类型、常量、基础辅助、坐标平移，以及跨领域的命中测试和选区布局。`structure` 负责调用领域布局，具体布局算法随领域就近维护。

包内直接引用相对文件路径，避免通过布局入口反向导入实现；包外使用核心包公共入口。不增加转发文件或额外目录 barrel，维护现有根入口导出。
