# MVP v4.1 补丁：基础谱面标识与小节边界

本目录定义六线谱编辑器 MVP v4.1 补丁。该补丁位于已完成的 MVP v4 与吉他演奏技巧 MVP v5 之间，为每条谱面行补齐 `TAB` 标识，为乐谱展示拍号，并让现有小节线类型具备完整的领域命令、历史和页面编辑闭环。

## 补丁目标

- 每条 system 在六线谱内纵向显示 `T/A/B`，谱号列宽和贯穿弦线由核心 layout 统一分配。
- 第一小节及拍号发生变化的小节显示拍号。
- 支持编辑单小节线、双小节线、终止线、开始反复线、结束反复线和双向反复线。
- 小节边界修改继续经过纯领域命令、结构校验、语义校验和 v4 历史 Store。
- 为 MVP v5 的技巧线与文本碰撞规避建立稳定的谱面正文起点和结构边界。

## 范围

- 每个 system 重复显示六线谱内的纵向 `T/A/B` 谱号。
- 拍号首次显示与变更显示；不因普通自动换行重复拍号。
- 谱首开始反复边界，以及每个小节之后的六类既有小节线。
- 小节线工具、no-op、撤销/重做与自动重新 layout。
- TAB、拍号、小节线的核心布局结果、SVG 消费与固定桌面视觉验收。
- 通过后续 Fix 编辑常用拍号，并保守协调小节容量、拍组、历史与选区。

## 非范围

- 自定义拍号、弱起小节，以及会截断真实音符的自动容量修复。
- 反复播放、反复次数、嵌套反复配对和播放流程校验。
- 第一/第二结尾房子、D.C.、D.S.、Coda、Fine 等跳转记号。
- 虚线、短小节线、不可见小节线和自定义线型。
- Beat/乐句剪贴板；该能力继续作为独立候选，不与本补丁共用范围。
- 移动端、响应式布局、多轨道同步 system 和分页打印。

## 核心决策

1. `TAB` 是 system 级行头，不属于任何 measure，也不写入乐谱文档。
2. 拍号来自现有 `measure.timeSignature`；基础补丁先完成布局与展示，后续 Fix 增加受限编辑入口与容量协调。
3. 现有 `measure.barline` 明确定义为“该小节之后的边界”；谱首开始反复使用轨道级起始边界表达。
4. 六类小节线全部保留。它们已有 schema、layout 和 SVG 渲染基础，本补丁不人为移除双向反复线。
5. 反复线在本补丁中只表达记谱结构，不承诺播放语义。
