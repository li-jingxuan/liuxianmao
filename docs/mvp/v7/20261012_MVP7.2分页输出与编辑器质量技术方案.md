> 代码基线：当前 worktree `2b52c01`，已合入本地 `codex/mvp6-music-text`。
> 范围依据：[版本路线图](../mvp-version-roadmap.md)、[差距规划](../20261010_六线谱编辑器可用性差距与后续规划.md)、[实现基础分析](./20261012_MVP7.2范围与实现基础分析.md)。

## 1. 交付目标与固定决策

使当前单轨六弦编辑器可以可靠导出 A4 多页 PNG 乐谱图片，并具备长谱、桌面兼容、真实输入法与基础无障碍的验收证据。

本方案采用以下默认决策，审查通过后按此实施：

| 项目 | 首版决策 |
| --- | --- |
| 输出方式 | A4 PNG 图片；单页直接下载 PNG，多页按页生成 PNG 后打包一个 ZIP，同时支持预览中下载单页 |
| 图片规格 | 300 DPI，2480×3508 像素，白色不透明背景；写入 PNG pHYs 分辨率元数据 |
| 纸张 | A4 纵向 210×297mm，四边 8mm，页脚独占 8mm |
| 编辑与预览 | 编辑仍用连续谱；新增只读逐页 SVG 预览，预览和图片消费共用音乐图元列表 |
| 页眉 | 首页面保留现有标题、作者、Capo 等谱首内容；后续页不重复谱首，不额外新增页眉 |
| 页脚 | 每页显示“当前页 / 总页数” |
| 断页 | 完整 system 是最小分页单元，system 内不截断 |
| 超宽/超高 | 明确诊断并阻止导出，不缩小字号、不静默裁剪；横向纸张/显式缩放延后 |
| 字体 | 在当前页面加载音乐字体和实际中文字体，Canvas 使用相同字体与文字度量；不直接截图 DOM |
| 文档模型 | 不改 schema，不新增持久化字段或领域命令 |
| 长谱优化 | 先测基线，再针对瓶颈优化；图片逐页绘制，不创建整首长谱 Canvas |

按用户最新要求，PDF、系统打印入口、beforeprint/afterprint 和真实纸张打印验收不再属于 v7.2 交付门槛。现有打印按钮在本阶段替换为“导出图片”，旧打印 CSS 可以清理；浏览器菜单打印不作为产品输出路径。

不包含作品新建/管理、领域文档文件保存、自动恢复、播放、多轨、云端作品库或移动端。导出乐谱图片不引入作品保存状态。

## 1.1 图片修订后的落地判断

可以进入实施，没有必须由用户补充才能设计的产品条件。本方案已给出格式、分辨率、分包方式、异常处理和草稿规则的默认值。代码尚未验证，不能把可实施性判断当作实现或验收通过。

## 4. 纸张与分页接口

### 4.1 坐标契约

采用固定逻辑单位与毫米换算：`unitsPerMm = 96 / 25.4`，不受屏幕 DPR、浏览器缩放或预览缩放影响。

- 内容宽：194mm，约 733.228 逻辑单位。用统一常量替换页面当前的近似值 733，可能引起边界小节重新断行，需回归。
- 页面高：297mm；去除上下边距及页脚后，音乐可用高度为 273mm。
- 页脚与音乐区不重叠；音乐至页脚的净空计入 8mm 页脚区。
- 页面 SVG 使用整页逻辑 viewBox，物理尺寸为 210×297mm；预览只做等比 CSS 缩放。

图像尺寸按 `round(mm / 25.4 × 300)` 得到 2480×3508。页面几何仍使用精确毫米换算；绘制时按实际像素宽高分别映射至整页逻辑尺寸，容许整数像素取整造成的微小比例差。输出不受设备 DPR、页面缩放或预览大小影响。300 DPI 经取整后物理大小允许约 0.1mm 误差。

预览采用 border-box 的 A4 外框，不叠加旧 `.paper` 的 padding。图片输出无需浏览器打印 CSS 或系统打印对话框。

### 4.2 核心接口草案

```ts
interface ILXMPageOptions {
  pageWidth: number;
  pageHeight: number;
  margins: { top: number; right: number; bottom: number; left: number };
  footerHeight: number;
  systemGap: number;
}

interface ILXMPageSystemPlacement {
  systemIndex: number;
  translateX: number;
  translateY: number;
}

interface ILXMPageLayout {
  index: number;
  width: number;
  height: number;
  systems: ILXMPageSystemPlacement[];
  scoreHeaderTranslation?: { x: number; y: number };
  footer: { text: string; x: number; y: number; fontSize: number };
}

type PageDiagnosticCode =
  | "empty-score"
  | "invalid-geometry"
  | "header-overflow"
  | "system-too-wide"
  | "system-too-tall"
  | "first-page-overflow";

interface ILXMPageDiagnostic {
  code: PageDiagnosticCode;
  systemIndex?: number;
  measureIds: string[];
  actual?: number;
  limit?: number;
}

type ILXMPaginationResult =
  | { ok: true; pages: ILXMPageLayout[]; diagnostics: [] }
  | { ok: false; pages: []; diagnostics: ILXMPageDiagnostic[] };

// 只引用原 layout，不复制或修改领域文档、system 几何和命中数据。
declare const paginateLayout: (
  layout: ILXMLayout,
  options: ILXMPageOptions,
) => ILXMPaginationResult;
```

非法配置（NaN、负边距、无正内容区、非法 gap）抛 RangeError；正常文档的不可输出内容返回结构化诊断，由网站映射为中文提示。不得以成功结果夹带裁剪页面。

给 `ILXMLayout` 增加可选 `scoreHeaderBounds` 和 `scoreHeaderHeight`。`buildLayout` 从谱首生成结果赋值，height 包括原有尾部净空；分页不通过第一条 system 的 Y 或标题字数猜测首部高度。显式文字 bounds 越出首部占位时需扩大占位或返回诊断。

### 4.3 分页算法

1. 校验配置、首部和所有 system/visualBounds 的有限坐标与非负尺寸；空谱拒绝输出。
2. system 的占位为 `system` 几何框和 `visualBounds` 的并集；现有 measure/technique/text bounds 测试确保该并集包住所有可见图元。边界缺漏优先修复核心 bounds，不由 DOM 测量补偿。
3. 检查占位宽度与内容宽、高度与音乐可用高度。超过即返回关联小节诊断。
4. 首页放置完整谱首，再放第一个 system；两者合计超过容量返回 `first-page-overflow`。首版不输出独立标题页，不截断标题。
5. 顺序装入 system，相邻行使用显式 systemGap，当前页不足时开启下一页。页首不重复加入原连续布局的 gap；每页按自身游标生成 translateX/Y。
6. 完成所有分组后生成“n / N”页脚。后续页顶部直接开始音乐，不重复标题。
7. 使用浮点比较容差 `1e-6` 逻辑单位处理数值误差，容差不承担可见裁剪；精确容量边界允许放入。

算法不重新布局小节、不移动音乐锚点，也不修改 hitIndex。跨页技巧已在 system 中拆段，继续消费原 continuation 和路径。复杂度目标为 O(system 数量)，输出只保存引用与平移量。

失败时界面展示诊断和原连续谱，不伪造完整分页预览。定位链接按稳定 measureId 返回编辑位置。超宽单小节、长段落标记及异常谱首都包含在越界检查中。

## 5. 共用渲染与图片生成

### 5.1 图元列表与双渲染适配

现有谱面只有线、圆、矩形、路径、多边形和文字，未发现依赖外链图片或 foreignObject 的音乐图元，可直接建立小范围渲染协议。图元包括稳定 ID、所属 system/技巧 ID、几何、绘制顺序和显式 style；不携带 DOM 事件或浏览器对象。

字体族、字号、字重、textAnchor、baseline、颜色、dashArray、lineCap/lineJoin、白色描边及绘制顺序全部显式化，避免导出依赖 CSS module 或 currentColor。文字先画白色 stroke 再 fill；内部空格按现有 whiteSpace 规则保留。布局继续提供最终坐标，渲染层不推导小节宽度。

SVG 编辑层和 SVG 预览消费该列表。选区、光标、歌词目标框、hover、透明技巧命中区及焦点色仍独立装配，不进入图片。保留业务 ID，继续使用原 hitIndex 进行编辑命中。

Canvas 使用 line/circle/rect/polygon、Path2D 和 fillText/strokeText；按 page placement 使用 save/translate/restore，路径使用原 d，不改写字符串。文字字体和 alphabetic baseline 与 SVG 保持一致；不使用 maxWidth 隐式挤压文字。

目前技巧包含 SVG marker 箭头。核心在生成对应路径时同步给出末端方向和多边形几何，按现有 marker 尺寸/refX 生成；推广现有 arrowHead 类型以表达任意方向。两个渲染器画同一多边形，停用对应 marker，避免重复箭头。必须验证推弦、扫弦/琶音及上下方向，与改造前图片对照。

本路线通过当前页面 Canvas 绘制已加载字体，避开把 SVG 序列化成独立图片时的字体和 CSS 继承问题。没有 DOM 截图、整页 html-to-image 或服务端浏览器依赖。

### 5.2 A4 PNG 与分辨率元数据

每页单独申请或复用一个 2480×3508 Canvas，先绘制整页白底，再按固定页面计划画首部、systems 和页脚。通过 `toBlob(..., "image/png")` 异步编码；null、上下文丢失或编码错误都返回明确失败。

Canvas 原生编码可能写入 96 DPI 元数据，不能仅放大像素后声称物理 A4。PNG 编码后插入或替换 pHYs：X/Y 均为 `round(300 / 0.0254) = 11811` 像素/米，单位为米。保持 IHDR/IDAT 原数据不变，将唯一 pHYs 放在首个 IDAT 之前并重算该 chunk CRC32；校验 PNG 签名、chunk 长度和边界，不处理任意非 PNG 输入。

测试读回 IHDR 与 pHYs，同时用独立图片工具检查宽高、DPI、白底和可见内容，不能仅测试写入函数自己的返回值。

### 5.3 多页下载与内存

- 单页直接提供 `乐谱标题_001.png` 下载。
- 多页 ZIP 内按 `乐谱标题_001.png` 等补零编号排序，下载名为 `乐谱标题_A4图片.zip`；预览同时可下载选中页。
- 文件名清理路径分隔符、控制字符及平台不支持字符，空标题使用“乐谱”，限制 basename 长度，保留中文。
- 不自动触发几十次浏览器下载；完整包准备后由用户点击“下载图片”发起一个下载。只报告“图片已生成/已发起下载”，不声称已保存到某个本地目录。
- 逐页串行绘制编码，每页处理后释放临时 Canvas/图像引用，并在页间让出主线程。单个 RGBA 画布约 33.2MiB，不同时创建全部页画布。
- ZIP 使用异步流式条目接口，已加入的 PNG 字节尽早释放。最终 ZIP Blob 仍需要内存，不宣称常数内存。
- 首版安全边界为最多 100 页、累计 PNG 数据 200MiB；超过时停止整包生成，提示单页下载，不静默降低 DPI。最终 ZIP 拼接的额外内存纳入实测。
- 生成时显示“第 n / N 页”，可取消；完成或取消清理对象 URL、临时 Canvas 和任务引用。供用户点击的下载 URL 保留到结果关闭/替换或组件卸载，不能下载触发后立即销毁。

## 6. 输出快照、草稿与字体

### 6.1 状态机与有效性

状态为 idle → preparing → previewReady → exporting → downloadReady；失败进入 error，取消返回 previewReady 或 idle。预览准备与图片编码分别显示进度。

快照记录 document 引用、sessionId/sessionVersion、density、showChordDiagrams、字体度量版本、layout 和 pages。输出不写编辑历史。

准备期间文档/偏好/字体变化取消旧任务；generation token 防止过期回调覆盖新结果。预览固定已提交内容，预览期间编辑区域不可操作；外部会话替换关闭预览并使任务失效。下载前再次检查会话有效性，旧结果不能以新谱名下载。

每次 toBlob/ZIP 异步回调、每页开始和每次 yield 后检查取消状态；不支持中断的浏览器编码回调完成后直接丢弃结果。失败不发布标称完整的 ZIP，提供重试和单页导出。资源释放放在 finally，重复点击不并发创建多组任务。

### 6.2 草稿规则

输出以已提交文档为准，不隐式应用歌词、和弦或设置草稿。

- 遇到未应用侧栏草稿、输入法 composition 或未结束的品位计时草稿，保持输入状态，提示“请先完成当前输入并应用或取消修改”，不开始导出。
- 品位草稿不因导出额外提交；沿用现有定时/失焦规则，重新点击时以当时已提交内容准备。
- 为侧栏控制器增加只读输出阻塞状态接口，聚合歌词/和弦草稿、ScoreSettings dirty 及 composition，不创建第二份草稿来源。
- 关闭预览恢复触发按钮焦点，外部替换后不恢复已失效元素。

这是编辑草稿保护，不新增作品保存 dirty 状态。移除方案原有原生打印事件和 Ctrl/Cmd+P 接管要求。

### 6.3 字体与度量

显式加载 Bravura 代表性符号并核验加载结果；页面已有字体声明可复用。音乐字体缺失阻止导出，不能以任意 serif 替代音乐字形。中文使用当前平台实际可用字体，字体和度量与两个渲染器一致；不承诺跨操作系统中文字体完全相同。

扩展现有度量逻辑为可复用请求/缓存服务。输出必须覆盖歌词、和弦、段落、谱首逐字请求及页脚；空文本不误判。Canvas renderer 使用已就绪的同一字体族，针对中文/空格、Bravura、两位品位和白色描边做 SVG/PNG 视觉比较。

字体事件使旧版本失效；任务使用 generation token。字体准备超时 10 秒后释放临时节点并允许重试。每页编码采用 15 秒超时，任务总耗时不由单一 10 秒字体超时限制；超时回调仍需清理并忽略晚到结果。

## 6.4 补充后的可实施性与技术依据

已补足原方案遗漏的像素/DPI、PNG pHYs、多页打包、字体双渲染、箭头几何、文件名、进度取消和内存上限。默认值足以推进，不需要新增后端或图像生成模型。

主要剩余不确定性是实际浏览器字形/抗锯齿差异和编码速度，属于首个技术验证及后续实测任务，不是缺失产品需求。首个验证必须成功后才扩展全部渲染图元；不把该判断标记为已验证。

技术依据：[MDN toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob) 说明 PNG 编码、可能的空结果及分辨率元数据；[PNG pHYs 标准](https://www.w3.org/TR/png-3/#11pHYs) 定义像素密度及单位；[fflate 官方仓库](https://github.com/101arrowz/fflate) 提供 ZIP/流式 API。实现时只按官方接口确认依赖契约。

## 7. 长谱与基础无障碍

### 7.1 基线与性能目标

建立固定 16 小节及 100 小节合法混合谱，并生成所有新 ID，复用核心复制/校验能力，避免人工复制 JSON 留下引用冲突。混合内容包括两位品位/x、休止/附点/连音、跨行技巧、四段歌词、指法图/和弦名、段落及长标题；最终增加上游半音推弦和拍点复用结果。

测量记录硬件、系统、浏览器版本、提交、数据和操作脚本。浏览器以生产构建为主要性能依据，开发模式仅用于诊断。每类操作预热 5 次、采样至少 30 次，报告 p50/p95；峰值内存使用可用浏览器分析工具并注明采样方式，不把不同引擎的不同口径混作同一指标。

候选验收预算如下，均未实测；切片 A 完成后补充基线并审查是否需要调整，不擅自放宽后标记通过：

| 指标 | 候选预算 |
| --- | --- |
| 100 小节单次纯 buildLayout | p95 ≤ 100ms |
| 单拍编辑/撤销至可见更新 | p95 ≤ 200ms |
| 复制 16 小节至可见更新 | p95 ≤ 500ms |
| 暖字体下 100 小节分页预览准备 | p95 ≤ 1500ms |
| 100 次编辑→100 次撤销→重做及预览开关 | 无崩溃、内容合法、无持续遗留测量节点/监听/Canvas/对象 URL；内存报告记录实际峰值和回落情况 |

单页 300 DPI 图片暖字体生成候选目标 p95 ≤ 2000ms（30 次采样）；100 小节全部 PNG/ZIP 的时间与峰值内存先实测再落定，不套用 1500ms 预览预算。拆分领域命令、字体度量、布局、React 提交、Canvas 绘制、PNG 编码及 ZIP 耗时。先考虑重复度量、重复布局、组件重渲染和索引构建；只有实测 DOM 规模是主要瓶颈时才另提虚拟化方案，并审查命中/焦点/导出影响。

### 7.2 无障碍与交互退出条件

- 谱面可见 focus-visible；工具栏、侧栏及输出预览全程键盘可达。
- 预览聚焦标题/首个操作；关闭后恢复触发按钮；模态预览管理焦点和 Escape，composition 时不误触关闭。
- 当前位置以小节/拍点/弦的中文摘要通过适度 aria-live 播报，不逐个品位渲染成海量 Tab 停靠点。
- 输出准备与失败有可读状态，禁用按钮有明确原因；颜色不成为唯一提示。
- 跨 system 导航、Shift 扩选、自动滚动、拖动取消和侧栏输入不被谱面快捷键抢占。

不承诺完整屏幕阅读器乐谱朗读；首版验收操作可达和状态可理解。

## 8. 测试与人工验收

### 8.1 自动化

- 分页：精确容量、差一点溢出、可变行高、标题占位、末页、空谱、超宽/超高、非有限坐标、非零 layout 起点、无副作用和确定性。
- 保真：全部 system 恰好一次，measureId/beatId 顺序不变；跨页技巧、四段歌词/和弦和页脚不越界。
- 双渲染：图元绘制顺序、文字白描边、baseline、箭头尺寸方向、dash 和路径平移；编辑图元抽取后命中与焦点无回归。
- PNG：IHDR 2480×3508、pHYs 11811、唯一正确位置及 CRC、替换原 96 DPI、恶意/截断 chunk 拒绝；独立图片解码工具复核结果。
- ZIP：条目数/顺序/文件名/图片尺寸，完整解包可读，导出部分失败不下载不完整包。
- 控制器：草稿阻塞、字体/编码失败和超时、取消、重复点击、会话替换、过期回调、超页数/大小限制及资源释放。
- 工程：pnpm test、pnpm type-check、pnpm lint、pnpm build。

### 8.2 浏览器与图片证据

默认目标为 macOS 的 Chrome/Edge/Safari/Firefox 当前稳定版，Windows 的 Chrome/Edge。记录实际版本；缺少环境明确列为待验收，不把模拟 UA 当作跨系统通过。

- 100%、125%、150%、200% 浏览器缩放下导出尺寸/DPI一致；紧凑/舒适和指法图开关组合内容正确。
- 16/100 小节 PNG/ZIP 用独立工具打开解包，检查页数、文字、箭头、续接、白底和最后一页；按像素/DPI换算为约 210×297mm。
- 比较逐页 SVG 与 PNG 的音乐内容，允许抗锯齿细微差异，不允许缺字、错字、箭头缺失或改变换行。
- 真实中文输入法候选选择、翻页、Enter/Escape，编辑歌词/歌曲信息；composition 中导出操作不得吞候选或提交半成品。
- 下载操作、取消、重复导出、字体缺失、外部替换、200MiB/100 页限制与单页下载。
- 基础键盘/屏幕阅读器状态检查，记录操作、截图/PNG/ZIP 路径、性能数据和未通过项。

不再要求 PDF、系统打印或真实纸张打印。PNG 可供用户另行打印，但不是本版本输出验收路径。

风险与应对：

1. 双渲染样式漂移：共用图元、显式字体/样式/箭头，做 SVG 与 PNG 对照。
2. 抽取音乐层造成命中回归：保持几何和稳定 ID，独立交互层不改。
3. 字体变化改变页数：字体版本参与快照有效性，取消过期结果。
4. 长谱图片/ZIP 内存：串行绘制、释放临时数据、大小边界与真实峰值测量。
5. 上游新增 lane：依赖完整 visualBounds，合入后重测，不在导出层猜几何。
