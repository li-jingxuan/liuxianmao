# 简谱移至歌词上方与谱面标记清理技术方案

日期：2026-10-13。状态：用户确认方向并授权开工后已实施。

## 目标与范围

根据用户本轮要求完成三项调整：移除 `system.notationLabels`，为 MVP v7.2 mock 的和弦配置指法图，将简谱从六线谱上方移至六线谱下方、歌词上方。

谱行纵向顺序统一为：**和弦名称／指法图 → 六线谱及其节奏、技巧内容 → 简谱 → 歌词**。和弦仍位于六线谱上方；多行歌词全部位于简谱下方。没有歌词但有简谱时，简谱仍显示在六线谱下方。

这是布局调整，涉及真实内容边界、空拍编辑高亮和分页，按 AGENTS.md 第 4 条先审查方案再实施。保留已有未提交修改，文档 schema 继续为 7。

## 实现方案

### 1. 去掉 notationLabels

- 删除 `ILXMSystemLayout.notationLabels`、布局中的标签生成及每项 24 单位的顶部占位。
- 删除共享 SVG／Canvas 场景中的标签图元和相关字体度量请求，使编辑器与导出图片同步取消阶梯文字和留白。
- 系统宽度不再受到这些说明文字的影响。
- 本次移除的是谱面标签展示，不删除已有文档的 `measure.sectionLabel` 数据、保存校验、复制能力及设置入口，避免改动旧谱数据。mock 中这些字段可继续用作测试说明，但不绘制。

涉及 `layout-types.ts`、`system-content-layout.ts`、`music-text-metrics.ts` 和网站 `score-scene.ts`。

### 2. Mock 补齐匹配的指法图

- 使用已有 `copyChordPreset("C")` 复制标准 C 和弦模板，为 mock 第 1、4、8 小节现有 C 和弦填充独立的 diagram 数据。
- 将对应 `display` 改为 `nameAndDiagram`，继续使用全局“显示和弦指法图”开关。
- 匹配是指指法图与和弦名称一致，不要求简谱多音、TAB 局部演奏音与完整开放和弦指法完全相同。第 4 小节保留多音标注测试用途。
- 不为其余没有和弦标记的小节新增和弦。

涉及 `example/example-mvp7.2.ts`；不新增和弦布局实现。

### 3. 简谱与歌词共享下方内容区

- 先完成 TAB 节奏和技巧投影，用 `getMeasureContentBottom` 及技巧实际边界确定正文下缘，避免简谱碰撞横梁、符尾和连音标注。
- 先以零基线布局各拍简谱，再依据整行简谱的联合 bounds 统一平移。最高八度点到正文下缘保留现有文本行间隙，最低八度点也参与占位；不再用固定的上方坐标和低音点数量反推基线。
- 歌词基线改为位于简谱实际下缘之后；没有简谱时继续从 TAB 正文下缘规划歌词，不预留空简谱行。
- 整行顶部只由 TAB／上方技巧和和弦决定；底部同时包含简谱、歌词及既有正文净空。有简谱、无歌词的行也必须计入简谱实际高度。
- 保持同拍横坐标、输入编码、独立记谱语义及最终一次整体平移不变。
- 空简谱拍的编辑高亮优先对齐同一 system 的简谱行；整行无简谱时在正文下方显示临时高亮，不写入数据、不增加正式行高，也不退回 TAB 上方。
- 继续遵守已确认的左侧竖线规则：有歌词时截止第一行歌词上缘；无歌词时截止最下层横梁，无横梁时回退末弦。简谱移动后不自行变更这条规则。

涉及 `system-content-layout.ts`、`numbered-notation-layout.ts`；图元和 hitIndex 继续消费核心布局，不用 CSS 单独移动文字。

## 验证与验收

- 旧段落标记仍能保存、清空与复制；添加标记不再改变谱面几何，不进入字体度量或导出图元。
- mock 加载合法；三处 C 和弦有标准指法图且快照独立；显示开关隐藏图形时保留数据，编辑与导出结果一致。
- 在紧凑／舒适布局下，最高简谱点位于 TAB、节奏与技巧下方，最低简谱点位于第一行歌词上方；两级高音、三级低音、同拍多音不重叠。
- 有简谱无歌词、有歌词无简谱、两者都无及多行歌词均能正确计算行高和左侧竖线。
- 空拍高亮和已有简谱点击命中位于新区域；连续录入、覆盖、撤销与重做沿用原行为。
- 更新核心及网站中依赖原位置和 notationLabels 的测试，执行全量测试、类型检查、相关 lint 与 `git diff --check`。
- 浏览器检查首页、指法图开关、简谱编辑及 A4 图片预览，保存新的验收截图并更新 mock 验收记录。

本次不增加简谱减时线、独立时值输入、TAB 自动转简谱或播放。

## 实施结果

- 已删除 `notationLabels` 类型、布局、度量及共享图元；段落字段继续保存但不影响谱面几何。
- mock 三处 C 和弦均配独立的标准指法图；全局开关验证隐藏后标记数从 3 变为 0，重新显示恢复为 3。
- 简谱用零基线 bounds 确定正文下方公共基线，歌词从简谱最低圆点之后排布；无简谱行不增加正式占位，空拍焦点使用同谱行简谱位置或正文下方临时区域。
- `pnpm test` 全量 557 项通过（核心 486、网站 71）；`pnpm type-check`、相关文件 ESLint 检查通过。
- 浏览器点击下方简谱进入编辑，单拍由 `1` 改为 `2'` 后撤销恢复 `1`；A4 预览显示一页且没有顶部阶梯文字。截图保存于 `artifacts/mvp72/简谱下移与指法图预览.jpg`。
