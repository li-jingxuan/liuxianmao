# MVP v7.2 简谱能力检查与测试谱验收

日期：2026-10-13。用户已确认八小节 mock 与首页默认谱例替换方案。本次仅更换验收数据，不代表 MVP v7.2 所有功能已完成，文档 schema 仍为 7。

## 当前能力

- 支持单拍新增、修改、删除和跨已有小节的连续录入；空格分拍、`+` 表示同拍多音、`_` 跳过并保留已有内容。
- 支持音级 1–7、`#`/`b` 前缀、最多三级高低八度点、独占一拍的 `0`/`-`；八度后缀绘制为实际圆点。
- 连续录入提供位置及覆盖预览，不允许覆盖时原子拒绝；成功修改进入撤销、重做历史。简谱随拍点剪贴板和小节复制保留。
- 简谱已按后续授权移至 TAB／节奏区下方、歌词上方，参与宽度、行高、命中、高亮和 A4 图片共享图元。没有简谱时不生成额外简谱内容。顶部段落标签展示已取消。
- 简谱仍是手工标注，不从 TAB 品位、调弦或调性自动生成，不反向改变 TAB 音符、休止或时值。`-` 不自动创建 Tie；尚无简谱自身的减时线、附点时值绘制或播放。

## Mock 内容与入口

数据为 `packages/lxm-editor/example/example-mvp7.2.ts`，导出 `EXAMPLE_MVP_7_2_DOCUMENT`。首页默认加载入口 `apps/website/stores/editor-store.ts` 已改用该数据，旧谱例文件保留。刷新首页可加载原始 mock；更换默认数据不对正在运行的旧编辑会话执行文档替换。

共八个 4/4 小节、39 个拍点、29 项简谱、15 个八度圆点，标准调弦、C 调、Capo 0。

| 小节 | 覆盖内容                                             |
| ---- | ---------------------------------------------------- |
| 1    | 四分音符、普通音级、单行歌词、C 和弦名称及指法图     |
| 2    | 八分音符、高八度、连梁、单行歌词                     |
| 3    | 升降号、二级高音与三级低音圆点                       |
| 4    | 四组三音、C 指法图、两行歌词；竖线截止第一行歌词上缘 |
| 5    | `0`、`-`，TAB 音符及休止与简谱独立                   |
| 6    | 两个空简谱拍，供单拍补录和连续跳拍使用               |
| 7    | 整小节无简谱与歌词；隔离成行时检查横梁收边           |
| 8    | 附点四分、八分和二分音符、C 指法图、两行歌词、终止线 |

这是覆盖记谱输入语法的 mock，不将极端八度标记与 TAB 品位的一致性作为验收条件。

## 验证结果

- 后续布局调整完成后，`pnpm test`：核心 486 项、网站 71 项，共 557 项通过；类型检查与相关 lint 通过。
- `pnpm type-check` 通过；歌词排序调整后核心类型检查再次通过。
- 七项 mock 验收测试覆盖正式 loader、首页默认文档、两种排版密度、简谱在 TAB 下方／歌词上方的边界、点击命中、八度点及导出图元、第一行歌词上缘和无歌词横梁收边、跨小节覆盖与跳拍、TAB 内容不变、单次历史、撤销重做、空拍补录与删除，以及指法图模板与开关、段落标签不参与布局、空简谱焦点不回退到 TAB 上方。
- 浏览器确认首页标题与八小节新数据；点击首拍简谱自动进入段落编辑的简谱子 TAB，单拍模式读取 `1`，修改为 `2'` 后成功应用，撤销后恢复 `1`。
- A4 预览生成一页，显示全部八小节；更新后的预览截图位于 `artifacts/mvp72/简谱下移与指法图预览.jpg`。原 `简谱预览.jpg` 为调整前记录。共享图元已验证，未将本次预览等同于 PNG 下载与像素质量验收。

后续建议先补齐简谱时值视觉表达，再独立讨论 TAB 到简谱的音高推导、同拍多音的排版方式和播放语义。
