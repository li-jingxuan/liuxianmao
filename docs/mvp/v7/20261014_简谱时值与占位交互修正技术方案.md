日期：2026-10-14。状态：已按用户授权补充细节并实施，工程检查与浏览器回归通过。

本方案补充 [简谱独立节奏与双谱对齐主方案](./20261014_简谱独立节奏与双谱对齐技术方案.md)，覆盖用户本轮反馈的四项问题。实施前保留工作区中已有独立简谱改造，不回退模型或恢复 TAB Beat 绑定。

## 2. 统一交互规则

### 2.1 占位是什么

占位表示独立简谱声部中的未录入时间。它不是休止 `0`、延时符 `-`，也不能保存为普通 `gap` 事件。已有 Tuplet 的 `gap` 仍保留其领域身份和实际时值，占位点击直接指向该组成员。

- 空位使用歌词相同的浅灰虚线框；横向空间不足时使用短标记。
- hover 使用浅蓝背景与虚线边框；当前选中的目标不叠加第二个 hover 框。
- 点击空位打开现有简谱编辑区，窗口就是该空位的时间范围；不在谱面上方新增另一行或输入框。
- 点击真实数字、升降号、八度点继续选中其真实 event/item。
- 提示只在编辑页面显示，不进入曲谱 JSON、命令历史、正式 ScoreScene 或图片导出。
- 已有简谱行内所有小节的未录入范围都可以显示占位；完全未建立简谱行的谱行由“添加简谱行”激活，不给整首空谱永久预留简谱带。
- 真实事件的完整实际时长均算占用，包括长音、显式休止与 continuation。不能只检查该时段是否有数字起点，否则长音内部会出现假空位。

### 2.2 变短

以四分音符 `1` 的 `[0,960)` 为例，改为八分后：

```text
原来：1（四分，0→960）
改后：1（八分，0→480）  □（八分空位，480→960）
```

保留当前 event/item ID、音高与起点；后续事件 tick 不动。占位由声部空白重新计算，用户提交其中内容后才创建真实事件，不自动写入休止。

与目标关联的 Tie 若因时间不连续失效，沿用影响预览与原子确认；不将缩短操作解释为持续音拆分，也不自动建立 Tie。

### 2.3 变长：目标音符扩展并覆盖

八分 `1` 改为四分，保留 `1` 的 event/items 身份和起点，将时长扩展至新终点。新范围内完整覆盖的后续事件被移除；新终点之后的事件保持原 tick。

| 原内容                      | 改后                              |
| --------------------------- | --------------------------------- |
| `1（八分） + □（八分）`     | `1（四分）`                       |
| `1（八分） + 2（八分）`     | `1（四分）`，原 `2` 被覆盖        |
| `1+3+5（八分） + 2（八分）` | `1+3+5（四分）`，保留完整目标音组 |

这属于明确的时值覆盖，不复用“合并至终点”的完整 Tie 链限制。不同音高也可以被覆盖，预览展示实际覆盖事件和标记影响；整个修改一次 revision、一次历史与一次撤销。

已实施的保护规则：

1. 新终点切到后续长事件中部时拒绝，提示调整范围；不擅自截短、重新起音或移动其剩余部分。
2. 超过小节容量时拒绝，不自动跨小节、推移其他事件或改变 TAB。
3. Tuplet 成员不单独改变实际时值；扩展范围不能切断任一 Tuplet。完整连音组变更继续使用整组窗口操作。
4. 被覆盖事件关联的 Tie/Slur/Fermata 使用既有影响确认，不把它们自动转接到目标音符上。
5. 内容和时值均未变化时为 no-op。预览失效、取消或校验失败不写历史。

## 3. 空位计算与几何

采用独立的“可录入时间槽”投影，避免重新给简谱占位绑定 TAB Beat，也不把空白渲染依附于旧的歌词 `musicTextCells`。

1. 用 `createNumberedRhythmContext` 计算每个事件的真实占用区间，校验后按 tick 排序。
2. 从 `[0,小节容量)` 中减去这些区间，得到普通未录入范围；Tuplet gap 单独生成有 eventId 的空位。
3. 普通空白按公共拍号的拍单位切分，碎片按可表达的普通/附点时值分解；四分变八分释放的半拍只生成一个八分空位。不能继续为整个小节无差别生成密集的 1/32 网格。
4. 每个槽记录 `startTick/endTick`、逻辑 anchorX 与显示/命中 bounds；必要时区分 `numberedTime` 与 `numberedEvent(gap)`。
5. 横坐标从联合 `timeAnchors` 查询或在同一时间段插值；空位的视觉宽度遵循歌词窄槽规则，不强行加宽正式布局。
6. 竖向位置使用数字正文行的基线/带状区域，不能使用含上方 Tie/Slur/Fermata 的整体 bounds。显示、hover、点击和输入预览使用同一个槽，避免框跑到数字上方。
7. 当前活动空位必须匹配 start/end 两个边界；不能仅凭 measureId 或一个 undefined beatId 判断“同一目标”。

## 4. 接入细节

### 4.1 核心命令

扩展 `numbered.event.setRhythm` 的候选规划：保持目标身份，按新终点收集完整被覆盖事件，拒绝部分事件/部分组，统一验证容量与关系。候选结果提供被覆盖事件 ID、已释放范围及既有标记影响；UI 只消费规划结果，不自行删除后续事件。

“释放范围”只用于反馈和定位，不写入文档。正式空位每次从最新声部推导，因此撤销、重做、粘贴、外部替换、拍号变化后也能恢复正确占位，不依赖上一次操作留下的临时列表。

### 4.2 布局和命中

增加独立的 numbered input slot 数据契约，以同一投影供编辑提示和 `hitTestNumbered` 使用。取代当前无差别 120 tick 网格；真实 mark/item/event 优先，空位随后。

`layoutParagraphFocus` 对空位使用精确槽位置和窗口，不再一律返回 `anchor-12 / height=18` 的通用框。已录入事件保持真实 item/event 焦点。输入槽不产生第三套音乐时间坐标，不改变 TAB 节奏或联合对齐。

### 4.3 hover 与占位组件

`index.tsx` 的 pointer move 引入独立简谱命中目标，hover 状态使用歌词/简谱的联合目标类型。取消 `target.kind === "numbered"` 的直接跳过；同目标比较对简谱检查 event/item 或完整时间窗口，对歌词仍检查 beat/verse。

`MusicTextEditingHints` 共用占位框、窄槽短标记、hover 和选中视觉样式，分别读取歌词 cells 与简谱 slots，不使用假 beatId。绘制层仍设置 `pointerEvents="none"`，正式命中由核心几何处理。

重排后旧 hover 不继续使用；关闭编辑、指针离开和拖选时按既有规则清理。IME、脏草稿、覆盖/技巧确认仍经过当前侧栏闸门。

### 4.4 升降号与拍号

升降号修正同时检查估算与浏览器真实 Bravura 度量，调整字号/垂直基线及对应命中几何；不能靠裁切或隐藏超出的部分解决。减时线以数字正文下缘定位，八度点、附点和真实连线继续正常占高。页面 SVG 与 Canvas 共用最终符号几何。

移除 `numbered-structure-layout.ts` 的拍号图元和相关度量请求，移除 `system-layout.ts` 仅因简谱换行存在而增加的拍号留白。真实 TAB 拍号及反复净空保留；简谱仍与 TAB 同起音对齐。

## 5. 验收

- `4/#4/n4`、`7/b7` 在同一节奏和八度下，简谱数字基线、减时线与行高一致；升降号完整可见、可点击。高低八度点仍产生必要净空。
- 简谱任何行首和拍号变化处均不出现重复拍号；TAB 和顶部公共信息保持正确，双谱同 tick 首音中心一致。
- 四分变八分：后方出现一个八分占位；点击该占位的窗口恰为释放的半拍，框与数字同一行。
- 八分变四分：吸收空位或完整后续八分音，以目标音符为准，后面事件不移动；一次撤销完整恢复。
- 覆盖到半个后续长音、部分 Tuplet 或越界时拒绝；标记失效时确认，取消不修改数据。
- 长音内部、真实休止和 continuation 时间内无假空位；Tuplet gap 点击保留成员身份和比例。
- 普通空位、Tuplet gap、真实数字、升降号、八度点均有准确 hover；当前选中目标不重复描边。hover 与点击是同一个目标。
- 单行空白、多小节稀疏简谱、跨行连线、两种密度、撤销/重做/粘贴/文件替换后占位正确，歌词 hover 与占位不退化。
- PNG 不包含占位/hover/选中框，符号效果与页面一致。

实施时先复现并修复相应回归，再运行整体 `pnpm test`、`pnpm type-check`、`pnpm lint`、`pnpm build`。当前 615 项测试与上述工程检查均通过；页面缩短、占位录入、扩展覆盖、撤销及正式 PNG 已完成实际验证。hover 目标和样式由集成测试覆盖，未将其记为手工指针移动验收。

## 6. 本轮已确认的边界

本轮使用的规则是时值扩展覆盖真实音符的语义，以及新终点落在后续长音中部时先拒绝的处理。占位与 hover 按歌词的视觉反馈恢复，实际目标使用独立简谱时间槽；不涉及 schema 再次升级。

## 7. 开工前实现契约补充

- 实测 Bravura 16px 的 SVG 文本框高约 64px，数字 14px 约 15.5px。升降号使用 Canvas TextMetrics.actualBoundingBoxAscent/Descent 等墨迹边界，数字仍沿用 SVG 度量；页面与导出共用读数函数。核心将符号等比缩放至数字墨迹高度以内，并垂直居中，渲染字号、bounds 和命中一致。不能把 64px 字体框直接缩成字号 4px，也不能仅忽略其 bounds。
- 空位规划属于核心纯时间函数：普通空白按拍号单位切段，再使用可表达的普通/附点时值最长优先分解；若存在不足最小书写时值的整数碎片，保留完整时间范围供自定义模板，而不舍弃 tick。占位初始时值读取槽自己的推荐 rhythm；Tuplet gap 读取原成员 rhythm。
- 几何只保存一份 measure.numberedInputSlots，包含稳定派生 key、目标、start/end、推荐 rhythm、anchorX 和 bounds。命中索引引用同一对象。槽在最终谱行平移后创建，使用数字基线，避免先平移后再次补 dy；不按每帧 1/32 时钟生成假空格。
- 空位的 hover、点击与选中共用同一槽边界，原编号时间网格删除。行高预算只由已有音乐或明确激活的空行决定，槽不再次撑高行。
- setRhythm 候选返回 overwrittenEventIds 与 releasedRange，按稳定 ID 进行 effects 汇总。完整覆盖普通事件可直接作为已请求的时值动作；涉及旧标记丢失仍走影响确认。即使完整覆盖整个 Tuplet，也保守拒绝单事件时值命令覆盖组，使用已有整组窗口编辑。
- 简谱 UI 新增“当前音符时值”规划预览，与录入文本的 parsed/issue 分开；修改时值不要求先输入一份新的简谱文本，也不把空白录入框预览到音符上方。
- 原时值扩展重叠拒绝测试已调整为目标覆盖测试，新增切断后续长事件与 Tuplet 的拒绝测试；保留旧输入纯函数、作用域独立性和原子历史检查。
