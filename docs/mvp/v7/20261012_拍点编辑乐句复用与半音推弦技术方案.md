## 1. 目标与基线

在已完成的 7.1-B 上增加可解释、可撤销的拍点结构编辑、Beat 乐句复用和半音推弦。当前核心文档 schema 6，已有 `beat.setRhythm`、小节范围复制、16 类技巧、连音、歌词与和弦；网站适配层提供独立会话和草稿保护。

本版交付五项能力：单个 Beat 等分为两拍、连续 Beat 合并、同小节连续 Beat 快照复制及插入/覆盖粘贴、半音与全音推弦选择，以及空格分隔的简谱连续编辑。每个编辑操作为一条核心命令、一次 revision、一次历史和一次宿主通知；复制快照不改变文档或历史。

简谱按最新连续编辑方案纳入本版；旧只读展示草案不再作为交付定义。作品/文件管理、播放、多轨、跨小节自动扩展、预推/回落、复杂装饰音和分页/PDF 均不纳入本版。简谱批次可跨小节写入已有拍，与首版 Beat clipboard 限定同小节是不同操作边界。

## 2. 首版行为与语义

### 2.1 拆分

- `beat.split` 接收轨道、小节和 Beat ID。首版等分为两个同附点、时值减半的 Beat；总实际 tick 不变，不压缩后续拍。不能表示为合法时值（例如三十二分音符再等分）时拒绝。
- 首版拒绝拆分连音成员；不隐式拆组或改变连音比率。
- 休止拆为两个休止。数字音符拆分为两个同弦同品位的音符，并逐弦建立内部 Tie，表示原持续音；第一拍保留原 Beat/Note ID，第二拍生成新 ID。
- 含 `x` 的 Beat 首版拒绝拆分：闷音不能 Tie，重复 x 会改变击打次数，不能将其当作持续音处理。
- 歌词、和弦及单音/Beat 技巧留在第一拍，不复制到第二拍。外部进入的连接仍指向第一拍，外部离开的连接改为从第二拍对应 Note 出发；区间终点落在原拍时延至第二拍，起点保留第一拍。
- 若重建后的连接、范围或内部 Tie 与现有技巧不兼容，整次拒绝并给出原因；不调用通用清理后悄悄删掉原技巧。具体兼容性由现有规则最终校验。

### 2.2 合并

- `beat.mergeRange` 接收同小节、顺序连续的起止 Beat ID，至少两拍。总时值须能表示为一个合法 rhythm，首版拒绝任何连音成员、跨小节范围或无法精确表示的时值。
- 支持连续休止，或者每拍数字音符集合完全相同且各相邻拍逐弦有 Tie 的持续音。其他音符序列、数字与休止混合、x 或未 Tie 的重复拨弦均拒绝，避免丢失音高和起音次数。
- 合并保留首拍与首拍 Note ID，移除后续成员和范围内部 Tie。外部进入连接映射至合并音符，外部离开连接从末拍映射至合并音符；跨范围区间端点映射至首拍。
- 首拍歌词/和弦/单点技巧保留。后续拍存在歌词、和弦、独立单音/Beat 技巧，或区间在范围内部开始/结束而无法无歧义表达时拒绝。不会将不同歌词拼接、覆盖和弦或扩大局部技巧范围。
- 合并前后小节容量及范围外 Beat tick 不变。选区折叠至保留的首拍；失败保持原选区、历史及文档。

### 2.3 复制快照

- 在现有选区上取涉及的完整 Beat，首版限定同小节连续范围，不根据弦矩形裁剪音符；界面明确“复制拍点（含全部弦）”。跨小节乐句继续使用 B 阶段完整小节复制。
- 新增纯函数 `createBeatClipboard(document, range)`，返回经过校验的独立值快照或错误。快照包含 Beat/Note、相对 tick、总实际时长、完整连音组、歌词、和弦和完整包含的技巧。
- 若源范围只包含部分连音组，拒绝复制；跨边界技巧按 B 阶段规则遗漏并返回结构化说明，同一关系只报告一次。孤立快照不能保留指向源范围之外的引用。
- 复制时深拷贝，粘贴时统一重建所有实体 ID；源文档随后修改、删除或撤销均不改变已经复制的内容。
- 剪贴板属于当前编辑会话的临时状态，不写入 document、不经 `onChange` 通知、不写系统剪贴板。外部文档替换或会话销毁清空；普通 undo/redo 不清空。
- 快照具有独立格式标识和版本，核心粘贴入口运行时校验形状、引用、时值、连音和技巧，不能只相信页面的 TypeScript 类型。首版仅接受当前会话 UI 产生的格式。

### 2.4 插入粘贴

- `beat.paste` 接收快照、目标小节、目标 Beat ID 和 `mode: "insert" | "overwrite"`。插入模式在目标拍之前插入全部快照，目标拍作为保留的后续内容。
- 不插入连音组内部。插入只消费右侧未承载歌词/和弦/连音/技巧及显式目标的普通尾部容量休止；不足时拒绝，不压缩其他音符，不新增小节。
- 复用核心时间轴协调器并补齐“技巧锚点也属于受保护内容”的判定；现有 `getFixedPrefixLength` 只覆盖文本/连音，不能直接用于消费带技巧的休止。
- 被消费尾部若为合法可拆的普通休止，可精确生成剩余时值休止；不能表示时拒绝。保留其余 Beat/Note ID 和顺序，统一计算新 tick。
- 插入打断既有 Tie 或使其他关系失效时，复用结构化影响提示，明确报告清理；若新副本技巧与目标现有技巧冲突，整次拒绝。

### 2.5 覆盖粘贴

- 从目标 Beat 起覆盖与快照总实际时长相等的连续完整 Beat。末端必须落在已有 Beat 边界；不能精确对齐或超出小节时拒绝，首版不自动拆目标拍。
- 覆盖范围涉及连音时必须完整包含整个连音组；部分覆盖拒绝。可覆盖的目标音符、歌词、和弦及组内技巧由副本整体替换，不做混合拼接。
- 预览显示目标拍数、时长及被替换文本/技巧摘要。实际覆盖有音乐内容的范围须由用户明确选择“确认覆盖”，沿用现有覆盖确认表达。
- 删除目标范围失效的外部技巧关系，输出 `technique.removed`；副本边界遗漏沿用复制摘要。不把旧关系自动连接到新音符。
- 页面预览与实际命令共用纯规划函数；提交基于当前文档再次规划和校验，预览过期不采用旧结果。一次提交失败不产生部分副本。

## 3. 半音推弦及 schema

- `bend.semitones` 从固定 `2` 扩展为 `1 | 2`；半音表示提高一个半音，全音维持两个半音。0、小数、负数和大于 2 均拒绝。
- 保持数字音符约束，x 不能推弦；已有同音符技巧冲突与重复规则继续统一使用 `validateTechnique`。
- 核心 layout 按参数输出 `1/2` 或 `Full`，同步测量文本外框、最小宽度、命中和视觉边界。SVG 层只消费核心结果，打印复用相同几何。
- 工具栏将“全音推弦”改为“推弦”，增加“半音 / 全音”选择；默认全音兼容原行为。选中已有推弦时读取实际参数，通过 `technique.update` 原位修改，同值为 no-op。
- 因持久化技巧取值扩展，正式 schema 升到 **7**。loader 只接受 schema 7；`upgradeDocumentToCurrent` 显式支持 4/5/6 → 7，不自动迁移。
- 旧格式校验须冻结旧 bend 为 `semitones: 2`，不可因为复用新 schema 而在旧版本中接受半音值。schema 6 保留现有作者/调性；4/5 按既有规则补字段，旧全音推弦及全部音乐 ID 保持不变。
- 所有内置示例及测试夹具同步版本；clipboard 格式和 document schema 分别管理，不持久化 clipboard。

## 4. 模块与命令边界

| 位置                         | 职责                                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| 核心 `beat-structure.ts`     | 拆分/合并纯规划、精确时值表示、引用映射与语义拒绝                                  |
| 核心 `beat-clipboard.ts`     | 快照生成与运行时校验、完整对象提取、复制引用映射                                   |
| 核心 `beat-paste.ts`         | 插入/覆盖预览与执行共用规划、容量和目标边界校验                                    |
| 核心现有命令入口             | `beat.split`、`beat.mergeRange`、`beat.paste` 分发，最终 schema/语义守卫及 effects |
| 现有时间轴/技巧/effects 模块 | 复用实际时长、保护锚点、技巧合法性和结构化影响，禁止页面另写 tick 算法             |
| 网站 session store           | 会话内快照生命周期、成功选区更新、历史与宿主一次通知                               |
| 网站 Beat 工具区             | 拆分、合并、复制、两种粘贴及预览；禁用原因可读                                     |
| 技巧工具栏/核心 layout       | 推弦参数编辑与一致的标注、bounds 和命中                                            |

首版结构命令不改变小节拍号、段落标记或曲首信息。拆分/合并导致原选区 ID 消失时，由核心返回明确的新目标，适配层在成功后更新；失败不移动选区。

新增结构化摘要包括拆分前后拍数、合并范围、粘贴模式/位置/拍数、实际重排与技巧遗漏/清理。位置基于编辑前文档；no-op/失败没有成功摘要。原技巧 effect 继续使用，不重复报告。

文本/设置草稿活跃或 IME 输入中禁用结构命令；复制、粘贴和切换工具不能绕过草稿保护。计时品位草稿在结构操作前取消，避免旧 Beat 引用回写。首版以显式按钮交付，避免接管文本框或系统剪贴板快捷键。

## 5. 实施顺序

### 补充：每个谱行最左侧竖线

按用户补充，每个 system 最左侧增加一条“｜”竖线，作为该谱行的视觉收边。实施后的复核确认竖线应位于左边缘，而非右边缘。

- 横坐标取最终 system 的最左边界 `system.x`；为避免线宽被 SVG 左侧 viewBox 裁切，1px 描边中心定位于 `system.x + 0.5`。
- 起点取当前 system 第一弦的最终 Y；终点取最终布局的 `system.y + system.height`。这里的“system 行结束”按整行布局底部解释，包含下方节奏、歌词及该行内部底部留白，不包含下一行之间的 `systemGapY`；不延伸到第一弦上方的和弦、简谱或技巧区域。
- 每行分别绘制，不连成跨 system 的整页竖线；线段从各行第一弦开始，无歌词等下方内容时也遵循实际 system 高度。
- 使用 SVG line，线色和线宽沿用普通单小节线。不改变小节线、终止线或反复线等音乐记号。
- 核心在简谱/歌词、技巧、谱首平移和整行高度全部确定后生成最终几何，页面与打印只消费布局结果；半线宽内缩保证描边不越出左侧画布。
- 竖线不成为 Note/Beat/技巧命中目标，不影响选区、拖选或历史。
- 验收覆盖多行、有/无歌词、多个歌词段号、稀疏末行、超宽单小节、行首反复线以及紧凑/舒适排版；核对横坐标为最左边缘、起点为第一弦、终点为该行底部、没有跨行延伸或左缘裁切。

## 7. 审查重点

本方案建议确认以下三项产品边界后实施：

1. 首版 Beat 范围限定同小节；跨小节乐句继续复制完整小节。
2. 拆分保持持续音语义，合并仅接受休止或有完整 Tie 的同音集合；无法保真的情况拒绝。
3. 插入容量不足直接拒绝；覆盖必须精确落在已有拍边界且显式确认，不隐式压缩、拆拍或扩展小节。

若要求任意音符序列合并、跨小节 Beat 粘贴或容量不足自动扩展，需要在审查时调整本方案，不能在实现中扩大默认范围。

## 8. 落地复查补充：接口和边界冻结

### 8.1 时间轴保护必须覆盖所有入口

- 新增统一的明确内容集合：notes Beat、歌词、和弦、简谱、连音及技巧引用的 Beat。技巧引用从 track 的 Note/Beat 索引解析，不能只在 measure 内查找。
- `getFixedPrefixLength` / `reconcileMeasureTimeline`、时值修改和拍号修改均消费同一保护集合；尤其修正全休止小节的快捷重建分支，带简谱或受保护锚点时不能按空谱重建。
- 拍号缩容的“移除文本再判断阻挡原因”分支必须同步去除简谱再比较；只影响错误分类，不允许成功路径丢弃内容。
- 插入保留目标 Beat，且只消费它右侧的无保护尾部休止。例：四拍空谱在第 1 拍前插入一拍，可消费最后一拍休止；在第 4 拍前插入一拍则拒绝。只有一个全小节休止的空谱也不能在保留该目标的同时插入；使用精确覆盖完成填入，不自动替换目标或扩小节。
- 目标处于连音组首拍前时允许插入，组内后续成员前拒绝；拆分/合并仍拒绝任何连音成员。所有 tick 均使用连音实际时长，不使用裸 rhythm 时长代替。

### 8.2 拆分与合并的引用映射

- 拆分多音集合时每根数字弦都生成第二个 Note 和一个 Tie；附点保持不变，最短时值失败。输入空 notes Beat 拆成两个空 notes Beat，不改成休止，不生成不存在的 Tie。
- 合并比较按弦号规范化的 Note 集合，不因数组顺序不同而拒绝；首版空 notes Beat 不合并，避免与休止语义混淆。
- 合并的外部连接只接受指向首拍的进入连接、来自末拍的离开连接；进入/离开内部成员的其他连接拒绝，不把它们挪到首拍改变发生时间。内部必须是逐弦相邻 Tie，其他内部连接拒绝。
- 对 P.M./Let Ring，合并范围记为 [first,last]：若技巧起点落在范围内，必须是 first；若终点落在范围内，必须是 last。满足条件才映射至保留拍，保证该技巧原先覆盖全部合并时长。仅覆盖部分合并时长的技巧拒绝，不能用同一目标 Beat 表达不同作用区间。
- 第一拍的单音/Beat 技巧保持既定规则；后续独立技巧或歌词/和弦/简谱拒绝。全部映射完成后校验所有技巧，拆分/合并不走会悄悄删技巧的 `replaceMeasure` 清理路径。

### 8.3 粘贴确认的有效期与校验

- `beat.paste` 必须携带 `allowOverwrite`；目标有 notes Beat、歌词、和弦、简谱、连音或受覆盖影响的技巧时要求为 true。仅无标记的普通容量休止可不确认。核心自行判断，不相信 UI 显示的覆盖数量。
- 覆盖规划返回 `confirmationKey`，按固定字段顺序序列化快照内容、目标范围、相关技巧、连音和拍号等实际读取内容；提交携带预览生成的 `expectedConfirmationKey`，核心重新规划后比较。不一致直接拒绝，要求重新预览确认，不将旧的允许覆盖状态用于新内容。
- UI 另使用会话单调递增的 `stateVersion` 跟踪命令、undo/redo 和合法替换，任何文档切换或 clipboard 更换即取消原预览/确认。不能仅使用 `documentRevision`：撤销再编辑可能产生相同 revision 的不同文档。
- 全量候选先明确清理因插入/覆盖失效的目标既有关系，再添加副本并整体校验；任何新副本非法或冲突均拒绝，不能按数组先后用 `pruneInvalidTechniques` 随机留下某一技巧。
- 插入跨过既有 P.M./Let Ring 的区间时，其端点语义维持现有定义：插入拍自然属于该区间；若副本含休止或产生区间冲突，按既定影响策略报告旧关系移除，副本关系不能被静默移除。预览同时显示这些移除。
- 覆盖受影响的关系包含端点被删除和无端点落在范围内但贯穿范围的技巧；最终合法的贯穿区间可保留，因新内容变休止等失效的必须报告。

### 8.4 Clipboard 的完整契约

- 固定格式标识 `lxm-beat-clipboard`、`version: 1`；载荷包含 beats（tick 从 0 起且连续）、tuplets、lyrics、chordSymbols、techniques、totalTicks 和独立的源位置/遗漏摘要。简谱随 Beat 深拷贝；不保存小节拍号标记、barline、sectionLabel、曲首信息或源外对象引用。
- 1–256 个 Beat，每个实体 ID 在载荷内全局唯一；空范围、倒置范围、非同小节范围拒绝。完整连音成员保留原顺序与 ratio；totalTicks 必须由实际时长重新计算一致，不能相信输入总数。
- 粘贴入口接收并运行时校验载荷；拒绝坏形状、错误 tick、重复 ID、dangling 引用、无效 token 和技巧，不用完整小节容量规则验证部分小节快照。对象 ID 及关联引用在每次粘贴时重建，源位置仅用于显示。
- 复制失败保留上一份合法快照；合法外部替换清空，非法替换保留；undo/redo 保留。对外取出/放入快照时隔离可变对象，修改读取结果不能污染会话缓冲。
- 复制没有命令历史，边界遗漏以复制结果的临时提示展示；粘贴时可重复展示该快照的遗漏摘要，但不重复生成同一条 relation effect，也不向已删除的源文档定位。

### 8.5 命令结果、选区及影响提示

- 拆分/合并/粘贴成功结果增加 `nextFocus: { trackId, measureId, beatId }`，不加入持久化文档。拆分和合并指向保留的首拍，粘贴指向副本首拍；网站保留当前 focus.string 并折叠选区。失败/no-op 不返回新焦点，不移动选区。
- store 在一次文档提交中接入 nextFocus，再做现有选区合法性校验；不能把被覆盖 ID 的通用回退当作新焦点，否则会跳到小节首拍。undo/redo 仍按既有历史文档与局部选区协调规则，不新增选择历史。
- effects 增加 `beat.split`、`beats.merged`、`beats.pasted` 摘要，携带编辑前位置、源/目标拍数和粘贴模式；显式拆分导致原 Beat 时值减半不标记为自动压缩。
- 合并消耗内部 Tie 属于操作本身，仅在合并摘要报告 consumedTieCount，不再当作“失效技巧丢失”重复报警；真正失效的外部关系仍输出清理 effect。使用结构规划返回的原因集合，避免 UI 或通用 diff 猜测。
- 更新 EditorImpactNotice 的完整判别联合和推弦名称，未知 effect 不渲染 undefined；所有新摘要、复制遗漏和错误可读。

### 8.6 版本迁移和半音推弦完整路径

- schema 4/5/6 的旧 Beat 使用 `numberedNotation` 之外的冻结结构，旧技巧固定 bend=2。旧版本携带新字段或半音值须拒绝，不能被 Zod strip 或新 schema 复用静默接受。
- 保留旧弦范围补齐的既有 loader 兼容顺序；迁移完成后统一通过 schema 7 与语义校验。不新增 schema 3 升级，也不把当前 schema 7 当作旧版本迁移输入。
- 分别为 4/5 补作者和调性、4 补 Capo；schema 6 已有字段必须完整保留。旧文档有音乐字段不能因解构默认值覆盖。
- 半音改变的不只有 path 标签：技巧宽度预留、测量、bounds、命中和选择提示都使用同一个参数化 label。工具栏从被选技巧初始化，按现有 ID 重建/同步编辑草稿，不让上次全音草稿覆盖新选中的半音。

### 8.7 左侧竖线的可执行几何规则

- 核心输出 `system.leftEdge` 的实际线段数组，X 位于 system 最左边界内缩半个描边宽度的位置，Y 起止为第一弦 → `system.y + system.height`。计算发生在最终 system content 排版后。
- 左侧竖线只作为视觉收边，不与行首反复符号或小节竖线合并，不改变任何音乐记号。
- 线宽完全落在现有左侧画布内；不改变 system.width、列宽、自动断行或 nominal system.height。
- 仅此新增视图元素与打印共用 SVG，无编辑目标、历史或 schema 字段；仍不交付分页。
