# 歌词与简谱空行编辑修复技术方案

日期：2026-10-13。状态：用户已确认方案并授权实施，修复与验收已完成。

## 目标

1. 歌词连续录入中的“允许替换预览中标记的已有歌词”默认勾选，仍可手动取消。
2. 歌词、简谱的空拍可以点击编辑，不要求事先写入占位内容。
3. 没有歌词、简谱的曲谱可以通过明确入口开始新增；支持新增第 1–4 段歌词。
4. 移除谱面左侧的 `1.`、`2.` 等歌词段号，编辑器、预览与导出保持一致。

## 原因与当前能力

- `buildHitIndex` 只为已有歌词和简谱生成音乐文本命中区域，空拍没有入口。
- `system-content-layout.ts` 只按已有内容计算歌词段数和简谱高度；完全空白的行没有编辑空间。
- `resolveParagraphFocus` 为缺失内容推算临时高亮，但高亮不提供命中区域，也不增加行高。
- 侧栏和核心命令支持向已有 Beat 新增歌词、简谱，缺少直接的新增行操作。
- 歌词是按 Beat 和 verse 存储，支持 1–4 段；简谱是每拍一组 tokens，当前不支持多条独立简谱声部。
- `readMusicTextDraft` 把覆盖开关初始化为 false。
- 左侧数字来自布局自动生成的 `lyricVerseLabels`。

## 交互方案

### 歌词默认允许替换

- 新建或重新加载歌词草稿时，将覆盖开关初始化为 true，并以相同值生成 initial，避免仅因默认值导致“未保存修改”。
- 用户可以取消勾选；当前草稿内保持其选择，实际替换仅在点击“应用全部”时执行。
- 保留对应预览和应用按钮中的覆盖数量提示，调整原先“已有歌词不会自动覆盖”的说明以符合新默认值。
- 简谱覆盖选项维持原有行为。

### 新增行入口

- 在歌词／简谱侧栏增加“添加歌词行”“添加简谱行”入口；没有选拍时以当前轨道首个可编辑拍为起点，有选拍时使用当前拍。
- 无歌词时添加第 1 段；已有歌词时优先选择当前谱行未使用的最小段号，最多 4 段。用满后提示通过段号选择编辑已有行。
- “添加简谱行”进入当前单条简谱区域；已有简谱时继续编辑该区域，不创建第二个简谱声部。
- 曲谱没有任何 Beat 时提示先添加拍点，不创建无锚点文本。
- 新增操作先建立编辑区域并聚焦输入框，不写入假歌词、假数字或空字符串。
- 切行、切拍仍复用已有草稿保护流程。

### 空行与空拍可编辑

- 核心布局明确产出歌词／简谱行的几何信息；行基线、行高、空拍单元格和焦点共用同一份几何，避免各自推算位置。
- 已有内容的行为空拍提供命中区域，横向按真实拍点及相邻拍点边界划分；保留已有文字图元的点击优先级，避免长歌词被邻拍空格抢占。
- 对完全没有内容的区域，通过编辑态布局参数为当前目标谱行临时预留所选歌词段／简谱区域；该空间参与行高和分页计算，避免挤入 TAB 或下一谱行。
- 空拍提示、轮廓仅在编辑层显示，点击后进入对应拍和段号；虚拟单元格不伪造歌词 ID，不作为真实音乐内容。
- 新增内容后由文档驱动正式布局；取消空行编辑、切换文档或历史恢复时清理临时区域。
- 图片预览与导出使用正式文档布局，不包含编辑用空行、提示或按钮。
- 保持纵向顺序：和弦／指法图 → TAB 与节奏、技巧 → 简谱 → 歌词。

### 移除左侧段号

- 移除歌词段号图元生成、字体度量请求和 SVG／Canvas 对应展示。
- 内部 verse 继续保留，用于多行歌词编辑、保存、复制和连续填词定位。
- 左侧谱面竖线沿用现有规则；不因为取消数字而改变其含义。

## 实现范围

- 核心布局：`layout-types.ts`、`system-content-layout.ts`、`hit-test.ts`、`numbered-notation-layout.ts`、布局参数传递及字体度量。
- 网站：`MusicTextSidebar.tsx`、`music-text-draft.ts`、`NumberedEditor.tsx`、编辑器壳与样式、共享场景及预览布局调用。
- 复用已有新增、撤销、重做命令，不增加文档 schema 字段或多简谱声部。
- 使用 TypeScript、React Hooks，在新增函数及关键几何、命中逻辑处添加中文注释。
- 保留当前工作区已有修改，实施时在其基础上修复。

## 验证与验收

- 歌词与简谱均为空的曲谱：可添加对应区域、点击空拍并输入，应用后显示正确，撤销后内容消失。
- 已有一部分歌词／简谱：点击同一行其余空拍可新增，不需要占位。
- 多段歌词：新增和切换第 1–4 段正确，不互相覆盖；段号用满时不给出不可执行入口。
- 只有歌词、只有简谱、两者都有：行序、焦点、命中与下一谱行不重叠；检查换行和分页边界。
- 新歌词草稿的覆盖选项默认勾选，取消后阻止覆盖已有歌词；默认设置本身不产生脏草稿。
- 编辑器、图片预览与导出都不显示左侧歌词段号，预览与导出不含临时占位。
- 添加针对空拍命中、空行几何、覆盖默认值的回归测试，运行相关测试、类型检查、相关 lint 和 `git diff --check`；浏览器验证新增、编辑、取消与撤销流程。

## 审查重点

本方案中的“新增简谱行”指为现有曲谱启用单条简谱编辑区域；歌词行按当前模型最多 4 段。空白编辑区域只用于编辑态，保存与导出仅包含真实内容。


## 实施与验收结果

- 歌词草稿的覆盖许可默认 true，initial 同步采用默认值，取消勾选仍能保留覆盖保护；更新说明及默认值测试。
- 布局新增 musicTextCells 和仅编辑态的 paragraphEditing 参数。真实文本优先命中，空拍单元格采用相邻拍中点划分，焦点消费相同几何；目标空行计入当前行高度并推动后续行。
- 段落侧栏新增两个添加入口，无选区可从首拍开始；歌词选择当前谱行最小未使用段号，简谱沿用现有单区域。取消简谱编辑与外部历史切换释放临时目标。
- 删除 lyricVerseLabels 类型、生成、字体度量及两处展示，保留内部 verse 和左侧收边规则。
- 全量测试 560 项通过（核心 489、网站 71），类型检查通过，相关文件 ESLint 与 git diff --check 通过。
- 浏览器验证：未选拍点击添加歌词行进入空白第 3 段；覆盖开关默认勾选；点击空行第 3 拍后目标正确切换；输入“新 词”提交后出现歌词，取消并撤销恢复。
- 浏览器验证：第 6 小节第 2 拍原无简谱，点击空白单元格进入简谱输入，提交“4”显示成功，取消并撤销恢复。
- A4 图片预览正常生成 1 页，不显示左侧段号或编辑虚线占位。截图：`artifacts/paragraph-editing/无段号图片预览.jpg`。
- 完全没有歌词与简谱的文档，通过新增回归测试验证两个编辑区域的命中、提交、输入文档不变性及正式布局不带临时空行。
