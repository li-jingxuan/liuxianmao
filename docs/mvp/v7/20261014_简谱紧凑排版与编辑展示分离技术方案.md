# 简谱紧凑排版与编辑展示分离技术方案

日期：2026-10-14。状态：已按用户授权实施第一版，624 项测试及工程检查通过。实际页面/PNG 与预览、打印图元一致性已验收，详见 [实施验收](./20261014_简谱紧凑排版与编辑展示分离实施验收.md)。

## 1. 目标与核心决策

解决两项观感问题：简谱音符之间过松；Tie/Slur 弧度、曲线与音符距离及上方八度点距离过大。采用两种布局用途：**编辑排版**适度预留录入与点击空间，**成品排版**用于预览、PNG 和打印，优先紧凑与可读性。

两种用途使用同一曲谱数据、同一时间列算法、同一渲染图元，只选择不同几何参数。字号暂时保持数字 14、音乐符号按实际墨迹适配，不用缩小字体解决间距问题。

必须保留原对齐约定：TAB 四分音符与简谱“前八后十六”的首音数字中心对齐。同一用途下，TAB 与简谱共同收紧共享时间列；不能单独缩放简谱横坐标，否则双谱会错位。两种用途允许换行和页数不同，成品预览必须与正式导出一致。

## 2. 最新代码发现

| 位置                          | 当前实现                                                                                | 对观感的影响                                                                  |
| ----------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `time-grid-spacing.ts`        | TAB 与简谱使用同一套时值列宽；同一行内相邻字形边缘额外留 6；简谱 gap 也贡献普通事件列宽 | 简谱缺少独立的紧凑间距参数；实际内容与编辑空白的宽度预算没有区别              |
| `system-layout.ts`            | 普通多小节行铺满目标行宽，只有末行或单小节行受 1.6 倍上限约束                           | 减少局部理想列宽后，剩余宽度仍可能被重新拉开，单改列宽未必看得出改善          |
| `numbered-notation-layout.ts` | 多音组每项至少占 12，项间距 6；上方点中心为 `glyph.bounds.y - 4 - i*4`                  | 音组较松；数字 bounds 本身含 2 单位保护边界，点到真实数字的距离比表面参数更大 |
| `numbered-mark-layout.ts`     | 全行最高音符 bounds 决定所有曲线的基准；再留 6；重叠关系每层抬高 14                     | 远处的高八度点也会抬高当前局部连线；嵌套连线有较大的固定层间距                |

| `system-content-layout.ts`    | TAB 底部与简谱整体最高图元间保留 8                                                      | 曲线边界估得越高，数字正文离 TAB 越远，需要随真实几何一起回算                 |
| 页面与导出                    | 编辑页面和 `prepareScoreImages` 均只传 density；预览与 PNG 已共用一个 prepared scene    | 可复用现有快照链路，增加用途参数即可分离布局，无须另写 Canvas 排版            |
| 浏览器打印                    | 已有 `@media print` 隐藏控件与编辑提示，但打印的还是页面编辑 SVG                        | CSS 隐藏占位不会重新计算坐标，打印需要独立的成品 SVG/分页投影                 |

本方案基于仓库现状，不沿用旧版与 TAB Beat 绑定的简谱排版。

## 3. 两种排版用途及参数

新增 `ILXMLayoutPurpose = "editing" | "presentation"`，`ILXMLayoutOptions.purpose` 默认 `presentation`。网站编辑器显式传 `editing`；现有 A4 预览和图片准备显式传 `presentation`。参数解析集中到 layout 模块，UI 不自行计算间距。

现有 `density: compact | comfortable` 保留，表示用户选择的整体密度；purpose 表示排版用途。网站仍默认 compact。**同一 density 下，presentation 不增加编辑空间，editing 只适度增加可操作空间。** 两种用途都保留 TAB、歌词、指法图和技巧的真实避让约束，不能承诺所有小节均固定缩短某个百分比。

以下为首轮参数，单位均为 SVG 逻辑单位，不是 300 DPI 图片像素；实现后用实际页面与导出对照微调并记录最终值。

| 参数                             | 编辑排版             | 成品排版     | 说明                                                |
| -------------------------------- | -------------------- | ------------ | --------------------------------------------------- |
| 简谱相邻真实字形最小边缘间距     | 4                    | 2.5          | 目前为 6，复杂记号可以自然扩宽                      |
| 多音组项间距                     | 4                    | 2            | 目前为 6，按完整升降号/数字/附点边界避让            |
| 简谱四分音符理想起音间距基准     | 26                   | 20           | 独立简谱参数；最终取共享时间列全部约束的最大值      |
| 简谱八分/十六分/三十二分理想基准 | 24 / 22 / 20         | 18 / 16 / 15 | 避免短时值等距粗暴压缩；真实字形优先                |
| 普通空位显示宽度                 | 24 目标宽度          | 无编辑预算   | 编辑时不足时仍可退化为窄标记；不是无限扩宽          |
| 空位 start→end 最小预算          | 28，密集片段受限降级 | 无编辑预算   | 包含显示框及净空；Tuplet gap 的音乐时长仍保留       |
| 含简谱谱行内容最大拉伸倍数       | 1.15                 | 1.08         | 所有含简谱行都受限，不只末行；纯 TAB 行沿用现有规则 |
| 上八度点到数字墨迹的边缘间隙     | 1.8                  | 1.3          | 使用真实墨迹上缘，不能再叠加字形框保护 padding      |
| 多个上八度点的边缘间隙           | 1.2                  | 0.8          | 点半径仍 1.3，中心距为直径 + 间隙，确保不粘连       |
| Tie 实际弧高                     | 2.5～4               | 2～3.5       | 按跨度取值并设上下限，不能用固定巨大弧高            |
| Slur 实际弧高                    | 3.5～5.5             | 3～5         | 与 Tie 可辨识，跨长范围仍有上限                     |
| 曲线到音符/八度点边缘净空        | 2.5                  | 2            | 以实际路径和相关障碍物计算                          |
| 相邻标记层的边缘间隙             | 2.5                  | 2            | 取代固定 14 层步长，不压缩必要的标记高度            |
| TAB 正文到简谱最高图元的净空     | 6                    | 4            | 只改变简谱带，不全局缩小歌词和指法图间距            |

长音、延时横线和附点根据真实字形及延续时间点建立约束，不沿用“全音符一定是短音符若干倍列宽”的假设。其他记号净空仍是硬下限。

## 4. 横向布局实现细节

### 4.1 共享时间列仍是唯一坐标来源

在 `summarizeTimeGrid` 增加已解析的用途参数：TAB 沿用自己的音乐最小宽度；简谱使用独立 min/ideal 预算；字形净空按 lane 区分，不把歌词/指法图的边缘间隔一并改小。

同一个 tick 的 TAB 起音、简谱数字中心和其减时线继续使用 `xByTick`。前八后十六、混合时值和 Tuplet 只改变空间分配，不改变领域 tick 或实际时长。

`gap` 在两种用途都贡献真实时间节点和连音组结构；presentation 不给它附加录入框宽度。休止 `0` 和延时符 `-` 是真实内容，两种用途均保留音乐净空。

### 4.2 编辑空位预算提前参与断行

目前空位在谱行布局完成后才计算几何，无法反向保证框宽。拟复用 `planNumberedInputRanges`，在编辑用途的 spacing 阶段将真实空位 start/end 纳入联合时间节点，并给槽建立有限的宽度/碰撞约束；最终显示与命中仍消费 `measure.numberedInputSlots`。

启用范围由稳定输入决定：本小节有独立简谱内容/连音组，或 `paragraphEditing` 明确激活该小节。完全无简谱的其他谱行不因 purpose=editing 永久扩大。空小节碰巧落在已有简谱谱行时仍显示占位，但不通过“先算断行、反推空位、再重算断行”的循环扩大整首曲谱。

当前 `summarizeMeasureSpacingWidth` 仅在存在 numbered events 时走联合网格，实施时必须增加“明确激活的空简谱小节”分支，并将激活 measureId 从布局入口传入 spacing；否则空简谱行仍不会获得编辑空位预算。无真实音乐内容时采用当前 TAB 时间列预算作为基线，不能将 25% 上限建立在零宽度上。

以普通四分改八分为主要验收例：释放的 `[480,960)` 空位在通常密度下可显示 24 单位完整框；若密集三十二分、极短残片或复杂多音组约束导致明显增宽，则沿用窄标记，选中后显示当前输入框。不能为了让每一个细分空位都是完整框而把全行拉散。

为了使“有限扩宽”可执行，编辑空位使用软约束：先算仅音乐的固有内容宽度，再尝试完整空位约束；附加编辑预算不超过本小节音乐内容宽度的 25%。超出时按可用时间跨度优先保留普通较宽槽，细分槽退化为窄标记。此上限只限制新增编辑预算，不裁剪真实音乐，也不改变槽的完整时间窗口。最终 slot.width 由解出的时间坐标计算，显示与命中共用该宽度，渲染层不再次规划空位。

### 4.3 限制整行拉伸，避免收紧后再次被拉开

`resolveSystemTargetWidth` 对含真实简谱或明确激活简谱的小节所在行使用用途的拉伸上限：

```text
targetWidth = min(可用行宽, 固定宽度 + 固有音乐/编辑内容宽度 × 用途拉伸上限)
```

固定宽度包含 TAB 行头、拍号、小节边界等，不被比例缩放。固有宽度超出可用行宽时维持原超宽诊断，不硬压缩、裁切图形。断行采用对应用途固有宽度，因此成品通常可容纳更多小节；未铺满的谱行允许留右侧空白。若后续希望所有行右边界完全整齐，需要另行选择均衡断行策略，本轮以用户要求的紧凑优先。

保持现有“只从固有布局扩张”的契约：先用更紧凑的 profile 解出成品固有列宽，再分配最终宽度，不对编辑 layout 做整体 scaleX。这样不需要将既有 `layoutMeasureSpacing` 改成可任意压缩的算法。

## 5. 八度点与连音线实现细节

### 5.1 八度点紧贴真实数字

从数字 glyph 提取墨迹矩形（当前音乐文字 bounds 含保护 padding，需显式剥离，不能散落 `+2/-2` 魔法数）。上方第一点：

```text
dotCenterY = numeralInkTop - octaveGap - dotRadius
下一点 centerY 再减去 2 × dotRadius + dotStackGap
```

多音组按各自数字中心与墨迹上缘生成点。保持升降号在数字行内的已有修正；低音点继续避开减时线，不把上点公式直接用于下点。点移动后同步重算 itemBounds、frame.bounds 和 hitIndex，页面、hover 和 PNG 使用同一几何。

### 5.2 连线改用局部相关内容避让

移除全行 `top` 和固定 14 层步长。每个 Tie/Slur 从真实端点及其横向覆盖范围求障碍：数字、该范围内的八度点、Tuplet 标签、Fermata 和已安排连线。远处不相交的高音点不再影响当前连线。

Tie 端点继续使用具体 item 中心；Slur 使用 event 端点。先生成贴近端点的候选曲线，再按重叠的实际障碍边界向上做最小避让；采用确定的优先级和有界的候选检查，不让布局结果依赖 mark 数组偶然顺序。建议排序为关系类型、时间范围、稳定 ID；嵌套范围内侧先安排、外侧再避让。

弧高根据横向跨度在 profile 的范围内变化。对两端同高、对称三次曲线，控制点抬升量为“目标实际弧高 / 0.75”；bounds 按真实极值与线宽计算，不能把控制点高度全部当成可见高度。跨行按每段实际跨度求曲线，并保留续接端点；只在确有碰撞时增加高度/上移。

Tuplet 和 Fermata 共用局部障碍与层间净空逻辑，保留自己的图形尺寸。已经占用的上方层用真实 bounds + 间隙避让，不统一每层再加 14。渲染 bounds 与点击容错矩形分开，点击容错不参与谱行高度。

曲线、点和标记布局完成后，`system-content-layout.ts` 根据真实最高图元与目的 profile 回算数字基线、谱行 visualBounds 和分页；既不裁切上方曲线，也不留下旧包围框产生的空白。

## 6. 编辑、预览、导出与打印接入

| 场景             | purpose      | 产物与交互                                                          |
| ---------------- | ------------ | ------------------------------------------------------------------- |
| 主编辑谱面       | editing      | 独立 layout/hitIndex；适度空位空间，选区、hover、输入框仅来自此布局 |
| 当前 A4 图片预览 | presentation | 重新布局并分页，显示成品 scene；不复用编辑坐标                      |
| PNG / 多页 ZIP   | presentation | 直接消费预览已准备的同一 scene/pages，不再次改密度或布局            |
| 浏览器打印       | presentation | 打印专用静态分页 SVG，使用相同成品布局契约，隐藏编辑 SVG            |

沿用 `prepareScoreImages` 的字体等待、真实墨迹度量、已提交文档快照和取消机制；将准备成品 scene/pages 的职责命名为通用 presentation preparation，图片编码仍单独负责 Canvas/PNG。`ScoreImagePreview` 继续消费 prepared scene，避免一套预览算法、一套图片算法。

打印适配需要一个独立静态打印层，而不是在 `beforeprint` 临时切换 React 编辑状态。打印层只消费最新成品快照，不绑定 pointer handlers；`@media print` 隐藏编辑纸张、控件和弹窗，显示分页打印层。预览存在时也不能重复打印主谱面和弹窗。

打印快照和字体准备在文档/字体/密度/指法图偏好变化时更新，旧快照立即失效。显式打印入口须在快照就绪后调用原生打印；浏览器快捷打印无法等待异步任务，若最新快照未就绪只输出准备提示，不能打印旧版谱或编辑坐标。打印适配不增加 PDF、远程服务或新的曲谱导出格式。

两种 layout 共用字体度量缓存；purpose 只变几何。presentation 忽略 `paragraphEditing`，不预留纯编辑空行，不生成编辑 inputSlots/占位层。模式不写入 JSON、不影响 revision、历史和复制；返回编辑时继续按 event/item ID 和 tick 定位，不能复用成品坐标。

这是布局 API 的显式行为调整：依赖空位命中或编辑提示的现有测试和外部交互调用需传 `purpose: "editing"`；默认构建不再返回编辑空位。几何函数 `layoutNumbered` 使用同一份 profile 同时参与 spacing 估算和最终投影，避免估算采用成品间距、绘制却采用编辑间距。

## 7. 改动范围与顺序

1. `layout-types.ts`、`layout-constants.ts` 与布局入口：集中新增用途/profile，并贯穿 spacing、system、content。可新建 `numbered-layout-profile.ts` 管理简谱参数，避免继续扩大通用常量文件。
2. `time-grid-spacing.ts`、`measure-spacing.ts`、`system-layout.ts`：独立简谱音乐预算、编辑空位有限预算、全行拉伸上限；纯 TAB 沿用现有行为。
3. `numbered-notation-layout.ts`、`numbered-rhythm-layout.ts`、`numbered-mark-layout.ts`、`system-content-layout.ts`：统一墨迹边界，八度点、局部曲线、层间净空与最终行高。
4. 网站编辑入口显式 editing；成品准备与 A4 预览显式 presentation；抽出可复用分页 scene SVG，打印层使用同一投影。
5. 使用同一谱例展示“编辑 / 成品”对照后再调参数，保存成品 PNG 和编辑截图作为验收证据。

先解决音乐自身的横向拉伸、八度点和曲线；再接入编辑预算与成品输出，最终整体复验。领域模型、技巧独立管理和时值变更语义继续沿用当前实现。

## 8. 验收与风险控制

- 相同曲谱、字体和 density 下，同一小节 presentation 固有宽度不大于 editing；实际音符与框不重叠，成品不再为了铺满行宽而明显拉散。
- 四分 TAB + 简谱前八后十六，两种用途分别满足首音数字中心同 x；事件 tick、Tuplet 实际时值、ID 与标记关系完全一致。
- 编辑四分变八分，在普通四分拍场景后方显示完整半拍框；密集三十二分/连音组不因要求所有空位完整框而被夸张拉开；点击仍得到完整准确的时间窗。
- `1' / 1'' / 1'''`、升降号与八度点组合紧凑但不粘连；三层减时线与下八度点保持必要净空。
- Tie、Slur 的短/长跨度、嵌套、多音组指定 item、跨小节与跨行均不碰数字和点；范围外的三高音点不再抬高局部连线。
- Fermata、Tuplet 标签与连线同时出现时局部避让稳定，命中 padding 不扩大谱行高度。
- 预览与实际下载 PNG 的每页 system 分组、坐标和页数一致；无占位、hover、选区和纯编辑空行。
- 打印只含一份成品分页谱面；文档替换、字体失效或未应用草稿时不输出旧快照。
- 纯 TAB、歌词多段、复杂指法图和真实吉他技巧不发生非预期挤压。修改几何预期的旧测试必须说明对应规则，不批量重录快照掩盖碰撞。

核心测试验证 profile 与共享坐标、有限空位预算和局部几何；网站集成测试验证快照模式及 preview/PNG/print 一致；实际浏览器对照验证字体与观感。实施后执行全量 test/type-check/lint/build。

首轮参数是可调起点。TAB 品位、歌词、和弦指法图或复杂技巧可能成为主导宽度，此时简谱不能单独继续挤近；应保留双谱对齐和音乐可读性。该取舍应在对照图里展示，而非承诺每一行都减少固定比例。

- `purpose` 已贯穿共享时间列、小节宽度、整行拉伸、数字组、八度点和局部标记布局。成品为核心默认，编辑页面显式选择 editing。
- 表中短时值基准与净空均已采用；comfortable 的简谱时值基准额外乘 1.25，compact 使用表中数值。多音组以数字墨迹宽度为基础，编辑最小项宽 10，成品最小项宽 8，保护 padding 不重复叠加。
- 曲线目标弧高采用 `min(上限, 下限 + 跨度 × 0.02)`，真实 bounds 包含线宽；按相关墨迹、点和已布局标记局部避让。Tuplet/Fermata 保留自身图形大小。
- `prepareScorePresentation` 是成品准备入口，原 `prepareScoreImages` 保留兼容别名。预览和打印共用 `ScorePresentationPage`，PNG 消费同一 scene/pages。
- 当前沿用浏览器快捷打印；打印专用层提前异步准备，未新增打印按钮。快照未就绪或失败时打印提示，旧快照不会冒充最新曲谱。物理打印机输出不属于本轮已验证内容。
- 原空位/空行编辑测试改为显式 editing，其他领域与音乐结构行为不变。
