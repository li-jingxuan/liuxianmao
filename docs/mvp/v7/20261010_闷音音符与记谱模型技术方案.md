# MVP v7.1-A 闷音音符与首批记谱模型技术方案

2026-10-10。用户授权进入下阶段，本切片实施 G08；G09/G10/G15/G12 按既定顺序后续实施。本方案先冻结表示、加载策略和组合规则，随后按此次授权实施。

## 1. 模型和版本

- 引入 `ILXMFret = number | "x"`；数字仍为整数 0–24。Note 的 `fret: "x"` 表示一次无确定音高的闷音/打击音，保留 Note ID、弦号、Beat 时值及全部选区/历史语义。不得用缺失 Note、rest、数值 -1 或和弦图禁奏状态替代。
- 同 Beat 可包含数字与 x，共享时值；不加入多声部或逐 Note 时值。
- schemaVersion 从 3 升为 4；正式 schema/loader 只接受 4，不自动升级外部 3，也不把新文档降级到 3。旧纯数值数据需由宿主确认并升级版本后加载。本仓库内置谱例由源码明确改为 4，音乐内容和业务 ID 不变；版本限制测试覆盖旧 3 拒绝与当前数值文档无变化加载。
- loader、schema、命令校验共享品位集合；仅类型变更或宽泛字符串校验不合格。和弦图原有 x 表示禁奏，保持独立校验。

## 2. 技巧规则

| 目标                                          | 支持                                                                                                                              |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| x 上的击弦/勾弦/滑音/延音线                   | 不支持；两端必须是数值品位，x 不能作为音高相同的延音目标，也不能跳过 x 去连接后面的音。                                           |
| x 上的推弦/揉弦/自然泛音/人工泛音/点弦/颤音奏 | 不支持；当前模型无法表达该 x 的具体音高/触弦位置或有音高的点弦。                                                                  |
| x 的拨片方向                                  | 支持，继续遵守恰好一个 Note 的既有规则。                                                                                          |
| 含 x 的扫弦/琶音与 P.M./Let Ring 范围         | 支持既有 Beat/范围表达；x 是真实攻击，不变成 rest，也不取消仍合法的范围。Let Ring 可覆盖混合乐句，不赋予 x 新音高或新的发声长度。 |

数字改 x 保留原 Note ID；不再成立的技巧由既有 prune 规则原子清理，G05 effects 报告。x 改回数字不自动恢复已清理的技巧，撤销可完整恢复原状态。新增/修改非法技巧由核心明确拒绝，schema 输入也经语义校验拒绝。

## 3. 输入与展示

- 谱面键盘 X/x 原子设置选区内各弦单元格，取消等待中的 1/2 数字草稿；工具栏提供“设置为闷音音符 x”。批量、空格新建、rest 转 notes、删除、撤销、重做和完整小节复制沿用现有命令。
- Ctrl/Cmd/Alt 组合键、输入法组合中与歌词/和弦文本编辑不被 x 快捷键接管。键盘解析为纯函数，页面只执行命令。
- x 与数字共用核心 Note layout、宽度、halo 和命中区域；显示小写 x，不增加新的叠加 SVG 装饰。连音括号、连梁、节奏容量和当前紧凑技巧尺寸保持。
- 保留原 14 小节技巧/时值测试谱；增加独立 x 混合谱测试入口，覆盖纯 x、数字/x 和弦、混合附点时值、休止、三连音及兼容技巧。

## 4. 后续切片冻结的首批边界

这些决策用于后续技术方案，不能在本次验收中计为已实现：

- G09：六弦标准/Drop D/自定义调弦，显式校验 pitch 与 MIDI 一致；capo 0–12、相对 capo 品位仍 0–24，改变调弦/capo 保留数字和 x，不悄悄转调。谱面小节编号、必要速度与段落标记只做记谱。新增必需字段另作显式版本升级，继续拒绝静默迁移。
- G10：先多小节复制/粘贴，整小节携带自己的拍号/连音/文本与完整技巧；之后才做 Beat 插入/覆盖，复用领域映射与影响说明，不推到跨小节。
- G15：首批同小节拆分/合并；容量精确相等，合并须内容兼容。拒绝部分连音组操作，文本和技巧重定位规则先定，再支撑 Beat 粘贴；暂不自动跨小节推移。
- G12：本版首批半音推弦，保持现有全音；预推/回落、倚音、重音及歌词延长线留待独立用例审查，本版不承诺全部实现。泛音与 x 不组合，本切片不扩展泛音触弦模型。

## 5. 退出条件

- 正式 schema/loader 接受 x 和原数值谱，拒绝旧版本及非法字符串/非整数/越界。
- 单音/矩形命令、Note ID 保留、混合内容、时值闭合、技巧拒绝/清理、影响提示、复制与历史有回归测试。
- 两种排版密度/窄宽断行的 x layout 和命中通过；规范混合谱可由 loader 接受。
- 浏览器验证数字/x 切换、草稿取消、批量、工具栏、撤销重做与技巧边界；不把真实 IME、长谱性能和打印/PDF 声称为已验收。
- 工程 test/type/lint/build/diff 检查通过。生产构建与读取 .next/types 的类型检查顺序执行，避免临时生成文件互相覆盖。
