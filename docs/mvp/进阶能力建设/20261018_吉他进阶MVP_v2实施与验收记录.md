# 吉他进阶 MVP v2 实施与验收记录

日期：2026-10-18。基线：`1fdb71f`；本轮实现位于当前工作区，尚未提交或合入 `codex/ui`。

状态：v2 浏览器收尾验收完成；主要学习流程、最终布局、编辑器恢复及确认清空均已复验，完整自动化和工程检查通过。

技术依据：[v2 完整理论与练习技术方案](./20261018_吉他进阶MVP_v2完整理论与练习技术方案.md)。

## 1. 实现范围

- 四个模块全部开放，新增模块详情和复习清单路由。
- 八节理论，每节包含目标、三个知识卡片、谱例或指板、易错点和关联练习。
- 六个固定练习：三个单选、一个多选、一个排序、一个指板目标选择。
- 七份独立短教学谱例：四分、八分、十六分、三连音、切分、和弦、技巧；全部通过正式 loader 和布局链路。
- 统一评分、结构化答案、提交锁定、重做、错误反馈与相关理论链接。
- 全站共用 14 节点学习序列，支持跨模块、继续学习和全部完成状态。
- 进度 schema v2、v1 单向迁移、原文保护、写入重试、错题历史与已复习状态。
- 内容区独立滚动、窄窗口侧栏与清空入口；清空及刷新重读使用应用内确认框。

考试、成绩、独立学习进度和错题页面仍留待 R5–R6。本轮没有服务端、录音、云端同步，也未修改曲谱 schema 或编辑器状态模型。

主要改动位于 `apps/website/`：

| 目录 | 实施内容 |

## 6. 收尾验收

旧构建的原生确认框导致的浏览器阻塞通过新建本地 origin `127.0.0.1:39572` 隔离；没有操作用户 Chrome 中的账号页或其他标签。最终构建的应用内清空弹窗先验证“取消”不改变 1/14 测试进度，再经用户明确授权点击“清除并重新开始”。页面归零后刷新，仍显示 0/14，旧记录没有从 v1 key 复活。

在同一隔离 origin 上完成最终布局抽查：680px 下窄侧栏清空图标可见、理论内容没有整页横向溢出；1024×500 下正文独立滚动，返回路径和标题保持在内容视口顶部，底部导航动作仍可访问。

返回 `/` 后编辑器成功恢复既有测试谱；将谱名临时修改并应用，再恢复原谱名并刷新，确认页面和属性面板均恢复为 `MVP v7.2 简谱测试谱`。这次操作只发生在隔离 origin，没有导出或覆盖用户曲谱文件。

浏览器内写入异常注入未执行，避免增加临时产品调试接口；写失败保留内存、重试最新快照由 store 自动化测试覆盖。本项风险和验证边界已记录，不阻碍本阶段浏览器收尾验收。v2 浏览器收尾验收完成。
