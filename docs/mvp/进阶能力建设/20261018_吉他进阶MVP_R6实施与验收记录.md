状态：已完成一轮方案复审并开始实施。核心业务、页面路由和自动化验证已完成；完整浏览器考试提交链路留待 R6 收尾验收。

## 方案复审结论

复审确认 R6 不能直接把当前 R5 评分函数用于所有历史答卷，也不能用单一题目 ID 表示不同考试版本的复习状态。因此方案已补充并实施以下约束：

- 结果和错题使用提交答卷的冻结快照；当前题库不能覆盖历史成绩。
- R6 当前只接受已注册的 `guitar-advanced-final-v1`；未来考试版本必须先提供版本化校验器和评分器。
- 考试复习 key 使用 `examId:questionId`，复习记录必须引用已提交、该题确实答错的 attempt。
- 练习错题继续使用最近一次答案，页面不假装拥有已被后续重做覆盖的旧答案。
- 低分模块提示是透明的排序结果，不自动生成个性化课程路径。
- v4 读取顺序为 v4→v3→v2→v1；高优先级记录损坏时读保护，清空移除四个版本 key。

## 已实施内容

- 新增 v4 进度模型、`examQuestionReviews`、v3/v2/v1 到 v4 的迁移和 v4 存储校验。
- 新增成绩历史、最好/最近成绩、阶段状态、模块汇总和考试/练习错题 selector。
- 新增考试错题复习标记 store 动作，校验 submitted attempt、错误题目和版本化 key，重复操作幂等。
- 新增 `/guitar-advanced/exam/result/[attemptId]` 独立结果页，并将 R5 提交后的结果入口接入该页面。
- 新增 `/guitar-advanced/progress` 学习进度页，替换侧栏“学习进度即将开放”占位入口。
- 结果页展示总分、通过状态、提交时间、考试用时、四模块得分、成绩历史、低分模块提示和本次错题。
- 进度页展示总体/模块进度、阶段状态、考试记录、练习错题和考试错题；支持理论、练习和再次考试入口。
- 新增空状态、无效结果地址、写入失败重试、复习幂等和窄窗口基础布局。
