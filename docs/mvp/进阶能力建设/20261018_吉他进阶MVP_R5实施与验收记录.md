状态：R5 综合考试已完成实现与工程检查。考试记录保存在当前浏览器，不提供服务端同步或认证凭证。

## 实施内容

- 新增固定考试 `guitar-advanced-final-v1`：12 道稳定 ID 题目，四模块各 3 题、25 分，单题权重为 9/8/8，总分 100、80 分及格。开始考试时检查题数、顺序、权重、唯一 ID、课程 ID 冲突、理论引用和标准答案；不符合契约时不创建答卷。
- 新增考试入口与答题路由。入口根据四模块理论和练习完成情况解锁，并逐项列出未完成内容；答题支持题号导航、答题进度、暂存退出和未答题确认。
- 答卷开始时保存完整题目快照；草稿可刷新恢复，提交后锁定。结果页展示总分、通过状态和模块分数；重复提交返回既有结果，不创建重复记录。
- 进度存储升级到 v3。保留 v1/v2 旧 key，按 v3→v2→v1 顺序恢复；v2 与 v1 迁移会保留现有学习记录。发现损坏或版本/key 不一致时进入读保护，不回退覆盖原记录。
- 答题和提交写入失败时保留当前内存状态并提供重试；保存失败的草稿不会从入口误导航，成绩写入失败可在结果页重试。清空进度同时移除新旧存储 key。
- 考试题继续复用已有评分和输入组件，不写入日常练习结果、错题或复习状态；题目素材不可用时禁用提交。
