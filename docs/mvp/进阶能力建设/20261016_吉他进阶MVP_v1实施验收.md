## 2. 实施时发现并修复的问题

首次浏览器流程发现 React 子页面的 `lastVisited` effect 可能先于学习布局的 hydrate effect 执行。如果该写操作先将默认空状态写入 `localStorage`，就会覆盖已有学习进度。

修复方式：store 的理论完成、练习提交、最近访问、重做和清空动作统一先执行幂等 `hydrateOnce()`，确认旧记录读入后才更新和持久化。回归测试专门模拟“已有完成记录 + 子页面先写最近访问”的顺序，确认旧记录不再被空状态覆盖。损坏或无法读取的存储会保留提示，避免未确认覆盖；用户确认清空后才恢复可写状态。

教学谱例初版曾复用整份 8 小节长谱，缩放后在理论区域过小。现改由 `score-example-adapter.ts` 从已有合法示例中提取八分音符小节，经过正式 loader 校验后以只读布局渲染；不创建编辑会话、不改曲谱 schema。

练习选项采用原生 Radio input，以获得标准键盘和辅助技术语义；重新练习会清除最近一次作答结果，但保留“该练习已完成”记录。

## 3. 验收结果

- 专属学习模块测试：13 项通过，覆盖内容引用、谱例 loader、评分、进度、存储恢复及“写动作早于布局 hydrate”的回归场景。
- 网站全量测试：120 项通过。
- `packages/lxm-editor` 核心测试：525 项通过。
- 网站 `lint`：通过。
- 网站 `type-check`：通过。
- Next.js 生产构建：通过，生成 `/guitar-advanced`、理论页和练习页路由。
- Chrome 生产预览：验证理论完成、练习答错反馈、正确答案反馈、重做、总览进度变化和整页刷新后 2/2 完成状态恢复；原生 radio 方向键可以切换选项。
- 窄窗口：1024px 与 680px 视口完成布局抽查；侧栏收纳，内容单列，无横向溢出。

浏览器验收数据保存在测试用的当前浏览器本地存储中；这不改变产品边界，用户记录仍只承诺当前浏览器。
