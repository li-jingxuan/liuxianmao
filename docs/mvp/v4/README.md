# MVP v4：范围输入与安全历史

本目录定义六线谱编辑器 MVP v4 的技术方案与实施边界。该版本把 v3 的单点输入扩展为跨弦、跨 Beat 的 TAB 单元格矩形选择，并补齐批量品位编辑、键盘导航和撤销重做。

## 范围

- 连续 Beat × 连续弦的二维 TAB 单元格矩形选区。
- 点击、Shift+点击、指针拖动和 Shift+方向键扩展选区。
- 方向键在弦、Beat 和小节之间导航。
- 对选区一次性设置相同品位或删除选中音符。
- 保留 v3 的单 Beat rhythm、附点、rest 编辑。
- 保留新增、复制、删除整个小节；不复制部分 Beat。
- 撤销、重做、no-op 跳过及常用历史快捷键。
- 所有批量编辑继续经过核心领域命令、结构校验和语义校验。

## 非范围

- Beat 或乐句的复制、剪切、粘贴及系统剪贴板协议。
- 多 Beat 的批量 rhythm、附点或 rest 编辑。
- 非连续选择、跨轨道选择和多声部选择。
- 批量复制或粘贴多个小节。
- 和弦标记、歌词、技巧和连音组的选区编辑。
- 历史持久化、保存后恢复历史和多人协作历史。
- 移动端手势、响应式布局和分页打印。

Beat/乐句剪贴板作为候选 MVP v4.1，仅在实际试用确认“反复手动重录部分小节”是主要效率瓶颈后进入实施。

完整版本边界见 [MVP 版本路线图](../mvp-version-roadmap.md)。
