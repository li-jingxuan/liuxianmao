# MVP v4：高频编辑效率

本目录定义六线谱编辑器 MVP v4 的技术方案与实施边界。该版本把 v3 的单点编辑扩展为连续 Beat 选择、键盘导航、剪贴板和撤销重做。

| 文档                                     | 用途                                                     |
| ---------------------------------------- | -------------------------------------------------------- |
| [技术实现方案](./technical-design.md)    | 定义选区、导航、批量命令、剪贴板、历史和页面交互契约。   |
| [详细实施计划](./implementation-plan.md) | 按可独立验收的步骤给出实现顺序、测试范围和版本完成标准。 |

## 范围

- 单 Beat 选择、连续范围选择、跨小节选择和当前轨道全选。
- 在弦、Beat 和小节之间进行键盘导航，并使用 Shift 扩展选区。
- 复制、剪切、粘贴和范围删除。
- 撤销、重做、历史合并及常用桌面快捷键。
- 所有批量编辑继续经过核心领域命令、结构校验和语义校验。

## 非范围

- 非连续选择、二维框选、跨轨道选择和多声部选择。
- 小节本体的批量复制粘贴、和弦标记、歌词、技巧和连音组剪贴板。
- 系统剪贴板中的通用文本 TAB 导入。
- 历史持久化、保存后恢复历史和多人协作历史。
- 移动端手势、响应式布局和分页打印。

完整版本边界见 [MVP 版本路线图](../mvp-version-roadmap.md)。
