# 谱面统一正常字重

2026-10-10。用户明确要求谱面文字与数字全部采用 400 字重。

和弦名称的布局及测量请求从 600 调为 400；品位数字、TAB 和拍号从 700 调为 400。谱面 SVG 根节点明确设置 400，歌词、指法图数字、连音与技巧文字沿用正常字重。字体、字号与遮挡弦线的白色描边保持。侧栏和工具栏的界面标题不属于谱面文本。

验证：字体度量与渲染使用相同字重，运行回归、类型、lint、生产构建并检查浏览器实际计算字重。

## 验收

本地开发页面 1440×900 下检查谱面 SVG 全部 167 个 text 节点，computed font-weight 均为 400，无其他字重。截图确认名称、品位数字、TAB、拍号、歌词、技巧与完整连音标注正常显示。核心 343 项与网站 36 项测试通过，类型检查、lint、生产构建及 diff 空白检查通过；本轮未执行系统打印预览。
