# 和弦上方动态占位与同行对齐方案

日期：2026-10-10。用户已确认分析建议并明确要求实施本轮优化。

## 问题与目标

当前和弦下缘以小节顶部定位，第一弦还有 28 的固定偏移，叠加 8 的净空后形成约 36 的留白。技巧虽然参与避让，但整行最高技巧会抬高所有和弦，即使横向没有重叠。

改为从第一弦出发，计算可见内容所需空间。同一 system 采用最严格的位置约束，名称基线和网格顶线继续对齐；不同品格数的图允许底边不同。各 system 独立计算。

## 算法与边界

1. 六线谱、节奏和技巧完成投影后，生成共用网格偏移的和弦块，并定位到各 Beat 的 X 坐标。
2. 收集最终可见品位文字（含描边）和技巧 visualBounds，仅保留上缘高于第一弦的内容；下方节奏与歌词不占上方空间。
3. 每个和弦的自然位置为其下缘距第一弦 8 个逻辑单位。对横向重叠或距离小于 4 的障碍，要求和弦下缘高于障碍上缘至少 8。
4. 所有和弦的位置约束取最小公共基线，等价于取各小节需要上移量的最大值。保留同一行名称和网格顶线对齐，不做逐个和弦浮动。
5. 由最终和弦、技巧、正文、歌词边界继续计算高度与下一行位置；命中区域消费同一份最终几何。

采用完整和弦块与技巧的保守包围框，保证安全净空；不增加领域数据字段，也不在渲染层用 CSS 修改几何。沿用现有字体度量与技巧边界精度。

## 验证

覆盖无技巧收紧、第一弦数字与描边、重叠技巧占位、远处技巧不抬高和弦、同行多小节对齐、不同品格高度、纯名称、窄宽度换行、最终命中与 system 边界。运行核心及网站测试、类型检查、lint 与构建。浏览器和打印验证的实际执行范围另行记录。

## 实施与验证结果

已在核心内容布局中实现公共基线约束；品位沿用含描边的几何，技巧使用最终 visualBounds。横向位置先确定，公共垂直位置再统一应用，渲染与命中均使用最终几何。

新增 5 项动态占位回归，覆盖无上方内容时 8 的净空、第一弦数字、重叠与远处技巧、删除技巧恢复、不同品格高度、纯名称、窄宽度换行及每行独立占位。既有文本回归改为检查实际二维避让，取消“所有和弦必须高于小节顶部及所有远处技巧”的旧断言。

核心 354 项、网站 36 项测试通过；类型检查、lint、生产构建及 diff 空白检查通过。

本地开发页面在 1280×720 视口核对：首行 Am/C/F/G 名称基线均为 13、网格顶线均为 25、网格底线均约为 55.6。截图确认推弦、Let Ring 与第一弦内容没有重叠。无标记及远处技巧场景由确定性几何回归验证；系统打印预览与其他浏览器未执行。
