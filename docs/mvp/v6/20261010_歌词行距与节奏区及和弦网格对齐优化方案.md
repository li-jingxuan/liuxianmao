# MVP v6 歌词行距、节奏区与和弦网格对齐优化方案

> 日期：2026-10-10。用户已审阅聊天中的分析，并明确授权“OK，改吧”。本方案落实该次授权；不扩大到字号、节奏语义或谱行间距的重设计。

## 1. 原因与目标

当前真实字体页面歌词四段基线间隔 29，文字 bounds 高约 19。节奏主梁位置固定在第六弦下方 38。Am、C、F 的名称基线同为 16，但指法网格顶线分别为 41、41、27.5：现有指法图按含空弦/禁奏标记的整体包围框对齐，导致无顶部标记的 F 网格偏高。

目标：歌词段间距约 24、字体不缩小；节奏区按实际连梁/符尾/附点所需净空收紧，同行统一基线；和弦按网格顶线及六弦中心轴对齐，名称沿用共同基线。

## 2. 实现约束

### 2.1 歌词与正文下缘

将段间 gap 从共享的 8 分离为独立 3，行高继续使用实际字体最大 ascent/descent，并保留现有 15/6 的保守下限：通常为 15 + 6 + 3 = 24。实际字形更高时自动扩行，不强制固定高度。

第一段使用节奏、休止、连音标注、技巧的实际内容下缘，再加一次 8 的净空。小节 height 含原有安全 padding，不能再当作可见图形下缘叠加一遍间隔。连音数字采用字号对应的保守 descent，括号端点及线宽也参与边界；保持数字和完整括号。保留小节 padded height 的兼容契约，歌词位置测试改为检查实际图形下缘。

### 2.2 自适应节奏基线

单小节先按原有分组算法生成连梁与孤立符尾，用最终图形求第六弦到主梁的最小距离：

- 基础符干终点净空 22，避免普通时值过短。
- 最上层连梁墨迹上缘与第六弦至少 14；按实际连梁层数、层距 5 和厚度 3 计算。
- 附点上缘至少留 8；孤立符尾上缘至少留 6。符尾使用本仓库 Bravura 字形轮廓的保守 ascent，不能只用连梁层数猜测旗帜高度。

独立小节调用使用自己的计算值；整谱在分行后取同行最大所需距离，统一调整所有小节的主梁、符干终点、旗帜及附点，再重算连音与高度。不改变实际音符锚点、品位、节奏、连梁分组或时值。

18 号 Bravura 三种向下符尾的 raster 轮廓 ascent 约 14.55、14.64、14.62，统一保守取 15；既有下缘计算保持。无附加约束时主梁距离通常由 38 收到 22，三层连梁至少 25.5。混合谱行采用最大值，同一行不逐拍上下跳动。

### 2.3 和弦网格

网格本地原点为顶线 y=0，六弦中心 x=22.5。水平平移固定使用中心轴，不再使用包含高品位标签、横按等附件的整体 bbox 中心。

每行名称共享基线；在其下按共同名称 descent、5 的间距及公共空弦/禁奏标记带，确定统一网格顶线。无标记的 F 同样保留标记带。真实 bbox 继续完整包含标记、高品位标签、横按及网格，仅用于列宽、避让、命中和高度。

公共标记测量请求包含 ○ 与 ×，避免 F 单独出现时使用一套不同的估算规则。全局隐藏指法图时不保留图或标记带的占位。

## 3. 修改范围

核心 `music-text-layout.ts`、`music-text-metrics.ts`、`system-content-layout.ts` 处理网格锚点与歌词行距；`duration-beam-layout.ts` 提供基线规划/统一平移；`system-layout.ts` 在连音与高度计算前对齐同行节奏；`rhythm-bounds.ts` 统一实际内容下缘。网站沿用最终核心几何，歌词高亮与命中随重排更新。

关键逻辑补中文注释。乐谱 schema、领域命令、草稿、全局开关和撤销历史不变。

## 4. 验证

增加真实预设 Am/C/F、高品位、附件不对称、全局隐藏、真实字体与估算的网格对齐验证；检查四段歌词行距、异常高字形扩行、实际节奏/连音下缘净空；覆盖不同连梁层数、孤立旗帜、附点、同行统一基线、休止和 Y 平移。

运行核心与网站测试、type-check、lint、build、diff 检查。浏览器核对实际字体、首行 Am/C/F 网格、歌词高亮和密度/窗口变化。系统打印预览与输入法候选未实际执行时继续标记待人工验收。完成后在本文件补实际数值与结果。

## 5. 实施结果与验收（2026-10-10）

已按上述方案实施。节奏区新增同行对齐步骤，先计算实际图形净空，再统一基线并重建连音布局。保留符干的音符连接点、谱内延续线和全部连音数字/括号。

- 默认四分时值主梁距离由 38 缩至 22；三层实际连梁需要 25.5。实际页面第一行混合时值按同行最大需求对齐。
- 实际字体页面四段歌词基线为 279.9、303.9、327.9、351.9，间隔均为 24（原为 29）。第一段按可见图形下缘留 8 的净空。
- 实际字体页面首行 Am、C、F 名称基线均为 16，网格顶线均为 42；每个网格六弦中心轴与所属 Beat/名称中心一致。
- 自动测试覆盖高品位 F、附件导致的非对称外框、较高字形扩大行距、三层连梁、孤立符尾、附点与同行统一基线；既有休止、连音括号、Y 平移和隐藏指法图测试继续通过。
- 浏览器在 1440×900 和 1100×800 核对布局、点击歌词及高亮位置；切换舒适密度和全局隐藏指法图后重排正常，隐藏后歌词间隔仍为 24。浏览器检查使用本地开发服务，生产版本完成构建检查。

验证结果：核心 332 项、网站 36 项测试全部通过；`pnpm type-check`、`pnpm lint`、`pnpm build`、`git diff --check` 通过。打印预览、真实 200% 缩放和输入法候选字操作未在本轮执行。
