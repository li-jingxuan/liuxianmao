# 和弦网格拍点左对齐与按需横向留白

2026-10-10，按已确认的排版建议实施。

## 排版规则

指法网格最左侧弦线对齐 beat 拍点，名称继续在网格上方居中；仅显示名称时沿用拍点居中。名称基线到网格顶线固定为 12 个谱面单位，不再按字形自动增加，保持同行网格顶线一致（按用户最新要求从 18 调整为 12）。

孤立和弦允许覆盖后续无和弦的拍点上方空白，不为每一个无和弦拍点预留指法图宽度。按实际名称、网格和附件的联合边界检查和弦碰撞，只在两块和弦之间空间不足时补足，至少留 4 个单位。歌词继续独立计算自己的间距。

同一 system 跨小节也检查碰撞；仅在 system 行尾为和弦联合边界保留净空。断行前使用完整候选行的间距结果，正式布局复用该结果，避免断行与渲染不一致。所有扩宽属于布局投影，不写入领域文档。

## 验证

覆盖孤立和弦不挤宽下一拍、非相邻和弦和跨小节和弦不重叠、行尾边界、网格左对齐、名称居中及固定 12 的垂直间距。运行核心回归与类型检查，验证网站消费布局仍兼容。

## 实施验收

已实现上述排版规则。核心 349 项、网站 36 项测试通过，核心与网站类型检查、核心 lint、网站生产构建及 diff 空白检查通过。

本地开发页面核对全部 8 个和弦：名称字号仍为 10、网格左边对齐拍点、名称位于网格中心，名称基线到网格顶线均为 18。截图覆盖常见和弦和紧凑谱行；未执行系统打印预览验收。

## 间距微调

18 项相关回归测试、核心类型检查及 lint 通过。开发页面全部 8 个和弦的实际间距均为 12，示例名称与顶部标记未发生视觉重叠。

### 调用兼容性修复

发现旧间距函数定义与无参数调用混用时，会在 `symbols.map` 处抛出异常。修复为保留原参数契约并提供默认值，system 调用明确传入 symbols 与 metrics；结果仍固定为 12。相关回归可复现修复前的报错，修复后页面正常显示，8 个和弦间距均为 12。
