# 和弦名称间距与谱行间距优化方案

日期：2026-10-10。用户已确认聊天中的建议，授权实施。

## 调整范围

- 名称下缘到空弦/禁奏标记带的间距从 5 改为 2；名称 descent 下限从 6 改为 3，较高字形按实际轮廓扩展。同行所有指法网格继续共用顶线和中心轴，标记带完整保留。
- system 默认外框间距从 36 改为 20，调用方显式传入 systemGapY 仍优先。
- 最后一段歌词底部留白从 8 改为独立常量 4。正文到歌词的净空仍为 8，歌词段间距仍为 24（异常高字形自动扩行）。
- 内容边界继续包含和弦、技巧、歌词、节奏与完整连音数字/括号，依内容高度排列，不固定 system 总高度。

## 验证计划

检查名称与顶部标记净空及高字形自适应，验证 system 默认及显式间距、歌词底部留白；运行测试、类型、lint、生产构建，浏览器核对真实字体和窄窗口。截图与实际结果补在本文中。
