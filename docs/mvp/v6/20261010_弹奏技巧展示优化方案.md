# MVP v6 弹奏技巧展示优化方案

> 日期：2026-10-10。状态：已实施；工程检查与桌面浏览器检查通过，系统打印预览尚未人工验收。

## 1. 范围与展示规则

本次独立于 EditorShell 职责重构，优化核心技巧几何并生成可编辑测试谱。保留文档 schema、技巧引用、领域规则与现有扫弦/琶音替代品位的设计。

| 技巧                          | 本次调整                                                     |
| ----------------------------- | ------------------------------------------------------------ |
| 推弦                          | 从品位完整右缘向右上方弯起，箭头朝上，Full 在箭头上方留净空  |
| 揉弦                          | 从品位右缘附近向右展开，长度适应拍点空间，不暗示延迟起奏     |
| Trill                         | tr 与辅助品位标在起音上方，波浪线从标签右缘开始              |
| 滑音                          | 上滑为 /，下滑为反向斜线；真实两端避开品位，跨行片段保持方向 |
| 自然泛音                      | 品位以 <n> 单次显示，沿用原位置和字号，不重复叠画            |
| 人工泛音                      | 保留普通品位，上方标 A.H.，不编造缺失的触弦品位              |
| 拨片方向                      | 下拨使用门形图元，上拨使用 V 图元，保持拍点对齐              |
| P.M./Let Ring                 | 短范围不输出反向虚线；范围起点文字与结束钩保留               |
| H/P、Tie、Tapping、扫弦、琶音 | 保留已有语义与目标对齐                                       |

## 2. 布局与空间

新增技巧宽度贡献计算，按轨道技巧与音符建立拍点所需空间索引，在 system 断行前扩宽受影响列。只在技巧需要的宽度大于原节奏列宽时扩宽，兼容歌词与和弦间距，不更改节奏 tick。

单音技巧用品位文字及描边边界决定起点与最小延伸宽度；同一音符多个技巧取最严格宽度，不重复累加。范围标签最小宽度分配到起始拍；跨小节范围延续原分段。保守预留图元、文字和 marker 外延，使行末技巧完整落在小节空间内。

最终 visual/collision/hit bounds 从同一组图元计算，继续复用二维向上避碰；纵向锚点保持随目标弦变化。自然泛音在建立锚点时使用完整 `<品位>` 边界，最终视觉投影隐藏基础数字，由技巧 segment 渲染一次并保留命中关系；领域音符和 ID 保持不变，音符导航和历史仍基于领域数据。

## 3. 测试谱与使用

生成独立 JSON 规范谱例，包含全部 16 种技巧、全/二分/四分/八分/十六分/三十二分时值、单/双附点、休止与三连音。加入同音推弦+揉弦、两位品位、密集短音、行末技巧和跨小节连接场景。

网站增加独立 `/technique-test` 测试页，复用现有 EditorShell。进入测试页通过正式 loader 载入谱例并清空该测试会话历史；离开时恢复进入前的编辑器状态。首页示例保持原样，不用测试谱替代用户的默认乐谱。页面提供谱例用途说明、返回入口及恢复测试谱入口；刷新可重新开始。

## 4. 验证与交付

先增加覆盖实际问题的核心回归测试，再修改布局。验证右侧起点、上指箭头、标签净空、滑音方向、泛音单次绘制、范围线方向、行末 containment、命中与不可变性；更新原先固定水平滑音和泛音重复投影的测试契约。

运行核心和网站测试、类型检查、lint、生产构建及 diff 检查。浏览器检查 compact/comfortable、密集短音、跨行、技巧选中和撤销；系统打印预览仍单独记录验证边界。

参考：[Guitar Pro 技巧说明](https://www.guitar-pro.com/docs/gp8/score/note/symbols/effects)、[揉弦说明](https://www.guitar-pro.com/docs/gp8/playeffects/touch-effects/vibrato)、[泛音说明](https://www.guitar-pro.com/docs/gp8/playeffects/harmonics-percussive-effects/harmonics)。具体间距为本项目排版决策。

## 6. 技巧尺寸进一步收紧（2026-10-10）

按用户提出的紧凑展示需求，在既有展示规则上收紧局部图形；不改领域数据与技巧起点语义。

- 技巧文字 10 → 9px；自然泛音和普通品位仍为 12px。
- 揉弦/Trill 波浪长度 18–28 → 12–20px，振幅 2 → 1.5px；尾段控制点仍限制在终点内。
- 推弦水平展开 12 → 10px、抬升 16 → 12px，Full 到终点距离 10 → 9px；同音揉弦始终共用推弦终点高度。
- 箭头 6 → 4.5px；H/P/Tie 弧高 8 → 6px；拨片符号宽 8 → 6px、高 6 → 5px。
- 技巧文字到波浪/虚线间距 4 → 3px；推弦叠加揉弦的尾部间隔保留 6px（包含白描边和避碰净空）；避碰 lane 步长 14 → 12px。
- 保留品位右缘 2px 净空、线宽 1.2px、白色描边及命中 padding；完整图元仍参与占位和避碰，不能仅通过 CSS 缩放。

验证仍使用原测试谱，重点观察 Full 与箭头的净空、短波浪可辨识度、同音推弦+揉弦、双位品位及密集短音；复用现有几何/命中回归测试，并运行工程检查及真实页面截图。

本轮验收：最终 410 项测试、类型检查、lint、生产构建通过；测试谱紧凑/舒适模式首屏与密集十六/三十二分音符浏览器检查通过。推弦+揉弦的终点同高断言保持通过，没有通过放宽测试来压缩净空。截图：[技巧尺寸收紧](./验收截图/20261010_技巧尺寸收紧.jpg)、[密集时值](./验收截图/20261010_紧凑技巧密集时值.jpg)。系统打印预览的人工验证边界沿用第 5 节。
