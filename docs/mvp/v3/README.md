# MVP v3：小节与节奏编辑

本目录定义六线谱编辑器 MVP v3 的技术方案与实施边界。

| 文档 | 用途 |
| --- | --- |
| [技术实现方案](./technical-design.md) | 定义节奏时间轴、领域命令、休止符布局和页面交互的契约。 |
| [详细实施计划](./implementation-plan.md) | 按提交切分实施顺序、测试要求与版本验收清单。 |

## 范围

- 修改 beat 的基础时值与附点，并以受控规则重排后续 beat。
- 创建、取消和渲染休止符。
- 新增、复制、删除小节。
- 对每次编辑执行小节容量、连续性和冲突校验。
- 小节结构变化后复用既有 system layout 自动换行。

## 非范围

- 多选、剪贴板、撤销重做（MVP v4）。
- 连音组、吉他技巧、歌词、和弦图、保存和导出。
- 自适应视口、分页打印和移动端交互。

完整版本边界见 [MVP 版本路线图](../mvp-version-roadmap.md)。
