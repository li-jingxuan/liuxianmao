# MVP v3 版本验收记录

## 1. 结论

MVP v3 于 2026-07-31 完成封版。节奏、休止、小节结构、A4 紧凑布局、稀疏 System 拉伸、命中与页面交互均达到 v3 完成定义，可以进入 MVP v4 方案审查与实施。

## 2. 封版修复

- 将 compact density 的小节单侧 padding 恢复为技术方案规定的 `8`，规范八小节谱例重新稳定断为 `4 + 4`；
- 同步恢复紧凑模式第二行命中目标；
- 将附点测试更新为已经采用的 `5px` rhythm lane 净空；
- 删除页面遗留的 layout 调试输出；
- 删除当前小节后，光标恢复到下一相邻小节首 Beat；删除末小节时回退到前一小节首 Beat。

## 4. 浏览器验收

验收环境：本地开发页面、桌面视口 `1440 × 1100`、A4 compact layout。

初始页面结果：

- SVG `viewBox = 0 0 733 384`；
- 2 条 System，每条 4 个小节；
- body 无横向溢出；
- 浏览器控制台无 error、warning。

实际操作结果：

- 点击首 Beat 第六弦后，全部 14 个依赖光标的工具栏按钮正确启用；
- 输入品位可覆盖目标音符，错误提示保持为空；
- 设为休止后目标音符消失并显示休止 glyph；再次直接输入合法品位可在一次命令中恢复 notes；
- 设置单附点后新增一个时值附点；设置八分音符后重新 layout 且容量合法；
- 新增小节后总数变为 9 并自动重排 System；
- 删除当前小节后总数回到 8，重新得到 `4 + 4`；
- 复制当前小节后总数变为 9，并根据内容宽度安全重排；
- 所有操作期间 SVG viewBox 随 System 数量更新，无页面脚本错误。

## 5. 与初始计划的差异

- 未单独增加 `example-mvp3.json.ts`。当前验收由稳定的 MVP v2 八小节 fixture、命令测试中的领域文档工厂以及 rest/rhythm 专项 fixture 共同覆盖；不降低 schema、语义或布局标准。
- `note.set` 的最终产品语义经过后续修复调整为“合法输入自动把 rest 转为 notes”，不再要求用户先手动取消休止。
- A4 compact density 使用 `8px` 小节单侧 padding、`15px` 最小列宽和 `0.48` 理想列宽缩放。
- 删除当前小节后恢复相邻小节首 Beat，不清空光标。

## 6. 已知限制

- 仍只布局和编辑第一条轨道；
- 不支持撤销重做、多选和剪贴板，这些进入 MVP v4；
- 不支持跨休止连梁、连音组、播放和复杂拍号入口；
- 休止和其他音乐字形依赖 Bravura/SMuFL；
- 单个固有宽度超过 A4 内容区的小节仍允许独占一行并横向超出，该边界不在 v3 内缩放；
- 分页打印、响应式和移动端交互不属于 MVP。
