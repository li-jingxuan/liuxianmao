# MVP v2：多行谱面与最小输入闭环

本目录包含 MVP v2 的实施文档。该版本的目标是让用户在自动换行的六线谱中，点击定位一个拍点与弦，并完成单音输入、覆盖和删除。

| 文档 | 用途 |
| --- | --- |
| [技术实现方案](./technical-design.md) | 定义布局、命中、命令和页面渲染的架构与数据契约。 |
| [详细实施计划](./implementation-plan.md) | 给出按提交切分的实施顺序、测试要求与验收清单。 |

## 范围

- 自动将连续小节分为多条 system（谱面行）并渲染。
- 在多行谱面中命中 `{ measureId, beatId, string }`。
- 通过领域命令输入、覆盖和删除 `0–24` 品位音。

## 非范围

- 时值、附点、休止符与小节结构编辑。
- 多选、剪贴板、撤销重做。
- 技巧、歌词、和弦、保存与导出。

完成定义与后续版本范围见 [MVP 版本路线图](../../mvp-version-roadmap.md)。
