# MVP v5：吉他演奏技巧

本目录定义六线谱编辑器 MVP v5。该版本在 v4.1 已稳定的领域命令、历史、自动断行和谱面边界上，引入可编辑、可保存并由核心 layout 驱动的吉他演奏技巧。

| [技术实现方案](./technical-design.md)    | 定义技巧模型、约束、命令 interface、跨 system 布局和页面交互。 |
| [详细实施计划](./implementation-plan.md) | 按可独立验收的切片给出实现顺序、测试范围和完成标准。           |

## 版本目标

- 支持击弦、勾弦、上滑音、下滑音、推弦、颤音、自然泛音、人工泛音、手掌闷音和延音线。
- 技巧是文档中的稳定领域实体，不依附于临时像素坐标。
- 连接类技巧校验音符存在性、同弦关系和严格时间顺序。
- 技巧新增、修改和删除复用纯领域命令、no-op、撤销与重做。
- layout 统一生成单 system 与跨 system 的技巧分段、标签、路径和碰撞规避结果。
- website 只消费 layout 并转发用户意图，不自行解析技巧关系或计算 SVG 路径。

## 核心决策

1. 技巧保存在 `track.techniques[]`，使用稳定 Note ID 引用起点和可选终点；不把目标关系重复写入两个 Note。
2. 击弦、勾弦、滑音和延音线是双音连接技巧；推弦、颤音和两类泛音是单音技巧；手掌闷音是同一 track 上的音符区间技巧。
3. 双音技巧必须同弦且起点早于终点；延音线还要求两端音高相同。
4. 同弦下一音只是页面快捷解析规则，最终提交的命令仍携带明确 Note ID。
5. 跨 system 只拆分视觉几何，不拆分或改写领域技巧实体。
6. 技巧层使用 system 级 lane 分配；lane 高度进入 system 高度和相邻 system 的 Y 排布。
7. v5 中，删除被引用音符或删除包含被引用音符的小节会级联删除相关技巧；复制小节不复制技巧。

## 非范围

- 跨弦滑音、跨弦延音线、无明确目标音的滑入/滑出。
- 预推弦、释放推弦、复合推弦曲线、推弦音高播放语义。
- 点弦、拨弦方向、扫弦、闷音死音、泛音菱形音头等更多记号。
- 技巧跨轨道、多轨道同步布局、播放引擎和 MIDI 表现。
- 用户拖拽曲线控制点和逐像素排版微调。
