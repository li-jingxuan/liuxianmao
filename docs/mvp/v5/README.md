# MVP v5：吉他演奏技巧

本目录定义六线谱编辑器 MVP v5。该版本在 v4.1 已稳定的领域命令、历史、自动断行和谱面边界上，引入可编辑、可保存并由核心 layout 驱动的吉他演奏技巧。

## 实施状态

MVP v5 已于 2026-08-12 完成首轮实现：十六种技巧已接入 schema、语义规则、领域命令、级联清理、自动断行布局、独立命中、编辑器工具和统一撤销/重做。规范谱例通过正式 loader 加载；全量测试、类型检查、Lint、生产构建以及固定 A4 浏览器检查均已通过。

## 版本目标

- 支持击弦、勾弦、上/下滑音、推弦、颤音、自然/人工泛音、手掌闷音、延音线、扫弦、琶音、点弦、颤音奏、拨片方向和 Let Ring。
- 技巧是文档中的稳定领域实体，不依附于临时像素坐标。
- 连接类技巧校验音符存在性、同弦关系和严格时间顺序。
- 技巧新增、修改和删除复用纯领域命令、no-op、撤销与重做。
- layout 统一生成单 system 与跨 system 的技巧分段、标签、路径和碰撞规避结果。
- website 只消费 layout 并转发用户意图，不自行解析技巧关系或计算 SVG 路径。

## 核心决策

1. 技巧保存在 `track.techniques[]`；按语义分别引用稳定 Note、Beat 或 Beat 区间，不把同一关系重复写入多个实体。
2. 击弦、勾弦、滑音和延音线是双音连接技巧；推弦、颤音、泛音、点弦和颤音奏是单音技巧；扫弦、琶音和拨片方向属于整拍；手掌闷音与 Let Ring 属于 Beat 区间。
3. 双音技巧必须同弦且起点早于终点；延音线还要求两端音高相同。
4. 同弦下一音只是页面快捷解析规则，最终提交的命令仍携带明确 Note ID。
5. 跨 system 只拆分视觉几何，不拆分或改写领域技巧实体。
6. 技巧层使用 system 级 lane 分配；lane 高度进入 system 高度和相邻 system 的 Y 排布。
7. v5 中，删除被引用音符或删除包含被引用音符的小节会级联删除相关技巧；复制小节不复制技巧。
8. 延音线属于 v5，按领域上的单条 Tie 在 layout 中拆成跨行弧线；通用圆滑线不进入 v5。
9. 三连音、四连音等连音组属于节奏时间模型，作为独立 MVP v5.1 候选，不混入技巧命令。
10. 扫弦与琶音保存为不同 Beat 技巧；按 [扫弦/琶音优先记谱 Fix](./strum-arpeggio-note-exclusivity-fix.md) 保留目标 Beat 的源 Note，并在核心 layout 中让技巧优先于品位文本显示。

## 非范围

- 跨弦滑音、跨弦延音线、无明确目标音的滑入/滑出。
- 预推弦、释放推弦、复合推弦曲线、推弦音高播放语义。
- 闷音死音、泛音菱形音头、倚音等需要改变 Note/Rhythm 表达的记号。
- 技巧跨轨道、多轨道同步布局、播放引擎和 MIDI 表现。
- 用户拖拽曲线控制点和逐像素排版微调。
- 通用圆滑线（Slur）及其嵌套、方向和乐句编辑。
- 二连音、三连音、四连音、五连音和六连音；由后续 MVP v5.1 节奏补丁处理。
- 轮指/震音拨弦、倚音、幽灵音、死音、摇把、拍弦与勾弦（slap/pop）；它们分别需要节奏、Note 外观或更复杂的参数模型。
