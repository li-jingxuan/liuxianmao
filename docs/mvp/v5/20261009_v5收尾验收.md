# MVP v5 收尾验收

## 结果

2026-10-09 完成 v5 代码收尾，可以转入 v5.1。打印预览人工检查单独保留，不宣称发布验收已全部结束。

本轮在 [音符锚点修复](./20261009_技巧音符锚点布局修复验收.md) 之后，发现并修复一个真实编辑缺口：点击点弦等技巧时，选区解析只支持扫弦、琶音，其余技巧会提示“当前技巧无法映射到可编辑的 TAB 单元格”，无法应用更改。

## 修复内容

- 16 类技巧都按稳定 Note/Beat ID 恢复合法选区。
- 双端技巧点击起点或终点时保留对应活动焦点；提交连接草稿按文档时间归一，避免倒置起止音符。
- 区间技巧恢复完整 Beat 范围，单音与整拍技巧恢复局部目标。
- 扫弦、琶音保留显式弦范围和方向，原有编辑语义不变。
- 自然音符锚点、二维避让、动态行高、跨行几何与最终命中范围见前一份修复报告。

## 验证

转入 v5.1 之前，核心 217 项、website 17 项，共 234 项测试通过；type-check、lint、生产 build 通过。

浏览器使用正式 v5 fixture 逐项点击 16 类技巧并执行“应用更改”：均恢复可编辑目标，没有选区映射错误或领域错误。点弦删除、撤销、重做，以及固定 A4 谱面已验证。

v5.1 接入后，全部 v5 既有测试继续通过。v5 独立 fixture 保留，无连音组文档的节奏权重、连梁与已有几何回归保持。
