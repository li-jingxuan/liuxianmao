- [x] 4. 选中简谱后，点击空白区域，会出现“残影”弹窗，如图：[参考图](./assets/bb2dcf15-e136-4a64-9baa-541b7b5d8566.jpeg)

  原因：气泡关闭时坐标归零，表单控件的 CSS `transition: all` 却延迟了 `visibility` 隐藏，输入框及按钮短暂绘制在左上角。已在气泡隐藏期间立即隐藏子树并取消过渡，保留 DOM 供布局测量。浏览器逐帧验证简谱、歌词气泡均无残影，重新点击可恢复。

- [x] 5. 4/4拍的谱子，最后一个 1/4 拍没办法输入延音线“-”[参考图](./assets/img_v3_0217a_d846b62b-bf5e-44e7-9b6b-2ceda7e563fg.jpg)

  原因：截图选中的是 TAB 格。TAB 键盘没有 `-` 输入分支，品位类型、校验及命令仅支持数字或 `x`；简谱中的 `-` 是独立声部的语法。原 TAB“延续一拍”通过复制前音并生成延音弧线实现，也不能完成弦格直接显示横线的需求。

  已确认口径：TAB 弦格内直接显示横线。已补齐 `-` 键盘输入、属性面板“设为 - 延音标记”、文档校验及保存重开支持，保持原拍点时值和独立简谱、歌词不变。横线不会作为实际品位参与音符级技巧或自动续音；已有 `x` 规则保留。真实 Chrome 已验证末拍字形、删除、撤销重做、属性入口及原生曲谱导出。

  边界：本轮未扩展含横线拍点的拆分、合并规则；涉及自动生成延音弧线的不兼容操作仍由核心拒绝。
