# BUG-021—029 修复与回溯

来源：[六线猫 bugfix](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47)，使用 lark-cli 读取 `0d8c47!A22:I30` 及 E 列九张参考图。读取版本 243。本文记录本轮改动，不覆盖工作区此前 BUG-001—020 的未提交成果。

## 验收口径

- BUG-021：和弦侧栏和气泡的“更多”文字与向下图标垂直居中。
- BUG-022：非法内容显示“简谱输入错误”；两种录入模式下清空当前音符可应用为 gap，保留事件 ID、时值和歌词锚点，谱面显示可编辑占位。空白位置重复应用不增加历史。
- BUG-023：四个十六分音符中的音符加附点再取消，音符内容和起点恢复，重新按同一拍连接。附点与紧邻音符互补调整，保持后音原结束及更后音符位置；无合法互补空间时保留文档并提示。
- BUG-024：截图实际展示十六分音符增长后将后续事件推迟，文字“长改短”与截图方向不一致。按共同意图处理：改变基本时值时，增长合并所占后音，缩短释放空位，其余音符不平移；覆盖前列出实际受影响拍位并确认。取消不修改，确认作为一次历史记录，可撤销。
- BUG-025：不能只把视觉上邻近的数字强连梁；连梁必须依据真实 tick、时值和拍组。按 revision 276 再验收反馈补充：四分改十六分后，本拍保留四个十六分位置（原音符一个、后方空框三个），可逐格或连续录入，后音 tick 不移动。
- BUG-026：歌词气泡输入框与应用按钮同一行，无时值控件。
- BUG-027：歌词侧栏输入框旁应用，取消底部恢复/应用栏；保留输入法保护、失败提示和撤销，沿用批准设计的生命周期：切换目标、类别或段落丢弃未应用输入，关闭气泡或收起侧栏保留会话。
- BUG-028：各侧栏顶部不再提供“定位谱面”按钮，当前位置文字保留。
- BUG-029：按 revision 276 新图重新排版。复制范围常驻显示；起止小节与短横第一行，插入位置宽选择器与“应用”第二行，无展开/收起或底部复制工具栏。

## BUG-025 / BUG-029 再验收修复

重新读取表格 `A26:I30`（revision 276）和两张已替换参考图。BUG-025 最新文字要求缩短后保留细分位置；“四个占位”的音乐时间口径为原音符加三个空位共四个十六分位置，不在四分时长之外多增加一个空位。BUG-029 最新图取代首轮“三参数同行”的布局要求。

BUG-025 首轮只解决了隐式空位净空，释放区仍按 TAB／最大可编码时值推导，720 tick 被合成一个附点八分空位，连续输入也会随长空位越到下一拍。现在基本时值缩短时，在同一命令中将释放区按新时值存为独立 gap，完整格后可精确编码的尾量也保留；无法编码的小尾量维持隐式空白，不取整或移动后音。真实音符间的附点相邻互补规则保持；附点占用显式 gap 时按空白消费，可编码尾量保留 gap 身份，不可编码尾量退回精确隐式空白，避免三十二分加点被错误阻止。编辑排版为显式 gap 预留各自空框净空，成品不显示输入框。扩回长音只消耗无词空位时直接应用，覆盖真实音符、带歌词空位或影响记号时仍确认。

BUG-029 使用新图的两行结构，区内按钮显示“应用”，可访问名称“应用复制小节范围”；保留禁用、错误、输入法和提交保护。1400/1600 下起止值完整、插入位置更宽、按钮垂直居中，复制为一次历史，撤销完整恢复文档。
