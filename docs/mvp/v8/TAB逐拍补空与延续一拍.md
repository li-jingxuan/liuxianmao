# TAB 逐拍补空与延续一拍

本次工作独立于简谱空位与歌词任务，不修改该任务的工作目录。六线谱的持续发声沿用同弦同品位音符与延音线；不把 `-` 当成品位或休止输入。

## 规则

- 自动重建尾部空白时按拍号分母的单位拍分段：4/4 中一拍为四分，剩两拍生成两个四分休止；不满一拍先补到拍界。
- 保留已存在且容量匹配的休止，用户明确设置的长休止不自动拆除。新建空小节仍按拍号单位拍初始化。
- 工具栏新增“延续一拍”。可选中有品位的源拍，或源拍紧后的空休止；把后方一个四分音符的空休止时间变为同弦同品位续音，并逐弦连接延音线。
- 整个源拍的音一起延续，不重新拨弦。新音使用新 ID，保留源音、目标首拍身份及其他音乐的起点和时值；操作原子提交，可一次撤销。
- 拒绝覆盖已有起音、闷音、连音组或带和弦/技巧等受保护的目标。没有足够空白或需要跨小节时提示原因。
- 第一版“延续一拍”用于分母为 4 的拍号；其他拍号继续使用已有延音线工具明确连接。

## 实现

`rest-beats.ts` 增加单位拍分段补空；`measure-timeline.ts` 仅在原尾部不匹配时调用。`beat.sustain` 原子命令复制音符并创建标准 tie，不改变简谱或歌词模型。界面复用现有草稿保护、弹层互斥及命令执行入口；简谱激活时不使用残留 TAB 选区。

本次版本位于独立工作区，未向正在编辑的原工作区回写文件。
