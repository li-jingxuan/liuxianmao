# REQ-076 六线谱木吉他试听技术方案

首版已实现，待验收。沿用评审确认的 Meta Steel Guitar v1.0.0、工具栏原位切换、TAB `x` 随和弦按节奏拨弦和反复回跳规则。第 1–5 节保留设计依据，第 6 节提供实际操作入口与验证结果。

需求是根据编辑器中当前编配的六线谱，播放木吉他旋律参考。这里将「旋律参考」理解为试听整条单轨 TAB 的实际弹奏，包括谱上已有的多弦伴奏。播放器从当前已提交的曲谱生成声音，简谱和歌词继续独立编辑。 [飞书需求 REQ-076](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi&range=A77:I77)

## 1. 评审结论与建议默认值

## 2. 曲谱到播放事件

单轨由现有文档加载器提供。使用 `beat.tick`、`createMeasureRhythmContext().getBeatDurationTicks()` 和 `getMeasureCapacityTicks()` 得到起音、实际时长与小节长度。先以整数 tick 建立时间轴，再统一按 `秒 = tick × 60 / (960 × BPM)` 换算。`♩ = 90` 始终以四分音符计速，切换至 6/8 依旧沿用同一时钟。休止、空拍和仅有和弦文字的拍保留原时间。 [单轨加载约束](../../../apps/website/stores/editor-store.ts) · [实际时值](../../../packages/lxm-editor/src/core/rhythm/tuplet.ts) · [小节容量](../../../packages/lxm-editor/src/core/rhythm/rhythm.ts)

### 2.1 音符与和弦取音

| 谱面内容 | 播放规则 |
| --- | --- |
| 数字品位 | `MIDI = 该弦空弦 MIDI + capo + fret`，按弦号查找调弦记录。显式数字优先于和弦指法，普通同拍多根弦同步起音。 |
| TAB `x` | 取谱面顺序中从当前拍往前最近的和弦标记，含当前拍，可跨小节。新和弦只有名称时，前一个和弦的指法在这里失效。已有 `chord.diagram` 时使用该弦记录，和弦图的显示模式和横按的绘制位置均不参与音高计算。 |
| 和弦内的节奏弹奏 | 指法给出 0 品或数字就按对应音高正常拨弦，指法标记禁奏的弦静音。同拍多个 `x` 只拨写出的弦，按 TAB 的附点、连音组和有效拍长调度；有扫弦／琶音标记时再应用方向与弦范围。 |
| 只有和弦名（建议） | 标准调弦下按根音和和弦性质精确匹配站内和弦库，取 `defaultVoicingId` 对应的指法。capo 按轨道值加一次。文档自带指法始终优先。固定本次播放使用的库版本，把只读指法交给播放计划，试听不会改写曲谱。 |
| 无法确定和弦音（建议） | 没有前置和弦、名称无法精确匹配、和弦库加载失败，或特殊调弦下仅有标准调弦模板时，保留拍长，跳过该 `x`，其余有音高的弦照常奏。合并提示受影响的小节；已知禁奏弦属于正常指法，不报缺失。 |
| `-` 延音标记 | 纯 `-` 拍沿用紧邻前拍仍在发声的有音高声部。现有整拍标记虽存于第 3 弦，播放按整拍语义处理。旧谱如有数字或 `x` 混排的 `-`，只延续 `-` 所在弦。谱首、休止后和反复跳转后找不到连续源音时保持静音。 |

验收例：标准调弦、capo 0，谱内保存 C 开放指法 `x32010`（6→1 弦）。连续三个八分音符分别在第 5、4、2 弦写 `x`，应依次听到 C3、E3、C4。该指法下第 6 弦写 `x` 则留出该八分时值。跨小节继承 C，换和弦的当拍立即取新指法。仅写和弦名称时，预期音高从当前版本和弦库的默认指法读取。 [名称解析及指法结构](../../../packages/lxm-editor/src/core/chords/chord-catalog.ts) · [和弦库资源](../../../apps/website/components/EditorShell/chords/chord-catalog-resource.ts)

音高超出播放支持范围时跳过对应音符并合并提示。当前文档可导入自定义调弦，不能假设所有谱都是标准 EADGBE。两种 `x` 的语义分别来自现有 TAB 类型和指法校验。 [TAB 与技巧类型](../../../packages/lxm-editor/src/core/types.ts) · [指法校验](../../../packages/lxm-editor/src/core/chords/chord-diagram.ts) · [延音标记](../../../packages/lxm-editor/src/core/rhythm/tab-continuation.ts) · [延音线校验](../../../packages/lxm-editor/src/core/techniques/technique-rules.ts)

### 2.2 反复线与起播

1. 先在谱面顺序建立小节访问表。普通小节按顺序访问。谱首反复从第 1 小节开始，`repeatStart` 设于小节右边界，反复从下一小节开始。`repeatEnd` 把当前段完整奏第二次，缺失左反复线时从谱首计算。`repeatBoth` 先完成左段反复，再把右侧下一小节作为下一段起点。
2. 首版覆盖单层反复，每个配对区间奏两次。发现嵌套、交叉或语义无法确定的边界时，本次按书写顺序播放并提示。单独的开始反复线缺少对应结束线时按普通边界处理。生成访问表时施加上界，异常谱面也能退出。
3. 「从当前小节」从该小节第一次出现在访问表的位置开始，继续沿访问表播放。例：第 1–3 小节为一段反复，总序列是 `1 → 2 → 3 → 1 → 2 → 3 → 4`。选择第 2 小节后为 `2 → 3 → 1 → 2 → 3 → 4`。选区有多拍时以当前焦点所在小节为准，无有效 TAB 定位时该选项不可用。
4. 每次访问独立记录序号。反复回跳后的和弦上下文按照跳转目标的谱面位置恢复，上一轮末尾的和弦和续音不会带入下一轮。正常跨小节的 Tie 可以持续发声。从小节中途起播时，如有一条有效续音穿过起播点，按原起音后的采样偏移进入尾段。

### 2.3 当前全部 16 类技巧的可行性与验收

编辑器列出 5 类音符连接、6 类音高与修饰、5 类演奏方向与范围，和文档白名单一致。现有字段足以识别全部记号并生成参考演奏。缺少触弦位置、演奏速度、深度或专用采样的地方，以下明确给出首版默认。覆盖按类型与参数验收，音色另用同谱对照实听。 [技巧菜单](../../../apps/website/components/EditorShell/tools/technique-catalog.ts) · [技巧类型与字段](../../../packages/lxm-editor/src/core/types.ts) · [参数与方向映射](../../../apps/website/components/EditorShell/tools/technique-toolbar-model.ts)

| 技巧 | 从谱面到声音的首版建议 | 验收听什么、测什么 |
| --- | --- | --- |
| 击弦 `hammerOn` | 按同弦源、目标音 ID 连接，在目标拍切入较高音，缩短拨弦瞬态，给目标一个短促的敲击起音。 | `3h5` 到拍升至 5 品，对比分别拨 3 品、5 品，第二个拨弦头明显减弱。 |
| 勾弦 `pullOff` | 同弦向低音连接，目标音保留轻微的勾弦起音，允许落在空弦。 | `5p0` 按时落到空弦，过渡听成一次连奏。 |
| 上滑音 `slideUp` | 在源音尾段向较高目标音连续变调，目标拍到达并续响。 | `3/5` 音高经过中间值；目标处没有第二次明显拨弦。 |
| 下滑音 `slideDown` | 同上，变调方向向下。可跨正常小节线，连接到同弦下一音。 | 5 品滑到 3 品，在目标拍落准，方向与上滑相反。 |
| 延音线 `tie` | 连续访问中，同弦同音用一个声部延长至目标拍尾，可串接多拍。`x` 先按和弦解析；两端实际音高冲突时保留各自可奏音并提示连线。 | 跨小节连续三拍只计一次起音；反复回跳切断原声部。 |
| 推弦 `bend` | 读取 `semitones`，用音高曲线从原音推高 1 或 2 个半音，保持至音尾。 | 1 弦 3 品 G4 分别到 A♭4、A4；不自动推回。 |
| 颤音 `vibrato` | 在主音或已推到的音高上轻微周期性揉弦，短音自动缩短调制窗口。速率与深度由播放器设默认。 | 声音连续，能听出周期变化，基准音高与拍点稳定。 |
| 自然泛音 `naturalHarmonic` | 把音符品位作为相对 capo 的触弦节点。常见 12、7／19、5／24 品按有效空弦的第 2、3、4 分音发声，弱化低频和拨弦头。其他节点可扩充映射；首版未映射的点保留谱面参考音并提示近似。 | 标准 6 弦 `<12>`、`<7>`、`<5>` 分别约为 E3、B3、E4。切换 capo 后三者一同移调。 |
| 人工泛音 `artificialHarmonic` | 只有按弦音，缺少独立触弦位置。建议以按弦音上方一八度的泛音作参考，使用较干净的高频衰减音色。 | 6 弦 3 品 G2 的 A.H. 默认听到 G3。高级触点或其他分音需要新增记谱信息。 |
| 点弦 `tapping` | 用目标品位和弦号合成较短的敲击瞬态，再接该音采样的余振。适用于独立单音。 | 与同弦同品普通拨音对照，起音短、拨片噪声弱，音高与节奏相同。 |
| 颤音奏 `trill` | 在主音和 `auxiliaryFret` 两个确定音高间交替，在有效拍长内收束。密集交替采用默认速度，短时值压缩到可演奏的次数。 | 主 5 品、辅 7 品有两个清楚的音高；把辅助品改为 8 后立即反映，音尾不越拍。 |
| 扫弦 `strum` | 依据 `minString/maxString` 与 `stroke`，下扫从低音弦到高音弦，上扫反向，弦间短距离错开。 | 同一和弦上下扫逐弦起音顺序相反。禁奏弦无起音，总展开时间小于本拍。 |
| 琶音 `arpeggio` | 取指定范围内实际音高，按 `ascending/descending` 排序；同音高以弦号稳定排序。展开比扫弦更疏，压缩在本拍内。 | 在交叉音高的指法中仍按音高升降，改变范围后只影响范围内的音。 |
| 拨片方向 `pickStroke` | 读取单音拍的 `stroke`，在起音亮度与瞬态上对上下拨作轻微区分。共用拨弦采样。 | 同一音连续上下拨，两个方向调用不同起音参数，音高、拍点与起音次数相同。方向辨识度要实听。 |
| 手掌闷音 `palmMute` | 对含起止拍的区间缩短衰减并削弱高频。在同弦续音时保留闷音已衰减的状态。 | 区间内各音更短、更暗，离开区间的第一颗新音恢复正常衰减。 |
| 持续响弦 `letRing` | 在含起止拍的区间内，让各弦跨拍自然衰减，至同弦下一次起音、区间末、播放跳转或停止时收束。 | 两弦交替时两音有重叠，同弦重拨会收前音；跨小节仍遵守区间终点。 |

**组合与边界**

- 先展开演奏顺序、解析和弦与音高，再处理同弦连接、多弦起音顺序及区间包络。声部按访问序号和弦号追踪。击勾、滑音可以跨过只弹别弦的拍，连接期间保持源弦连续；遇到休止、反复回跳或失去可定音目标时结束该连接。可以奏出的端点仍按谱发声。
- 同一声部只起一次音。Tie 优先合并同音；推弦和揉弦叠加音高偏移；闷音可以修饰扫弦的每一根弦。相同区间的同类效果取并集。校验已处理自然／人工泛音互斥、同拍扫弦／琶音互斥及 P.M.／Let Ring 区间冲突。合法但争用同一过渡的标记（如同一对音同时有上滑与击弦）建议用滑音确定音高路径、击弦修饰到达时的起音；相互矛盾的方向只取一个确定的演奏方向并汇总提示。
- 扫弦／琶音范围内有显式音时按已写的音弹，范围外显式音保持原拍点。编辑器也允许空休止拍带扫弦／琶音记号。建议这种拍按范围内当前和弦的可奏弦发声，删除记号即恢复静音；普通休止和仅标和弦名的空拍保持静音。 [技巧校验](../../../packages/lxm-editor/src/core/techniques/technique-rules.ts) · [休止拍上扫弦与琶音的现有用例](../../../packages/lxm-editor/tests/layout/chord-traversal-rest.test.ts)

## 3. 分层和音源

| 播放计划 | `packages/lxm-editor/src/core/playback/` | 纯函数接收单轨文档及只读和弦指法，输出小节访问表、拍点、逐弦声音事件及合并提示。拍点保留访问序号、`measureId`、`beatId` 和起止 tick。声音事件保留来源 ID、弦号、基准与目标音高、起止 tick、逐弦起音偏移、音高变化与音量包络。对技巧类型做穷尽分派，新增类型时由类型检查和覆盖测试提醒补映射。 |

已选定 Meta Creative Audio 发布的 Meta Steel Guitar v1.0.0（CC0-1.0）。母带为 48 kHz、24-bit WAV，另有 OGG 版本。按六根弦、125 个弦与音高组合及三档力度共收录 375 个拨弦样本。拟随站点托管并按当前乐谱所需加载，以清单匹配弦号和音高。个别缺音优先取同弦邻音移调，例如第 6 弦 B2 可从同弦 A♯2 上移半音。音源入选与技巧听感分别记录，后者仍需实听验收。 [发布版本](https://github.com/facebookincubator/Meta-open-sound/releases/tag/meta-steel-guitar-v1.0.0) · [音源规格与清单](https://github.com/facebookincubator/Meta-open-sound/tree/main/systems/instruments/meta-steel-guitar)

同拍多声部使用统一增益和短包络控制峰值及断音，长音允许自然衰减，续播超过样本有效尾段时保持静音。用低音、空弦、高品位、六弦和弦与延音试听样张确认覆盖和听感，并检查首次播放加载时间。样本下载或解码失败时停止本次请求并提供重试。

原型调音建议从三类 Web Audio 参数入手：用 `detune` 表达推、滑、揉，用采样偏移和 `GainNode` 控制击勾、点弦与余音，用 `BiquadFilterNode` 塑造闷音、拨片和泛音的起音色彩。泛音先算目标分音再选样本，滤波只负责着色。暂停后恢复滑音、推弦或颤音奏时，从当前位置恢复音高曲线、交替相位和包络，避免重放拨弦头。优先做泛音、点弦、拨片和手掌闷音的同谱对照；若实听区分度不足，记录具体技巧和音区，再决定调参或补录专用样本。

播放时音频调度和游标共同读取音频时钟。游标通过 `requestAnimationFrame` 读取当前拍点，在拍点变化时更新；谱面只更新编辑态播放层。进入新谱行且活动拍移出视窗时才触发跟随，手动滚动后本次停止自动跟随。音频计划、速度和游标均为会话状态，曲谱 JSON、导出结果、撤销历史及文件状态由原有机制管理。 [会话重建](../../../apps/website/components/EditorShell/session/EditorSession.tsx) · [谱面缩放与滚动](../../../apps/website/components/EditorShell/score/use-score-view.ts) · [拍点布局](../../../packages/lxm-editor/src/layout/layout-types.ts)

## 4. 播放控制与异常

| 场景 | 建议行为 |
| --- | --- |
| 点击播放 | 读取当前已提交谱面和选定起点。控件显示加载态，停止可取消。用户保留所有未应用草稿，试听明示以已提交的谱为准。全谱或选定起点之后没有可发声事件时，提示「这段六线谱没有可播放的音符」。 |
| 暂停与继续 | 暂停冻结当前位置，取消已排队的声音并短淡出当前声部。继续用原位置重建调度，穿过该位置的长音用采样偏移与短淡入恢复。停止清除游标并回到本次起点。仅在停止时编辑速度与起点。 |
| 播放完毕 | 播到底自然结束，清除游标，播放按钮恢复可再次试听。 |
| 编辑、撤销或重做 | 涉及 TAB 音符或时值、连音组、调弦、变调夹、和弦及相关技巧、反复线和小节顺序时，使正在准备、播放或暂停的计划失效。只改标题、歌词、独立简谱、显示设置或选区时继续使用当前计划。以实际影响播放的已提交字段为准，不能仅靠 `documentRevision`。 |
| 曲谱替换或离开编辑器 | 播放请求失效，取消调度、停止所有声部并释放会话资源。每轮请求校验会话与播放代次，已有音源加载回调到达时只处理当前有效请求。重复点击不能产生多套播放队列。 |
| 切到后台或系统中断 | 建议自动暂停，回到页面后由用户继续，避免页面节流导致漏拍或意外发声。 |
| 快捷键与交互 | 首版用可键盘聚焦的原生控件。进入试听后焦点移至播放，退出后回到耳机。在试听控件内可按 Escape 退出。切换工具组时沿用现有草稿保护，隐藏的编辑控件退出 Tab 顺序。谱面录入仍走原有命令入口，影响试听的数据变更按上方规则停止播放。加载失败、停止原因和降级反馈只在状态变化时播报。 |

## 5. 验收与落地顺序

| 验收项 | 可复核场景 |
| --- | --- |
| 音高 | 标准调弦第 1 弦 0 品为 MIDI 64，变调夹设 2 为 66，再输入 3 品为 69。改调弦后对应弦发声随之变化。按试听档案分别听单音、同拍多弦及扫弦、琶音方向。 |
| 全技巧覆盖 | 用菜单目录和核心白名单双向核对第 2.3 节 16 行，每行都设计独立用例。有方向、范围、辅助品或推弦幅度的项目覆盖全部分支。纯时间轴断言逐弦事件、目标音高、起音次数与结束位置；浏览器用相同曲谱、音量和速度对照开关技巧后的听感。 |
| 组合与真实谱 | 推弦＋揉弦、扫弦＋P.M.、跨小节 Tie／Let Ring、滑音中暂停续播、反复回跳清音。《理想》的技巧为击弦 4、勾弦 5、Tie 31、扫弦 2；另用短谱覆盖示例曲缺少的技巧，再实听泛音、点弦、拨片与闷音。 |
| 节奏 | `♩ = 120` 时四分音符 0.5 秒、附点四分 0.75 秒、三个八分三连音平分 0.5 秒。4/4 换到 6/8 时后一小节从前一小节容量结束处开始。休止期间无新起音，Tie 与 `-` 续音无第二个拨弦头。 |
| `x` 与反复 | 验证保存指法、禁奏弦、已知名称查默认指法、未知名称、特殊调弦、附点和三连音，按《理想》的预扫计数核对指法解析。以 `2 → 3 → 1 → 2 → 3 → 4` 验证段中起播，回到第 1 小节后重新取该处和弦。另测双向反复与异常边界提示。 |
| 状态与防串音 | 覆盖加载中停止、反复快速点击、换谱后旧加载迟到、暂停后续播、撤销后重播、退出与切后台。在 `OfflineAudioContext` 或真实浏览器检查声部起止，通过浏览器交互检查没有残留声音和游标。 |
| 编辑器回归 | 在 1440px、960px 断点两侧和窄屏检查试听入口与侧栏入口位置、编辑工具顺序和横向滚动。进入试听时在原位替换工具，谱面高度保持一致。停止后保留试听工具，退出时恢复编辑工具并清理加载请求、声音和游标。试听、跟随和缩放时保持编辑选区，乐谱导出内容、文件状态和撤销深度保持一致。 |

建议实现顺序为和弦与反复时间轴、16 类逐弦演奏规则和高风险音色对照、工具栏与游标联调。当前结论是全类型映射可行；音色逼真度与首次加载耗时留待有声样张和浏览器实测。速度与编辑中断按第 1 节保留为建议默认值。

## 6. 实现与验收入口

打开 `/editor`，点击工具栏右侧的耳机，再点「播放」。默认速度为每分钟 90 个四分音符，可在停止时改为 40–240 BPM。进入试听前先选中 TAB 中的拍，即可选择「从当前小节」。点击「停止」可调参重播，再点耳机返回编辑。通过其他入口提交影响演奏的修改（如调弦）会结束当前播放，修改标题或歌词可继续播放。

浏览器从本站按谱加载六根弦的官方采样。正常拨弦、较轻的起音和较强的下拨可取不同力度层。OGG 解码失败时可使用同名 AAC。泛音、滑音、点弦、手掌闷音等技巧由木吉他拨弦采样配合音高、滤波与包络生成。听感评审请重点对照起音、音高和余音长度。[音源与许可](../../../apps/website/public/assets/audio/meta-steel-guitar-v1/SOURCE.md)

自动化验收覆盖《理想》的和弦指法、反复段中间起播、16 类技巧、暂停后恢复与过期加载隔离。浏览器回归脚本从实际编辑器入口操作。[播放计划测试](../../../packages/lxm-editor/tests/core/playback-plan.test.ts) · [引擎测试](../../../apps/website/tests/playback-engine.test.ts) · [会话测试](../../../apps/website/tests/score-playback-session.test.ts) · [浏览器回归](../../../apps/website/tests/req076.next.browser.mjs)

Chromium 从正式音频输出录得 24.05 秒技巧对照和 10.72 秒《理想》片段，均无削波。本地验收文件在 `output/req076/`，打开 `listen.html` 可按技巧和小节定位。另在编辑器令 OGG 解码失败，内置谱成功回退到本站 20 个 AAC 样本并显示播放游标。音色接近实琴的程度留给实听验收。
