# REQ-002～006 交互设计确认稿

来源：[六线猫 bugfix](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi)。已通过 lark-cli 读取表格及五张参考图。

## 已确认的设计口径

- 沿用现有蓝白编辑器视觉，以桌面曲谱编辑为主要使用场景。
- 音符的时值、附点、状态点击即应用，支持撤销。
- 连音展示全部六种比例：2:3、3:2、4:3、5:4、5:3、6:4。
- 连音先选择比例，再点击应用。选择比例本身不修改谱面。
- 界面显示二连音、三连音、四连音、六连音；两种五连音显示“五连音（5:4）”“五连音（5:3）”。悬停或聚焦解释比例含义；摘要和应用按钮使用相同中文名称，谱面括号使用成员数字标记。
- 本轮产出为独立、可点击的交互设计稿。

## 视觉与布局

- 主色沿用编辑器蓝色 `#2459EF`；选中浅底 `#EDF4FF`；谱纸与面板白色 `#FFFFFF`；工作区 `#F1F5F8`；正文 `#202B3D`；次要说明 `#687587`。
- 中文界面使用系统无衬线字体，曲谱符号使用 SVG，避免依赖外部字体。
- 顶部保留曲名和编辑工具；中央显示可滚动的谱纸；右侧属性面板固定宽度，内容左对齐。
- 音符、小节线与连音比例使用相同的选中、禁用、聚焦视觉，减少识别成本。
- 窄屏时将面板放到谱面下方，曲谱视口内部滚动，页面本身不横向溢出。
- 以符号、曲谱和选择反馈承载信息，减少重复文字、卡片和大面积提示。

## REQ-002：编辑视图缩放

- 默认 125%；可选择 100%、125%、150%、200%。
- 控件固定于谱面视口右下角，横向排列减号、当前比例、加号；点击比例向上展开档位菜单。
- 横排控件采用紧凑尺寸，整体约 118×34px；减号/加号各约 26px 宽，百分比约 60px 宽，减少内边距与箭头间距。
- 减号和加号按相邻档位切换，到达边界后禁用。
- 整张谱面等比例缩放，工具栏、侧边栏和缩放控件尺寸保持固定。
- 放大不改变每行的小节分配及打印排版，超出视口的内容通过滚动查看。
- 各档位下选中反馈、鼠标命中与谱面保持对齐。

## REQ-003：未选中状态

- 保留简短提示，引导用户在谱面选择音符或小节。
- 删除“前往谱面选择”“浏览简谱与歌词”“查看歌曲设置”“浏览小节工具”四个入口。
- 未选中时不展示与当前状态无关的应用操作。

## REQ-004：选区－音符

- 保留位置、时值、附点、音符状态。
- 时值、附点、状态统一使用紧凑按钮组，选中项高亮，符号提供名称提示。
- x 弹奏标记和延音标记仅作用于所选弦格；整拍休止作用于整拍。
- 多拍选区的时值、附点遵循现有单拍限制，禁用时给出简短原因。
- 删除参考图下方框出的延续一拍、编辑此拍和弦、演奏技巧、删除所选弦音符及相关说明区域。

## REQ-005：选区－小节

- 保留段落标记编辑。
- 单小节线、双小节线、终止线、开始反复、结束反复、双向反复使用紧凑符号按钮。
- 悬停或键盘聚焦时显示名称；当前选项高亮。
- 遵循现有小节边界规则，不能应用的选项置灰，并提供简短原因。
- 去除原来的大块提示。

## REQ-006：选区－连音

- 保留当前连音摘要、比例按钮组、应用按钮、删除当前连音组。
- 六种比例全部可见；根据所选连续音符的数量显示可用性。
- 比例的前项必须与所选成员数相同，例如 5:4 需要五个成员。
- 待应用比例与已应用比例区分，点击应用后谱面与摘要同步更新。
- 保留同小节、连续、时值与附点相同等已有约束；不新增跨小节或嵌套能力。
- 删除参考图中两处红框长说明，禁用原因按需显示。

## 评审重点

- 125% 默认视图是否方便点击，四档缩放是否易于切换。
- 未选择时侧边栏是否足够简洁。
- 音符按钮的符号与选中状态是否易于理解。
- 小节线按钮是否足够紧凑，名称和禁用原因是否便于查看。
- 连音六种比例是否一眼可见，待应用与已应用状态是否清楚。

## 交互验证场景

- 四档缩放分别检查谱纸尺寸、选中位置及滚动范围，侧边栏和缩放控件保持原尺寸。
- 音符修改即时反馈；切换为整拍休止后撤销，原拍内容可恢复。
- 多拍选区下时值、附点不可应用，禁用原因仍可通过聚焦查看。
- 小节末尾的开始反复和双向反复不可应用，其他小节可验证正常选中。
- 连音比例选择后、点击应用前，谱面与已应用摘要保持原值。
- 切换连音成员数量后，待选比例重新校验；删除连音组只移除分组。
- 窄屏页面无横向溢出，曲谱在自身视口内滚动。
