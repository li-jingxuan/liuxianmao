# BUG-031～033 · 弹层警告与全局和弦显示

来源：飞书「六线猫 bugfix」工作表 `0d8c47` 第 32～34 行，读取 revision 376，并下载查看三张原始参考图。

状态：BUG-031、BUG-032、BUG-033 均已完成，用户已确认验收通过。

## BUG-031、BUG-032

两张截图都是 `Warning: trigger element and popup element should in same shadow root.`，分别定位到 `ChordPresetControls` 和上层 `MusicTextSidebar`。

浏览器复现和 DOM 诊断确认：`Dropdown destroyOnHidden` 销毁了旧弹层，但 rc-trigger 仍保留它的元素引用。再次打开时，触发按钮仍连接 document，旧的隐藏弹层已经断开，其 `getRootNode()` 返回自身，触发警告；这里没有实际使用 Shadow DOM。

移除该下拉的 `destroyOnHidden`，关闭时沿用组件默认的隐藏与复用，随快捷编辑器卸载统一清理。现有搜索清空、Escape 焦点恢复、IME 保护、打开和弦库等行为继续沿用。

## BUG-033

原先 `EditorShell` 把 `showChordDiagrams` 固定为 `true`，侧栏单选只改当前和弦草稿的 `display`，所以投影一直显示指法图。布局缓存也没有依赖该配置。

将开关改为编辑器会话的全局视图状态，侧栏单选即时切换，并让布局缓存依赖开关。编辑谱面、打印与图片导出共同使用它；保留和弦原始名称、指法、未应用草稿与音乐历史。当前目标没有指法时，也可以开启其它和弦的指法显示。

在单选钮组下补充 `Tips: 谱面显示配置全局生效。`。
