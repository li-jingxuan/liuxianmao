# 六线谱编辑器可用性差距与后续规划

> 2026-10-10。状态：按用户最新范围修订。本版只完善编辑器本体；作品业务流程另开版本，播放延后，不考虑多轨和云端作品库。后续功能尚未实施，本文不是 v7 的详细技术方案。

## 1. 结论与可用标准

当前品位、节奏、选区、历史、技巧、歌词和和弦的主体闭环已建立。本版目标是把这些能力补齐、做稳，使已有乐谱在编辑器中可以完整录入、可靠修改与清楚展示。

本版“完善可用”定义为：**桌面端、单轨、六弦吉他，接收已有合法乐谱，完成常用音符、节奏、技巧和文本编辑，保证复制与撤销不丢音乐内容，长谱能稳定浏览并完整输出。** 评估从乐谱已进入编辑器开始，不以作品新建、作品管理、保存状态或刷新恢复作为本版完成条件。

范围边界：

- **本版纳入**：小节增删复制、音符与节奏编辑、常用记谱补齐、编辑影响说明、乐句复用、单轨谱面设置、布局/打印输出及编辑器质量验收。
- **独立业务版本**：作品新建/管理、文件打开/保存/另存、保存基线与 dirty 状态、自动持久化/重启恢复、离开作品保护等作品生命周期流程。
- **延后**：G11 播放校对、节拍器和循环，另行规划，不是本版前置条件。
- **不考虑**：多轨道、云端作品库；不因模型里存在 tracks 数组而扩展轨道编辑或管理。

“小节新增/删除”属于编辑器内的音乐结构编辑，继续保留；“新建作品”属于业务流程，移出本版。现有 loader 与文档模型保留为集成能力，不新增作品业务 UI。宿主负责提供乐谱和接收编辑结果，具体持久化方式在业务版本设计。

### 3.1 编辑器交互与集成边界

- 保留合法文档、纯领域命令和布局/命中的统一契约；操作失败不部分修改，no-op 不增加历史。
- 品位计时草稿与歌词/和弦未应用草稿，在编辑器内切换目标、关闭面板、撤销/重做时仍需正确处理。这是编辑体验，不等于作品保存 dirty 管理。
- 编辑结果的领域内容应自足且可由现有 loader 校验；本版不据此增加文件 UI、保存快捷键、保存基线或自动持久化。
- 本版按单轨输入和单轨渲染验收。多轨数据属于宿主集成边界的能力限制，不新增轨道选择、同步时轴、轨道管理或多轨布局。
- 现有 title 等字段可以消费与展示；作品命名、目录、重命名等管理流程另属业务版本。

### 3.3 本轮复核补充的语义与验收边界

1. **拍点结构与删除语义（G15）**：当前 Backspace/Delete 删除选区内音符，不删除 Beat；设为休止作用于完整 Beat，并清空其所有弦音符。时值修改可能协调后续拍，不能因此声称已有自由拍点增删。先按典型录谱流程确定必要拆分/合并操作，再设计领域命令；涉及歌词/和弦锚点或连音组时不能悄悄转移含义。
2. **单轨与声部边界**：当前 rhythm 在 Beat 上，同拍音符共享书写时值；Tie 可表达相邻同弦同品位延续，但没有每根弦独立时值/声部。首版按单轨、整拍统一时值验收，不宣称支持全部复杂指弹织体；独立声部时轴不是本轮自动追加任务，也不扩展多轨。
3. **音符 x 的关联规则（G08）**：x 没有普通品位音高，不能套用数值高低比较或同音延音规则。新增模型前明确与推弦、滑音、泛音、Tie 等的允许组合及拒绝/清理策略；错误操作不部分提交，清理影响按 G05 提示。
4. **调弦/capo 的影响（G09）**：建议默认保留品位，改变音高解释与谱面标记，不自动改谱转调；准确写明相对 capo 品位和可用品位上限。调弦 MIDI/文字名称保持一致，更新参与技巧语义校验，操作可撤销；若将来需要自动转调，单独设计。
5. **宿主集成而非业务流程（G16）**：外部替换文档先校验再提交会话，旧文档的延迟回调不能写入新文档；替换历史按约定清空/重置，避免撤销跨到另一份谱。区分用户命令通知与宿主回填，不形成循环更新；暂不要求保存基线、持久化或多实例管理。
6. **键盘与长谱操作（G07）**：当前已有方向键、Shift 扩选、焦点自动滚动、拖动取消和历史快捷键，不能列为未实现。补足跨行/首末拍/侧栏切换的实际验收：滚动只影响谱面，输入框与 IME 不被谱面快捷键抢占，拖动越界/取消后可继续操作，失去焦点时品位草稿按既定策略处理。提供可发现的快捷键/操作说明与禁用原因，不要求额外增加缩放控件。
7. **布局与输出的同一份音乐内容（G06–G07）**：紧凑/舒适、字体就绪重测、浏览器缩放与分页后命中/选区保持稳定 ID；屏幕与输出的品位、技巧、歌词、和弦及隐藏开关一致。增加跨行/跨页技巧、两位品位+x、连音/附点/休止混合验收，确保文字和箭头尺寸收紧后仍可辨认。

这些补充是既定编辑器范围的规则和退出条件，不将作品生命周期、播放、多轨或云端作品库重新纳入。本版“完善”指上述明确支持范围内的完整与可靠，不要求所有拍号、所有技巧或复杂声部一次性齐全。

## 5. “编辑器完善可用”的验收清单

- [ ] 由宿主/测试谱提供合法单轨初始文档，在编辑器内增删小节并完成至少 16 小节的音符、附点、休止、连音、技巧、歌词与和弦编辑。
- [ ] 支持音符 x，语义与休止、P.M.、和弦图禁奏弦明确区分。
- [ ] 复制含技巧的小节/乐句；跨边界对象按约定处理，引用有效；撤销/重做后内容一致。
- [ ] 时值重排、压缩及技巧清理有可理解的影响说明；非法操作无部分修改。
- [ ] 品位计时草稿与音乐文本未应用草稿在编辑器内切换目标、关闭面板和历史操作时处理正确。
- [ ] 本版确定的调弦/capo/结构标记、乐句复用和拍点结构切片通过真实单轨谱例验收；整拍统一时值限制明确记录。
- [ ] 宿主替换文档不受旧延迟草稿污染，历史/焦点按约定重置，错误输入不破坏当前会话，结果通知不循环回填。
- [ ] x 的技巧组合与调弦/capo 的品位保留规则明确且可撤销；键盘、侧栏、IME、长谱跨行导航和拖动取消通过实际操作验收。
- [ ] 输出领域文档仍可校验；同一文档和配置布局确定，不要求文件保存/重载 UI。
- [ ] 100 小节混合谱能浏览、选区、修改、复制、撤销，有性能证据。
- [ ] PDF/实际打印完整清楚，已有标题、品位、技巧、歌词和跨页内容不丢失。
- [ ] 目标桌面浏览器、缩放和真实中文输入法验收通过，未支持范围明确记录。
