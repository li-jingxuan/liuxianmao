# BUG-030 · 简谱横向间距

飞书表格第 31 行要求“简谱可以更加紧凑（横向间距）”，参考图标出第 6 小节第 3 拍四个十六分音符 `3 3 4 5`。

## 原因与修复

紧凑模式的短音符理想宽度偏大，谱行布局再按内容比例分配额外空间，放大了同拍短音符之间的距离。将紧凑编辑／成品的八分、十六分、三十二分理想宽度分别收为 16、12、11。真实字形、附点、歌词及 TAB 的避让约束继续生效；共用时间网格仍保持双谱相同 tick 对齐。

此次只修改简谱布局 profile。BUG-025 的显式 gap 最小净空、固定时间窗、逐格录入与历史逻辑保持原有实现。
