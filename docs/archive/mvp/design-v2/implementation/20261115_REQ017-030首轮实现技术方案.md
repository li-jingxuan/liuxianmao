## 需求与设计核对

对照飞书归档 A18:H31、11 张参考图、需求口径稿及独立原型，14 项均有对应设计：REQ-017 首页与路由；018 简谱／同段歌词范围；019、020、029、030 气泡与侧栏；021～023 和弦库与调性推荐；024～028 自定义指法。

实现细节补充：调性复用现有明确资料与和弦目录，小调将自然小调三和弦、七和弦及和声小调补充分组；统一手指选择器初始未指定，选择已有对象时编辑它，无选中时显式指定下一次新建手指，不从上个对象意外继承。切换文本目标沿用当前正式会话规则：离开文本目标丢弃未应用输入，组合输入／弹窗阻止切换，歌曲设置保留离开保护；不新增自动应用。

## 实现组织

按 Matt Pocock `codebase-design` 的小接口原则，把范围解析、顺序与边界检查放在共享模块中；界面只传目标与内容，失败不得写入任何历史。复用已有领域命令、会话草稿、模态与撤销机制，不引入另一套正式状态。

- 现有编辑器会话移至 `/editor`；首页按设计实现，入口与已有编辑器返回链接更新，其他路由保持。
- 默认 mock 增加明确 C 大调资料；不增加旧谱兼容流程。
- 简谱以事件为单位，歌词以同轨道、同段可填词位置为单位，范围包含首尾。拖选、Shift 点击／方向键支持跨小节和排版行。范围与 TAB 不混选；选区替换或清空一次提交，超界整批失败，短输入清空余位，保留原时值及锚点，不扩大为批量属性修改。
- 气泡与侧栏共用现有草稿，名称旁应用统一提交，删除立即执行；移除重复预览、底部操作栏及常驻说明。和弦库仅保留全部和弦／我的指法，调性分类、图文卡片，列表独立滚动、详情固定。
- 自定义指法保留结构校验与最后有效预览；新增拇指 `T`，按点／横按默认允许未指定手指，同指重复不判冲突。顶部紧凑工具行，header 最新错误，右侧名称、预览、另存；完成回填、父级应用。
