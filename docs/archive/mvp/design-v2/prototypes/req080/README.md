# REQ-080 简谱弧线原型

[打开可点击原型](./index.html)。桌面评审使用 1440px 或更宽的视口。顶部深色工具条用于切换评审选区。

- 选中简谱后点击工具栏弧线图标。气泡在图标正下方展开，两个命令使用等宽、等高的横排布局。
- 两个相邻同音推荐「延音线」，仍可手选「圆滑线」。两个相邻异音或一段包含重复音的连续乐句推荐「圆滑线」。跨普通小节线的相邻音同样适用。
- 不可用的命令保留位置并解释条件。选中已有记号的端点时，相应命令显示「移除」。两类弧线均可撤销、重做。
- 气泡支持键盘打开，按 `Esc` 收起并回到弧线图标。执行命令后保留谱面选区。

当前评审按 REQ-080 的简谱范围制作。含休止符或空位的连续性口径按暂不可用演示，待确认是否允许圆滑线跨过它们。
