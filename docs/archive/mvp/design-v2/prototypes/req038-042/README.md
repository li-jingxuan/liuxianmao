# REQ038–042 交互设计稿

仅用于设计对稿，未接入产品，不包含生产代码修改、持久化或新的推荐算法。

在仓库根目录执行 `node docs/archive/mvp/design-v2/prototypes/req038-042/build.cjs`，随后直接打开本目录 `index.html`。使用工作区实际安装的 React、Ant Design 和 esbuild；脚本、样式及和弦目录均内联，无需 CDN 或本地服务。自包含文件约 939KB，超出聊天 HTML 渲染上限；聊天内展示浏览器截图，实际交互请打开入口文件。body 透明，产品容器为白色，默认展示歌曲设置。

- **歌曲设置（REQ040/041，最终已确认）**：350px 侧栏；仅歌曲名称、编谱作者可编辑，曲谱信息标题右侧的“应用”只保存这两项并更新左侧谱面头部，无改动时禁用。数字 1 音高、大小调、主音拼写、小调记法全部使用紧凑静态只读展示，不提供编辑控件。基础拍号 4/4 静态只读一行，变调夹另起一行并独立应用，无改动时禁用；两类应用互不提交另一类草稿。外部“错误提示示例”开关仅展示紧凑整行红字，不添加歌曲名称必填等新校验。
- 调性作为未来真正创建曲谱时的基础必填信息，本原型不增加创建或调性编辑流程。产品框外的“旧曲谱示例 / C大调 / A小调记6”为明确标注的对稿辅助，只切换固定展示样例，不写入曲谱信息草稿。旧曲谱示例保留已记录的 1=C，缺失 mode 时显示“调性未确认”，不推断大小调、主音或小调记法。A小调记6样例展示已记录的 1=C、A小调、主音 A、主音记 6，不代表小调默认值。
- **和弦推荐（REQ042）**：更多推荐弹层标题右侧和弦库 link。已确认显示“C大调·和弦推荐”等；未确认示例显示“常用和弦推荐”，不猜调。切换示例或搜索，点击卡片可查看选择反馈。复用产品现有 `quickChordMatches`、`queryChordCatalog` 和实际目录数据，没有新推荐算法。未确认情形的卡片是现有常用和弦展示样例。
- **和弦库回退（REQ038，已确认恢复旧分组）**：默认 A小调以展示全部四组：自然三和弦 7 项、七和弦 7 项、小调和声补充 4 项、其他和弦 174 项；可切换 C大调（三和弦 7 项、七和弦 7 项、其他 178 项）。搜索时仅平铺搜索结果。自然和声分组来自目录现有查询，剩余集合按和弦身份去重，实际指法来自已有目录，不沿用 12 根音分组。

入口参数：`?scene=song`（默认）、`?scene=recommend`、`?scene=library`。顶部导航、展示样例、推荐状态与错误提示示例均为原型对稿辅助，不代表最终产品新增控件。

主要可访问名称：导航为 button“歌曲设置 / 和弦推荐 / 和弦库回退”；歌曲产品内的编辑控件仅“歌曲名称 / 编谱作者 / 变调夹”。只读调性通过 `dl`“调性信息（只读）”展示；产品框外 segmented 为“歌曲展示样例（对稿辅助）”（radio“旧曲谱示例 / C大调 / A小调记6”）。两个“应用”可通过 `data-testid="apply-info"` 与 `data-testid="apply-capo"` 区分。推荐页控件为“推荐展示状态 / 搜索推荐和弦”；库页控件为“库示例调性 / 搜索库和弦”。和弦卡片按钮名称为“选择和弦 C”等。AntD segmented 的 input 本身透明，浏览器自动化请点击对应可见文字。

浏览器复核：[检查记录](screenshots/review-result.json)。检查只读展示、产品框外样例切换、旧曲谱缺失 mode 不猜调、名称/作者与变调夹独立应用、推荐及搜索标题、旧分类192项完整展示，以及720px与390px原型布局。

刷新检查与截图：保持本地4191服务运行，执行 `node docs/archive/mvp/design-v2/prototypes/req038-042/review.cjs`。需可解析的 Playwright 和本机 Chrome；可用 `LXM_PLAYWRIGHT_MODULE` 指定 Playwright 模块，`PROTOTYPE_URL` 指定服务入口。
