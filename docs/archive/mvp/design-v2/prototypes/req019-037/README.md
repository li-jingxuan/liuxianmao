## 设计与来源

使用 `frontend-design` 与 `ui-ux-pro-max`；已读两份 SKILL.md、原口径 `../../specs/20261115_REQ-017-030需求与口径.md`，逐张查看 `artifacts/req019-037-references/` 的 REQ019-G、020-H、021-H、031–037-G，共 10 张本轮关键参考图。020、021 以 H 列标注图为准。最新来源与逐项验收由主会话记录在 [交互设计待确认](../../specs/REQ-019-037交互设计待确认.md)。

配色：纸白 `#FFFFFF`、画布 `#F3F6FA`、墨蓝 `#202838`、交互蓝 `#285BE0`、选择浅蓝 `#EDF3FF`、错误红 `#BC3547`。系统中文字体，32–34px 控件，6px 常规圆角，8／12／16px 间距，克制紧凑的 AntD 风格。产品已有 AntD 6.4.4；静态页只模拟控件外观，不引入生产依赖。音乐指法与撤销／重做使用本地 SVG。技能检索 `keyboard focus modal --domain ux` 命中可见焦点与不遮挡焦点，保留控件键盘焦点，不对整个弹窗画蓝框。

布局计划：左侧白纸六线谱是上下文，右侧 360px 编辑栏；气泡紧邻已选拍点，名称与应用同一行。库内左侧滚动列表、右侧固定详情；自定义以指板为主视觉、右侧有效预览。用音乐内容与精确对齐表达工具属性，去掉常驻解释与重复状态。用户指定的现有视觉基线优先于技能中面向新产品的风格建议。

## 建议审阅顺序

1. **编辑器**：气泡 header 与名称标签间距压缩；应用按钮仅显示「应用」，无底部已应用文案或操作栏。改名不会更换指法；气泡与侧栏实时共享草稿。选用常用和弦、更多推荐、库指法、自定义完成均只回填；点击名称右侧「应用」才更新谱面并短 toast。删除立即应用。
2. **更多下拉与侧栏**：点气泡「更多」，搜索下面左侧「和弦推荐」、右侧「和弦库 >」。无底部浏览入口。两处推荐复用 `tile()`，4 列 2 行，上指法下名称，建议 72 × 78px。侧栏顶部小图约 51 × 58px，常用和弦与更多配置基线对齐。
3. **和弦库**：卡片左图，右侧名称／级数上下排列；右侧标题示例 `F IV`，列表独立滚动，详情固定。级数仅有明确调内映射时显示，调外／我的指法不伪造级数。切换 G 大调或 A 小调仅浏览，曲谱仍 C 大调。全部／我的 Tab hover 无描边无位移。搜索仅一个输入容器，内层无蓝框。
4. **单拍绑定**：点击前三个 TAB 拍点或顶部审阅状态。第 3 拍为空，直接显示新增表单；无选区／多选提示选择单拍。先切到「简谱与歌词」再选拍，页签不被抢占；点击或停留和弦页签时立即绑定单拍，不需要「编辑当前拍和弦」，不强制展开其他工具。
5. **自定义**：按弦／横按／擦除，撤销／重做使用与主工具栏同一 SVG。按点 hover 为 22px 蓝色实心圆，与谱面选框同色；落点平时为墨蓝实心，选中叠加细蓝环。横按演示：点同一品的两根弦。选中按点后按 1–4／T／0，或使用手指选择。Esc 无改动直接返回；改动后直接出现「继续编辑／放弃修改」确认，不给整个弹窗加蓝框。完成只回填父草稿，取消不改变它。
6. **查看我的指法**：已确认暂存往返。编辑后点「另存为我的指法」与「查看我的指法 >」；取消／Esc 返回恢复暂存，包含尚未校验的输入、指板、撤销／重做历史；点击收藏仅预览，点击选用才确认替换。取消替换留在库中，保留暂存；确认后返回自定义，仅替换自定义缓冲，仍须完成编辑 → 父草稿 → 应用谱面。未保存时查看库可审阅 empty；库底部提供仅用于评审的清空本次收藏入口。
7. **技巧字号**：原 9 与拟议 7／6.5 布局单位对比，7（约 78%）为推荐默认，6.5 备选，可拖动 6–8。范围已确认覆盖 H / P / S、P.M.、let ring、A.H.、T、tr、推弦文本等同类谱面技巧文字；工具栏维持 13px。自然泛音原 8 按同比例缩小但最低 6，已有内嵌 6 不继续缩小，命中范围不缩小。原 H/P 碰撞回退 6 的事实注明。编辑／印刷示意共用字号规则。具体字号与印刷清晰度仍待设计稿确认，不能作为定稿参数。

Esc 按层处理：更多下拉／未完成横按首端点先取消该层；离开确认中按 Esc 等同继续编辑，不穿透；从我的指法按 Esc 仅返回暂存自定义。重复进入同一拍的和弦页签／气泡保持同一草稿，另一拍沿用丢弃旧未应用草稿。

## 待确认与限制

- REQ031：外层常规 focus 是否保留仍待用户确认。库中提供「保留常规焦点／仅键盘虚线」两种设计比较；不将任一种写成既定。内层重复蓝框均已移除。
- REQ037：同类谱面技巧文字统一调整范围已确认；6.5／7 以及最终碰撞回退规则仍是设计拟议，须随设计稿确认。原型采用 SVG 局部比例示意，不代替正式排版、碰撞和印刷回归。
- REQ033：暂存往返、取消恢复、选用先确认替换已确认，不再标为待确认导航。
- 22px 按点、72 × 78px 推荐卡以及具体留白属于本轮设计建议，等待设计稿确认。
- 库为有限静态和弦数据与指法版本，不是完整算法库；跨目标切换沿用丢弃未应用草稿示意。原型不实现真实乐谱播放、文件导出、持久化或生产排版引擎。

## 浏览器核对

已使用本机 Chrome + 已有 Playwright 包完成实测，无浏览器脚本错误：

- 名称同步、改名保留指法、同拍不重读、切到另一拍丢弃草稿、非和弦页签不被抢占。
- 空拍新增、显式应用、直接删除及实际谱面状态更新。
- 自定义无改动 Esc 返回；有改动弹出确认；确认内 Esc 继续编辑不穿透；横按首端点 Esc 先取消。
- 指板按点和手指输入；暂存未校验的 `abc` 起始品位后，从我的指法 Esc 返回，完整输入／指板／历史恢复一致。
- 点击收藏只预览；点击选用确认，取消留库并保留暂存，确认返回自定义；完成只回填草稿，随后应用才更新谱面。
- 库搜索、库内浏览 G 大调不改变曲谱 C 大调、左列表滚动时右详情位置固定、我的指法空状态。
- 1600px 桌面、900px 小窗、390px 竖屏已截图。390px 库／自定义／技巧页均无页面横向越界；小窗采用独立审阅布局。
