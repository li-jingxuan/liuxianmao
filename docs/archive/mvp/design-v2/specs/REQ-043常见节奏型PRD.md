## 1. 目标与入口

把常见节奏快速应用到当前拍或连续多拍，保留原有内容的顺序，按需补入待填空位。

直接用“节奏型”替换工具栏“拍点”，位置为 **小节 → 节奏型 → 连音**。点击打开模板及预览浮层；不新增第二个入口，旧拍点菜单内容不混入。入口替换不扩大为删除全产品的底层拆分、合并、复制等命令。

简谱和六线谱共用模板，**本期只修改当前活动谱层，不支持双谱**。面板内不提供谱层切换；当前活动的是歌词、和弦或没有有效音符／拍位置时，先提示选择简谱或 TAB 位置，不能借用另一层旧选区。

## 2. 逐拍应用规则

本需求的 beat 指完整演奏拍：4/4、3/4 是一个四分音符时长，6/8 是一个附点四分音符时长。它不是程序中任意一个八分或十六分拍点。一次模板周期等于一个演奏拍。

每个目标拍独立执行：

1. 按原时间顺序收集这拍内需要保留的内容位置：音符组、明确休止、有歌词／和弦等内容的空位置。TAB 同时发声的多根弦算一组；简谱同一时刻的复音也算一组。原有多个拍点即使被 Tie 相连，也各自算独立的保留位置；清除 Tie 不合并、删除其中任何拍点。
2. 纯空白、无内容的 gap、空 TAB 拍不占保留名额，不因空隙阻止应用。
3. 把上述内容依次放入模板位置，更新起点和时值，保留音高、八度、变音、弦号、品位及明确休止类型。位置不够时按 §8 处理。
4. 剩余位置补为**待填空位**。不自动填音、复制音高／品位、生成休止或建立延音线。
5. 同小节多拍逐拍重复，不把第一拍的多余音挪到第二拍，也不把后面的音提前填到第一拍。

“保留顺序”不表示保留原时间位置。模板可以让第二个音更早或更晚开始，总拍长与范围外内容不变。

## 3. 典型结果

以下均以 4/4 的一拍套“前八后十六”为例，结果为八分、十六分、十六分：

- 一个四分音符 `1` → `1（八分）＋空位（十六分）＋空位（十六分）`。
- 两个八分音符 `1、3` → `1（八分）＋3（十六分）＋空位（十六分）`。
- 三个音 `1、3、5` → 依次保留三个音，更新为模板时值。
- 音符中间有空位 `1、空、3` → 顺序提取 `1、3`，得到 `1、3、空`；空位原时间不固定保留。
- 纯空白 → 三个待填空位。
- 一个四分休止 → 八分休止＋两个十六分空位。**已有休止保留一次，不自动把新位置都变成休止。**
- 音符与休止 `1、0` → 八分音符 `1`＋十六分休止 `0`＋十六分空位。
- 四个有内容位置 → 模板只有三个位置，先阻止并提示具体拍与数量；不删除第四个音。

待填空位是有明确时值的编辑位置：简谱使用 gap，TAB 使用无弦音符的普通空拍；与简谱 `0`、TAB 休止和 TAB 空弦 `0` 品均不同。编辑态可显示虚线框，成品不凭空绘制休止、音符或预览虚线框。时间结构仍参与保存和布局。之后填音应继承空位时值，不因上一次单音时值偏好覆盖模板。

## 4. 目标范围自动识别

- 只有当前选中的音符／拍点，或拖选长度不足一拍：使用焦点所在的完整演奏拍。选中一个十六分音符也可直接操作，不要求先拖出完整一拍。
- 连续选区长度达到一拍：覆盖选区首尾涉及的完整演奏拍；部分拍边界向外归入完整拍。面板显示最终拍号与范围，谱面高亮实际将处理的所有拍，不能只高亮原来的短音。
- 整小节选区自然按每拍套用。面板不再提供“当前拍／整小节”切换，由谱面目标决定范围。
- 首期仅同轨同小节。跨小节、跨轨、不连续目标、无当前拍或其他拍号可以浏览模板，但不允许应用。目标小节真实拍号优先于歌曲基础拍号。
- TAB 一拍内全部六弦共用时值，应用涉及全部六弦，不能只改选中弦的节奏。
- 自动识别处理拍不等于截断跨范围内容。任何音符、明确休止或带歌词／和弦的 gap 从范围外延入或延出范围，都先按 §8 提示扩大范围；纯无内容空窗可在范围边界分割，保留范围外空窗。
- 未应用的正文或属性输入不顺带提交；存在会影响内容的未完成编辑时，沿用当前编辑完成／取消流程。

## 5. 模板与拍号

以下时值以十六分为 1：四分 4、八分 2、附点八分 3、三十二分 0.5、附点四分 6。新增细分需要精确到三十二分，不能按整数十六分取整；这是未来实现要求，原型只演示精确时值。

4/4、3/4 共用 **12 种拍内模板**，按“常用 8 种／三十二分细分 4 种”分组，避免把密集细分混进基础模板：

- 四分音符 `[4]`。
- 两个八分 `[2, 2]`。
- 前八后十六 `[2, 1, 1]`。
- 前十六后八 `[1, 1, 2]`。
- 四个十六分 `[1, 1, 1, 1]`。
- 附点八分＋十六分 `[3, 1]`。
- 小切分（十六＋八分＋十六）`[1, 2, 1]`。
- 十六＋附点八分 `[1, 3]`。

三十二分细分：

- 附点八分＋两三十二 `[3, 0.5, 0.5]`。
- 两三十二＋附点八分 `[0.5, 0.5, 3]`。
- 八分＋四三十二 `[2, 0.5, 0.5, 0.5, 0.5]`。
- 四三十二＋八分 `[0.5, 0.5, 0.5, 0.5, 2]`。

6/8 使用五种附点四分单拍模板：附点四分 `[6]`、三个八分 `[2, 2, 2]`、四分＋八分 `[4, 2]`、八分＋四分 `[2, 4]`、六个十六分 `[1, 1, 1, 1, 1, 1]`。

4/4、3/4、6/8 的整小节分别重复 4、3、2 次。“三个八分”是 6/8 自然细分，不是三连音，不加连音数字 3。不能把四分周期模板自动拉伸成附点四分；连梁和减时线按每个演奏拍分组。

本轮扩展的是拍内节奏，小切分也只覆盖一拍；整小节选区仍重复同一模板，不代表跨拍切分或一小节内不同模板的组合。模板不暗加休止、Tie 或连音组。

原需求“四个十分音符”按“四个十六分音符”理解；“八分+附点+16分”按“附点八分＋十六分”理解。

## 6. 技巧、连接与内容保护

### 6.1 用户确认后移除演奏标记

技巧、Tie／延音线、连音组、圆滑线、延长记号等与目标相关的演奏标记，不再一律阻断。先计算新的逐拍结果，展示实际将移除的项；点击“应用节奏型”后在同一浮层内确认：

> 将移除 2 项标记：击弦、延音线。保留原音符，按节奏型调整。

按钮为“返回预览”和“确认调整”。无受影响标记时一次应用即可，不增加确认。只清除受影响谱层／目标相关标记，范围外无关记号保留。连接另一端在范围外时，提示其跨范围影响；确认只删除连接关系，不删除外端音符。

取消、返回、Esc、关闭均不改谱。确认针对当前模板、谱层、范围、内容及版本；任何一项变化都使确认失效，重新预览后重新确认。连音组仅部分进入目标时应扩大到完整组才能调整，不留下失效半组；连音中的原音按起点归属各演奏拍并保留顺序，不复制成多个起音。

### 6.2 歌词与和弦不是可随意清除的技巧

建议保留歌词全部段内容并跟随其原音符／gap；和弦跟随原拍点，名称与指法不改。带词或和弦的空位需作为有内容位置参与顺序映射，不能按“纯空位”丢掉。预览注明保留内容会随原位置重排。

若现有锚点无法一一保留，则阻止并说明哪项内容不能保留，不用“清除标记”的笼统确认删除歌词或和弦。本稿原型只能演示简化内容跟随，不证明生产锚点迁移已实现。

## 7. 简化后的操作与反馈

面板仅保留：标题、当前谱层与目标拍范围、对应拍号的模板、当前／应用后对照、一句结果说明，以及取消／应用。无双谱、谱层选择、范围切换、搜索、常驻成功校验条或重复的说明区。

v2.1 改为上方全宽模板区、下方紧凑“当前 → 应用后”并排对照，压缩原右侧大面积留白；模板桌面四列，8 种常用和 4 种细分各自成组，正常态对照区目标不超过 170px。内容过高时滚动正文，底部按钮保持可见。

选择卡片只预览。说明示例“保留 1 个音，新增 2 个空位”；多拍可以写“2 拍分别套用，保留 3 个内容，新增 3 个空位”。有错误或标记移除时才出现对应提示。

- 应用前重新检查文档、目标和内容。外部目标变化后显示“选区已变化，请重新预览”，不能把旧预览提交给新目标。
- 应用中禁用重复提交；多拍一次提交，任何一拍失败整体不写入。
- 提交失败保留模板与预览，可重试；失败不创建历史。
- 成功关闭浮层，保留范围高亮并回焦入口，状态提示可撤销。一次撤销恢复整次多拍操作、空位、原内容与被清除标记；产品重做恢复同一结果。
- 相同内容、时值、空位及标记结果不增加历史；不能只因重新生成了内部位置 ID 就创建“变化”。

## 8. 需要保留的建议边界

下列规则原为设计补充建议，随 v2.1 整体确认后作为实施边界：

1. **每拍内容数超过模板位置时阻止**，明确第几拍有多少内容、模板能容纳多少；不删除尾音，不把多音合并，不跨拍借空位。
2. **有内容事件跨出范围时提示扩大范围**，保护音符、明确休止及带内容 gap 的范围外部分。若一个原事件完整位于多拍范围内，按其原起点只映射一次到所属拍，后续时值按模板和空位重建；这不等于把多个 Tie 相连的独立拍点合并成一个。必要的连接移除仍需确认。
3. **歌词与和弦独立保护**，能一一跟随就保留，不能保留则阻止；不包含在默认清除演奏标记中。

首期仍不包含跨小节、跨轨、其他拍号、自定义模板、收藏、最近使用、试听、插入并顺移后续内容、双谱联动或生产自动转写。普通时值／拆分继续独立工作，不恢复历史上撤销的“细分简谱”“拆分并同步”入口。

## 9. 验收要点

以下供产品验收；自动化与浏览器已覆盖项目见[实施记录](../records/REQ-043产品实现与验证.md)，未将原型结果作为生产证据。

- **A01** 一长音变三位置：原音保留一次，两个新增位置为空，不复制音高、不加 Tie。
- **A02** 两音变三位置：保留两音顺序，第二音允许缩短，末位为空。
- **A03** 已有空位、混合 gap、纯空范围均可用；仅提取有内容位置，不伪造休止。
- **A04** 明确休止保留类型和顺序；一个长休止只占一个保留位置，其余新增空位。
- **A05** 每拍超额阻止，指出具体拍；多拍总数够用也不能跨拍挪音，失败整体不写入。
- **A06** 点击短音可自动定位完整拍；多拍首尾向外归完整拍，高亮与只读范围一致。
- **A07** TAB 多弦和简谱复音各算一个位置；TAB 修改整拍六弦，保留弦品位和组内内容。
- **A08** 4/4、3/4 共用 12 种、6/8 使用 5 种模板，时长正确，整小节分别 4／3／2 周期；三十二分起点和时长精确保留，三层连梁／减时线正确；6/8 三八分不是三连音。
- **A09** 标记先预览影响，再确认移除；取消／返回不写谱；确认失效后不能沿用。
- **A10** 歌词所有段、和弦名称和指法一一保留，带内容空位不能被丢弃；无法保留时解释原因。
- **A11** 跨范围音符／休止／带内容 gap、部分连音组、跨小节、无当前拍、不支持拍号不误写；连接移除不删除外端音，Tie 相连原拍点不被合并。
- **A12** 单谱隔离，另一层持久化资料不改；不出现双谱开关。另一层真空窗派生提示沿用原规则。
- **A13** 选择／取消只影响预览；过期需重算；失败可重试；双击应用只有一次提交。
- **A14** 多拍与标记清除一次撤销／重做；相同结果无历史；关闭后已应用数据保留。
- **A15** 空位保存、重载仍保留模板时值，补音继承时值，成品无空框或伪造的休止；原休止仍正常显示。
- **A16** 唯一入口原位替换“拍点”，键盘和焦点可用，常态面板没有多余开关或成功提示。
