## 设计原则

沿用当前编辑器的白色谱纸、灰蓝画布、蓝色操作色、系统中文字体和本地音乐符号。原型独立放在 [req019-037](../prototypes/req019-037/README.md)，不修改正式产品路由或组件。

使用 `ui-ux-pro-max` 和 `frontend-design` 技能。色彩延续既有基线：纸白 `#FFFFFF`、工作灰 `#F4F6FA`、墨蓝 `#202838`、交互蓝 `#285BE0`、选择浅蓝 `#EDF3FF`、错误红 `#BC3547`。输入与主操作高 32px，间距采用 8／12／16px。主视图按 1400px 桌面编辑器审阅，缩小预览不等于修改产品最小宽度。

本轮 UX 检索 `modal focus return unsaved` 命中可见键盘焦点；React 检索 `input focus border nested` 命中弹层焦点管理。采用“焦点留在可操作控件、关闭后恢复触发位置”的原则；不把 React 19 的具体 API 建议当作项目实现要求。Ant Design 已安装版本为 6.4.4，正式实现优先使用其组件。

## 本轮已确认的口径

用户通过会话中的选择卡明确选择 `navigation=preserve-return`、`technique=all-text`：

1. **REQ-033 导航。** 暂存自定义编辑、打开“我的指法”，取消／返回后恢复全部本次编辑状态，包括尚未校验通过的输入、指板内容、撤销重做历史。点击收藏卡片只预览，点击“选用”时确认替换；取消确认保留暂存内容并留在库中，确认替换后返回自定义界面，仅替换自定义编辑缓冲，之后仍须“完成编辑”回填父草稿，再点击“应用”写入谱面。保存收藏仍独立保留；不自动保存、不自动应用谱面。
2. **REQ-037 范围。** 统一调整谱面所有同类技巧文字（如 H／P／S、P.M.、let ring、A.H.、T、tr、推弦文字及自然泛音文字）。具体字号以原型效果确认。

## 随设计稿确认的边界

以下边界在设计稿中说明，用户确认设计稿时一并确认；若用户另有口径，先修订设计：

- **REQ-021 缺省级数：** 仅在有可靠调内级数时展示；搜索结果、调外和弦、自定义指法缺少级数时不编造罗马数字、不以“标准调弦”冒充级数。原型可先展示已知的 C 大调分组。任意调外和弦的分析不在现有级数能力中。
- **REQ-031 焦点：** 参考图箭头标出的是内层重复蓝框，拟移除这一层；保留外层单一焦点表达以及键盘可见焦点。若用户指所有输入外框均移除，需要进一步确认样式。
- **REQ-036 激活范围：** 拟在用户进入／已停留“和弦”页签时直接绑定已选单拍，不自动抢占歌曲、简谱与歌词等其他页签，不强制展开收起侧栏。同一拍的气泡／侧栏复用现有未应用草稿，重复进入不从谱面重读覆盖；切换到另一拍时沿用旧口径丢弃旧拍未应用输入。没有单拍或存在范围选区时提示选择单拍，不扩展为批量和弦编辑。

## 沿用的已确认规则

依据 [REQ-017～030 已确认口径](20261115_REQ-017-030需求与口径.md)：

- 名称、推荐、库选用、自定义完成及显示方式先修改共享草稿，再点击“应用”写入谱面。删除例外，立即删除并清空输入。
- 改名保留指法；选择推荐和弦或库指法同时回填相应名称与指法。自定义取消不修改父草稿。
- 调性来自曲谱明确的主音、大小调数据；`1=C` 单独不足以推断 C 大调还是 A 小调。库内临时浏览不修改曲谱调性。
- 现有 IME、弹层层级、会话失效和焦点恢复保护继续生效；本轮不擅自改为切拍自动应用。

实现核对：谱面“仅名称／名称与指法”当前已由 BUG033 定义为全谱即时显示偏好，继续沿用；和弦名称、指法内容仍遵守共享草稿后应用规则。本轮不回退该显示偏好修复。

## 实施前技术事实

现有库组件为 `ChordLibraryModal`。目前自定义弹窗 Esc 直接取消，没有未保存修改确认；从库进入自定义会交接卸载原库，没有自定义与“我的指法”的往返暂存机制。

已有级数仅来自按调性生成的推荐分组，文本搜索转入全目录后不附通用级数；不能承诺任意和弦或指法均有准确级数。

谱面 H／P／S 默认 9 布局单位，H／P 碰撞后的内嵌标签已有降为 6 的回退；工具栏 H／P／S 是 13px 的控件文字，两者不应混淆。正式实现需要同步字体测量、避让、命中、SVG 和 Canvas，不能只改页面 CSS。

字号建议优先审阅 7／9（约 78%）的统一比例，同时提供 6.5 的备选预览。已有密集内嵌标签为 6，不应继续机械缩小；自然泛音等不同原始字号按统一比例并保留最低可读字号。字体视觉收紧时继续保留足够的点击范围，不能按缩小后的字形同步压缩可点击区域。具体阈值在设计稿确认后落实为实施参数。
