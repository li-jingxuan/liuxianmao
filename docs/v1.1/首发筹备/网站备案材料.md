# 六线猫网站备案材料

用于六线猫在阿里云办理个人首次 ICP 备案。域名和服务器均已准备，按湖南省长沙市的申报场景整理。 [阿里云个人网站备案指南](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)

## 网站信息

| 备案字段 | 建议填写 |
| --- | --- |
| 备案性质 | 个人 |
| 服务类型 | 网站 |
| 网站名称 | 六线猫，提交前核对备案省份的命名要求 |
| 备案域名 | `liuxianmao.com` |

| 网站负责人 | 备案人本人，按本人证件和联系方式填写 |

[阿里云网站信息填写指引](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/fill-in-website-information) · [阿里云域名备案说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/prepare-and-check-the-domain-name)

### 网站用途备注

> 本网站提供浏览器端吉他曲谱编辑工具，支持六线谱、简谱、歌词和和弦编辑、曲谱试听，以及曲谱文件的本地导入和导出。

## 个人材料清单

- [ ] **本人有效居民身份证原件**。准备正反面清晰照片，按阿里云 App 提示上传并完成人脸核验。
- [ ] **本人常用手机号、应急手机号、邮箱**。本人手机号需能接听审核电话、接收核验短信。
- [ ] **证件住所和详细通信地址**。按证件信息、实际情况及当地管局规则填写。
- [ ] **省份补充材料（如需）**。选定省份后，按备案页面提示准备域名证书、手持证件照等材料。 [阿里云备案材料说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/overview) · [各省通信管理局备案规则](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-regulations-of-the-miit-for-different-regions)

证件照片、证件号码、联系方式和详细地址直接在阿里云备案表单填写或上传。

### 湖南长沙个人首次备案补充材料

- **身份证原件彩照和人脸核验**。这是阿里云湖南规则页列出的个人基础材料。 [阿里云湖南备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-hunan)
- **网站建设方案书**。阿里云材料总表将湖南无主体新增备案列为需提供方案书的场景，湖南规则页的个人材料清单未单列。先备好六线猫底稿，补齐实际部署信息、网站截图和签名栏，按本次订单确认是否上传。阿里云地区规则汇总列出的签字、扫描和邮件步骤适用于已有网站备案后继续新增网站的场景，首次备案的提交渠道以订单提示为准。 [六线猫网站建设方案书](网站建设方案书.md) · [阿里云备案材料总表](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/required-materials) · [阿里云地区规则汇总](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/understand-the-icp-filing-rules-of-each-regional-authority)
- **域名证书、手持证件照、单独的个人承诺书**。湖南规则页未将这些列为个人首次备案的通用附件，按订单提示补交。域名证书可以在阿里云域名控制台的 `liuxianmao.com` 管理页下载备用。 [湖南备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-hunan) · [域名证书下载指引](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/the-domain-name-certificate)

### 备案地区和地址

备案由个人主体住所所在地的省级通信管理局受理。以长沙作为实际所在地申报时，选择「湖南省／长沙市」，证件住所照身份证填写，通信地址按实际地址填写。如果身份证地址在外省，先在备案系统做基础信息校验，确认是否需补交本地居住证明。仅在其他省份有符合当地规则的真实住所或居住证明时，才按当地条件申请。 [湖南省通信管理局办事指南](https://hunca.miit.gov.cn/bsfw/bszn/art/2024/art_7ef0d8bd3b0d433ba4b9b277f883f74d.html) · [阿里云基础信息校验](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/basic-information-check) · [阿里云跨省备案规则](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/limits)

## 提交与上线

1. 在阿里云 ICP 备案控制台选择「网站」「个人」，填写主体和网站信息，按提示上传材料并提交初审。 [阿里云 ICP 备案控制台](https://beian.aliyun.com/order/index.htm)
2. 收到工信部核验短信后，在 **24 小时内**完成短信核验，再等待省通信管理局审核。 [工信部短信核验操作说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/sms-check)
3. 拿到正式网站 ICP 备案号后，在首页页脚居中展示编号并链接至工信部备案系统。配置域名解析和 HTTPS，确认 `liuxianmao.com` 和 `www.liuxianmao.com` 都能到达正式入口，再对外开放。 [首页页脚源码](../../../apps/website/app/page.tsx#L114) · [工信部备案系统](https://beian.miit.gov.cn/) · [工信部备案管理办法](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)
4. 自网站对外开通之日起 **30 日内**办理公安联网备案，获批后在首页页脚补上公安备案号及查询链接。 [全国互联网安全管理服务平台](https://beian.mps.gov.cn/)
