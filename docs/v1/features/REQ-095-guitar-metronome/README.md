## 需求与验收标准

### 用户场景与范围

用户打开吉他谱后，可以用稳定的节拍练扫弦、分解和弦或单段指法。编辑态可独立计拍并调节练习速度和拍号。试听态可开启随谱节拍，听曲谱的同时看拍点、听重音。

当前工作区通过工具栏右侧的耳机按钮进入「木吉他试听」。试听模式将谱面设为只读，可播放、暂停、继续或停止已提交的 TAB，可从谱首或当前 TAB 小节开始。曲谱速度和试听临时速度均为 20–300 整数 BPM，以四分音符为单位，曲谱未设置速度时按 90 BPM 试听。编辑器可设置 2/4、3/4、4/4、6/8 拍，拍号按小节记录。 [曲谱与试听基线](../../design-baseline/score-files.md#木吉他试听与曲谱速度) · [工具栏](../../../../apps/website/components/EditorShell/workspace/EditorToolbar.tsx) · [试听控件](../../../../apps/website/components/EditorShell/playback/PlaybackToolbar.tsx) · [拍号选项](../../../../packages/lxm-editor/src/core/constants.ts#L94)

### 首版需求

1. 编辑态在工具栏右侧、紧邻「试听」放置「节拍器」入口。点击打开非模态浮层，收起后继续计拍，入口仍显示运行和静音状态，旁边提供快捷停止。试听态保留拍点、状态和「设置」，原「静音」的位置改为「启用节拍器」，每次进入试听和换谱后默认不勾选。谱面左侧播放区统一控制试听及已启用的节拍器。
2. BPM 接受 20–300 的整数，含边界，单位为四分音符／分钟。初次打开时读取当前曲谱已保存的有效 BPM，隐藏谱首速度标记仍照常读取。无有效速度时使用 90 BPM，并标明默认来源。拍号默认读取谱首首小节，可手动选 2/4、3/4、4/4 或 6/8。谱首无有效拍号或超出首版选项时用 4/4，说明回退原因，可识别的原拍号一并显示，例如「曲谱为 5/8，练习按 4/4」。练习采用固定拍号，切换选中小节时维持当前设置。
3. 编辑态手动调整只影响独立练习，收起或停止后仍可继续使用，实际换谱或离开编辑器后清除。停止时可用「恢复曲谱设置」重新读取当前已保存的速度和谱首拍号，按同样规则回退。提交空白、小数或越界的 BPM 时说明有效范围，保留最近一次有效值，修正后可开始。整个过程不写入曲谱、撤销历史或待导出状态。
4. 每次开始都从第 1 点起拍，停止后清除当前拍点。2/4、3/4、4/4 每个四分音符响一声，每小节分别循环 2、3、4 点。6/8 每个八分音符响一声，面板按 3+3 展示六个拍点。首拍重音默认开启，每小节只加重第 1 点，6/8 的第 4 点保持普通拍。节拍器默认有声。运行期间锁定 BPM、拍号及恢复操作，停止后可改。首拍重音和静音即时生效，取消静音时沿用当前拍序，静音时拍点继续推进。
5. 试听态勾选后，节拍器从谱面实际发起播放时同步计拍。加载期间等待，暂停时提示音停下且拍点停在当前位置，继续时从同一位置接续。停止、播完、播放失败或退出试听时清除当前拍点及提示音。播放中勾选从下一拍加入，取消勾选立即结束点击和高亮，谱面播放继续。切换模式时停止原模式的节拍，返回编辑态时保留练习设置，浮层收起且等待用户开始。
6. 试听节拍使用实际播放速度和当前小节拍号，跟随起播位置、播放进度和临时调速。气泡顶部只读显示这两个当前值，随后显示曲谱设置来源，底行保留「首拍重音」与「恢复」。气泡与临时调速区的「恢复」均恢复曲谱试听速度，拍号随谱面推进。
7. 编辑态启动提示音失败或有声运行被中断时回到已停止，保留设置并提供重试或静音练习指引。静音运行中恢复声音失败时维持静音和拍序。试听态的提示音单独失败时提示异常，拍点继续跟随，谱面试听照常运行。实际换谱和离开编辑器会停止当前播放或计拍，取消换谱或离开确认时保持原状态。

首版覆盖编辑态独立练习和试听态随谱节拍。预备拍、自定义重音或细分、音色和音量调节、跨会话记忆纳入后续范围讨论。

### 验收场景

| 场景 | 操作与预期结果 |
| --- | --- |
| 布局与键盘 | 在不低于 1440px 的 `/editor`，编辑态工具栏可打开浮层。试听态常驻拍点、默认不勾选的「启用节拍器」和「设置」。气泡内依次显示当前速度及拍号、曲谱来源、首拍重音与恢复。编辑浮层和试听气泡支持点外部关闭，内部按 Esc 收起并把焦点交还入口。 |
| 曲谱参数与回退 | 用已保存 72 BPM、隐藏速度标记、首小节 2/4 的谱打开面板，显示 72 BPM 和 2/4。用无速度且谱首为 5/8 的导入谱打开，分别显示默认 90 BPM 和回退 4/4，并可辨认原拍号和回退原因。选中后续不同拍号的小节时，面板拍号保持固定。 |
| 手动设置 | 停止时分别输入 20 和 300，均可开始。提交空白、19、301 或 90.5，提示范围并保留上一次有效值。设定练习 BPM 与拍号，停止、收起再打开，值仍保留。点击「恢复曲谱设置」，读回当前保存值或对应的回退值。曲谱内容、撤销历史和待导出状态不因练习设置改变。 |
| 计拍与重音 | 用 120 BPM 测试，2/4、3/4、4/4 的相邻拍点间隔 0.5 秒，每轮分别循环 2、3、4 点。6/8 的相邻拍点间隔 0.25 秒，每 6 点循环并显示两组 3 点，唯有第 1 点重音。关闭重音后从下一个拍点起各点等重。运行时 BPM 和拍号不可改，停止再开始从第 1 点起拍。 |
| 静音与收起 | 运行中静音，后续拍点持续推进且无点击声。取消静音后从下一个拍点恢复声音。收起面板后状态仍可见，一键停止后无后续点击或拍点，重新打开显示已停止。 |
| 试听同步 | 默认直接播放谱面，拍点不亮。勾选后随第一拍起播，加载期间保持等待。暂停后拍点停在当前拍，继续后接续，停止或播完后清除高亮。中途勾选从下一拍加入，取消后谱面继续。调整临时速度时同步改变计拍速度，气泡显示同一 BPM；从气泡恢复，与工具栏一起回到曲谱速度。 |
| 音频不可用 | 模拟浏览器拦截音频启动或运行中断，显示已停止和恢复指引，重试时沿用练习设定。主动选择静音后可以开始可视练习，尝试取消静音仍失败时可继续看拍点，并能读到错误提示。 |
| 换谱与离开 | 运行中打开换谱或离开确认，取消后节拍继续。实际换谱或离开 `/editor` 后没有后续点击，新谱或重新进入页面时加载该谱的默认练习参数并保持停止。 |
