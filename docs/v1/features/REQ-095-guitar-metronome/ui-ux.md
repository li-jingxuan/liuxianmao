# 吉他节拍器 UI/UX 评审稿

本稿供 v1.0 口径与原型确认。在浏览器打开交互稿，建议以 1440 × 900 查看。初始画面展开节拍器便于评审，产品进入编辑器时默认收起且停止。原型模拟从谱首开始的木吉他试听、小节游标和临时调速。启用节拍器后可听到真实点击声。底部评审控件用于切换固定拍号的样例与异常场景。 [需求与验收](README.md) · [可点击原型](prototype/index.html)

## 放置与视觉

- 编辑态的第二行工具栏右侧保留「试听」与「节拍器」，浮层向下右对齐，宽约 370px，主要覆盖右侧属性面板边缘。浮层无蒙层，谱面仍可操作。若右侧控件会被遮挡，切换到对应操作时收起浮层。 [编辑器基线](../../design-baseline/editor.md#工作台与会话) · [工具栏源码](../../../../apps/website/components/EditorShell/workspace/EditorToolbar.tsx)
- 试听态左侧依次为谱面「播放／暂停／继续」「停止」、播放选项和临时调速。接着是节拍器状态、拍点、「启用节拍器」「设置」，最右为「退出试听」。「启用节拍器」默认不勾选，左侧播放区统一控制播放和已启用的节拍器。状态按实际流程显示「未启用」「待播放」「跟随播放」或「已暂停」。 [试听控件](../../../../apps/website/components/EditorShell/playback/PlaybackToolbar.tsx)
- 「设置」点击后向下右对齐展开约 324px 的气泡。标题下方并排只读展示「试听速度（BPM）」和「当前小节拍号」。曲谱来源置于数值下方、底行上方。底行左侧为「首拍重音」，右侧为「恢复」。临时调速区和气泡里的恢复按钮均读作「恢复曲谱试听速度」。气泡默认收起，打开时局部覆盖工作区。
- 两种模式沿用白底、`#f4f6fa` 工作区、`#dce2ec` 边框、`#202838` 正文与 `#285be0` 强调色，控件高度约 32–36px，圆角 6px。编辑态浮层展开曲谱来源和操作说明。 [工作区样式](../../../../apps/website/components/EditorShell/index.module.scss) · [全局色系](../../../../apps/website/app/globals.scss)
- 拍点格从 1 开始编号。当前拍格加粗边框和底部横线，首拍重音另用菱形、虚线和文字提示。6/8 在第 3、4 点间留组间距并加垂直分隔线。拍点无缩放、震动或全区闪烁，每次推进只更新格子及当前拍序读数。
- 编辑态运行时，入口显示「运行中」，静音时补充「已静音」，旁边提供快捷「停止」。进入试听态时结束独立计拍。退出试听时结束随谱计拍，返回编辑态后可用原练习设置手动开始。

## 参数与拍点

编辑态练习速度初次使用曲谱当前已保存的有效速度，即使谱面隐藏速度标记也照常读取。练习拍号初次使用谱首首小节受支持的拍号。选中其他小节时保持练习参数。无有效曲谱速度时取 90 BPM。谱首拍号缺失或超出独立练习选项时取 4/4，编辑浮层说明回退原因。试听态拍号按实际播放小节显示，按播放计划计拍。例如导入的 5/8 若能正常试听，显示并计 5 个八分音符拍点。 [曲谱与试听基线](../../design-baseline/score-files.md#木吉他试听与曲谱速度) · [歌曲设置组件](../../../../apps/website/components/EditorShell/settings/ScoreSettingsForm.tsx) · [拍号和速度常量](../../../../packages/lxm-editor/src/core/constants.ts)

所有拍号共用「每分钟四分音符数」这一 BPM 单位。数值接受 20–300 的整数，含边界。以下以 120 BPM 为例。

| 练习拍号 | 一个小节的拍点 | 相邻拍点间隔 |
| --- | --- | --- |
| 2/4 | 1、2，四分音符 | 0.5 秒 |
| 3/4 | 1、2、3，四分音符 | 0.5 秒 |
| 4/4 | 1、2、3、4，四分音符 | 0.5 秒 |
| 6/8 | 1、2、3 ｜ 4、5、6，八分音符 | 0.25 秒 |

首拍重音默认开启，仅加重第 1 点。6/8 第 4 点是第二组开头，保持普通拍。两种模式共用重音选择。编辑态静音默认关闭，可在计拍中切换，静音时照常走拍，恢复声音从后续拍点继续。

## 状态与交互反馈

| 场景 | 行为与反馈 |
| --- | --- |
| 编辑态展开、收起 | 入口切换浮层，点击「收起」、浮层外普通工作区或按 Esc 可关闭。关闭后保持已提交的练习参数，运行时继续走拍，入口继续显示状态。 |
| 试听态设置气泡 | 「设置」切换气泡，点击「收起」、气泡外或按 Esc 可关闭。关闭后保留有效设置与当前拍序。 |
| 调整与恢复 | 编辑态停止时可改练习速度及拍号，「恢复曲谱设置」读取最新已保存的速度及谱首拍号。试听态的临时调速同时影响谱面和随谱节拍。气泡与调速区的「恢复」同步回到曲谱速度。两种恢复均保留重音选择。 |
| BPM 校验 | Enter、失焦或开始时校验空白、越界或小数，提示「输入 20–300 的整数。」并保留最近一次有效值。用「开始节拍器」遇到错误时焦点回到 BPM；收起时舍弃无效输入。 |
| 开始、运行与停止 | 独立练习用开始和停止，每次开始从第 1 点起拍。运行期间锁定速度、拍号和恢复操作，给出短说明。面板内或工具栏停止均清除当前拍点，保留练习设置。 |
| 试听同步 | 勾选后在谱面实际起播时计拍，加载期间等待。暂停冻结当前拍点，继续时接续，停止、播完或播放失败时清除高亮和提示音。播放中勾选从下一拍加入，取消勾选立即结束提示音及高亮，谱面继续播放。停止或播完后保留本次试听的勾选，退出试听或换谱重置。 |
| 声音不可用 | 编辑态有声开始失败或运行被中断时显示已停止，保留练习参数并提示重试或使用静音练习。静音运行中恢复声音失败时维持静音及拍序。试听态节拍提示音失败时提示「节拍提示音不可用，拍点继续跟随谱面。」 |
| 换谱与退出 | 取消离开或换谱确认时继续当前练习。实际换谱或离开编辑器时停止并清除会话练习设置，打开新谱后重新从曲谱设定初始化。 |

## 键盘与无障碍

- 编辑态用 Tab 定位「节拍器」入口，以 Enter 或 Space 展开。浮层使用有标题的非模态对话区域，入口公开展开状态及受控区域。已停止时首焦点为练习速度，运行时首焦点为「停止节拍器」。
- 试听态 Tab 从谱面播放和停止经过调速区及「启用节拍器」「设置」到「退出试听」。打开设置时聚焦首拍重音。气泡内按 Esc 收起并把焦点交还「设置」。方向键、空格、Enter 由聚焦控件处理，输入法组合过程交给输入法。
- 从工具栏快捷停止后，若浮层展开则焦点放到「开始节拍器」，否则回到「节拍器」入口。外点收起时保留已经移到外部控件的焦点。键盘焦点始终有蓝色描边。
- 用文字表达开始、停止、静音及异常状态。读屏通过提示了解关键状态变化，当前拍读数可主动获取，逐拍更新不进入实时播报队列。

## 评审路径

1. 用 1440 × 900 打开原型。核对入口与「试听」相邻，以及浮层、六线谱、右侧歌曲信息的关系。确认 BPM 来源显示 88、拍号为 4/4。将练习速度改为 72 并切换拍号，收起、再打开，确认练习值保留及右栏曲谱速度不变。点「恢复曲谱设置」回到 88 BPM、4/4。
2. 用 120 BPM 分别试 2/4、3/4、4/4、6/8。核对拍点数量、6/8 的分组及首点重音。运行时切换重音与静音，核对速度和拍号的锁定、静音拍点继续推进。收起后确认运行文字与快捷「停止」，尝试重开面板及直接停止两条路径。
3. 点「试听」，先直接播放，验证默认关闭。播放中勾选「启用节拍器」，核对下一拍加入，暂停时拍点冻结、继续时接续、停止时清除。改变临时速度，打开「设置」，核对字段、曲谱来源和底行的顺序，点「恢复」回到曲谱速度。停止后重新播放，核对勾选状态与第 1 拍起播。退出试听，再次进入后核对默认关闭。
4. 在底部评审工具选择「72 BPM（隐藏标记）、2/4」，核对谱首速度标记隐藏时仍读取 72 BPM、2/4。切换「速度与拍号缺失」或「无速度、导入 5/8」，核对 90 BPM、4/4 及来源提示。输入空白、19、301、90.5，验证错误与修正路径。切换「模拟声音不可用」，用有声启动观察失败，再静音开始并尝试恢复声音。最后用「模拟离开编辑器」检查停止及返回后的状态。
5. 用键盘完成展开、调节、开始、Esc 收起及快捷停止。检查当前拍格和重音标记在不辨认蓝色时仍可区分。

## 实现采用的口径

- 试听默认关闭节拍器。播放中开启从下一拍加入，关闭立即清除点击声和高亮。气泡将当前试听 BPM 和小节拍号置于曲谱来源上方。
- 练习 BPM 统一采用四分音符／分钟、速度边界及 90 BPM 缺省值。拍号读取谱首首小节、首版四档与 4/4 回退，以及 6/8 每个八分音符发声、仅第 1 点重音。
- 编辑态运行时锁定练习速度与拍号，收起继续、快捷停止，以及声音异常、换谱与离开时的反馈。
