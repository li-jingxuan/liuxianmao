## 需求与验收标准

为经常连续写相同扫弦、指法或节奏的编谱者，在目标小节正文内居中显示单小节重复记号 `𝄎`（形似 `%`）。它表示目标小节按紧邻前一小节的演奏内容再弹一次。目标小节仍有自己的位置和正常拍数，演奏完继续下一小节。用户可以展开记号，回到普通小节录入或修改实际内容，并在保存重开后继续编辑和试听。

- 三小节测试谱中，第 2 小节显示 `𝄎`，保留六根弦线、两侧小节边界及正常时长。从谱首试听顺序为第 1 小节四拍 → 第 2 小节四拍 → 第 3 小节四拍。两个四拍段音符和节奏相同，青绿游标在第 2 小节自己的四个拍位依次推进。
- 点击记号选中整小节，右侧显示来源、目标及拍数。展开后可选中实际拍位并修改。保存重开后，记号、展开状态、实际音乐和试听顺序与已保存状态一致。
- 第一小节无法添加。覆盖已有内容必须显式确认。取消保留既有内容，一次撤销恢复替换前的完整小节。不同拍号、歌词等边界提供原因和可执行的下一步。

## 交互交付

双击打开 [prototype/index.html](prototype/index.html)，评审视口宽度至少 1440px。`brand.png` 与 HTML 放在同一目录即可离线使用。打开时选中第 2 小节，谱例含前后各四个 TAB 音符。原型评审区可更换谱例、重置和切换方案。

### 工作台与入口

浅灰工作区 `#f0f1f3`、白谱纸 `#fff`、深色谱字 `#252b35`、编辑蓝 `#1d5bc6`、播放青绿 `#087d75`。顶栏沿用六线猫标识及菜单结构。工作台用系统中文字体，品位用等宽数字。谱纸集中呈现同一行三小节，说明留在谱纸下方，评审控件放在谱纸外。属性栏用当前小节的编号、拍号、时长和内容状态组织信息。

| 场景 | 操作与反馈 |
| --- | --- |
| 从右栏添加 | 选择目标小节，或从工具栏点「小节」。在右侧「小节 → 反复与跳转」确认「来源 → 目标」与拍数，然后点「添加单小节重复」。目标为空时立即完成，目标保持选中，状态条告诉用户添加到哪个小节并提供撤销。 |
| 从谱面上下文进入 | 右键小节，或聚焦小节后按 `Shift+F10`。选择「小节工具 › 反复与跳转」，打开右侧面板并聚焦同一控件区。预览、禁用条件、确认与撤销共用这一个控件。 |
| 有记号时查看与编辑 | 点击符号选择整小节，侧栏显示「重复前一小节」「展开为普通小节」「编辑前一小节」。符号状态下可导航至前后小节，拍内编辑入口随实际音符隐藏。展开保留当前实际演奏内容，焦点落到首拍可编辑品位。一次撤销可恢复记号。 |
| 试听 | 点耳机「试听」，从进入前所选小节起播，起点可改为第 1 小节。播放、暂停、继续、停止与试听状态同区。页面切到后台时暂停并提示原因，返回后可从当前拍继续。试听时谱面只读，侧栏收起，退出后恢复原选区。青绿游标和顺序栏同步显示目标小节及拍位。可用「上一拍」「下一拍」逐拍验证。 |
| 保存重开 | 「文件 → 保存模拟」记录已应用的曲谱、重复状态和当前评审方案。「文件 → 重开模拟」恢复保存的状态，重开前有未保存的修改时先确认。原型使用浏览器存储，若 `file://` 存储被浏览器限制，则在当前页面内保存，并提示有效期。 |

### 备选方案与边界

用同一初始谱例比较。先从第 1 小节首拍的 `3` 品创建第 2 小节的记号，再将源首拍改为 `6` 品。两个选项位于谱纸下方的「原型评审」区域，代表两套产品行为。默认预览 A，跟随历史归档建议。 [归档技术方案](../../../archive/mvp/versions/v7/20261012_单小节重复记号技术方案.md)

| 待确认方案 | 第 1 小节 `3` → `6` 后 | 后续编辑与试听 |
| --- | --- | --- |
| A 保留原内容并展开 | 第 2 小节自动去掉记号，显示创建时写入的 `3` 品。状态条提示「第 2 小节已展开，保留源小节修改前的内容」。 | 直接编辑第 2 小节。试听首拍依次为第 1 小节 `6` 品、第 2 小节 `3` 品。一次撤销恢复源品位和目标记号。 |
| B 随前一小节同步 | 第 2 小节保持记号，并同步为 `6` 品。状态条提示「第 2 小节已同步更新，保留重复记号」。 | 试听两个小节均用更新后的 `6` 品。手动展开时得到当前同步内容，随后独立编辑。一次撤销恢复源内容和目标同步前的内容。 |

## 交付与审查

### 产品验收路径

1. 在编辑器导入同拍号的三小节 `.lxm`。第 1 小节录四个四分音符，首拍为 `3` 品；第 2 小节先录 `9` 品。选第 2 小节，从「小节工具 → 单小节重复」打开右栏，点「添加单小节重复」。先点「取消」，确认 `9` 品保留，再重新打开确认并点「替换并添加记号」。谱面显示居中的 `𝄎`，六弦及小节线保留。点 `[data-measure-repeat-target]`，核对整小节高亮和右栏「重复前一小节」。
2. 从第 1 小节试听。核对 `1 → 2 → 3`，第 1、2 小节四拍音高一致，游标按第 2 小节自己的四个拍位前进。导出「六线猫专用谱(.lxm)」并导入，复查记号和试听。点「展开为普通小节」，核对第 2 小节显示 `3` 品并聚焦首拍；撤销后恢复 `𝄎`。
3. 点「编辑前一小节」，把源首拍设为 `6` 品。第 2 小节自动展开、仍显示 `3` 品，影响详情提示保留原演奏内容。一次撤销同时恢复源首拍 `3` 品和第 2 小节的 `𝄎`。再撤销添加，可恢复第 2 小节原来的 `9` 品。

产品使用快照方案。目标保留自己的小节线、拍号、有效时长和独立内容。若源音乐或相邻关系发生变化，只有相邻内容仍等价且边界合法时才保留记号。第一小节、空源、重复链、不同拍号或有效时长、任一节有歌词、跨小节技巧或简谱连接、相邻处有分段或反复与跳转边界时禁用添加；同拍号且等长的弱起可沿用普通校验。缩写状态可以选择整小节，展开后才能编辑实际拍位。 [反复与跳转合稿](../REQ-106-反复房子/design-review.md) · [交互原型](prototype/index.html)

若小节开头的 `x`、扫弦或琶音使用前面写入的和弦指法，快照也保存这段节内起始指法。展开和重开文件后仍可还原这些拍位，节内实际写入的和弦从对应拍位起生效。

### 手动验收脚本

1. 打开基础谱，在第 2 小节右键，经「小节工具 › 反复与跳转」进入右侧属性。添加后确认符号居中，TAB 弦线、小节线和小节的整体选区仍在。点击符号只能选中整小节。
2. 点「试听」，起点改为第 1 小节。连续按「下一拍」十二次，核对 `1×四拍 → 2×四拍 → 3×四拍`。第 2 小节的音高序列与第 1 小节相同，游标保持在第 2 小节。点「停止」再点「播放」，验证自动走过相同路径。播放时切到其他标签页再返回，核对后台暂停提示及游标停留。点「继续」，核对第 3 小节走完后显示「试听结束」，退出后恢复选区。
3. 保存带记号的版本。展开第 2 小节，将首拍改成 `7` 品。点「重开模拟」先取消，确认 `7` 品保留，再确认丢弃并重开。核对记号恢复、试听仍按三小节顺序。若浏览器支持本地文件存储，刷新页面后也可从「重开模拟」找回快照。
4. 在 A 下点击「编辑前一小节」，改第 1 小节首拍为 `6` 品。第 2 小节展开且首拍仍为 `3` 品。撤销源编辑后，切到 B，再把首拍改为 `6` 品。第 2 小节保持记号，手动展开后为 `6` 品。再改第 2 小节首拍为 `8` 品，第 1 小节应仍为 `6` 品。
5. 依次加载「选择第一小节」「第 2 小节有内容」「第 2 小节拍号不同」「第 1 小节有歌词」「第 2 小节有歌词」「重复链」。逐个验证上表的原因和恢复操作。「第 2 小节有内容」先取消，再确认，最后撤销与重做。取消及撤销后应看到原品位 `5 / 3 / 2 / 0`。

### 自动验收与适用范围

在已安装 Playwright 和 Chromium 的环境运行 `node docs/v1/features/REQ-108-单小节重复/prototype/acceptance.mjs`。可通过 `LXM_PLAYWRIGHT_MODULE` 指定 Playwright 入口，通过 `LXM_BROWSER_EXECUTABLE` 指定 Chromium 或 Chrome 可执行文件。 [验收脚本](prototype/acceptance.mjs)

已在 Playwright 1.65.1 与 Chrome 158 以 1440 × 900、离线 `file://` 运行验收，覆盖入口、符号几何居中、十二拍顺序、自动播放、暂停与继续、Web Audio 示意音的频率序列、两个方案、保存重开及异常反馈。以 1440 × 790 目视复核编辑和试听两种布局。

第 3 小节模拟触发 `visibilitychange` 后，旧脚本可复现等待「试听结束」超时，因为页面进入后台会暂停试听，回前台需要手动继续。新版脚本使用 Playwright 页面时钟共同推进 `setTimeout` 与 `performance.now()`，逐拍断言，并覆盖后台暂停、回前台保持暂停、手动继续及结束。示意音另核对发音调用的频率序列。补跑前台真实时钟，十二拍及结束状态按顺序出现。

原型使用 90 BPM、单音品位和 Web Audio 合成示意音，界面有明确标识。实际木吉他采样、复杂节奏与扫弦技巧、完整 `.lxm` 往返、多轨及复杂结构联动留待产品实现验证。产品确认人、最终方案及确认日期待记录。
