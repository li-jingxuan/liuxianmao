# REQ-011 六线猫 v1.0 GEO 技术方案

**待评审。** 让使用联网问答的琴友找到六线猫的写谱入口，让开发者找到与实际版本相符的接入文档。验收重点是公开资料可访问，其中的产品、文件格式和版本信息可以被准确引用。[飞书 v1.0 需求表](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=D9eELE)

## 现状与首发范围

首页已经直接展示产品介绍、谱例、写谱步骤和编辑器入口。仓库 README、两份包 README 和 Core API 手册已统一包名、文件格式及候选安装口径。[首页](../../../../apps/website/app/page.tsx) · [项目 README](../../../../README.md)

建议首发沿用现有首页和 `/editor`。首页集中回答写谱、保存和嵌入问题，`/editor` 承接实际试用。开发者文档先以正式放行的 GitHub 版本页和包文档为依据，公开后再从首页补真实链接。页面搜索元信息、canonical、sitemap 和站长平台验收归入 v1.1 REQ-001 SEO。[Core README](../../../../packages/lxm-editor/README.md) · [React 接入指南](../../../../packages/lxm-editor-react/README.md) · [搜索筹备资料](../../首发筹备/01-搜索与内容发现.md)

## 首页要答清楚的问题

| 用户会怎么问 | 建议公开的答案 |
| --- | --- |
| 六线猫是什么？可以编辑什么？ | 六线猫是浏览器里的吉他曲谱编辑器。可以在同一份谱里写六线谱（TAB）、简谱、歌词和和弦指法。主页提供「打开编辑器」入口。 |
| 吉他谱怎么发给学生，又能留着继续改？ | 导出六线猫专用谱 `.lxm` 供下次导入编辑，另导出 A4 PNG 发送给学生。需要 PDF 时可在浏览器打印界面另存。 |
| 怎么把六线猫嵌入 React？能自己做编辑界面吗？ | React 19 应用可用 `@liuxianmao/lxm-editor-react` 嵌入写谱工作区。自建界面可用 `@liuxianmao/lxm-editor` 加载和编辑曲谱，并生成布局和播放计划。安装命令与链接以已公开的对应版本为准。 |

把答案写入可见正文，沿用首页已有谱例和操作步骤。文件格式用 `.lxm`，内容为 UTF-8 JSON。网站截图或谱例若要另行公开分发，先落实素材授权。桌面下载链接随对应平台的正式制品上线。[文件与导出基线](../../design-baseline/score-files.md)

## 实施步骤

1. **发布可引用的内容。** 首页的产品定义、示例解释、常见问题和入口链接由 Next 服务端输出。把包版本、安装命令和支持平台与实际放行的制品对齐。
2. **核对公开来源可访问。** 在生产构建验证 HTML 和编辑入口，发布后从外网逐个打开首页和已公开的版本文档。若现有 `robots.txt`、反向代理或 CDN 规则挡住了目标平台的搜索爬虫，再核实是否需要调整。以 ChatGPT 搜索为例，`OAI-SearchBot` 控制搜索抓取，`GPTBot` 对应模型训练，两者可以独立配置。`robots.txt` 只用于排查现有抓取规则，新增文件不作为本期交付项。[OpenAI 爬虫说明](https://developers.openai.com/api/docs/bots)
3. **抽查 AI 回答及引用。** 用同一组问题在 ChatGPT 搜索和一个可用的中文联网问答服务建立上线前基线，发布后第 7 天和第 30 天复查。按实际回答和引用来源判断哪些事实还需补清。

## 验收方式

- **页面可读。** 关闭 JavaScript 或查看初始 HTML，能取到产品用途、`.lxm` 与成品的区别、开发者入口以及可访问的 `/editor` 链接。开启 JavaScript 后，从首页打开编辑器，完成修改、导出 `.lxm` 和重新导入。
- **引用来源可用。** 从外网打开首页、编辑器入口和已公开的版本文档，确认链接指向正确的公开页面与版本。发现目标搜索爬虫受阻时，记录具体规则和受影响的页面，再决定是否调整。
- **公开事实一致。** 官网与正式版本文档对 `.lxm`、PNG、打印、Core 和 React 包名、React 19 以及下载状态给出一致答案。逐个打开对外链接，确认版本和权限。
- **保留问答样本。** 每次记录日期、平台、地区、问题原文、是否返回答案、答案是否包含关键事实、引用链接及错答。使用上表三道题，再增加「在线怎么写带和弦的吉他六线谱」作为不带品牌的测试。答案和引用出现情况用于判断后续内容改进，项目验收看公开页面与实测记录。

## 请确认两项

1. **对外页面。** 建议 v1.0 先做首页和 `/editor`，直接复用当前首页布局。Core 和 React 指南继续以版本化仓库文档为入口，随公开发布补链接。
2. **抽测口径。** 确认使用上面的固定问题和两类联网问答服务。正式上线抽测时按实际部署地址核对引用链接。
