# REQ-087 百度、Google 搜索与 GEO

**目标**　让搜索「在线六线谱编辑器」的创作者找到 Web 入口，让搜索 React 接入方法的开发者找到当前版本的文档。沿用飞书已有需求，技术方案先评审，确认后实施。

## 交付与验收

1. 首页初始 HTML 呈现产品用途、真实谱例说明与编辑器链接。分别核对首页、编辑页的标题、描述、正式地址和 canonical，验证带渠道参数的链接仍归到同一正式地址。
2. 在正式域名和实际部署子路径验证 robots、sitemap 与公开页面的响应。通过百度搜索资源平台和 Google Search Console 验证站点，分别记录提交、抓取和可获知的索引状态。
3. 官网、README、npm 与教程对文件格式、包名和可用平台给出一致说明。用固定中文问题抽查生成式问答，记录回答、引用地址和需要修正的事实。上线后第 7、14、30 天按方案复核。

**待确认**　正式域名、可索引页面、站长平台权限和公开内容口径。验收依据为页面实测与检查记录，排名及引用量作为观察项。[技术与内容方案](../../首发筹备/01-搜索与内容发现.md)
