# BUG-082 琶音符号高度

**待验收。** 使用相同起止弦的扫弦和琶音，其起笔、箭尖与符号上下外沿对齐。琶音的两种方向保留波线和竖直箭头，相邻两弦范围也能显示完整波形。 [飞书工单](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A83:I83)

## 验收路径

1. 打开 `/editor` 默认谱例《理想》，找到第 33 小节 Dsus4／D 和弦附近。随仓库保存的谱例中，标注区的扫弦和琶音均为第 1 至第 4 弦。也可在相邻拍分别设置第 1 至第 6 弦或第 5 至第 6 弦的扫弦、琶音。
2. 对照两个符号的上下边界，再切换到相反演奏方向，确认琶音波线接到箭头底边，箭头完整可见。选中任一符号后检查起止弦端点仍可操作。
3. 如需检查成品，分别打开图片和打印预览，核对相同弦范围的符号高度。

琶音原本额外把箭头移出目标弦线，并给下行琶音预留了更大的符干间距。本次复用扫弦的箭头几何，缩短波线使其止于箭头底边。自动回归覆盖两种演奏方向、全弦与相邻弦范围、符干净空和端点点击。 [布局实现](../../../../packages/lxm-editor/src/layout/techniques/technique-layout.ts) · [布局回归](../../../../packages/lxm-editor/tests/layout/technique-layout.test.ts)
