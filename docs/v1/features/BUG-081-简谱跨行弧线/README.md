# BUG-081 简谱跨行弧线

六线猫 v1.0 · 对稿 v1 已确认 · 实现待验收。 [飞书 BUG-081](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A82) · [可操作原型](prototype/index.html)

## 需求与验收标准

简谱的延音线或圆滑线跨到下一谱行时，读谱者需要顺着上行起音找到下行落音。飞书「参考图片」标出了两个 `1` 上方的短弧，要求起音侧靠近右侧小节线，落音侧靠近左侧小节线。「参考图片-2」给出了从两个行边接续的谱面示例。 [飞书 BUG-081](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=E82%3AF82)

- 同一谱行的弧线仍从起音连到落音，保持现有完整弧形。
- 跨相邻两行时，上行的弧段从起音上方朝右小节线延伸，下行的弧段从左小节线内侧接到落音上方。靠近小节线的一端渐平，与小节线有可见留白，整条笔画留在行内。
- 局部有高八度点、其他弧线或谱面标记时，弧线仍需保留净空。分别用同音延音线和异音圆滑线核对接续方向。

## 交互交付

在 1440px 或更宽的浏览器直接打开独立 HTML，默认显示「延音线／建议稿」。对比使用同一份简谱、和弦、TAB 和歌词。原型里的「修改前」按问题截图示意短弧，使用固定谱例展示。

1. 在原位切换「修改前」和「建议稿」，对照上行右侧和下行左侧，核对边界留白与接续方向。上行左侧的同一谱行弧线可作对照。
2. 切到「圆滑线」重复比较。延音线用 `1 → 1`，圆滑线用 `1 → 5`，同一类型在前后两档共用音符位置。
3. 取消「显示对稿标记」，查看石墨色弧线在白色谱面上的实际读谱效果。可用 Tab 在两组切换和复选框间移动，方向键切换同组单选项，空格切换复选框。

页面沿用现有编辑器的顶栏、工具栏、谱面和右侧栏比例，以及白色谱面、石墨色符号和蓝色选区。现有简谱弧线工具提供延音线和圆滑线，简谱布局会按谱行拆分连接。 [简谱与歌词设计基线](../../design-baseline/editor.md#简谱与歌词) · [编辑器颜色与文字基线](../../../../packages/lxm-editor-react/page.css) · [简谱弧线布局](../../../../packages/lxm-editor/src/layout/music-text/numbered-mark-layout.ts)

## 实施决定

- 简谱延音线和圆滑线共用跨行规则。开放端沿水平方向接近行边小节线，常态从小节线墨迹内侧留约 5 个逻辑单位。双小节线以靠谱行正文的笔画为准。
- 极窄处优先保留数字中心与节奏槽横坐标，弧段按剩余宽度收短、降低。多音延音线仍对准实际相连的数字，弧线沿用现有按谱面标记避让的垂直规则。
- 跨三行及以上时，每个中间谱行从左边界附近画到右小节线附近，采用最多 2 个逻辑单位高的浅弧。中间谱行即使没有简谱数字，也显示该弧段。
- 图片和打印共用成品排版与同一套简谱弧形。换行位置以各自的排版宽度为准。同一谱行内的简谱弧线和 TAB 弧线继续使用原有几何。 [简谱弧线布局](../../../../packages/lxm-editor/src/layout/music-text/numbered-mark-layout.ts) · [成品共用入口](../../../../packages/lxm-editor-react/src/EditorShell/output/image-export-controller.ts)

## 交付与审查

1. 在 1440px 或更宽的编辑器，用简谱弧线工具连接行末与次行首尾相接的同音，再用不同音高复验圆滑线。上行向右、下行由左接入，弧端与小节线间应有留白。用同行相邻音做完整弧形对照。
2. 以紧凑排版复验，优先选择靠近双小节线的行末音并加高八度点。确认弧线接到原数字上方，数字横坐标稳定，圆点保持净空。选取跨至少三条谱行的圆滑线，确认所有中间行均有一段浅弧。
3. 打开「导出」中的图片与打印预览，按各自 A4 换行检查同样的接续左、右方向与中间行浅弧。

从仓库根目录可复跑 `pnpm --filter @liuxianmao/lxm-editor exec vitest run tests/layout/bug081-numbered-cross-system-arc.test.ts`。回归覆盖紧凑双小节线、多音延音线、异音圆滑线、高八度点净空、两个中间空行及共享成品图元和分页。 [布局回归](../../../../packages/lxm-editor/tests/layout/bug081-numbered-cross-system-arc.test.ts)
