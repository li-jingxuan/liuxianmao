# REQ-103 琶音起始弦

[飞书需求](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi&range=A94:I94) · [已确认交互稿](prototype/index.html)

## 需求与现有交互

用户希望参考扫弦的操作，快捷调整琶音的起始弦。飞书参考图展示了选中的琶音符号。现有琶音支持选择上行或下行，添加时用同拍的多弦选区确定范围，已有符号可点击端点定位选区。扫弦还支持在谱面拖动上下端手柄，或在侧栏选择弦号，多选时可批量调整同一端。 [编辑器交互基线](../../design-baseline/editor.md#tab节奏与技巧) · [扫弦谱面手柄](../../../../packages/lxm-editor-react/src/EditorShell/score/StrumInteractionLayer.tsx#L258) · [扫弦侧栏](../../../../packages/lxm-editor-react/src/EditorShell/tools/StrumRangeInspector.tsx#L25)

## 已确认口径

- 选中已有琶音后，沿用扫弦交互。谱面上下两端均可拖动，侧栏可选择上端弦和下端弦。
- Alt／Option 点选多个琶音后，可批量调整同一个谱面端点。每个琶音保留自己的方向和另一端，修改后至少覆盖两根弦。

## 交互稿与验收

- 以 1440px 为最小视口，分别选中上行和下行记号。拖动上下任一端并核对弦线吸附、波线方向及侧栏同步。
- 多选不同方向的琶音后，从侧栏或谱面批量修改同一端，核对各自对端和方向。可用弦位须满足整组选区的两弦下限。批量修改一次撤销。

对稿时拖动默认选中琶音的蓝色圆点，再按住 Alt／Option 点按第 2 小节第 3 拍的琶音。试着从侧栏改上端弦，核对两个记号的波线变化，再点「撤销」。

手柄跟随当前活动记号。增选时保留手柄位置，移除活动记号后切到仍选中的第一项，与扫弦一致。

## 编辑器验收路径

1. 打开编辑器，在不同拍添加上行和下行琶音，分别给出 2–5 弦和 3–6 弦的初始范围。选中一个琶音并拖动上下蓝色手柄，检查吸附、波线和侧栏同步。按 Esc 取消一次拖动，再撤销已提交的测试调整。
2. Alt／Option 增选另一个琶音。从右侧「琶音范围」把上端设为第 4 弦，检查两处分别覆盖 4–5 弦和 4–6 弦，第 5 弦在上端下拉中禁用。撤销一次恢复两个范围。
3. 在谱面拖动手柄批量调整同一端，检查各自方向和对端。若选区还含扫弦，核对该扫弦的范围。

已在 1440 × 900 的 Chromium 中通过编辑器联调，覆盖上下行双端拖动、侧栏同步、批量弦位限制、Esc 和一次撤销。既有扫弦侧栏调整及撤销一并复测。

## 实现

琶音复用扫弦的手柄、吸附和侧栏控件，波线预览沿用成谱的波形。混选时按活动记号类型拖动，侧栏按技巧类型提供范围。端点命令校验整批范围及受影响的延音线，整批调整记入一次历史。 [端点交互](../../../../packages/lxm-editor-react/src/EditorShell/score/StrumInteractionLayer.tsx) · [端点命令](../../../../packages/lxm-editor/src/core/commands/commands.ts)
