# REQ-101 简谱右键菜单

已实现，待验收。[飞书需求 A92:I92](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi&range=A92:I92)　[可点击交互稿](prototype/index.html)

## 需求与范围

编谱时，可在简谱行直接右键打开节奏型、圆弧/连音线和连音设置，也可复制、粘贴或清空简谱内容。菜单标题显示「简谱工具」，副标题显示小节和拍位。简谱录入仍从谱面左键或侧栏打开。

- 作用目标为当前轨道的简谱音符、休止、延音或可录入的空位。右键点在已有选区内保留原始起点、焦点和范围，点在选区外改为落点单选。右键打开菜单本身只更新选区，不弹出录入表单，也不更改曲谱。
- 连续选区沿用简谱已有的 Shift 点选和拖动，允许跨小节、跨谱行。只有实际命中简谱位置时才打开简谱菜单。简谱连接记号继续使用独立编辑入口，TAB 命中继续打开「谱面工具」。标题、页边和歌词区域不触发简谱菜单。
- 键盘可在谱面持有焦点时通过菜单键或 Shift+F10 打开，锚定当前简谱焦点。↑／↓移动菜单焦点，Enter 执行，Esc 关闭并返回谱面。点菜单外、滚动谱面或切换文件时关闭。浮层临近窗口边缘时向内调整。
- 右键换目标和菜单写入都沿用草稿、只读与模态框守卫。有未应用草稿时优先处理草稿，退出确认后重新发起菜单操作。菜单仅包含标题、选区和菜单项，禁用原因通过无障碍描述提供。

## 菜单操作

节奏型、圆弧/连音线、连音设置从右键菜单打开时，复用工具栏气泡的内容组件、校验和提交逻辑。气泡以右键菜单项附近为展开位置，操作当前简谱选区。

| 菜单项 | 单点或空位 | 连续选区 | 执行与反馈 |
| --- | --- | --- | --- |
| 节奏型 | 打开简谱节奏型面板，以当前拍为作用目标 | 使用现有简谱节奏型目标解析 | 选择模板后预览，按现有面板规则应用和确认影响。 |
| 圆弧/连音线 | 打开弧线工具，单点时无可新增的弧线 | 可选「延音线」和「圆滑线」，命中已有弧线的原端点时可移除 | 两个相邻同音可加延音线，连续的简谱单音可加圆滑线，最终以现有弧线工具校验为准。 |
| 连音设置 | 查看已有连音组；符合条件时可在本拍创建三连音 | 按现有连音规则设置比例，选中已有连音组时可移除 | 复用简谱连音工具和本拍创建预览。 |
| 复制简谱 | 复制一个有内容的简谱位置 | 复制同一小节内的连续范围，保留内部空位与时值 | 使用编辑器内的简谱剪贴板。保留范围内完整的连音组与简谱记号。端点超出选区的记号不复制，有省略时提示。全空、跨小节或切断连音组的选区禁用。 |
| 粘贴简谱… | 从落点起覆盖剪贴板时长 | 从选区最早位置起覆盖，截止位置须落在选区内。剪贴板较短时保留选区余量 | 空位直接粘贴。涉及已有内容时先显示实际写入范围，再由「覆盖并粘贴」提交。无简谱剪贴板、超出小节／选区、切断事件或连音组、触及跨小节连音组、覆盖有歌词的位置时禁用。 |
| 清空简谱内容 | 清除当前位置的简谱内容，全空时禁用 | 清除范围内的简谱内容，允许跨小节 | 保留原时值、歌词锚点和简谱行。若会移除关联的延音线、圆滑线等记号，先展示影响范围，取消时保留选区和曲谱。无法通过领域校验的范围禁用或由命令提示原因。 |

复制和粘贴只处理简谱。剪贴板不带歌词，粘贴覆盖遇到已关联歌词的位置时须保留原谱并提示用户选择其他落点。粘贴和清空只修改对应简谱范围，成功后保留可定位的简谱焦点，可用编辑器撤销一次恢复整笔变更及关联记号。确认前重算目标、影响和文档版本，目标变化时取消提交。

## 交互稿与验收

以 1440px 为最小视口打开原型。原型初始展开第 1 小节第 1–2 拍的菜单，下方评审栏可重置或切换示例。谱面为固定的四四拍示例，工具面板和写入效果用于演示主要交互。

1. 右键选区内另一拍，标题仍显示完整范围，蓝色选区及原焦点不变。右键选区外的简谱或空位，标题切为落点单选。右键 TAB 示意区，检查菜单标题分流。
2. 复制首个示例的两拍，到第 3 小节第 1 拍的空位粘贴，核对两拍内容写入。右键第 2 小节第 1 拍覆盖现有两拍，先取消再确认，撤销后核对谱面。第 4 小节第 1 拍有歌词、第 3 小节第 4 拍容量不足，以及无剪贴板时，粘贴均禁用。
3. 试用「跨小节选区」和「连音组保护」示例，检查复制项禁用。跨小节的普通简谱选区可清空，取消连接记号确认后曲谱不变，确认后一次撤销恢复原内容和记号。
4. 从初始选区分别打开「节奏型」和「圆弧/连音线」，试选模板并应用、添加或移除圆滑线。第 3 小节第 3–4 拍可试同音延音线。从「连音组保护」示例选中第 5 小节第 1–3 拍的完整连音组，打开「连音设置」并移除。对第 1 小节第 1 拍应用「两个八分」后，可在该拍预览创建三连音。检查右键菜单的六个菜单项和排序。
5. 用 Shift+F10、方向键、Enter 与 Esc 操作菜单。在窗口底部附近打开菜单，检查自动避让。点击外部或滚动谱面收起菜单。

## 首版剪贴板范围

首版复制和粘贴限单小节，跨小节选区可清空。复制仅带简谱，目标已有歌词时阻止粘贴。

## 编辑器验收

1. 在编辑器打开一份含简谱的曲谱，用 Shift 点选同小节的两个音符。右键选区内的任一音符，应保留原选区和焦点。
2. 分别从右键菜单和工具栏打开节奏型、圆弧/连音线、连音设置，核对控件。右键菜单应有六项操作，菜单项下方无提示区域。Esc 关闭气泡或菜单，Shift+F10 可在谱面焦点处重新打开菜单。
3. 复制带歌词的简谱选区，尝试分别粘贴到空位、有简谱或有关联歌词的位置。空位直接写入，有简谱时显示覆盖确认，有关联歌词时禁用。覆盖后撤销及重做，焦点应留在目标拍位。
4. 跨小节选中一条连接记号的两个端点，清空时应先确认。取消保留原谱，确认后一次撤销恢复选区内容及记号。右键六线谱应打开「谱面工具」。

## 实现依据

现有右键入口在 `EditorShell.handleScoreContextMenu`，按 TAB 落点打开菜单。简谱入口应复用左键的 `hitTestNumbered`／`rangeFromTarget`、乐谱顺序解析 `resolveMusicTextRange` 和草稿协调器。三个工具复用 `RhythmPatternPanel`、`NumberedArcTool` 与 `TupletToolbar` 使用的简谱目标解析、提交和影响确认。清空沿用范围编辑命令及连接记号影响确认。现有 `createNumberedClipboard` 与 `numbered.range.paste` 会携带或替换关联歌词，简谱菜单需在提交路径落实剪贴板过滤、目标歌词保护与覆盖确认。已有单小节剪贴板边界可作为首版约束。
