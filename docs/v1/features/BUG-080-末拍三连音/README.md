# BUG-080 末拍三连音

在 2/4、3/4、4/4 的简谱中，可将完整一拍转换为一组八分三连音。拍内转换保留下一小节开头的音符和歌词。需要把小节线两边的音合组时，可使用 BUG-079 的跨小节选区。 [BUG-080](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A81:I81) · [BUG-079](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A80:I80)

## 确认方案

1. 在简谱选定拍位，打开「连音工具」，选择「在本拍创建三连音」。预览标出当前一拍和三个八分三连音槽位，点「应用」提交一次独立操作。
2. 若本拍是两个普通八分音，保留原音和歌词，按原顺序放进前两个槽位，最后一格留空供用户续填。若已录入「前八后十六」，三个原音按顺序进入三个槽位，书写时值统一为八分音。节奏型「前八后十六」本身继续可用。
3. 填满后的连音组无法展开为三个普通八分音时，显示「本拍空间不足，无法展开成三个普通八分音符」。刚转换的操作可一次撤销，恢复原来的时值、音符和歌词。

以 4/4 的一拍为例，普通「前八后十六」是 480 + 240 + 240 tick。八分三连音均分为 320 + 320 + 320 tick。原书写时值全部按 3:2 缩放则是 320 + 160 + 160 tick，总时长为 640 tick。 [简谱时值校验](../../../../packages/lxm-editor/src/core/numbered/numbered-rhythm.ts)

## 验收场景

打开 `/editor` 中的《理想》，在第 35 小节第 2 拍录入两个八分音，或录入一个八分音和两个十六分音。选择其中一个音，打开「连音工具」→「在本拍创建三连音」。检查预览、空位续填、歌词绑定、一次撤销、保存后重新打开，以及第 36 小节原音是否仍在。已有音的转换保留事件和音符 ID，以维持歌词和弧线的绑定。 [核心命令](../../../../packages/lxm-editor/src/core/numbered/numbered-commands.ts)
