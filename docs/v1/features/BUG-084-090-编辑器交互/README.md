## 本轮口径

- **084、088** 已确认上表规则。084 的关联条件是混合选区，作用对象可以在不同拍；088 的起点记号指 Segno 与 Coda。
- **086、087** 两处入口共用六列两排的记号。使用模态对话框设置反复组、房子和跳转配对。反复房子标题旁的问号使用 Ant Design Tooltip。
- **089** 侧栏展示实际的小节播放顺序。点听按一次到访定位，同一小节的不同到访分别可选。真实《理想》听序按谱件生成，原型中的 57 次到访仅供样式评审。
- **085、090** 在编辑器中分别核对滚动条显隐、反复房子的选中与键盘焦点样式。

## 反复房子的评审谱例

[直接打开第 32–33 小节的一房设置](prototype/measure.html#endings)

用截图中的小节编号单独演示两房分支。反复起点为第 17 小节，共享段末为第 31 小节，结尾区末为第 35 小节。第一遍弹 32–33 后回到 17，第二遍弹完 31 后进入 34–35，随后从 36 继续。共同出口由结尾区末推算。只填单个房子的起止和遍次，无法完整表达这组边界。

将鼠标移到标题旁的问号图标，或用 Tab 聚焦图标，即可查看 Ant Design Tooltip 中的反复房子说明。按 Esc 可单独收起提示。有效的两房示例默认显示「2 遍 · 2 个房子」，点「展开演奏详情」可核对逐遍路线。把总遍数改为三遍时，同一行提示「第 3 遍还没选房子，可稍后补」。

从[小节工具](prototype/measure.html)默认选中的第 4 小节添加反复房子，可核对与第 17–35 小节既有组相交的情形。弹窗只提示将结尾区末改到第 16 小节或更早，并标出对应字段。

## 使用实际编辑器验收

从首页「打开编辑器」进入默认谱《理想》。该谱有 42 个小节。选「木吉他试听」，将播放起点设为「从头开始」，当前谱件生成 64 次到访。在顺序栏分别点第 17 小节的第一次和第二次到访，核对游标与高亮是否落在所选的那一格。

回到编辑态，在第 24 小节用 Alt／Option 混选相邻的琶音和扫弦，拖其中一个记号的端点，检查另一记号及一次撤销。单击第 32–33 小节的一房括线可编辑完整反复组。把总遍数改为三遍，展开演奏详情，再取消或应用并撤销。

验收反馈后的谱面样式以实际编辑器为准。BUG-088 选中第 28 小节，通过「小节工具」加回跳记号。第 27、28 节号继续对准各自右侧小节线，Segno 出现在第 28 节号上方。行末符号在排版边界内向左留出净空。BUG-090 核对第 32–33 小节一房的遍次数字为 7px 灰字，两端竖线从横线起量各 8 个谱面单位。
