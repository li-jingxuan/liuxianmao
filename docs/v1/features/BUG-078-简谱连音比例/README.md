# BUG-078 简谱连音比例

交互稿已确认，简谱顶部的「连音工具」已补齐六线谱已有的六种比例。 [飞书工单](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A79:I79) · [编辑器设计基线](../../design-baseline/editor.md#简谱与歌词)

## 交互稿

[打开 1440 px 可操作原型](prototype/index.html)。切换选区后打开「连音工具」，试用不同的比例。应用后可以再次打开工具，选「删除连音组」。

- 沿用六线谱的两行三列布局、符号和顺序，提供 2:3、3:2、4:3、5:4、5:3、6:4。五个音时同时提供 5:4 和 5:3，指针悬停或键盘聚焦可读到完整比例。
- 本项沿用简谱已有的同小节连续、等书写时值规则。比例与选区不匹配时按钮置灰并说明原因。跨小节与末拍录入分别在 BUG-079、BUG-080 确认。
- 2:3 会延长所选音。只有本小节内有足够的连续空余时长时才允许应用。移除缩短型连音时，同样检查还原空间。两者都从首音起算，组外音符和歌词锚点保留。交互稿用 2:3 检查空间不足时的提示。
- 验收时检查六种比例、5:4 和 5:3 的不同实际时长、2:3 的空间检查、旧三连音的加载和删除，以及编辑谱面、图片和打印预览中的比例标记。

## 验收路径

1. 在 `/editor` 的同一小节内录入 2～6 个连续等值的十六分音符，按住 Shift 选择首尾，打开「连音工具」。五音选区可分别使用 `5:4` 和 `5:3`。试用另一比例前，先从面板删除已应用的连音组。
2. 选择两个十六分音符，后方留至少一个十六分音符的空位，确认能够应用 `2:3`。去掉余量后复验按钮禁用和空位提示。应用或拆组时确认首音、组外音符和歌词锚点保留。
3. 打开新版默认《理想》第 32 小节，检视已有三连音可定位和删除。编辑、图片和打印共用谱面标记，`3:2` 显示惯例数字 `3`，其他比例显示完整比例。
