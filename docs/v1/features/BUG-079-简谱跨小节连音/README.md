# BUG-079 简谱跨小节连音

相邻小节的三个连续、同书写时值且未归组的简谱音，可用「连音工具」编成 3:2 三连音。组首音的起点固定，其余两音按实际三连音时值等分。起点移到前一小节时，歌词随原音移动并保留原关联。小节线可以经过组内持续时值。 [飞书工单](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A80:I80)

在 `/editor` 的简谱中，准备相邻小节末尾两个八分音与下一小节首拍一个八分音。点击首音，再按住 Shift 点击末音，打开「连音工具」并选择「三连音（3:2）」。确认三个原音都保留，相邻起音间隔为 320 tick，下一小节首音与其歌词移动到前一小节。检查反向选区、拆组、撤销和重新打开谱件。当前《理想》第 35 小节末拍可以用来准备上述验收音符。

也可测试前一小节末尾一个八分音与下一小节头两个八分音。合组后第二个音跨过小节线持续，第三个音仍在次小节。换谱行时弧线随行分段，只显示一个组号。拆组需要足够的书写时值空间。复制组涉及的小节时，应一并选中两个小节。
