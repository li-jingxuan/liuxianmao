# REQ-100 自定义水印

**待验收**　老师给学生分发练习谱时，可以为每张 A4 成品页放置一处文字署名或自选图片。两种水印都可调整大小、不透明度、旋转和位置，设置在当前曲谱会话内复用。[飞书需求](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi&range=A93:I93)

## 首版范围

| 设置项 | 已确认口径 | 选择依据与影响 |
| --- | --- | --- |
| 水印内容与样式 | 默认关闭。开启后可选择一行文字或一张本地图片，均可调整大小、不透明度、旋转角度和位置。 | 透明 PNG 可保留标志的镂空与轮廓。图层位于谱线、歌词和页码下方。 |
| 生效范围 | 在图片和打印预览里设置，应用于缩略图、整页预览、单页 PNG、ZIP 内每一页、打印及另存 PDF。编辑时保持干净谱面。 | 编辑视图按连续谱行展示，成品按 A4 分页。把水印定位在成品页上，每页都能带走署名，且不会挤开音符或歌词。 |
| 保存范围 | 同一份谱在当前编辑会话内复用设置。新建、换谱或重新打开文件时默认关闭。 | 分发给不同班级可换署名，无须修改原谱。若希望接收者打开 `.lxm` 也能恢复水印，则需把配置纳入曲谱格式、导入校验、保存和撤销语义。 |

## 交互设计稿 v3 · 图片水印旋转

[体验旋转试排](prototype/index.html#rotate) · [旋转效果截图](prototype/旋转试排.png) · [水平图片水印示例](prototype/index.html#logo) · [从默认关闭状态体验](prototype/index.html) · [文字署名示例](prototype/index.html#example)

旋转示例从当前页逆时针 30° 的草稿开始，左侧缩略图显示已应用的水平版本。点「水平 0°」可比较原图，点「↷ +30°」可切换倾斜方向。滑块支持 −180° 至 +180°，方向键每次微调 1°。居中时图片绕自身中心旋转，左下和右下角位按旋转后的外框保留边距。普通上传从 0° 开始。

原型可直接在桌面浏览器打开，最小视口为 1440 px。使用《理想》示例谱，复制一段乐谱后用现有成品引擎排成三页，便于翻页比较。预览右上角可切换图片和打印。

1. 在示例里点「替换图片」或将自己的标志拖入方框。编辑器在本机读取 PNG、JPG、WebP，单张上限为 5 MB。格式、大小或解码失败时显示原因，保留上一次可用图片。普通入口也可从「自定义水印 → 图片水印 → 试用示例」体验。
2. 调整滑块，当前页立即试排。图片长边默认为纸宽的 38%（可调 10%–65%），不透明度默认为 18%（可调 5%–45%）。位置可选居中、左下和右下。角位距纸边均为纸宽的 6%。窄长图和横版标志都按原比例缩放。
3. 点「应用到全部页」，缩略图、打印层和之后生成的 PNG / ZIP 使用同一设置。试排期间点「还原」可恢复上次应用值和原下载。关闭开关并应用可移除水印。可在「文字水印」中改用文字署名。

## 用户操作

在 `/editor` 选择「导出 → 图片(.png)」或「导出 → 打印」。两个预览沿用现有三栏布局，在右侧设置区加入同一组「自定义水印」控件，左侧缩略图和中央 A4 页作为效果反馈。以 1440 px 为最小评审视口。

1. 开启水印，选择图片或输入文字。大小、不透明度、旋转角度和居中、左下、右下位置在当前页实时试排。点「应用到全部页」后，所有缩略图更新，保留正在查看的页码与生成范围。再打开另一种预览时显示同一水印。要移除时关闭开关并应用。
2. 文字上限为 32 个用户可见字符，组合字符按一个计数。去除首尾空白，粘贴换行统一为空格。开启后为空、超限时在输入框旁说明原因并保留原输入。草稿待应用时暂停生成、下载和发起打印，可点「还原」回到上次应用值，关闭预览也只丢弃草稿。
3. 应用后可生成当前页、全部页，或打开系统打印窗口。应用替换的图片、布局、新文字或关闭状态后，上一份已生成文件从下载区撤下。编码、原生保存或打印进行中锁定水印控件，取消后可继续修改。

## 实现设计

**数据归属。** 在随曲谱会话重建的 `EditorShell` 中保存已应用的有效值。文字记录内容，图片记录已解码的本地资源及原始比例，两者都记录大小、不透明度、旋转角度与位置，关闭用 `null` 表示。表单草稿留在预览弹窗内。水印属于输出设置，沿用 v8 `.lxm` 及现有宿主接口，编辑历史、脏标记与保存基线只受曲谱操作影响。每个 React 编辑器实例独立持有设置。[会话重建入口](../../../../packages/lxm-editor-react/src/EditorShell/session/EditorSession.tsx) · [输出入口](../../../../packages/lxm-editor-react/src/EditorShell/index.tsx)

**分页与绘制。** 复用 `prepareScorePresentation` 产生的谱面场景和分页。分页完成后，React 包的成品模块根据有效文字、字体度量和纸张宽高计算一份页级绘制参数，供 SVG 和 Canvas 共用。纸面尺寸相同的页可复用此结果。修改水印只更新绘制参数与成品任务，不重新测量歌词或运行 `paginateLayout`。[成品准备](../../../../packages/lxm-editor-react/src/EditorShell/output/image-export-controller.ts) · [A4 尺寸和分页](../../../../packages/lxm-editor/src/layout/structure/page-layout.ts)

| 消费端 | 接入点与绘制顺序 |
| --- | --- |
| 缩略图、主预览、打印/PDF | `ScorePresentationPage` 在白底矩形之后、谱头与谱行之前画 SVG 文本组或带透明度的图片。试排时仅当前页使用有效草稿，应用后常驻的 `ScorePrintLayer` 接收同一有效设置。文字作为文本节点传入，`<`、`&` 等按原文显示。 [SVG 成品页](../../../../packages/lxm-editor-react/src/EditorShell/output/ScorePresentationPage.tsx) · [打印层](../../../../packages/lxm-editor-react/src/EditorShell/output/ScorePrintLayer.tsx) |
| 单页 PNG、全部页 ZIP | `encodeScorePage` 将相同的页级参数交给 `renderPageCanvas`。白底与页面缩放完成后绘制水印，再画谱面及页脚。局部 `save/restore` 隔离旋转、字体与透明度。沿用逐页编码、2480 × 3508 像素和 300 DPI。 [Canvas 绘制](../../../../packages/lxm-editor-react/src/EditorShell/score/score-canvas-renderer.ts) |

文字默认居中、逆时针旋转 30°，使用现有谱面正文字体和黑色 12% 不透明度。字号默认 40 个 A4 逻辑像素，可在 12–96 之间调整。长文字按实际字宽等比缩小，整行至多占纸宽的 75%。文字和图片都支持 5%–45% 不透明度、−180° 至 +180° 旋转及 −30°、0°、+30° 预设。左下和右下按旋转后外框对齐，保留纸宽 6% 的边距。预览、逐页编码和打印使用同一个几何函数。[水印绘制参数与本地资源读取](../../../../packages/lxm-editor-react/src/EditorShell/output/score-watermark.ts)

**任务一致性。** 现有 `ImageExportSnapshot` 捕获文档版本，`useImageExportTask` 在快照引用变化时会重做准备。保持文档快照引用稳定，把已应用水印单独作为输出参数。每次生成锁定“文档版本＋有效水印＋页范围”，整包逐页使用这份输入。应用新值时复用现有任务令牌和取消逻辑，回收旧 Blob URL、清掉宿主 Blob 与保存反馈，使迟到结果无法恢复旧下载。字体变化继续走现有重新准备流程，同时重测水印。[生成与保存任务](../../../../packages/lxm-editor-react/src/EditorShell/output/use-image-export-task.ts) · [预览与打印设置](../../../../packages/lxm-editor-react/src/EditorShell/output/ImageExportModal.tsx)

**打印一致性。** 浏览器原生快捷打印使用常驻打印层中最近应用的设置。预览中的打印按钮还须核对当前编辑器根节点的打印层已就绪，且其已渲染的曲谱和水印版本与预览匹配。等待 DOM 更新后再放行，可避免改完署名立即打印时取到上一版。桌面菜单沿用同一预览入口，在字体就绪后、调用 `host.print()` 前复核版本。图片继续通过 `host.writeOutput()` 交付生成的字节。[打印调用与实例隔离](../../../../packages/lxm-editor-react/src/EditorShell/index.tsx) · [桌面宿主契约](../../../../packages/lxm-editor-react/src/editor-host.ts)

## 验收场景

| 场景 | 操作与通过条件 |
| --- | --- |
| 上传与试排 | 选择透明 PNG、竖版 JPG、WebP 试排。调整大小、不透明度及角位后，当前页即时反馈。正式应用后检查所有缩略图、PDF 和打包的 PNG。替换成损坏、超限或格式不支持的文件时显示对应提示。还原应恢复旧图及其布局。 |
| 文字样式 | 在图片或打印预览中调整字号、不透明度、角度和位置。草稿只更新当前页，应用后全谱更新，切换到另一种预览时沿用已应用的设置。还原应恢复上一版的全部文字样式和下载。 |
| 默认与清除 | 用同一份谱生成干净 PNG，开启水印后再关闭并重新生成。前后两张干净图的相同位置像素一致，页数、页脚和谱行位置一致。仅修改水印时曲谱保存状态和撤销记录一致。 |
| 输入边界 | 输入空白、32/33 个可见字符、组合字符、换行及 `A&B <练习>`。边界按规则处理，最长合法署名完整可见。未应用时还原或关闭，再打开仍为上次应用值。 |
| 多页与打印 | 对至少三页的谱设置同一署名，检查首页、中间页、末页的缩略图、PNG、ZIP 解包图片和实际 PDF。各页位置、方向、浓度一致，谱号、品位数字、歌词和页码清楚。关闭打印的“背景图形”再验一次，并以黑白打印样张确认可读性。 |
| 文件与时序 | 生成署名 A 后改为 B，旧下载立即失效。取消多页生成后换字重试，所得全部页仅有 B。改字后立即发起打印，Web、桌面打印均使用 B。保留现有超过 100 页按页生成及 ZIP 容量限制。 |
| 会话隔离 | 在两个编辑器实例分别应用不同署名，分别生成和打印。新建、导入、刷新后为关闭状态。导出 `.lxm` 并重新打开，曲谱内容与开启水印前一致。 |

## 工作区验证记录

- 文字水印浏览器回归验证了样式试排、还原、应用到全部页、双向切换预览和第二页实际导出的右下文字像素。另在 1440 px 视口下生成打印 PDF，确认两页均含文字水印。图片回归验证了三页 ZIP 和 PDF 的旋转像素。[浏览器回归](../../../../apps/website/tests/req100.next.browser.mjs)
- `v1.0` 分支。网站 Vitest 共 96 个文件、900 项通过，覆盖成品快照、PNG 编码、文件流程和编辑会话。导出任务浏览器回归通过取消、字体失效、重开、迟到结果及下载地址回收。[成品快照测试](../../../../apps/website/tests/score-presentation.test.ts) · [PNG 测试](../../../../apps/website/tests/image-export.test.ts) · [任务时序回归](../../../../apps/website/tests/image-export-task.browser.mjs)
- Web 在正式 `/editor` 中导入三页曲谱，解包 ZIP 后逐页核对 +31° 彩色半透明标志，再对关闭背景图形的三页 A4 PDF 核对 −30° 的标志位置及镂空。关闭水印后生成的首页 PNG 与最初的干净首页逐字节相同。导入、新建和刷新均重置水印。同页嵌入两个编辑器，也分别生成了各自署名的 PNG 和对应实例的 PDF。[正式浏览器回归](../../../../apps/website/tests/req100.next.browser.mjs)
- 在浏览器切到打印样式、重新加载字体的过程中，常驻打印层会保留同一份曲谱的完整分页。实测 `beforeprint` 恰好发生在重新度量期间，导出的 PDF 仍有三页，各页均为刚应用的 −30° 水印。
- macOS Electron 从本地打开《理想》，上传半透明 PNG，应用 −30° 后经桌面保存入口写出 2480 × 3508、300 DPI 的图片。由原生菜单重开打印预览，经主进程以关闭背景图形的选项输出两页 A4 PDF，两页均检出旋转水印。纸质打印的明暗留作实机验收。
