# REQ-102 扫弦框选

[飞书需求](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi&range=A93:I93) · [已确认交互稿](prototype/index.html)

## 需求与现有交互

用户希望在按住 Alt 多选扫弦时，用拖框一次选中多个扫弦拍点。参考图展示了同一谱行内跨小节的蓝色选中效果。

当前支持 Alt／Option 点选不相邻的扫弦或琶音，以及普通框选连续扫弦。选中的技巧可用于后续批量操作。 [编辑器交互基线](../../design-baseline/editor.md#tab节奏与技巧) · [BUG-062 验收路径](<../../../archive/mvp/versions/v8/问题 & 需求/bug-list.md#bug-061067-验收路径>)

## 已确认口径

- 按住 Alt／Option 拖框，可跨小节和谱行。框内命中的扫弦和琶音追加到当前选择，已选项保持选中。
- Alt／Option 点选继续增选或移除单个技巧。普通 TAB 框选沿用现有交互。

## 交互稿与验收

- 以 1440px 为最小视口，先选中一个框外对象，再跨谱行拖框。拖动时预览命中的扫弦和琶音，松手后追加到技巧选区。框内的普通 TAB 音符仍可用普通框选操作。
- 再次框选重叠范围，核对已有选中项保持选中。Alt／Option 点按单个记号可切换该项。

对稿时点击「标出试拖位置」，按住 Alt／Option 从 A 拖到 B。预览应包含 3 个扫弦和 3 个琶音，松手后侧栏应显示 7 项，含框外预选的 1 项。反向再拖同一区域，检查选区仍为 7 项。

本稿按拖框与箭头、波纹或其符干的点选热区相交来判定命中。

## 编辑器验收路径

1. 打开编辑器，载入含扫弦和琶音的多行 TAB 谱。点击一个框外记号，按住 Alt／Option 跨行拖框。拖动时检查框内箭头、波纹和符干的命中高亮，松手后检查原选中项和新选中项。
2. 反向拖框覆盖同一区域，核对选中项数量。Alt／Option 点按一个已选记号将其移除，再点一次加回。
3. 拖框时按 Esc，核对预览消失且旧选区保留。松开修饰键，用普通拖动选一段 TAB 弦格。

已在 1440 × 900 的 Chromium 中通过编辑器联调，覆盖跨行预览、追加、反向拖框、点按切换、Esc 和普通 TAB 拖选。

## 实现

谱面在按下时保留起点和选区。位移达到 4 个屏幕像素后开始框选，并以 SVG 坐标计算扫弦、琶音和符干的命中。松手后按谱面顺序追加命中项。起手后松开 Alt／Option 仍可完成当前拖框。 [谱面交互](../../../../packages/lxm-editor-react/src/EditorShell/index.tsx) · [框选命中](../../../../packages/lxm-editor-react/src/EditorShell/score/traversal-marquee.ts)
