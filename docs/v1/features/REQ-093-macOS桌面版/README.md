# REQ-093 Electron macOS 桌面版

**目标**　macOS 用户可以从官网下载并安装编辑器，断网编辑和保存与其他端兼容的曲谱。

## 交付与验收

1. 提供标明系统、架构和版本的 DMG。完成 Developer ID 签名、公证与票据装订，对最终文件核验签名和 SHA-256。
2. 在承诺支持的系统和架构上从浏览器下载，经 Gatekeeper 安装启动。断网打开本地练习谱、修改、试听、保存和重开，验证 PNG、打印、未保存退出与覆盖安装。
3. 与 Web、Windows 交换同一份 `.lxm.json`，核对谱面内容；记录每种已验证架构、系统版本和制品标识，供首页与发布页引用。

**待确认**　最低系统版本、Apple Silicon／Intel 覆盖范围、安装包形式与公证账号。[桌面发布方案](../../首发筹备/02-开源与三端交付.md)
