# REQ-093 Electron macOS 桌面版

**目标**　macOS 用户可以从官网下载并安装编辑器，断网编辑和保存与其他端兼容的曲谱。

**状态**　实现中（飞书 REQ-007）。

本地 macOS arm64 DMG 已通过镜像校验、挂载和启动。Mac 生产构建已验证离线资源、原生曲谱读写、A4 成品、退出保护和 Web 曲谱双向交换。Developer ID 签名及 macOS 14 上的下载和实装待验证。[本地验证记录](../REQ-092-Windows桌面版/桌面版技术方案.md#6-本地验证记录)

## 交付与验收

1. 提供标明系统、架构和版本的 macOS arm64 DMG。应用使用 Apple Developer ID Application 签名，DMG 容器按打包能力使用同一开发者身份签名。首发不做公证或票据装订。核验应用签名和 DMG 实际签名状态，计算最终 DMG 的 SHA-256。
2. 从候选发布地址用浏览器下载，由普通用户安装和首次启动，记录 Gatekeeper 等系统提示及结果。断网打开本地练习谱、修改、试听、保存和重开，验证 PNG、打印、未保存退出与覆盖安装。
3. 与 Web、Windows 交换同一份 `.lxm`，核对谱面内容。记录已验证的架构、系统版本和制品标识，供首页与发布页引用。

**首发验收**　从 macOS 14 arm64（Apple Silicon）起步。[REQ-006／007 桌面版技术方案](../REQ-092-Windows桌面版/桌面版技术方案.md)
