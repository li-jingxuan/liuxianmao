## REQ-106 · 反复房子

1. **选区。** 支持拖选、Shift 点击、Shift＋方向键和表单输入起止小节。新房优先预填尚未覆盖的遍次。点括线编辑时选中整段，可调整边界和遍次，蓝色虚线预览草稿。合稿支持 Shift 选区和表单；拖选细节见单项原型。 [单项规格与原型](README.md)
2. **谱面。** 括线从起始小节左边界开始，在末小节右边界收口。跨行时，前一行延伸至行尾，下一行用 `(1.)` 等标示续线，最后一段才收口。同房多遍可写 `1., 2.`；布局为括线、段落标记和跳转记号保留独立层，换行、缩放及打印仍要核对。多个小节只对应一个房子对象，跨行续段与起始段一起编辑和删除。
3. **反复组。** 建议面板明确显示反复起点、共享段末端、最后房后的共同出口，并把房子归属到同一反复组。组可由普通反复线和相邻结尾推导，仅有一个明确候选时预填并显示范围。有歧义时要求选择归属。首版支持每组最多三遍、不嵌套且结尾范围互不交叠。前几遍房末回共享段起点，最后一遍进共同尾段。反复次数不足或覆盖缺口必须提示；允许先保存未配齐的谱，试听到缺房遍次的分岔小节后暂停。结尾区内未分给任何房的小节应提示「未被任何遍次演奏」，便于编谱者核对有意的留空。
4. **异常与删除。** 同组出现重叠、同遍次多个出口或越出结尾区时拒绝当前提交，保留草稿并定位字段。删除前列出受影响遍次。试听到缺房时提示「第 N 遍没有反复房子」，允许返回补房。此例用显式共享段 1–3、结尾区 4–8、尾段 9–10 来演示。

### 《理想》联验

| 路线 | 试听次序 | 第二遍差异 |
| --- | --- | --- |
| A · 飞书原描述 | `1–33 → 17–31 → 34 → 25–31 → 35–42`，64 次到访 | 第 31 小节直接接第 34 小节。 |
| B · 当前谱件及工单备注 | `1–33 → 17–34 → 25–31 → 35–42`，66 次到访 | 第 31 小节后演奏 32、33，再进 34。 |

两条路线都核对 `33→17`、`34→25`、`31→35`。建议以当前谱件的 B 作为回归基线，产品选择 A 时再按确认后的符号重录。默认 Segno 回跳沿用本次试听的既有反复进度，且 D.S. 本身不把普通反复组自动加一遍。若第 35 小节采用三房写法，建议在第 34 小节指令中显式指定「按同组第 3 遍继续」，校验 Segno 在本组共享段内，随后从 25 弹到 31 进三房。若采用共同尾声写法，使用第 34 小节 `D.S. al Coda`、第 25 小节 Segno、第 31 小节 To Coda、第 35 小节 Coda。两种写法都会完整演奏 25–31。 [曲谱与工单来源](../REQ-105-谱面跳转记号/README.md#理想谱面写法对照) · [可试听 A/B](../REQ-105-谱面跳转记号/prototype/index.html#ideal)

## REQ-107 · 曲首回跳与结束

| 工具符号 | 谱面位置 | 配对与演奏 |
| --- | --- | --- |
| `D.C.` | 当前小节右上方 | 无配对。弹完本小节，回到曲首第 1 拍。建议同一指令在一次试听中执行一次，再次经过后顺行到曲尾。 |
| `Fine` | 当前小节右上方 | 作为重奏终点。首遍照常经过。重奏命中本次配对时弹完该小节再停止。 |
| `D.C. al Fine` | 当前小节右上方 | 选择一个可达 Fine。回曲首，从第 1 拍重奏到该 Fine 小节末。 |
| `D.S. al Fine` | 当前小节右上方 | 选择一个 Segno 和一个可达 Fine。从 Segno 小节第 1 拍重奏到 Fine 小节末。 |
| `D.C. al Coda` | 当前小节右上方 | 选择一个可达 To Coda。回曲首，重奏命中该 To Coda 后，由 To Coda 的配对决定跳到哪个 Coda。 |

`𝄋` 和 `𝄌` 对齐小节起始线，D.S.、D.S. al Coda 和 To Coda 沿用 REQ-105 的位置和链路。同一小节开头、末端各允许一个跳转记号。房子、普通小节线和 `𝄎` 分别有自己的显示位置。配对用记号身份保存，界面显示小节号。Segno 在指令小节或之前；Fine／To Coda 在重奏起点起、指令所在小节之前，Coda 在 To Coda 之后。唯一候选预填，多候选手选。移动或删除目标后重新校验，已保存配对失效时保留原指令并给修复入口。删除弹窗列出直接配对与受影响的上游指令。 [REQ-105 现有规则](../REQ-105-谱面跳转记号/README.md)

建议允许先应用、保存未配齐的指令。侧栏显示待处理字段，指令实际触发时暂停在已弹完的小节末，并定位缺失位置。有一条活跃的 Fine 或 To Coda 目标时遇到另一条待执行回跳，或同边界同时触发回跳、反复线、房子分岔／回跳或旧谱重奏，沿用 REQ-105 的暂停和修复模式。首遍未生效的辅助记号正常经过。已完成的普通反复与房子遍次在本次回跳期间保留，使用显式续遍时按所选反复组更新。正常完成时在实际结束小节末显示游标和结束原因，异常时可返回配对或冲突边界。

原型右栏可切换独立 D.C. 的备选方案。「只提供 al Fine / al Coda」限制新建独立 D.C.，已导入的同类指令保留并提示改为带结束方式的记号。 [单项规格与更多谱例](../REQ-107-曲首回跳与结束/README.md)

## REQ-108 · 单小节重复

1. **添加。** 选中目标小节，点击 `𝄎`，右栏显示「第 N−1 小节 → 第 N 小节」和实际拍数。空目标确认添加即可。已有内容先展示受影响的 TAB、节奏、和弦、简谱、连音和技巧等，再由用户确认覆盖。取消保留原内容，一次撤销恢复整个目标小节。
2. **显示与编辑。** `𝄎` 居中覆盖 TAB 正文，保留六根弦线、小节边界与小节编号。图元和整节命中独立；已缩写的音符及其拍内编辑入口随谱面隐藏，试听照常走过自己的拍位。「展开为普通小节」恢复实际音乐内容并聚焦首个可编辑拍位，可一次撤销。侧栏提供「编辑前一小节」。
3. **建议采用快照。** 创建时把源小节的可重复音乐复制到目标小节，目标使用独立的内容 ID 和本节拍位。前一小节音乐、拍号、有效时长、结构边界或相邻关系改变后重新校验。目标无法继续表示为「照前一小节弹」时自动展开，保留原音乐。提示与源编辑属于同一笔撤销。「同步并保留记号」是评审备选，合稿可以切换试听对照。

| 边界 | 拟定处理与恢复 |
| --- | --- |
| 第 1 小节 | 灰显并提示「第 1 小节没有前一小节」。选择后续小节。 |
| 目标已有内容 | 确认替换。取消、撤销可找回目标原内容。 |
| 拍号或有效时长不同 | 灰显，并列显示源／目标的拍号及实际拍数。先在小节设置对齐。相同拍号且实际时长一致的弱起仍须通过其他条件。 |
| 源或目标有歌词 | 灰显，并指出存在歌词的小节，提供定位。保留词位，用户可自己调整或改用普通小节。 |
| 重复链、空源、跨界技巧 | 先展开前一小节的记号，或补录有效音乐。涉及跨小节连音或技巧时给出连接位置，编谱者修正后再添加。 |
| 分段／跳转边界 | 首版建议仅允许相邻两小节之间为普通单线，目标小节无新段落且中间没有跳转边界。房子入口或出口跨越这对小节时提示调整位置。当前小节的外侧结束线仍用其原有样式。 |
| 插入、复制、移动或删除小节 | 按新的相邻关系和音乐等价性校验，一致且边界合法时保留缩写；否则展开并保留目标内容。复制一个完整小节时重新建立 ID，复制拍位不携带缩写标记。 |

合稿演示首节禁用、替换确认、逐拍试听、展开、源编辑两方案、结构线和重复链提示。不同拍号、歌词的操作样例见专稿。 [REQ-108 单项规格与原型](../REQ-108-单小节重复/README.md) · [历史数据设计](../../../archive/mvp/versions/v7/20261012_单小节重复记号技术方案.md)

## 持久化、布局与工程验收

- 以现有 `.lxm` 导出并重开验收。房子覆盖范围用稳定小节身份，保存遍次与组归属；跳转使用稳定记号身份；`𝄎` 保存显示标记与实际演奏内容。旧谱中已有的普通反复、REQ-105 配对及《理想》重奏记录须读回并走原试听路径。数据版本以动工时当前 schema 为准，迁移只补充所需的新表示。
- 播放计划先解析小节到访，再从到访小节展开各拍音符，以同一个计划驱动伴奏、游标、到访日志和跳转衔接试听。从中间起播建议用从曲首推导出的首次到访上下文。所选小节被跨过时指明原因并给出「从曲首」。回跳遇到前一条未完成的配对或循环时在可解释边界暂停，避免重复发音。
- 编辑、撤销、重做和结构操作在同一提交中处理引用与历史。打印与导出沿用同套布局几何，验证跨行括线、同一小节存在多个记谱层、终止记号和小节号避让、`𝄎` 位置及窄小节净空。评审按至少 1440px 进行。

| 验收场景 | 操作及预期 |
| --- | --- |
| 截图入口 | 初始第 2 小节。小节线与记号组间有横线。用鼠标与 Tab 验证 `1.`、`𝄋`、`Fine`、`𝄎` 释义。切到第 1 小节核对 `𝄎` 禁用原因。键盘上下文入口打开同一组符号。 |
| 三房跨行 | 一房 4–5 横跨两行，同一括线从 `1.` 续到 `(1.)`。从头试听 `1–3→4–5→1–3→6→1–3→7–8→9–10`，共 16 次到访。删二房后在第二遍第 3 小节末暂停，补第 6 小节恢复次序。 |
| D.C. 与 Fine | 默认 `1–6→1–3`，Fine 首遍顺行，重奏第 3 小节末停止。将第 6 小节设为独立 D.C. 时走 `1–6→1–8`。换成 D.S. al Fine 并配第 2 小节 Segno 后走 `1–6→2–3`。 |
| D.C. al Coda | 在曲首回跳示例中删除第 3 小节 Fine 和第 6 小节旧指令，添加第 8 小节 Coda、第 3 小节 To Coda、第 6 小节 D.C. al Coda。关联号选 3 和 8，预期 `1–6→1–3→8`。删除 Coda 后在第 6 小节末暂停，直接定位第 3 小节 To Coda，再补齐。 |
