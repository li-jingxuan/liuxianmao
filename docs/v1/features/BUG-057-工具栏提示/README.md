# BUG-057 工具栏提示

[飞书工单](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=0d8c47&range=A58) · [编辑器设计基线](../../design-baseline/editor.md#工作台与会话)

## 修复口径

编辑器主工具栏的按钮提示统一展示操作名称。有对应快捷键时，同时展示当前平台的按键。启用和禁用时都采用这套规则。工单截图中的扫弦和琶音按钮是本次验收的重点。

主工具栏沿用已有的快捷键定义。共用符号按钮分别处理提示内容和可用状态，侧栏继续使用其选区说明。节奏型、连音和小节的入口禁用时，由外层元素接收键盘焦点。

## 验收路径

1. 打开 `/editor`，使用至少 1440px 宽的视口。将鼠标移到灰显的扫弦、琶音按钮上，核对提示只显示对应的技巧名称。
2. 将鼠标移到「撤销」「重做」和休止按钮上，核对提示由操作名称和对应快捷键组成。选中可编辑的六线谱拍点，再悬停「单附点」，提示应只显示「单附点」。
3. 用 Tab 聚焦扫弦或琶音按钮，核对提示内容和悬停时一致，按 Esc 后提示关闭。通过「帮助 → 快捷键」仍可查阅完整按键说明。

## 验证记录

在 `v1.0` 工作区的 `/editor` 上使用 Chromium 验证。1440px 下检查四个禁用的扫弦和琶音入口、启用的单附点和休止、撤销在两种状态下的按键提示，以及键盘收起琶音提示、节奏型气泡和完整快捷键说明。1710px 下检查禁用的节奏型、连音和小节入口可聚焦并显示名称。

[浏览器回归](../../../../apps/website/tests/bug059.browser.mjs)覆盖扫弦和琶音按钮的启用及禁用提示、撤销的快捷键提示，以及扫弦和延音线操作。网站 897 项测试与 TypeScript 检查通过。
