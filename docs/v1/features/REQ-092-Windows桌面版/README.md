# REQ-092 Electron Windows 桌面版

**目标**　Windows 用户可以安装桌面编辑器，断网继续写谱，并和 Web、macOS 交换原生曲谱。

**状态**　实现中（飞书 REQ-006）。

Windows x64 桌面应用已完成交叉构建。本机交叉构建在 NSIS 打包阶段超时，签名 EXE 及 Windows 11 安装、启动和互开仍待验证。

## 交付与验收

1. 提供注明版本、支持系统与架构、经开发者 Authenticode 签名的 Windows x64 NSIS EXE，核验最终制品的签名和 SHA-256。从候选发布地址用浏览器下载，由普通用户安装和首次启动，记录 SmartScreen 等系统提示及结果。
2. 断网从中文路径打开练习谱，修改、试听、保存、重开并导出 PNG。检查未保存退出、无写权限时的反馈，以及本地字体、音色等资源。
3. 将 Windows 保存的 `.lxm` 交给 Web 与 macOS 打开，核对品位、和弦与排版。验证覆盖安装与卸载，记录操作系统、架构和制品版本。

**首发验收**　从 Windows 11 x64 起步。[REQ-006／007 桌面版技术方案](桌面版技术方案.md)
