# REQ-092 Electron Windows 桌面版

**目标**　Windows 用户可以安装桌面编辑器，断网继续写谱，并和 Web、macOS 交换原生曲谱。

## 交付与验收

1. 提供注明版本、支持系统与架构的安装程序，校验最终制品的 Windows 签名和 SHA-256。从候选下载地址以普通用户安装、启动，记录系统提示。
2. 断网从中文路径打开练习谱，修改、试听、保存、重开并导出 PNG。检查未保存退出、无写权限时的反馈，以及本地字体、音色等资源。
3. 将 Windows 保存的 `.lxm.json` 交给 Web 与 macOS 打开，核对品位、和弦与排版。验证覆盖安装与卸载，记录操作系统、架构和制品版本。

**待确认**　最低系统版本、支持架构、签名与测试设备。建议先验证 x64；下载入口按实际放行结果开放。[桌面发布方案](../../首发筹备/02-开源与三端交付.md)
