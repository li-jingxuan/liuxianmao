# REQ-088 首页与 Web 编辑器首发

**目标**　吉他老师从首页看到成品示例，在浏览器中写完四小节练习，带走可修改的原谱和可发给学生的图片。沿用已有首页、工作台与曲谱文件行为。

## 交付与验收

1. 在 1440px 及以上视口，首页可查看一份有公开授权的示例，进入编辑器、新建或导入曲谱。下载区、源码与接入文档指向已放行的实际版本。
2. 在 Web 编辑器中修改品位与和弦，查看简谱、歌词，试听并输出 A4 PNG。导出 `.lxm.json` 后重新导入，核对修改仍在；修改后离开时能看到保护提示。
3. 在声明支持的浏览器及实际部署路径验证深链接、刷新、字体和音频资源。保存构建版本、浏览器与验证结果，供桌面端复用同一谱例做交叉验证。
