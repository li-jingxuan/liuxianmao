# REQ-094 国内首发宣传与海外分发

**目标**　用同一份原创练习谱把读者带入实际写谱体验。微信公众号和 Bilibili 面向国内教师与玩家，YouTube 用英文字幕服务海外搜索用户。

## 交付与验收

1. 准备有授权的四小节谱、原生文件、A4 成品图和桌面录屏。公众号教程可按图跟做，B 站主片演示从录入到导出，YouTube 版提供英文标题、字幕及中文按钮释义。
2. 按正式上线日安排预热、首发、海外补发与答疑。在实际渠道核对电脑访问入口、渠道参数和版本说明。按国内主渠道优先分配制作工时。
3. 在第 7、14、30 天分别检查可用的播放／阅读、入站、有效编辑和导出数据；注明时间窗、分母与不可观测项。记录用户遇到的具体卡点和下一轮选题。

**待确认**　首发日、渠道账号、素材授权与实际统计能力。选题样例、低预算工时及归因细则见[国内宣传与海外分发](../../首发筹备/03-国内宣传与海外分发.md)。
