## 可见变化

- REQ031：Segmented 使用 AntD 默认 hover／选中效果，删除内部样式覆盖和误作用于页签的通用 `aria-pressed` 样式。指法卡片的选择状态规则限定在卡片上。
- REQ033：新增 `ChordCustomSurface`，自定义编辑器持续挂载；“查看我的指法 >”在其上层打开库，下层临时 inert。取消／Esc／X 只关闭库，恢复触发器焦点。选用后确认替换，通过编辑器引用修改原缓冲，可撤销，不重建输入节点。保留无效字符串、工具、手指和历史。替换确认使用 `mask.closable`，没有 deprecated 警告。空收藏不预选系统指法。
- REQ038：新增独立 `browseChordCatalog`，保留旧推荐查询语义；全部 192 项按当前调性的 12 个根音位置分组，每组 16 类。自然根音优先，搜索／筛选保持分组，详情随临时调性显示名称、级数和音阶关系，选用使用当前拼写。未确认调性时按绝对根音分组，不猜大小调。C7 在 C 大调显示“含调外音”，A 小调 G#dim7 显示“和声小调内”。
- REQ039：空名称且无指法的单拍保留灰色顶部框，仅显示“尚未配置和弦”；自定义入口放在下方表单，已有内容的正常预览保留。内容仍先草稿后应用。

额外完善弹层生命周期：宿主关闭时销毁和弦内容，外部文档版本变化使会话失效时，一并卸载上层库／确认层；自定义和通用守卫只处理实际所属 dialog 的按键，避免确认层 Cmd+Z 修改下层缓冲。正常 handoff 和焦点恢复保留。
