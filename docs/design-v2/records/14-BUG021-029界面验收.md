## 设计口径

采用 frontend-design 的简短方案、实现后截图自查流程，以及 ui-ux-pro-max 的桌面表单提交反馈、关联标签和 React 受控输入指引。沿用产品当前字体、字号、控件高度和色系：白色 `#fff`、正文 `#202938`、辅助文字 `#607084`、边界 `#dce3eb`、和弦强调 `#2457eb`，其余主按钮继续使用现有 Ant Design 主题。

- BUG021：“更多”文字与独立 SVG 向下箭头使用同一个居中 flex 行，侧栏及和弦气泡共用。
- BUG026 / 027：`[歌词输入……………………] [应用]`，两表面共享同一草稿与提交入口；气泡不增加时值，侧栏移除常驻恢复/应用底栏。失败信息仍显示；输入法、Enter、撤销及原有生命周期继续生效。
- BUG028：共享侧栏上下文保留当前对象及位置文字，移除“定位谱面”按钮。
- BUG029：复制范围固定可见，按最新图改成两行。第一行标签“复制范围”，下方 `[起始小节] – [结束小节]`；第二行标签“插入位置”，下方 `[宽插入位置选择器…………] [应用]` 同行。说明、阻断原因和错误保留在范围区内，无展开/收起和底部复制工具栏。

桌面最小验收宽度 1400px。截图自查后修正了范围字段分配，确保最小宽度下起始、结束值完整显示。没有调整谱面字号、侧栏整体宽度或基础主题。

### BUG029 最新反馈的局部设计与自查

再次读取 `frontend-design/SKILL.md` 与 `ui-ux-pro-max/SKILL.md`。局部计划保留上述五色、产品现有字体和 Ant Design 控件体系，仅调整复制区的顺序与占宽：范围等宽两列，中间短横独立占位；插入字段占剩余宽度，应用按钮靠右，两行左右边缘对齐。标签与控件间距沿用 8px，两行间距 12px；不引入新的卡片、字体、色彩或动效。方案对照最新截图后，删除旧方案的“三参数同行 + 下一行确认复制”。

ui-ux-pro-max 定向检索采用表单关联标签、提交反馈和 React 受控输入建议：复制范围通过 `aria-labelledby` 关联可见标签，起止选择器保留明确名称，插入标签关联选择器，视觉按钮为“应用”，可访问名称为“应用复制小节范围”；原 loading、禁用与错误路径保留。

真实截图自查发现共享小节表单的底部 margin 导致按钮低于插入选择器，已用复制区局部样式归零并以同一行中心偏差 ≤2px 复核。1400/1600 下范围标签、短横、第二行插入标签和宽选择器清楚可读，两行左右对齐且无页面横向溢出。成品截图使用非默认的“第8小节后”，覆盖实际选项文本的可读性。

离开策略按 [13 · 歌词与简谱侧栏设计](../specs/13-歌词与简谱侧栏设计.md) 及设计导航的现行规则：切换目标、类别、段号丢弃未应用输入；重复同目标、只关闭气泡或收起侧栏时保留会话。本轮没有改变该策略。
