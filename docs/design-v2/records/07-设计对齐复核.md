# 设计 v2 对齐复核

日期：2026-11-05。按本轮用户授权实施，以 `index.html`、`prototype.css` 和 `02-交互规格.md` 为基准；本轮前已明确移除的「视图」入口继续移除。

## 界面与入口

- 统一设计稿色彩、中文系统字体、13px 正文、58px 标题栏和44px 工具带。桌面纸面宽780px，1600px以上为800px；正式导出及打印继续使用既有 A4 几何。
- 右栏固定400px，四个横向任务页签、对象定位和底部操作常驻，表单使用单一主要滚动区。标题只保留收起图标。
- 工具带保留历史、六种真实时值和桌面菜单。附点、闷音、休止、删除等重复操作回归选区面板；「延续一拍」移到 TAB 音符状态。简谱连接操作归入简谱任务。
- 删除不再使用的窄屏「更多工具」、搜索目录和相关断点，以及无调用的谱行目标推测、属性和只写状态。
- 无选区时展示开始编辑的引导；页签浏览不自动建立和弦目标，简谱选区不能借用旧 TAB 位置操作和弦或连音。

## 任务表单

- 简谱正文、真实 tick 节拍预览、影响摘要依次呈现。节奏、音高连接、复制粘贴和移除事件分别分组；范围冲突展开节奏组。单音组用单行输入及 Enter 应用，连续录入保留 Ctrl/Cmd+Enter。
- 简谱复制直接提供源范围、实际复制及遗漏摘要、目标位置、覆盖及插入粘贴。合并归入节奏；连接记号维护归入音高与连接。
- 歌词与简谱动作区常驻离开丢弃提示，结束会话的动作标为「结束编辑」。保留同目标气泡与侧栏同步、输入法保护及独立组提交。
- 和弦先展示名称及指法预览，再展示名称输入、六个常用预设及更多预设、六弦、横按和观察范围。表格6→1弦与图形一致，底层存储仍按原契约更新；空弦/禁奏说明手指禁用原因。
- 歌曲按「曲谱信息 / 演奏设置」组织，基础拍号和变调夹并列；每组仍独立应用及恢复。小节线、段落标记、局部拍号和复制共用完整小节面板，重复进入仍可展开并定位边界组。
- 对象条比较完整目标身份；歌词、简谱定位使用实际图元和范围。底部状态展示当前谱层位置，撤回旧的「X处待处理草稿」数量。

## 保留的核心能力

原型演示值不作为领域能力上限：保留全部已支持时值、调性、和弦预设、技巧参数、小节/拍点复制粘贴、简谱连接和连音、撤销重做、原生曲谱导入导出、图片输出及输出保护。此次调整入口和呈现，未删除核心音乐命令。

## 浏览器复核

真实 Next 页面完成以下检查，未记录页面脚本异常：

- 1440×900、1440×720及1920×1080时右栏均为400px，表单无横向溢出。
- 单音组 Enter 应用后可撤销；复制返回实际范围、事件数、歌词数和遗漏连接数。
- 和弦表格为6→1弦；无目标时页签不自动打开名称输入。
- 侧栏收起/重开、曲谱信息独立应用、歌词离开丢弃与未应用歌词输出保护。
- 普通小节面板中再次从工具带进入小节线，仍显示完整小节设置并展开边界组。
- 存在旧 TAB 选区时，简谱连音入口仍按当前简谱对象工作。
