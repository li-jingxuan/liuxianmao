# REQ-019/020/021/022/023/029/030 和弦实现验收

本记录覆盖真实产品和弦侧栏、快捷气泡与和弦库。需求依据为 [REQ-017～030 需求与已确认口径](../specs/20261115_REQ-017-030需求与口径.md)。沿用当前蓝白紧凑样式；原型只用于交互与视觉核对，数据使用正式 `score-tonality`、`chord-catalog` 与本地指法收藏。

## 实现与口径

- 气泡和侧栏使用同一草稿。名称旁“应用”统一提交名称、指法和显示方式；快捷选择、库“选用此指法”、自定义“完成编辑”均只回填草稿。
- 名称标签末尾“删除”直接删除当前和弦、清空两处输入，并进入正式撤销历史。无谱面和弦时，删除只清空尚未应用的草稿。
- 删除重复“指法图”区域、气泡常驻保存／全局显示／名称关系说明及气泡、侧栏底部操作栏。显示方式采用“仅名称／名称与指法”单选。
- 侧栏显示 8 个真实指法图卡，仅保留“更多配置”库入口。气泡显示 6 个快捷名称及“更多”；更多菜单搜索下方为 4 列 2 行图卡推荐。
- 快捷列表跟随曲谱已应用的明确调性，不从 `1=C` 猜测大小调。小调使用原有自然小调三／七和弦与和声小调补充规则；快捷推荐的属大三、属七来自同一和声小调分组。
- 快捷项优先使用目录已有的开放指法，其次使用目录中把位较低的真实版本。G7、Cmaj7 等现有目录仅有封闭／高把位版本时如实显示，不补造原型指法。
- 库默认页签为 `all`，仅保留“全部和弦／我的指法”。全部和弦包含自然三和弦、七和弦、小调的和声补充及其余目录和弦，仍支持根音、类型、全库名称搜索。临时浏览其他调性不修改曲谱。
- 库左侧列表独立滚动，右侧名称、预览与版本详情贯穿固定详情区。切换分类／筛选将左侧列表复位；已暂存选择保持到用户另选或关闭。
- 目标切换与草稿会话沿用既有正式规则，本轮未新增导航确认。已有非标准调弦限制、精确非默认指法暂存、会话令牌及输入法保护继续使用。

## 集成定位

- 名称输入：侧栏 `[aria-label="和弦名称"]`；气泡 `#chord-popover-name`。
- 应用、删除、更多配置：各自编辑表面中同名按钮。
- 快捷列表：`[aria-label="本调常用和弦"]`。
- 库分类：`[role="tablist"][aria-label="和弦库分类"]`；默认 `#chord-library-tab-all`。
- 库左列表：`[data-testid="chord-library-scroll"]`；右详情：`[data-testid="chord-library-detail"]`。

产品接线已在 `MusicTextSidebar.tsx` 和弦区块完成，无额外父级 props 接线要求。未修改自定义指法弹窗与 `chord-preferences.ts`，未提交 Git。
