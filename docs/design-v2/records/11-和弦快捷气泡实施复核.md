# 和弦快捷气泡实施复核

按用户确认的[规格 10](../specs/10-和弦快捷气泡.md)及工具栏调整稿接入实际编辑器。独立原型继续作为设计参考，产品不读取其固定数据。

## 实现

- 「技巧」右侧加入和弦图标；单一 TAB 拍位可添加，同拍跨弦归一，已有和弦进入编辑。无有效 TAB 目标、简谱或歌词焦点、跨拍选区时禁用并可查看原因。
- 选拍只定位；点击图标或已有和弦才打开 360px 非模态气泡。已有和弦使用真实音乐图元边界，空拍使用 TAB 光标锚点；布局复用下、上、右、左候选与完整侧栏降级。
- 气泡名称、六个预设、显示方式与完整侧栏共享 `draft.chord`。预览复用领域校验、布局及图元；名称变化不推导指法，预设只改输入。
- 应用使用原 `SetChordSymbol`，一次命令一起提交名称、图与显示；普通 Enter 不提交，Ctrl/Cmd+Enter 应用且停留。× 和 Escape 丢弃未应用值，切目标和页签直接丢弃。
- 按最新截图反馈，气泡底部移除「结束编辑」「完整设置」，仅保留右对齐的「应用和弦」；标题栏 × 保留。复杂编辑直接使用右侧和弦页，收起后使用现有「打开编辑台」入口。
- 气泡与侧栏共享输入，错误入口展开并定位指法字段。收起保留会话，IME 与结束冷却期间阻止应用、退出、预设覆盖和工具栏导航，同时保留原输入接收组合文字。
- 更多预设菜单的 Escape 只关闭菜单并返回入口，不结束和弦会话。侧栏收起后再次点击工具栏按钮，保留输入并聚焦气泡名称。
- 无图可应用名称；非法图在仅名称模式仍阻止应用；非标准调弦禁用预设。其他预设、六弦、手指、横按、清图与删除继续留在完整侧栏。

## 验证

- 网站 TypeScript 与改动 TS/TSX、浏览器脚本 ESLint 通过。
- 初次实现终验：工具栏目标、快捷表单、完整和弦表单、错误字段定位、对象选择、草稿规则、浮窗几何及附点相关测试，8 个文件、85 项通过。移除两个底部按钮后，相关表单及会话测试 3 个文件、29 项再次通过。
- `chord-popover.browser.mjs` 真实组件回归覆盖：两个底部入口移除、标题 × 退出、工具栏状态与重复进入、零写入打开、双表面输入、预设焦点、应用/撤销、IME、空拍名称应用、非法图及错误定位（起始品位与无横按时重复手指）、调弦、退出与离开丢弃、空间不足保留输入。
- 独立复核发现的问题修正后补验通过：更多预设按钮及菜单项上的 Escape 不丢弃草稿；侧栏编辑 → 收起侧栏 → 工具栏重复进入，名称输入正确获焦。
- 1440×900、1440×720、1920×1080 下检查 360px 宽度和目标不遮挡。1440×350 时隐藏气泡并保留完整侧栏输入，恢复尺寸后重现。
- `music-text-coexist.browser.mjs` 通过：歌词与简谱共享输入、独立时值、未应用丢弃、IME、应用、撤销重做，以及设置仍保留离开确认与输出保护。
- 移除按钮后，和弦浏览器回归再次通过，并刷新三个桌面尺寸截图。实际 Next 页面 1440×900 确认底部仅一个应用按钮、标题 × 保留、名称自动获焦，无页面脚本异常。
- 独立设计原型同步移除两个按钮及空布局，侧栏联动场景改为直接编辑；十个场景、三种桌面尺寸的浏览器复核通过，21 张设计截图全部刷新。设计目录 157 个本地链接无缺失。

共存回归同步修正两个测试入口：简谱结束动作使用当前标题栏按钮；Capo 下拉改为键盘选择，避免侧栏滚动后的弹层坐标影响测试。
