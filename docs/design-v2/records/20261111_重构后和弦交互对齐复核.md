# 重构后和弦交互对齐复核

本轮基线：`feat/mvp-v8-gap-review`，`b3ff81c`。先阅读 `EditorShell/README.md` 及重构后的 chords、music-text、session、settings，再对照[六线猫 · 和弦交互方案 v2.3](../prototypes/chord-library/prototype.html)及[说明](../prototypes/chord-library/README.md)修正。保留原有模块边界，本轮代码尚未提交。

## 差异与修正

- 库内普通名称按钮改为四列级数／名称／选中标记卡片；自然三和弦、七和弦、小调和声补充分组展示。指法版本由下拉框改为可见版本卡，展示 6 → 1 弦品位。
- 全部库无筛选时优先展示原型中 C、D、E、G 等常见项，其余目录完整保留；配置页默认显示原型的 23 个常见添加候选，搜索仍覆盖全部系统和弦。收紧配置页标签下间距及候选按钮高度，避免不必要的额外换行。
- 恢复调性横幅、跟随曲谱／临时浏览切换和调性设置入口。精确匹配当前草稿的名称及指法；不把只改过名称或独立自定义图误认成系统指法。
- 常用配置补配置内搜索添加、六槽入口预览、恢复默认六项、指法标签及“更新常用指法”。默认 C、G、Am、Dm、Em 使用开放指法，F 使用一品横按；已有保存配置不被自动替换。
- 我的指法支持搜索。导入仍需确认且校验 revision，补待导入收藏名称和六弦品位的可展开预览；保留隔离、备份和不支持版本处理。
- 自定义弹层改为 850px 双栏；38px 指板目标、连续横按、弦顶空弦／禁奏切换、新按点手指选择、当前按弦摘要、折叠精细表单和谱面缩小示意。保留原子操作、本地撤销、输入缓冲、最后有效图和独立收藏保存。
- 和弦库宽 1000px，和弦侧栏宽 440px，快捷浮窗宽 378px。统一弹层标题／副标题、边距、边框、主题颜色和固定操作底栏；配置预览首行四项，与原型对齐。
- 侧栏补“配置”“选择其他指法／编辑指法”；快捷预览补当前名称／指法说明和行内编辑入口。关闭快捷浮窗保留共享草稿与侧栏，结束会话仍遵守既有草稿规则。
- 空名删除显示“应用删除”。设置入口聚焦调性；带未应用设置返回时提供应用／放弃／继续编辑，保留版本和 owner 校验。弹层退出恢复原入口焦点。
- 弹层正文按请求 id 重新挂载，避免 Ant 保留隐藏内容导致取消配置后重开仍残留未保存的顺序／添加项；同样隔离每次库筛选和自定义局部历史，退出动画仍保留当前请求内容。
- 浏览器发现 Select 的外置 portal 被工作区隔离为 inert，宿主将弹层内 Select／Dropdown 挂载到同一 dialog 域，显式设置 popup 层级与鼠标交互，避开 Ant 外壳的 pointer-events 继承；1440×650 真实 Next 页面原生点击 G 调成功。快捷浮窗、侧栏的“更多”改按触发位置控制，避免两个菜单同时打开；搜索每次打开恢复焦点，Escape 先关闭菜单并保留父草稿。
- 650px 高度下“更多”菜单曾超出视口，现根据触发按钮上下空间决定展开方向与最大高度。搜索／系统说明／底部入口固定，候选区域独立滚动；真实页面两个底部入口均在 y597–625 内，原生鼠标 trial-click 通过。

## 验证边界

本轮核对实际产品布局与自动化交互。原型背景为固定演示谱面，产品背景保留真实编辑器，不比较整页背景像素；不同目标小节与系统目录指法名称按真实数据展示。预览沿用现有核心的 3–5 品格自适应绘制，原型固定五格只作示意；编辑指板仍为五格观察窗口。实际操作系统中文 IME、辅助技术及真人吉他演奏性不由自动化验收代替。
