# 简谱与歌词设计对齐复核

2026-11-05，对照 `prototype.js` 的 `writingPanel()`、`lyricsPanel()` 及 1440 × 900 实际页面完成修正。

## 差异与处理

| 位置 | 原实现差异 | 本轮处理 |
| --- | --- | --- |
| 音高与连接 | 音高文本框和五个升降、八度按钮堆叠，缺少就地应用 | 按稿排列「选择音符／八度」「音高／变音」；增加应用、恢复和依赖说明 |
| 连接操作 | 重复分组标题、按钮纵向堆叠 | 去掉重复标题；连接终点下方并排放置延音线、连音线按钮 |
| 记号维护 | 低频维护直接露出 | 延长记号、现有连接端点更新与删除收入「更多记号设置」；选中记号时展开 |
| 节奏与范围 | 时值应用主要依赖底栏，拆分合并与常用字段混排 | 增加就地应用与恢复；拆分合并独立折叠；事件切换放入高级范围 |
| 歌词覆盖 | 覆盖许可常驻，逐项表格单独折叠 | 合并为「覆盖与逐项预览」；摘要显示项数、段号、覆盖状态；映射和阻塞提示常驻 |
| 折叠与删除 | 摘要整串粗体，箭头和删除样式不一致 | 使用紧凑标题、次级摘要、右侧箭头；歌词与简谱删除均使用红色文本按钮 |

## 保留的实际能力

- 正文、时值、单个音高继续独立应用与恢复；新按钮复用原有提交、依赖与输入法保护。
- 八度范围按后续要求调整为高音最多三层、低音最多两层；保留显式还原号，以及只改一个维度时保留其余音高编码的行为。
- 保留复杂节奏、固定覆盖范围、连音组、延长记号与现有连接维护。
- 歌词保留四段隔离、覆盖许可、`_` 保留原词、休止跳过、逐项定位及完整校验。
- 紧凑气泡中的高级字段继续隐藏并禁用焦点进入；完整设置可展开并聚焦目标分组。
