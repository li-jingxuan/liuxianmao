# 右侧编辑台 v2 实施验收记录

## 实现范围

基于当前工作区未提交代码继续实施，保留既有音乐排版、简谱目标和共享输入修改。未新增音乐算法、文件协议或持久化，未执行发布或合并。

- 编辑器专属 1440px 最小桌面画布，固定 400px 侧栏；四入口、对象条、单主正文滚动、常驻任务动作与收起/重新打开。
- 简谱、歌词两表面共享当前输入，收起不销毁 owner；业务目标规范化，结束编辑经过统一请求。文字真实离开直接丢弃；和弦及设置仍保护离开。
- 简谱三组独立提交/恢复，内容配置结构化基线；其他组未应用时不自动前进，时值及成员音高主要动作留在当前目标。
- 歌词连续覆盖默认关闭；按真实事件/空白时间窗展示跨小节节拍映射。和弦显示配置计入脏值并按受控值提交。
- 设置保留单 owner，歌曲与小节双正文 Portal；段落标记、复制范围位于小节任务。四组状态与登记独立，原小节绑定、冲突及失效输入保护。
- 登记以 owner token/generation 同步失效，旧 effect/cleanup 无权恢复或删除新登记。文件/图片统一阻断提示，文件读取后及替换前重新校验输入和完整版本。
- 外部变化保留当前失效原文并禁用旧候选；当前会话显式离开后丢弃。定位只滚动和绘制临时描边，不改变选区或音乐文档。

## 与原型的实现差异及人工补验

节拍数量、覆盖和连接影响采用当前领域规划可证实的数据；没有移植 HTML 的固定曲谱、模拟解析、演示撤销或成功提示。动作槽由当前 owner 直接渲染，不增加第二份 dirty/canApply 状态；未单独创建 `SidebarActionBar`。

集成回归曾发现：仅选择简谱事件后进入歌曲再打开小节，原本没有 TAB selection，局部目标为空。已在接受文字目标时记录其明确的小节引用，后续小节工具和设置使用该引用；没有回退选择首小节。

最终复核另补齐了收起后受保护导航自动展开确认、和弦冲突后实际修改重新校验，以及范围复制的内部命令预检（保留复制 busy 对外部输出/导航的保护，允许 owner 本次复制通过同一 adapter）。浏览器补测实际复制新增一个小节和一条历史。

真实操作系统中文输入法的候选窗、第三方 Select 在系统缩放下的遮挡，以及打印实机输出仍需人工补验。脚本的 composition 事件只证明事件保护分支，不代表真实中文输入法验收。独立输出沿用原管线，编辑器最小宽度在打印中移除。

## 截图反馈后的设计查漏补缺

针对用户截图再次逐项对照 `02-交互规格.md`、`prototype.js` 和 `prototype.css`，补齐以下遗漏：

- 删除正文顶部旧版「添加歌词行 / 添加简谱行」，任务切换改为「简谱 / 歌词」，首次浏览默认简谱。
- 无目标时只显示选取说明；真实 TAB 选区可显式进入当前时间位置的简谱录入，入口本身不建事件、不增加历史。歌词入口不再猜首小节，保留简谱目标供填写歌词。
- 对象条改为标题与「定位谱面」同行，拍位与范围在下一行；补齐四任务页签图标。
- 简谱按「方式与正文 → 横向节拍映射 → 节奏与范围 / 音高与连接 / 复制与粘贴」排列。事件选择并入节奏分组，低频设置折叠，移除正文重复应用与恢复按钮，由底部当前组统一提供。
- 歌词段号前置、方式改为紧凑切换，完整映射表及输入规则折叠；错误保留就地呈现，覆盖许可与真实规划继续生效。
- 歌词和简谱气泡均增加「完整设置」，显式转移焦点且尽量保留正文选区；同步渲染不抢另一表面焦点。
- 音符视图补齐六种时值，按时值/附点、状态、技巧、删除排列；简谱目标不借旧 TAB 选区执行命令。
- 小节视图改为局部拍号、段落、折叠边界、折叠复制；歌曲入口显示目标小节。程序定位复制字段时自动展开祖先分组，继续复用原设置 owner。
- 歌词/和弦删除移至正文独立折叠组，底部保留当前修改摘要和具体任务动作。
