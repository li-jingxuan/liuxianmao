# 和弦库实施验收与归档

日期：2026-11-11。状态：**产品代码已实施，自动化验收通过；人工演奏性、真实 IME 与辅助技术验收待完成**。

用户在完成 [v2.3 设计回溯](20261111_和弦设计与近期改动对齐复核.md) 后授权从 `feat/mvp-v8-gap-review` 新建 worktree 开发，完成后合并并归档。本记录描述产品结果；原型的 86 项检查继续保留为设计证据，不混计产品测试。

## 实现范围

- 两个和弦编辑表面共用固定“更多”、六项“我的常用”、全库搜索、已提交曲谱的调性推荐和库/配置入口。选择只回填唯一父草稿，保留 display；名称修改保图，已有空名仍按既有 Remove 删除，新建空名拒绝。可读预览保留最后有效图，区分保存方式与全局显示覆盖。
- 系统库位于 `apps/website/public/assets/chords/`：版本 manifest 与不可变 `catalog-2026.11.11.1.json`。192 identities、212 套不同 voicing；结构、身份/别名、公式、实际 MIDI 最低音与根音低音通过自动检查。构建前验证 manifest/数据/审核清单与确定性生成结果一致。无 API route、第三方存储或存储密钥。
- 共享 HTTP 资源处理首次加载、重试、并发合并、10 秒总时限、流式 16 KiB/2 MiB 上限、同源/目录约束、版本一致性、旧请求失效与更新失败保留快照。已打开库固定合法版本，首次失败可在原库重试。
- 本地常用/收藏具备严格 version 1 导入导出、显式替换预览、6/200/1 MiB 限制、存储失败内存降级、坏记录隔离与原文备份、未知版本保护及跨标签 revision 冲突。收藏保存与 local 完成/谱面应用分开，不改曲谱调性。
- 自定义编辑具有独立 local buffer、≥32px 弦品目标、方向键网格、两端点横按、六弦/横按表单、窗口观察、局部撤销重做、结构化错误及 lastValid 预览。增改删横按为纯原子事务；失败不改输入，必要清指号不清实际品位。完成只回填父值，取消保留父草稿。
- 新增 namespaced `lxm:tonality` reader、可选 minor 主音记法 1/6 和原子 `SetScoreInfo`；schema 仍为 v8。保留未知 metadata，不猜旧谱大小调；曲谱信息整个组处理冲突、显式恢复/认可，标题输入不消除整组冲突。按钮与组内 Enter 共用一条提交路径。
- Modal 沿用单一 Runtime 宿主；同 owner 捕获身份、目标、版本与父值，closing/handoff 期间继续锁定，旧 afterClose id 不释放新任务。库转 custom 不先改父草稿。曲谱设置通过专用暂停/恢复保存原和弦值，授权仅适用本次 info 组，背景撤销/输出仍受保护；设置成功重新核对基线并登记新版本。

真实浏览器回归同时发现并修复了两条集成缺口：迟到的文件导出点击会叠加输出草稿弹窗；弹层期间隐藏的文字 portal 在关闭后可能被 overlay 旧 inert 值重新锁住。输出回调现在检查 Runtime Modal gate，overlay 恢复文字 portal 的当前 inert 意图。暂停设置期间的背景撤销也明确阻断。
