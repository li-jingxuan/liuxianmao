## 修订结果

- **删除事务**：父应用区分 Set/Remove；已有空名（含空白字符）跳过待删旧图校验，删除整份和弦并保留拍点，新建空名拒绝。custom 完成和收藏命名仍要求非空合法名。直接删除沿用已实现入口与草稿保护，不重复新增功能；一次撤销恢复名称、图与 display。
- **键盘与目标**：普通 Enter 保留父应用语义，custom Enter 只回填，搜索/Select/按钮不穿透。记录旧菜单 Escape 与 Modal guard 的 IME cooling/内层 popup 缺口。补已有/新增/TAB `-`/独立简谱/无目标样例，禁止残留 TAB 目标误用；指法图 x、TAB x、TAB - 不转换语义。
- **工作区与低屏**：1400px 桌面最小宽度替代旧手机工作区要求，窄窗口横滚；不恢复侧栏标题行，纯图标收起再开保草稿；弹层按可视高度滚动并保持完成可达，打印继续解除工作区最小宽度。旧手机自适应截图保留历史。
- **图形与谱图边界**：可读编辑预览、≥32px 语义网格目标与缩小谱图分工明确。现有 `ChordDiagramLayout` 没有弦品命中身份，谱面只选整个 chord；墨迹、布局预留和点击保护边界不能混用。记录 `.6`/网格宽 27/名 9/横按厚 3/指号最低 5.5 的工作区现状及源字号推算边界，均不复制为新组件常量；现有缩放作用于所有谱面投影。
- **全局显示偏好**：未指定时沿用保存 display，true 在有图时显示图，false 只显示名；不改保存快照。新增提示审查，缺图明确说明，编辑预览仍可查看。真实间距、分行、绘制、命中与输出按同一有效投影回归。
- **会话和设置**：复用已存在 owner-aware adapter、协调器及输出保护；owner 身份捕获、closing/handoff、info 整组冲突、专用 suspend/resume 仍待实现。设置保持自己的 owner；交接授权仅开放本次 info 的 `SetScoreInfo`，不能排除所有 owner 或全局忽略草稿/Modal。将其纳入按钮与组内 Enter 的验收。
- **文件与验收范围**：目录/配置/编辑模块保留小 Interface；布局和通用提交模块以兼容回归为主，实际缺口才改；补跨小节、长名、高把位、多横按、显示偏好矩阵、动画期锁和异步确认复核，不顺带重写 compact 或其他谱层。

系统目录继续采用仓库内 `apps/website/public/assets/chords/` JSON + 同源 HTTP。192 identities、多 voicing、六常用项、本地收藏及导入导出仍是后续交付目标；不接第三方存储，不增加后端存储路由。
