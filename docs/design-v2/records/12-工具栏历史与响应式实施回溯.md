### 延音线工具栏快捷入口

用户确认“连音”指同音延音线。先在工具栏原型与说明中补充弧线符号，再接入产品的 H／P／S 快捷区。按钮名称“延音线”，提示连接相邻拍上的同弦同品位音符；单选起音时查找同弦下一音，反向选区按时间排序。复用原有技巧校验、提交保护和历史，原完整技巧入口继续保留。已有相同连接时高亮，重复添加为 no-op；无目标、不同品位、多弦、不相邻拍或其他谱层目标时沿用禁用与原因提示。原有 x 音符兼容规则保持。

相关 3 个测试文件／24 项测试、网站类型检查及修改文件 ESLint 通过；未运行全量测试。真实 Chrome [专项脚本](../../../scripts/toolbar-tie.browser.cjs) 通过：无效品位禁用及提示、单选起音添加、谱面生成弧线和按钮高亮、重复零写入、一次撤销重做、正式导出重新导入及 375px 可达，零 pageerror。原型亦验证弧线按钮、交互绑定和 375px 可达。截图保存在 Git 忽略的 `artifacts/toolbar-tie/`，可复跑脚本生成。

## 已选技巧的键盘删除补修（2026-11-08）

选中 let ring 时，谱面会同时建立用于定位的 TAB 范围（首拍到尾拍、第 1 弦）。旧 Backspace/Delete 直接对这个范围发 `RemoveNotesInRect`，导致覆盖的 3/12 品音符被删除，而不是删除技巧。现在按当前对象分发：有 `selectedTechniqueId` 时只发 `RemoveTechnique`，没有技巧对象时才删除普通 TAB 音符；技巧 ID 已失效时不退回删音符。删除复用工具提交的草稿、版本与模态保护，快捷键说明同步为“删除所选技巧或音符”。
