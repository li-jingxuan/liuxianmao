# 本轮功能回溯

本次重新读取当前工作区的源码和测试，以最新未提交修改为准；只调整设计资料，不修改产品文件。

## 当前行为与设计修订

- 歌词、简谱：换目标、页签、模式、段号或结束编辑，直接放弃未应用输入，不确认、不暂存。重复激活相同目标保留输入。
- 和弦、歌曲设置：保留未应用修改的离开确认；歌曲设置仍按原独立分组处理。
- 气泡与完整侧栏：保留同目标共享输入；仅收起侧栏不代表结束编辑。
- 导出：当前仍有未应用输入时阻断；不存在已离开位置的暂存列表，也不会因为已丢弃的旧输入继续阻断。
- 应用：只在显式应用成功后写入曲谱。简谱正文、时值、单个音高继续分别应用。

因此删除第一版原型的顶部待处理数量、跨位置暂存、返回旧输入和文字切换确认；增加底部离开提示。原「切换保护」场景改为「和弦切换确认」，原「待处理修改」场景替换为「导出检查」。

## 依据

- `apps/website/components/EditorShell/music-text-draft.ts`：`resolveSidebarRequest` 对歌词、简谱的离开返回 execute；相同目标返回 ignore；设置未应用时仍可返回 confirm。
- `apps/website/components/EditorShell/MusicTextSidebar.tsx`：删除简谱跨目标草稿登记与恢复入口；输出阻断检查当前编辑；取消文字编辑直接结束。
- `apps/website/components/EditorShell/NumberedEditor.tsx`：移除 `savedDraft` 及相应初始化，保留只读当前编辑快照和独立分组应用。
- `apps/website/tests/music-text-sidebar.test.ts`：新增直接离开、非法输入离开、重复对象保留，以及设置未应用仍确认的断言。
