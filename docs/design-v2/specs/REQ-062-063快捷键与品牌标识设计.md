## REQ-062 快捷键总览

在编辑器顶栏的「文件」左侧放「键盘图标 + 快捷键」，沿用 32 px 的次级按钮。顶栏所在宿主或视口宽度小于 1200 px 时，使用同位置的图标按钮，保留「快捷键」无障碍名称和 Tooltip。主编辑器的顶栏适配视口，谱面工作区可横向滚动。纯触屏也可以点按入口查询。

点击打开只读弹窗。默认显示全部分组，按操作名、按键和上下文筛选，例如「重做」「Ctrl + Z」「休止」「歌词」。每项左侧显示操作和必要的生效条件，右侧显示键帽。按设备选择默认键帽，允许切换 macOS 和 Windows。无结果时显示「未找到匹配的快捷键」和「清除搜索」。

桌面弹窗建议宽 620 px，窄屏左右各留 12 px，标题和搜索区固定，列表在弹窗内部纵向滚动。键盘打开后聚焦搜索框，Tab 在弹窗内循环，Esc 或关闭按钮退出并将焦点还给入口。弹窗内保留文本输入的原生编辑行为。查看快捷键沿用现有弹层管理，保留谱面选区、未应用草稿及既有保护；确认类弹层占用工作区时沿用现有焦点优先级。

### 快捷键清单

| 分组 | 按键 | 操作与生效条件 |
| --- | --- | --- |
| 编辑历史 | `Ctrl/⌘ + Z` | 撤销谱面修改。文本输入框内由输入框处理撤销。 |
| 编辑历史 | `Ctrl/⌘ + Shift + Z`，`Ctrl + Y` | 重做谱面修改。Windows 首选展示 `Ctrl + Shift + Z`，并标注 `Ctrl + Y`。 |
| 六线谱（TAB） | `↑` `↓` `←` `→`，`Shift + 方向键` | 落在六线谱格时移动选中格或扩展选区。 |
| 六线谱（TAB） | `0`–`9` | 输入 0–24 品。输入 `1` 或 `2` 时可在 600 ms 内接第二位数字。 |
| 六线谱（TAB） | `X`，`-` | 在弦格录入 x 弹奏标记或横线延音标记。 |
| 六线谱（TAB） | `R`，`Shift + R` | 将所选拍设为休止或取消休止。取消休止得到空拍，恢复原音符用撤销。 |
| 六线谱（TAB） | `Backspace`／`Delete`，`Esc` | 删除选中的音符或技巧。Esc 取消品位输入或收拢选区。 |
| 歌词、简谱与和弦 | `Alt/Option + ←/→` | 歌词或简谱移动至前／后一个录入位置。仅在对应输入框或其活动目标下的谱面生效，未应用改动按导航规则处理。 |
| 歌词、简谱与和弦 | `←` `→`，`Shift + ←/→` | 歌词或简谱连续选区在谱面上移动焦点或扩展范围。 |
| 歌词、简谱与和弦 | `Backspace`／`Delete`，`Esc` | 连续选区在谱面上清除范围内容或收拢选区。单项编辑中的 Esc 按当前草稿和气泡状态退出编辑。 |
| 歌词、简谱与和弦 | `Enter` | 歌词单项输入换行。简谱、和弦及连续范围的输入框应用当前输入。 |
| 歌词、简谱与和弦 | `Ctrl/⌘ + Enter` | 在相应属性编辑区应用当前歌词、简谱或和弦内容。 |
| 曲谱设置与技巧 | `Enter` | 在歌曲与小节设置的输入框应用当前修改组，在技巧数字参数输入框提交当前参数。 |
| 自定义和弦指法 | `方向键`，`Enter`／`Space` | 在指法网格移动焦点，或操作当前格。 |
| 自定义和弦指法 | `1`–`4`，`T`，`0` | 已选按点时设为对应手指、拇指或未指定。 |
| 自定义和弦指法 | `Ctrl/⌘ + Z`，`Ctrl/⌘ + Shift + Z`，`Ctrl/⌘ + Y` | 在指法弹窗内撤销或重做指法修改。 |
| 自定义和弦指法 | `Enter`，`Esc` | 文本框内 Enter 完成指法编辑。Esc 请求关闭，并沿用指法草稿保护。 |

「全部」覆盖编辑器中有业务含义的键盘动作。通用的 Tab 焦点移动、菜单和下拉组件的方向键与确认操作沿用组件约定。文件操作、拍点复制粘贴、时值和 H／P／S 技巧保留原有按钮和说明。普通浏览器与文本编辑快捷键继续由各自的交互处理。

### 就地提示

- 撤销、重做、切换休止、TAB 删除复用现有工具按钮的 Tooltip。普通悬停约 300 ms，键盘聚焦也可查看。排版先放操作名，再放短键帽。三种状态都预留在同一个提示层里，包括可用、不可用及已选中；不可用时补充现有原因。
- 「切换休止」同时显示 `R` 和 `Shift + R` 的含义。点击动作按当前选择决定切换方向。对已选 TAB 格，在鼠标停留或键盘焦点处显示简短输入提示，避免鼠标扫过每格时连续弹出。
- 歌词、简谱、和弦和曲谱设置的「应用」展示所在区实际接受的 Enter 操作。歌词、简谱输入框的帮助补充前／后位置键。指法编辑沿用现有局部键盘说明，并与总览使用相同文案。
- Tooltip 至多展示常用组合及禁用原因，剩余上下文留给总览。Esc 优先收起当前提示层，随后回到宿主按键规则。触屏用户查询总览，直接点击编辑控件即可操作。

## REQ-063 页面 Logo 放置

复用 `BrandIcon` 和 `public/assets/brand/` 的现有猫图标。在页面级回首页入口采用「图标 + 六线猫」。首页和吉他进阶共用 `HeaderBar`，品牌与导航分别对齐页面的左右两端，桌面两侧各留 24 px，窄屏各留 16 px。品牌图标和字号桌面分别为 40 px 和 20 px，窄屏分别为 32 px 和 16 px。编辑器图标为桌面 26 px、窄屏 24 px。各页面保留可点击热区和「六线猫首页」名称。 [共用顶栏](../../../apps/website/components/HeaderBar.tsx) · [品牌组件](../../../apps/website/components/BrandIcon.tsx) · [全站图标](../../../apps/website/app/layout.tsx)

| 界面 | 拟定放置 |
| --- | --- |
| `/` 首页 | 顶栏左侧 40 px 图标与「六线猫」，窄屏为 32 px，页脚沿用文字署名。 |
| `/editor` 编辑器 | 顶栏左侧 26 px 图标，独立于谱名和文件操作。无曲谱或不可绘制时用同一品牌位置，正文呈现新建和导入入口。点击 Logo 走现有离开保护。 |
| `/guitar-advanced` 学习路径、`/modules/[moduleId]` 模块、`/theory/[lessonId]` 理论、`/practice/[exerciseId]` 练习 | 共用吉他进阶顶栏左侧 40 px 图标，窄屏为 32 px。 |
| 吉他进阶 `/exam` 考试、`/exam/attempt/[attemptId]` 答题、`/exam/result/[attemptId]` 成绩、`/progress` 进度 | 同一顶栏位置，答题和学习过程退出沿用既有保护。 |
| `/technique-test` 技巧测试 | 测试页载入控件沿用独立标题，内部嵌入的编辑器顶栏显示同一品牌。 |
| 内嵌侧栏、和弦库、指法弹窗、文件弹窗、快捷键弹窗 | 品牌由所属页面顶栏提供，浮层标题聚焦当前任务。 |
| A4 预览、PNG 和打印、原生 JSON | 成品区域以曲谱内容为主，品牌位于编辑器外壳。 |
| 浏览器页签、主屏幕图标 | 使用同一图源的 favicon 和 Apple Touch Icon。当前通用 404／500 采用框架页面，本轮设计沿用浏览器级品牌。 |

## 验收

1. 桌面与窄屏都可进入总览。以「休止」「⌘ Z」「Alt」搜索能找到当前平台相关项，清除后恢复全量，切换平台会替换键帽，同一组合的别名可检索。
2. 悬停或聚焦撤销、重做、休止、删除及输入应用时，键帽符合当前动作和条件。H／P／S 等符号仍按产品原义呈现。触屏能通过总览一次查完。
3. 弹窗关闭后返回入口焦点。带着未应用草稿打开和关闭，草稿、选区和撤销历史仍可继续使用。输入法确认、弹层优先级、浏览器原生键盘行为按实际产品复核。
4. 桌面和窄屏核对首页、编辑器（含空状态）、吉他进阶各子路由、技巧测试及页签的 Logo。吉他进阶子页的品牌只出现于共享顶栏，导出的谱面遵循原排版。
