# 右侧编辑台交互规格

> 历史基线：本文保留当时规则；最新离开规则以 [README](../README.md) 及 [10 · 和弦快捷气泡](10-和弦快捷气泡.md) 为准。和弦未应用输入现为离开丢弃，歌曲及小节设置仍确认。

状态：设计提案，待讨论；本稿不代表已实现，也不授权产品实施。
依据：[设计方向](./01-设计方向.md)推荐方向 A；项目命令与文档入口见根目录 README.md。
范围：右侧栏、谱面快捷气泡（popover）及二者的编辑关系；独立 HTML 原型由主任务表达。
本文描述目标体验；涉及现有规则时标明约束，新增布局与交互均视为提案。当前行为、源码与测试依据见 [功能回溯](../records/04-功能回溯.md)。

## 1. 不变的领域边界

- 歌词绑定简谱事件及第 1–4 段，不绑定 TAB beat，不因换弦或指法改变归属。
- 和弦绑定 TAB beat；简谱事件和 TAB beat 的位置不能互相充当默认目标。
- 打开输入、切模式、创建指法预览不写谱；应用前仅保留当前会话的局部输入，显式应用成功后才创建音乐数据。
- 简谱内容、事件时值、单音符音高三组独立提交，任何一组应用不得夹带另两组修改。
- 不提供跨组「应用全部」；连续歌词的一批映射是一次歌词操作，不是跨组提交。
- 音乐合法性、覆盖范围、连音影响、复制粘贴结果以既有领域规划与命令为准。
- 不新增自动配和弦、自动节奏修复、自动转调、播放引擎或新的谱面能力。
- 同时音、连音组、延音线、连音线分别表达，界面不得将其统一解释为同一关系。

## 2. 外壳、布局与对象定位

顶部依次为「编辑台 / 收起」、四页签、对象定位条；底部为当前任务状态及分组动作。
四页签固定为「选区 / 简谱与歌词 / 和弦 / 歌曲」，替换方向稿所述现状中的「段落」名称。
页签只决定展示哪类工具；显式点击输入、编辑或谱面对象才确定可提交目标。
无关联对象时允许浏览页签和帮助，不自动创建事件、不替用户选择最近拍点。
定位条示例：「简谱音符 · 第 2 小节 · 第 1 拍 · 第 2 音」；歌词另显示「第 1 段」。
和弦定位条明确写「TAB · 第 2 小节 · 第 1 拍」；歌曲写「整首歌曲」。
范围对象显示起止小节与拍位，不能只显示「当前选区」；连音组附成员数与比例。
「定位谱面」仅滚动并突出对应对象，不提交、不切换目标、不改变表单焦点。
谱面可视选区与编辑目标不一致时写「正在编辑原位置」，并分别提供定位与切换入口。
定位信息使用文本与轮廓共同表达；不依赖颜色，长曲名与长位置可换行。
内部仅一个主要纵向滚动区；页签、定位与动作区常驻，输入焦点不得被其遮挡。
底部主动作使用具体动词，如「应用简谱内容」「应用时值」；不使用含糊的「保存」。
多个组未应用时，底部列出组名并跳到各组，不合并成一个主提交按钮。
视觉沿用方向稿色彩、系统中文字体及既有音乐图元；数字预览强调时间顺序。

## 3. 选区页签与三个子入口

「选区」保留谱面直接操作的任务入口，子入口为「音符 / 小节 / 连音」。
默认展示与所选对象匹配的子入口；用户主动展开的分组不被普通预览刷新折叠。
音符入口显示谱种、弦品或简谱成员、拍位、时值以及可用的既有记号入口。
选中 TAB 音符时提供「编辑此拍和弦」；不能将 TAB 音符直接当作歌词承载者。
选中简谱事件时提供「编辑简谱」「填写歌词」，进入对应模式并保留完整位置。
时值、休止和技巧沿用既有命令；此页与顶部工具带重复入口必须共享相同禁用理由。
小节入口承接「当前小节」段落标记、局部拍号及小节复制范围。
小节入口明确显示目标小节，局部拍号说明现有命令实际影响区间，不暗示全曲修改。
复制范围先选起止小节及插入位置，显示范围和结果摘要，再执行既有复制命令。
连音入口仅在适用选区显示可用的连音比例、成员与解除等既有操作。
「连音组」标识节奏分组；「延音线 / 连音线」放在音高与连接，避免术语混淆。
不适用的操作保持说明，如「请选择同一可编辑范围内的成员」；不伪造可用预览。
进入会改变文字编辑目标的子入口直接丢弃未应用输入；和弦及歌曲设置未应用时仍执行离开确认。仅展开说明不触发导航。

## 4. 简谱：先输入，再看节拍，再调整

「简谱与歌词」内部以「简谱 / 歌词」切换任务；切换直接丢弃当前文字未应用输入。
简谱顺序固定为：录入方式与正文 → 节拍映射预览 → 三个任务分组。
录入方式保留「单音组编辑 / 连续录入」；方式改变不写谱，直接丢弃当前未应用输入并按新模式初始化。
正文紧邻语法提示与示例；空格区分先后音，`+` 表示同时发音，其他语法沿用现有解析。
单音组修改显示当前事件原内容；连续录入显示起点、范围及已有事件回填语义。
正文失焦不应用；合法内容实时产生界面预览，非法中间输入保留原文。
未完整解析时用「输入尚未完整」解释，不以最后一次合法结果冒充当前可提交预览。
节拍预览从左向右排列：简谱数字在上、对应拍位在下，底部补充影响说明。
现有事件、待写入事件、将覆盖事件同时具有文字或线型区别，颜色只作辅助。
摘要示例：「可用 2 拍 · 输入 1.5 拍 · 替换 3 个事件 · 应用后到第 2 拍」。
摘要数字来自现有规划；不把单纯字符数当作音符数或覆盖范围。
点击预览项仅检查其谱面位置及旧值 → 新值，不提交、不移动正文光标。
内容较多的节拍预览可以横向滚动，始终显示起止位置；400px 侧栏表单本体不产生横向滚动。
范围越界、歌词归属或连接受影响时，显示准确摘要与既有确认步骤。
输入通过校验且内容组有变化时，提供「应用简谱内容 / 恢复简谱内容」。
应用成功仅清理内容组，保留时值组与单音符音高组的未应用状态。

### 4.1 节奏与范围

常规输入默认折叠，标题保留时值与范围摘要；发生范围冲突或从时值详情进入时展开，展示起止位置、既有范围模式、录入模板与当前事件时值。
「新录入时值」是录入偏好；「当前事件时值」修改已存在事件，两者分开标注。
已有事件的正文应用保留当前时值；模板参数不能悄悄覆盖已存在事件时值。
允许的均分、自选、成员时值与附点选项均来自现有能力，不扩充时值集合。
当前事件时值调整显示旧时值 → 新时值，以及后续事件移动、缩短和连接影响。
时值组提供「应用时值 / 恢复时值」，不提交正文或单个音高。
「等分持续音」等离散命令单列动作；执行前验证会影响的草稿依赖。
某操作与其他组冲突时保留表单，并写明「请先应用或恢复简谱内容」等具体理由。
当前会话内的应用与离散命令仍遵守依赖校验，折叠不改变校验结果；切模式或更换文字目标则按离开规则丢弃未应用输入。

### 4.2 音高与连接

默认折叠，标题保留「单音符音高未应用」等状态；从音符入口进入时自动展开。
先选事件中的具体成员，再编辑音高；以「第 2 音：3」等标签区分同时音成员。
升、降、还原与八度按钮只更新音高组草稿，保留现有音高及八度范围校验。
切换成员目标直接丢弃未应用输入，按新成员已应用值初始化，不能把原成员的文本带入另一成员。
提供「应用单音符音高 / 恢复单音符音高」，不改变事件时值或整段正文。
连接区域依次选择起点、终点，再显示「添加延音线 / 添加连音线」等已有动作。
延音线按音符成员、连音线按事件识别目标；文案解释差别，不承诺自动纠错。
延长记号等离散操作使用具体动作名；操作前显示影响和既有合法性错误。
离散动作不视为第四个待提交组，也不能借动作提交旁边未应用的音高。

### 4.3 复制与粘贴

默认折叠；内容依次为源范围、复制摘要、目标位置、覆盖或插入模式。
「复制简谱范围」读取已应用谱面；有冲突草稿时先处理，避免误以为复制了输入框。
复制成功显示实际范围及跨范围连接未复制数量，不能省略领域返回的遗漏信息。
粘贴先展示现有规划可提供的覆盖、移动与连接影响，再使用具体执行按钮。
按钮分别为「覆盖粘贴 / 插入粘贴」，不能用一个「应用」隐藏二者区别。
剪贴板为空时显示「请先复制简谱范围」；失效或版本不兼容时保持原谱不动。
粘贴是独立命令；成功后重新核对草稿依赖，不能将三组顺手标记为已应用。

## 5. 歌词：单点、连续与四段

歌词区首先显示「第 1–4 段」选择及当前简谱事件，段号不等同于歌曲段落标记。
切段意味着更换歌词目标，直接丢弃当前未应用输入；四段各自归属，不互相覆盖。
单点模式展示原词、单行输入、当前音符及下一歌词位置。
同一事件可填写短句；单点不按短句中的空格拆成多个位置。
单点 Enter 为「应用并下一处」，Shift+Enter 为「仅应用」；谱尾停留并说明已到末尾。
没有修改时显示「下一处」；不能凭导航动作创建空歌词。
连续模式使用单行语义的文本输入区，示例为「风 吹 _ 过 山 谷」。
半角、全角空格均分词，忽略首尾空格；`_` 跳过一个可填位置并保留原词。
按现有简谱位置映射，跳过休止；可填空白位置沿用当前规划，不创建简谱音符。
每项最多 64 字、每批最多 256 个位置；不接受换行与制表符，超谱尾整批拒绝。
时间预览对齐音符与词，列出位置、原词 → 新词及新增、覆盖、跳过、未变化状态。
点击某项只查看位置；不把连续模式的实际目标改成该项，也不丢失整批输入。
已有歌词默认保护；列出将覆盖的条目与数量，用户勾选允许替换后才可提交。
存在任一错误时整批不写入；不能静默应用合法前半段。
主按钮为「应用歌词」，摘要写明本批数量与覆盖影响；避免「应用全部」文案。
单点删除与清空行为沿用现有命令，并明确当前段号；连续 `_` 绝不解释为删除。
无简谱承载位置时显示「请先选择可填写歌词的简谱位置」，提供返回简谱入口。

## 6. 和弦：TAB 拍位与六弦指法

对象定位始终显示 TAB 拍位；从无和弦拍点进入也只建立草稿。
先用名称与指法图预览明确当前和弦，再展示名称输入、常用预设、六弦表、横按及显示范围。
预设填入当前草稿并标记未应用，不能直接写谱；名称与指法由用户确认。
六弦表逐行显示弦号、品位、手指；弦序与既有指法图一致，并明确方向。
品位提供「× 禁奏 / ○ 空弦 / 1–24」；手指保留未指定及 1–4。
改成空弦或禁奏后清除该弦手指，禁用手指控件并解释原因。
预览与表格联动只表达当前草稿；输入非法时停止生成误导性指法图并指出字段。
横按最多 4 个，显示品位、起弦、止弦、手指及单条删除入口。
校验整数、弦范围、端点顺序及既有横按一致性；不自动反转用户端点。
起始品位 1–20，只改变观察窗口，不改变实际品位、不转调。
「创建指法图」仅创建界面草稿；「清除指法图」保留名称，应用前可恢复。
显示模式沿用现有选项；名称、指法与显示配置作为当前和弦一次独立应用。
非标准调弦时显著提示「常用预设暂停，仍可自定义六弦与横按」。
非标准调弦不自动改写现有指法，也不暗示名称由实际发声音高自动推断。
底部为「应用和弦 / 恢复和弦修改」；删除已有和弦使用独立明确动作。
和弦名称或指法有未应用修改时，换目标、换页签或结束编辑仍需确认；取消确认保留原目标与输入。

## 7. 歌曲：全局与小节局部的迁移

歌曲页只组织整曲信息：歌曲名称、编谱作者、调性、基础拍号、Capo。
歌曲信息、基础拍号、Capo 沿用各自独立应用语义，互不夹带。
「应用歌曲信息」包含其既有字段；选择调性不暗示自动移调已有音符。
基础拍号明确实际作用区间：从首小节到首次局部拍号变化之前，依据既有规则计算。
已有但当前不可编辑的拍号保留只读显示，不能自动替换成下拉首项。
Capo 保留 0–12 整数，0 表示不使用；不把空值视为 0。
现有歌曲表单的「当前小节 / 段落标记 / 小节复用」拟迁至「选区 → 小节」。
歌曲页保留「编辑当前小节」引导，显示目标小节，点击后定位到小节入口。
迁移只调整入口，不改变段落标记归属、小节复制规则或局部拍号命令。
小节草稿绑定原小节；谱面另选小节时先处理草稿，不将标记写到新小节。
设置草稿未处理且会影响复制时，阻止复制并指明需处理的组。
歌曲设置保留未应用修改的离开确认；即使当前展示歌词或简谱，仍不能跳过设置确认。

## 8. Popover 与侧栏共存及焦点

保留现有共存方向：popover 展示快捷输入，侧栏展示同一目标完整设置。
两处使用当前同一目标的局部输入、预览结果与提交状态，不维护可互相覆盖的两份表单值。
主动打开的表面获得输入焦点；另一表面同步内容时不自动 focus、不抢光标。
例：用户在歌词 popover 输入，侧栏映射更新，输入光标及 IME 会话仍留在气泡。
从气泡点击「完整设置」时属于显式转移，侧栏定位同一字段并尽量保留光标范围。
侧栏收起或重新打开仅改变呈现，不触发提交、还原或再次加载草稿。
气泡关闭区分「隐藏表面」与「结束文字编辑」：隐藏保留当前会话输入；结束直接丢弃未应用输入。和弦及歌曲设置的离开确认仍适用。
两个表面提交同一组时共享提交锁；一次按键最多产生一次既有命令。
提交失败后两处显示同一错误，焦点留在发起表面；成功不突然跳到另一表面。
气泡容纳基本输入与具体组的应用入口，不把所有高级表单塞入浮层。
气泡越过可视范围时调整位置；不可见表面不进入 Tab 顺序，不覆盖侧栏焦点。

## 9. 当前输入、离开与导出

歌词、简谱的未应用输入只属于当前编辑会话。换文字目标、换页签、换歌词段号、换模式或结束编辑时直接丢弃，包括非法输入与多个分组未应用的情况；不弹出文字离开确认。
返回原位置重新读取谱面已应用值，不恢复已离开位置的输入；不提供跨目标暂存、待处理列表或返回旧输入入口。
重复激活相同业务目标、当前页签或当前模式不重置输入。同目标气泡与侧栏共享；仅收起侧栏或隐藏气泡且会话未结束时保留输入。
和弦及歌曲设置保留离开确认。可应用的独立任务沿用「应用并切换 / 放弃并切换 / 返回编辑」；设置仍按既有分组处理，不合并三组简谱应用。
取消和弦或设置确认后保留原页签、目标及输入；确认期间目标被删除或文档变化时先复核，不执行失效命令。
IME 组合中仍阻止提交与会结束编辑的操作，组合结束后重新校验；移除文字离开确认不取消输入法保护。
导出检查当前输入与编辑状态：当前仍有未应用输入时阻断，提示用户应用或结束当前编辑后重试，不自动应用或丢弃。
已在文字导航中丢弃的旧输入不再阻断导出；离开文字编辑不能跳过和弦或歌曲设置仍需处理的状态。
处理结束后由用户再次发起导出，不从旧回调自动导出一个可能变化的版本。不承诺跨刷新、跨设备恢复输入。

## 10. 状态矩阵

下表为目标交互验收矩阵；「应用」均指当前明确的分组或独立任务。

| 状态 / 触发 | 预览与应用 | 导航与输出 | 焦点 / 恢复 |
| --- | --- | --- | --- |
| 无目标 | 说明选取方式，禁用写谱 | 可浏览页签 | 显式选取后进入输入 |
| 干净 | 显示已应用值，无重复提交 | 直接切换，可输出 | 记住表单滚动位置 |
| 文字单组有效修改 | 展示差异，仅该组可应用 | 离开直接丢弃，当前导出阻断 | 恢复只重置该组 |
| 文字多组有效修改 | 各组独立应用，无合并按钮 | 离开丢弃全部未应用组，当前导出阻断 | 同会话内跳组保留输入 |
| 文字输入无效 | 保留原文，错误组禁用应用 | 离开直接丢弃，当前导出阻断 | 错误摘要链接字段 |
| 同目标重复激活或仅隐藏表面 | 输入、预览与应用状态保留 | 会话继续，未应用输入仍阻断导出 | 气泡与侧栏共享 |
| 和弦或歌曲设置未应用 | 保留独立应用及校验 | 离开确认，当前导出阻断 | 取消确认保留原状态 |
| IME 组合中 | 不触发提交或离开 | 阻止会结束编辑的操作 | compositionend 后重验 |
| 提交中 | 锁定同组重复命令 | 不重复导航或输出 | 保持发起表面焦点 |
| 提交失败 | 保留草稿与错误，不清脏状态 | 留在原目标 | 可修正或重试 |
| 外部变化使目标失效 | 撤去可提交预览，禁止旧命令 | 重新选目标后重验 | 保留可查看原文，不自动重放 |

## 11. 校验、IME、快捷键与恢复

字段输入保留中间值；空、负号、小数等不被失焦时自动改成合法值。
轻量错误就地显示；提交出现多处错误时聚焦可链接摘要，并保留各字段错误。
应用禁用原因必须可见，错误文案说明位置与修正方法，不只写「非法参数」。
IME composition 期间 Enter 仅确认候选，不应用、不跳下一处、不触发谱面快捷键。
组合结束后重新解析；组合期间阻止会结束编辑的操作，不能把半个候选文本提交到谱面。
简谱单行正文 Enter 应用内容；连续正文 Ctrl/Cmd+Enter 应用内容，具体提示随模式显示。
歌词单点沿用 Enter / Shift+Enter；连续歌词使用 Ctrl/Cmd+Enter 应用本批。
文本框内 Ctrl/Cmd+C、V、Z 保留文本语义，不触发范围复制、谱面粘贴或文档撤销。
页签使用方向键及 Home/End；文字目标切换遵守直接丢弃规则，和弦及设置保留确认；Tab 按视觉顺序访问可见控件。
Escape 先关闭最上层菜单或确认层；落到文字结束编辑动作时丢弃未应用输入，单纯隐藏气泡时保留会话。IME 组合中不得借 Escape 结束编辑。
「恢复本组修改」回到该组最近有效已应用基线，不影响其他组，也不生成撤销记录。
已应用音乐操作通过既有撤销恢复；文档撤销或外部更新后重新核对草稿依赖。
成功状态用短文本说明结果，失败保留输入；不将点击应用直接显示为成功。

## 12. 空态与桌面尺寸

无选区显示「在谱面选择音符或小节」；简谱与歌词仍可浏览输入规则。
无歌词承载对象、无和弦指法图、无可用剪贴板分别给出一个明确的下一步入口。
最小产品视口宽度确定为 1440px，本轮仅设计桌面，1440 × 900 为基准画面。
谱面与右侧编辑台始终并排。侧栏固定 400px；标题右侧只保留收起按钮，移除四角展开按钮及宽度切换。
更大窗口扩展谱面可用空间与留白；侧栏、页签、对象定位和底部动作保持相同结构。
移除窄屏演示、抽屉、遮罩与底部编辑区。小于 1440px 不切换布局，只保留桌面最小画布并允许横向查看。
主动收起侧栏仅释放谱面空间，不结束文字会话；重新打开回到原对象和输入，焦点回到明确入口。
收起后重新打开保留当前页签、分组展开及输入；六弦表固定保持弦号、品位、手指三列。
较低桌面高度通过侧栏正文独立滚动承载，常驻标题和动作不遮挡焦点；不靠缩小文字挤入控件。
验收覆盖 1440px 基线及更宽桌面、400px 固定侧栏和收起/打开。评审板画框只截取部件，不代表另一种产品布局。

## 13. 讨论与决策记录

已推荐：采用方向 A 的四任务入口，强化对象定位，使用按时间排列的映射预览。
已限定：先做设计表达，三组独立提交、先应用后建数据、既有领域引擎均保持边界。
已确定：仅覆盖 1440px 及以上桌面，不考虑窄屏；侧栏固定 400px，仅保留收起按钮。
提议待讨论：歌曲中的小节局部入口迁至选区，歌曲页保留可发现的跳转提示。
提议待讨论：底部状态区的多组导航密度，以及文字离开丢弃提示的可读性。
后续产品验证场景：不同文字目标往返不恢复、同目标输入保留、仅收起侧栏、歌词第 2 段覆盖、和弦及设置确认、非标准调弦、气泡 IME、三组独立应用及当前导出阻断。
评审以用户能否确认对象、读懂影响、独立应用及理解离开后输入的去向为标准；原型检查与产品验收分别记录，见 [评审核对](../records/03-评审核对.md)。
