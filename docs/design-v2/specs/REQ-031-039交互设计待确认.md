## REQ031：Ant Design 默认页签效果

最新要求：“tab hover 效果用 ant-design 默认效果就可以了，现在这个背景色很奇怪”。

使用现有 AntD Segmented 的默认选中、hover、过渡与底色。取消影响 Segmented 内部选中状态的通用 `[aria-pressed="true"]` 规则，以及本轮不需要的选中颜色和边框覆盖。hover 不增减边框，不改变尺寸。使用默认 Input，维持一个输入容器和可见键盘焦点。

原型中没有 Segmented 内部样式覆盖；直接打包项目安装的组件，预览与拟议实现有相同样式来源。

验收：鼠标由全部切到我的，未选页签呈 AntD 默认 hover，标签位置不变；搜索不存在嵌套蓝框，Tab 键焦点可见。

## REQ033：保留下层自定义弹窗

最新要求：“点击‘查看我的指法 >’不需要关闭指法编辑弹窗，直接覆盖在指法编辑弹窗上层即可”。参考图二是 `Warning: [antd: Modal] maskClosable is deprecated. Please use mask.closable instead.`。

自定义 Modal 保持挂载，库以更高层级打开，初始页签“我的指法”。下层可见边缘体现覆盖关系；交互和焦点限定在最上层。取消、X、Esc 仅关闭库，焦点回“查看我的指法 >”。下层未完成名称、无效起始品位字符串、按点、工具、手指选择、撤销／重做均保留。

沿用此前已确认的替换规则：点击收藏仅预览；点击选用后确认替换，取消确认留库；确认后关闭库，替换下层缓冲，允许撤销。完成编辑回填父草稿，再“应用”写谱。底层关闭守卫不会同时处理库或确认层的 Esc。另存收藏仍独立保留。

生产实现需调整当前单请求 handoff，保持自定义编辑器组件实例；不要靠退出后重建来实现此次覆盖。`ChordLibraryReturn.tsx` 中已弃用的 `maskClosable={false}` 改用 `mask={{ closable: false }}`，核对所有本轮相关 Modal。原型已经使用新 API。

验收：观察库打开期间下层输入 DOM 节点相同；无效输入往返不丢失；替换／撤销、焦点、Tab、Esc 各层独立，控制台没有上述弃用警告。

## REQ038：完整目录按当前调性分类（本轮拟议方案）

最新要求：“所有的和弦都要按照调性来分类，除非无法分类的和弦”。

当前系统库是 12 根音 × 16 类型，共 192 个身份。旧查询只返回自然三／七和弦 14 项及小调补充，导致其余落入“其他”。本轮需要完整目录分组能力，不能仅删除标题，也不能把全部变化和弦称作自然调内。

拟议将完整目录按**当前调性下的根音位置**分为 12 组，每组 16 类：

- 优先排列七个自然音阶根音，再排列五个变化根音；组标题如“C 大调 · I 级根音 C”“C 大调 · ♭II 级根音 Db”。
- 卡片仍五列、左图右名称与级数。卡片级数表达根音及和弦性质，例如 C 是 I、Cm 是 i、C7 是 I7；不推断实际音乐中的和声功能。
- 右侧补充音阶关系：自然三和弦、自然七和弦、自然调内、和声小调内、含调外音。依据完整和弦构成音检查，扩展、挂留与变化和弦不整类归入自然调内。
- 所有系统和弦都已知根音及类型，因此全部可分类，本稿不出现“其他和弦”。“我的指法”继续单独收藏列表，不凭任意自定义名称伪造级数。
- 搜索和根音／类型筛选只减少列表，仍保留当前调性分组、名称拼写和级数。右侧详情随调性变化重新解释。
- 大调以自然大调为基准，小调以自然小调为基准：A 小调中的 C 为 III、F 为 VI、G 为 VII、G# 为升 VII；不与相对大调记法混用。
- 临时浏览不修改曲谱；曲谱调性未明确时不凭 `1=C` 猜大小调，先显示按绝对根音的完整目录，支持临时选择主音与大小调。该降级规则沿用已有口径，原型主场景是已明确的 C 大调。

具体例子：C 大调中 C/Cmaj7 是自然三／七和弦，C6/Cadd9/Csus2/Csus4 是自然调内，C7 含 Bb，显示含调外音，均在 C 根音组。D7 含 F#，不自动断言为 V/V。A 小调中 Am/Am7 属自然三／七，E/E7/G#dim/G#dim7/Caug 属和声小调内；A/A7 含 C#，显示含调外音。

用户确认本稿时，确认的是这个完整分组信息结构；若希望按自然和弦／副属／借用等和声功能分组，需先修订设计与功能判定口径。当前方案不尝试无上下文确定功能。

实现验收：任意可浏览大小调下目录身份无缺失、无重复，192 项分完；包含全部 16 类；搜索不丢失分组。自然调内、和声小调与含调外音各有独立例子，临时浏览和详情一致，曲谱调性不变。

## REQ039：空拍顶部状态

选中单个未配置和弦的 beat，保留侧栏顶部原有灰色背景框，居中显示“尚未配置和弦”。不在这个空状态内同时展示未命名、标准调弦、尚未设置指法及编辑指法等占位内容。

下方名称输入、自定义指法、常用和弦保留；未输入时应用禁用。选用指法或完成自定义后预览本次草稿，应用后才写谱。已有和弦的正常预览、无选区／多选提示和自动绑定规则沿用现有已确认行为。

验收：无和弦的单拍顶部框保留，文案准确；已有和弦不显示此空文案，换拍能正确同步，草稿预览与已应用状态不混淆。
