# 工具栏附点补充设计

本轮恢复工具栏的单附点、双附点入口，补充此前仅将附点放在选区详情中的设计。以本补充稿覆盖 07 文档中「附点回归选区面板」的入口约定，编辑台的附点下拉仍保留。

## 设计稿

- [附点状态交互稿](../prototypes/toolbar-rhythm/index.html)：普通时值、单附点、双附点、不可编辑四种状态；可点击附点按钮或编辑台下拉，观察同步。
- [完整原型](../prototypes/editor/index.html)：时值按钮后增加附点分组，与「选区 → 音符 → 附点」联动。沿用固定演示数据。

## 布局与交互

六种基础时值后追加一个独立的附点分组，接着排列小节、拍点、连音与技巧入口。按钮沿用产品现有 32px 高度、音乐图标、提示气泡、焦点轮廓和蓝色选中态，不增加文字常驻标签。

两个附点按钮互斥：单附点为基础时值的 1.5 倍，双附点为 1.75 倍；再次点击已选按钮恢复无附点。切换基础时值保留附点数量。取消附点不会改变基础时值。使用原生按钮与 `aria-pressed` 表达开关状态，支持 Tab 聚焦、Enter/空格执行；提示说明当前作用和再次点击取消的行为。

工具栏与编辑台读取同一曲谱状态，不维护独立附点草稿。TAB 单拍选区可立即修改，跨拍范围不可用；修改后可撤销。简谱事件与空占位按既有时值目标路由：事件修改独立简谱声部，空占位只更新后续录入时值。歌词、和弦等目标不借用保留的 TAB 选区。未应用草稿、当前弹层及现有音乐规则继续控制可用性，不绕过容量或连音限制。

## 设计依据与验收

使用 `ui-ux-pro-max`，针对桌面工具栏检索 `toolbar toggle selected state desktop`（ux），采用明确的选中态和即时语义状态；React 检索 `derived state event handlers`，采用渲染派生状态与直接事件处理。保留项目现有配色、图标和工具链。

验收覆盖：两种附点入口可见、互斥与重复取消；工具栏与选区下拉同步；切换时值保留附点；TAB/简谱目标隔离；无目标、多拍选区和草稿阻挡；现有时值操作与撤销。测试以工具栏触发行为、既有目标与音乐命令回归，加实际页面交互核对为证据。

本轮结果：工具栏附点新增 10 项测试，连同目标解析及工具动作回归共 20 项通过；TypeScript、改动文件 ESLint、原型脚本语法检查通过。浏览器核对了补充稿的单附点状态、完整原型附点入口，以及实际产品从八分音符切换单附点、双附点、再次取消的侧栏同步；1440px 下完成工具栏显示验收。测试使用独立页面，未修改用户已打开页面的曲谱。
