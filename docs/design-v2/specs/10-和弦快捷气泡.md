# 和弦快捷编辑气泡

日期：2026-11-05。状态：设计已确认，工具栏调整版已接入产品；[实施复核](../records/11-和弦快捷气泡实施复核.md)。以下保留设计约定，独立原型继续使用演示数据。

[打开可点击设计稿](../prototypes/chord-popover/index.html) · [设计目录](../README.md)

## 1. 设计依据与当前规则

参考用户提供的简谱气泡截图，采用「锚定目标 → 快捷输入 → 当前状态 → 应用」结构、浅边框、圆角、留白与蓝色焦点。标题 × 负责退出，复杂编辑直接使用右侧同目标编辑台。和弦没有音符时值，原来的时值行替换成常用指法与显示方式。

以下约束来自当前 `ChordEditor.tsx`、`MusicTextSidebar.tsx` 和 `music-text-draft.ts`，不是新增音乐能力：

- 和弦绑定 TAB 拍点，目标身份为 track / measure / beat；换弦不建立另一份同拍和弦输入。简谱事件不能作为默认和弦目标。
- 名称、指法图、谱面显示是同一和弦的一次应用。输入、选预设、切显示和创建图都不写谱。
- 改名称不会自动修改指法，也不校验名称对应实际发声音高。选择常用预设才同时替换名称、指法和显示方式。
- **最新离开规则：和弦、简谱、歌词离开直接丢弃未应用输入；歌曲和小节设置保留确认。** 初期 `02`、`05` 和旧评审截图里的和弦离开确认已被后续规则取代，本稿不恢复它。
- 重复进入同一目标、仅收起侧栏或隐藏气泡不重载输入。当前未应用输入继续阻断导出，处理后用户重新发起导出。

设计时产品的气泡会话只包含简谱和歌词；本次实施已补齐和弦气泡、工具栏入口、焦点转移及双表面共享输入，实际验证见实施复核。

## 2. 布局与信息顺序

桌面最小产品视口 1440px，侧栏保持 400px。气泡宽 360px，内边距 12px，高度随内容自然收缩；移除底部次级按钮和独立链接行，不预留空布局。错误和调弦说明按需增高，不在气泡内嵌套长表单滚动。

1. 标题：已有数据为「编辑和弦」，空拍为「添加和弦」。同行展示「TAB · 第 2 小节 · 第 1 拍」与 ×。
2. 名称：单行文本框，保留非法中间值；空态示例「例如 C、Am、G7」。无变化时应用禁用。
3. 常用指法：单排六项 `C / G / Am / F / Dm / Em`。其他预设在右侧编辑台中访问，不在气泡叠加更多菜单。
4. 指法与显示：左侧当前指法预览，右侧调弦信息及「仅名称 / 名称与指法」切换。图标题始终是「当前指法」，不把新名称盖在旧图上造成自动匹配的错觉。
5. 说明：名称与指法关系、离开丢弃提示；快捷键写明 Ctrl/Cmd+Enter 应用且停留当前拍。
6. 操作：底部仅保留右对齐的主按钮「应用和弦」。退出使用标题 ×；复杂编辑直接在右侧同目标侧栏进行，已收起时使用现有「打开编辑台」。

气泡只解决名称输入、常用指法选择、查看图形和谱面显示。六弦、手指、横按、起始品位、清图与删除和弦留在侧栏；不把和弦表单整体塞进气泡。

## 3. 目标、焦点与共享输入

### 工具栏入口（本轮调整）

移除谱面空拍上常驻的「＋和弦」。在工具栏「技巧」右侧添加分隔线与 32×32px 图标按钮，图标为 20px 线性指法图加号，沿用工具栏颜色、圆角与焦点样式。按钮不带常驻文字；悬停和键盘聚焦显示提示，辅助技术可读名称与展开状态。

- 未选有效 TAB 拍点、仅有简谱/歌词目标，或选区无法归一为单一 TAB 拍时禁用；提示「先选择一个 TAB 拍点，再添加和弦」。禁用原因可从可聚焦的按钮外层读取。
- 选中无和弦的 TAB 拍时显示「添加和弦 · 第 N 小节 · 第 N 拍」，使用指法图加号；选拍仅显示谱面选中态，不自动弹出编辑器。
- 当前拍已有和弦时改用指法图图标，提示「编辑和弦 · 第 N 小节 · 第 N 拍」，进入原有和弦编辑，不重复添加。
- 点击后在谱面目标旁打开气泡并聚焦名称，气泡始终锚定谱面上的已有和弦或 TAB 拍点；不锚定工具栏。按钮用浅蓝底表示当前会话已打开。
- 同一目标重复点击只返回当前输入并聚焦名称，保留未应用值；不切换开关、不立即写谱。IME 及冷却期间禁用此入口与拍点切换。

点击已有和弦名称或指法图仍可直接编辑。仅浏览和弦页签或单纯选拍不自动聚焦、建事件或写入和弦。名称输入、侧栏编辑和退出规则继续按以下约定执行。

两个表面共享同一输入、校验、dirty、提交锁及已应用基线。任何一处修改只同步另一处的内容和预览，不抢焦点，不清光标，不重复提交。预设被选中后，焦点留在所选按钮；打开编辑、使用「打开编辑台」或点击「前往修正」时按对应入口定位焦点。

六弦、横按、起始品位等复杂字段直接在右侧同目标和弦页编辑。侧栏已收起时使用现有「打开编辑台」，继续当前会话并恢复侧栏焦点；不再提供气泡底部的「完整设置」按钮或名称文本选区转移约定。指法错误仍提供「前往修正」，展开侧栏及对应组并聚焦错误字段，保留全部当前输入。收起侧栏后仍可用气泡编辑。

气泡是非模态对话框：有可访问标题与 TAB 定位，不加遮罩、不锁住页面 Tab。Tab 按视觉顺序访问控件，可进入完整侧栏；失焦不应用、不结束会话。普通 Enter 不应用和弦，Ctrl/Cmd+Enter 应用当前和弦；与原有和弦快捷键契约一致。

## 4. 应用、退出与恢复

应用只在目标仍有效、当前值有变化、名称及已有指法均合法、非 IME/提交中时可用。成功后保留当前拍与气泡，刷新两表面的已应用基线；一次应用只产生一条既有音乐命令，不自动前进。失败保留输入，说明具体原因，焦点留在发起表面。

标题 ×、气泡层 Escape 都结束和弦会话并丢弃未应用值，返回谱面目标。展开的菜单先处理 Escape；不让关闭菜单触发结束会话。点击其他目标或切页签直接丢弃旧输入；回到旧位置读取已应用值。已应用数据通过文档撤销恢复。

「仅名称」只影响谱面显示，不删除图；气泡仍可预览存储的指法，并补充「指法保留，不显示在谱面」。无图时可应用合法名称；「名称与指法」禁用并给可见解释。已有非法图即便切「仅名称」也不能绕过图校验。

IME composition 及结束后既有冷却窗口内，不允许应用、预设覆盖、目标切换、结束、侧栏收起或跨表面焦点转移。数据从外部更新使目标失效时，保留原文和原位置说明，撤去旧可提交候选，提供重新选取；不得把输入自动写到邻近拍点。

## 5. 状态覆盖

| 设计场景 | 气泡与操作 |
| --- | --- |
| 已有和弦、干净 | 显示原名称及图，应用禁用；可用标题 × 退出 |
| 选择常用指法 | 名称、图、显示同步改变；预设仅在完整名称和图匹配时高亮；谱面仍保留原值直到应用 |
| 工具栏添加 | 初始展示选中的 TAB 空拍；点击工具栏图标后无名称、无图，应用禁用；填写名称或选预设后可用；打开零写入 |
| 工具栏未选拍点 | 图标禁用；悬停或键盘聚焦外层可查看原因，不使用旧目标添加 |
| 仅名称、无图 | 无图占位，禁止假画六根空弦；合法名称可应用；直接在右侧编辑台创建图 |
| 仅名称、有图 | 继续预览存储图，文字说明不显示在谱面，不清除数据 |
| 自定义调弦 | 六个预设禁用，已有图保留；名称和自定义指法仍可编辑，指法不会自动转置 |
| 名称无效 | 就地错误，保留输入并禁用应用 |
| 指法无效 | 暂停图形预览、显示具体字段错误；「前往修正」定位右侧编辑台的错误字段 |
| 侧栏共享编辑 | 两表面编辑同一目标并同步当前输入；收起后用「打开编辑台」继续，不经过气泡底部入口 |
| 靠近谱面边缘 | 优先下方，其次上方；上下不足时改放左右，箭头跟随目标；约束于谱面区域，不越入侧栏或挡住目标 |
| 空间不足 / 锚点不可见 | 隐藏气泡呈现，保留会话；侧栏仍可继续，空间恢复后按锚点重新放置 |
| IME / 提交中 | 保留文字，不允许第二次命令或离开；提交锁由两个表面共享 |

## 6. 原型范围与评审方式

原型包含十个场景（九种气泡场景加未选拍点状态），工具栏添加/编辑、拍点选择、名称、六个常用指法、显示切换、应用/撤销、标题 × 退出与重开、侧栏共享编辑、错误定位、边缘翻转和收起可点击。「侧栏共享编辑」沿用 `scene=settings` 地址，便于既有截图脚本继续使用。页面上方的场景条与标注属于评审工具，不是产品功能。

指法图、曲谱、历史及应用反馈使用固定演示数据；本稿不会读取产品 store、连接音乐引擎、持久化、导入导出文件或替换当前产品页面。侧栏只展示已有复杂编辑的去向，六弦样例取前几品，起始品位错误只演示填写「1」修正，不能据此缩小实际 1–24 品或横按能力。数值与指法合法性仍须由产品已有领域逻辑判定。

评审重点：气泡是否够紧凑、名称与图的关系是否清晰、预设是否易点、右侧同目标编辑是否清晰、标题 × 与底部应用是否容易区分。产品接线与真实音乐命令验收已记录在实施复核。

## 7. 技能参考与适用边界

本轮使用 `ui-ux-pro-max` 的 UX 定向检索「popover editor focus not obscured」，命中 Web 焦点不被遮挡指南；React 检索「form focus controlled state」命中共享受控输入与焦点管理。后者的模态焦点陷阱建议不适用于本次非模态气泡，故不采用锁焦。

工具栏调整补充 icons 定向检索「icon button accessible label」，采用返回的图标语义指南：图标在按钮内装饰隐藏，按钮自身提供名称、展开状态和可访问说明。图形为本稿内联 SVG 示意，实施继续使用项目统一图标。

遵循现有中文系统字体、蓝色强调、SVG 图元、语义标签及可见禁用原因，不引入移动端触控规范或新图标依赖。原型适配 `prefers-reduced-motion`，状态不只依赖颜色。

以下为移除底部按钮后的独立设计原型验证，不代替产品功能验收；产品验证见实施复核：

- 工具栏新增状态检查通过：未选拍点禁用及提示、选空拍不弹出、点击按钮零写入打开、已有和弦进入编辑、重复进入保留输入、IME 期间禁用入口与拍点切换，以及结束后焦点返回 TAB 拍。十个场景可访问，原九种气泡行为继续通过。

- 根导航、迁移后的桌面基准与附点原型可打开；和弦原型 JavaScript 语法及 `git diff --check` 通过。浏览器未记录页面脚本异常。
