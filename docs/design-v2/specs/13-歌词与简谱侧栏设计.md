# REQ-007～016 · 歌词与简谱侧栏设计

状态：交互设计提案，四项行为口径已经用户确认；尚未实施到产品。

来源：[六线猫 bugfix · tcgLfi](https://pcnhehlhivqu.feishu.cn/wiki/UEivw1G7Liuaqnk20d1cqCoxnHb?sheet=tcgLfi)。已使用 `lark-cli` 解析 Wiki、读取 REQ-007～016 原文，并下载核对十张参考图。本文只覆盖这十项；REQ-018 的连续选区另行设计。

入口：[可点击设计稿](../prototypes/lyrics-numbered/index.html) · [截图评审页](../prototypes/lyrics-numbered/review.html) · [交付说明](../prototypes/lyrics-numbered/README.md)。

## 1. 已确认的行为口径

以下四项由用户逐项选择确认，优先于旧设计和现有产品行为。

1. **移除拆分与合并。** 本轮面板不保留持续音拆分、合并的入口，不以折叠方式继续藏在面板里。连续录入和时值编辑继续保留。
2. **简谱按输入时值自动替换。** 覆盖默认允许，范围随输入的实际时长计算；删除固定范围开关、自定义覆盖时长、录入起点及强制填满预设范围的操作。例如当前一个四分音符 `1`，选择八分时值输入 `1 2`，应用后成为两个八分音符，占原来的一拍。空白一拍只填一个八分音符时，不强制填满剩余半拍。
3. **歌词空输入与 `_` 都表示留空。** 空输入应用只清空当前位置；`风 _ 过` 清空中间位置，编辑态用占位框显示。一个或多个普通空格只分词，不产生额外空位置。`_` 不再保留原词，这与当前产品的旧规则不同。
4. **八度、变音跟随谱面选中的单音。** 多音 `1+3` 中，点中 `3` 后点升号，只改成 `1+#3`。侧栏用简短摘要展示当前目标，删除成员和音高下拉框；不默认为整组修改。

## 2. 布局与状态

- 延续编辑器的蓝白配色、白色谱纸和灰蓝画布；音乐符号用本地 SVG，界面使用系统中文字体。
- 保留右侧一级栏目和“简谱／歌词”二级切换，不新增工作流或全局导航。
- 位置栏压缩为标题、位置和定位操作；删除“正在编辑原位置”“切换到当前选区”等重复说明。
- 简谱主体顺序：单行内容输入 → 默认展开的节奏设置 → 节拍映射预览 → 可折叠的八度与变音。
- 歌词主体顺序：段号 → 单行连续输入 → 对齐预览。第 1～4 段分别编辑。
- 面板底部采用紧凑的恢复与应用操作，不重复堆叠状态说明。
- 桌面谱面与侧栏并列；窄屏谱面内部滚动，面板下移，页面不横向溢出。
- 产品下方的评审控制只用于切换演示状态，与实际产品操作区域分开。

## 3. 简谱录入

### 3.1 未选择与开始录入 · REQ-007

有有效 TAB／小节位置而未进入简谱编辑时，保留简洁图示、“从当前谱面位置开始”和“录入简谱”按钮。删除参考图中的两段长说明。完全未选择位置时，不允许把输入写入任意位置。

### 3.2 连续输入与帮助 · REQ-008、009

- 只保留连续录入，不显示“录入方式”或“单音组编辑”切换。
- 使用普通单行 Input，删除文本区的右下角缩放手柄和换行能力。
- 输入标签旁保留问号，悬停、键盘聚焦或点击展开规则。空格分隔先后发声，`+` 表示同时发声，`'` 与 `.` 表示高低八度，`#`、`b`、`n` 表示变音，`0` 休止，`-` 延续。Enter 应用；输入法选词中的 Enter 不提交。
- 删除“可用多少拍／输入多少拍／覆盖多少处”“将处理多少事件／应用后位置”等重复长摘要。
- 保留能看出音符与拍点关系的节拍映射预览；预览草稿不等于修改谱面。

### 3.3 节奏设置 · REQ-010、011

- 节奏区默认展开，紧贴输入，不需要向下寻找常用时值。
- 常用等时值与节奏模板使用可辨识的名称和符号示例；具体模板集合以交互稿为评审提案，不视为已接入核心的完整模板目录。
- 时值与附点使用同一套符号按钮，侧栏与气泡保持一致；将来实施时应复用公共组件。
- 正文输入、模板选择进入共享草稿，点击“应用”写入谱面。对已选音符的独立时值修改沿用即时生效与撤销的交互；正文有未应用修改时，应先应用或恢复正文，再修改独立属性。
- 不显示“固定范围替换”“允许覆盖”“高级录入范围与复杂节奏”“恢复均分”等高级范围入口。
- 自动覆盖仍须校验可写位置和事件边界；非法输入或超出可写区域时，就近显示简短原因，禁止半次写入。自动范围不能默默截断已有连音组或删除无关歌词。

### 3.4 八度与变音 · REQ-012

- 分组改为“八度与变音”，不再包含连接操作。
- 八度用带上点／下点的数字符号，覆盖低两层、本位、高三层；变音用无记号、还原、升、降符号。按钮提供名称提示和选中反馈。
- 点击即修改谱面当前选中的单音，支持撤销；侧栏摘要随谱面选择同步。
- 正文未应用、无音高目标或休止等不适用状态下禁用，并按需解释原因。
- 删除“选择音符”“音高”“应用单个音高”“连接终点”“添加延音线”“添加连音线”和“更多记号设置”。

### 3.5 移除低频入口 · REQ-013

移除整个“复制与粘贴”“移除当前事件”区域，不用隐藏或折叠替代删除。后续如有删除、复用需求另行定义；本轮设计不扩大到全局剪贴板能力。

## 4. 歌词录入

### 4.1 未选择 · REQ-014

保留简洁图示和“先选择歌词位置”。删除长说明及“返回简谱”链接。选到可填词的位置后才进入编辑，不能靠未选择态按钮创建任意目标。

### 4.2 连续歌词与空位置 · REQ-015

- 默认连续编辑，侧栏和气泡均删除单点／连续切换。
- 空格分词，单个词可以包含多个汉字；不按汉字逐字拆分。按简谱的可填词位置顺序映射，沿用跳过休止的规则。
- 空输入、纯空格输入应用后将当前位置设为空位置；不是无效输入，也不是“什么都不做”。
- `_` 明确留空一个位置，可以与普通词混用；全 `_` 也是有效的清空操作。
- 编辑态中空位置显示占位框；占位框属于编辑提示，不作为歌词字符印到成品谱面。
- Enter 与“应用”均提交当前草稿并停留当前位置，不导航到下一处。
- 侧栏与气泡使用同一草稿。一个表面输入后，另一个即时同步；切换第 1～4 段时读取对应段的已应用内容。

### 4.3 精简动作 · REQ-015、016

- 气泡只保留关闭 X 和“应用”；删除“完整设置”“结束编辑”“应用并下一处”“下一处”。
- 侧栏删除“下一歌词位置”、下一处的快捷键说明和整个“移除歌词”区域。
- 底部保留紧凑恢复／应用，不堆叠“当前内容已应用”和离开规则的重复提示。无变化时应用禁用，有可提交变化时启用。
- 保留现行生命周期：切换目标、类别或段号时丢弃未应用输入；仅关闭气泡或收起侧栏时保留当前会话。恢复只恢复未应用输入，撤销恢复已经提交的谱面修改。

## 5. 评审重点与交付边界

主要检查：常用字段能否在首屏找到，符号是否易识别；侧栏与气泡是否同步；输入错误是否紧邻字段；自动替换与歌词留空是否符合已确认规则；应用后是否原地停留。

设计稿使用固定示例数据模拟草稿、应用、恢复、撤销和目标切换。它不等于真实编辑器的命令、排版或文件格式已经修改；跨小节复杂节奏、连接关系保真、既有歌词保留、旧文件升级和完整中文 IME 需要后续产品实施与验收。特别是 `_` 的语义变更，实施时必须同步修改解析器、预览和帮助说明，不能只换 UI 文案。

## 6. 可点击评审场景

1. 进入简谱编辑，输入 `1 2`，选择八分模板；映射预览展示两音共一拍。应用后谱面更新，编辑位置不跳转；撤销恢复原事件。
2. 侧栏输入 `3 5`，打开谱面气泡，检查值相同；气泡继续改为 `3 6`，侧栏同步。关闭气泡后重新打开，未应用输入仍在。
3. 输入非法音高或超过可写区域，预览附近显示明确原因，应用禁用，谱面不发生局部变化；恢复后回到已应用值。
4. 点中多音 `1+3` 的第二音，展开八度与变音，点升号；第一音保持不变，第二音变为 `#3`。撤销后恢复 `3`。
5. 有正文未应用修改时尝试改八度或独立时值，应说明先处理正文；不能把草稿与已应用事件意外混合。
6. 切到歌词，输入 `风 _ 过`，预览中间为空位置；应用后谱面对应位置为编辑占位框，当前目标不变。
7. 将当前已有歌词输入清空并应用，当前位置变为空位置；空输入不能被当成错误或跳过。
8. 在第 1 段应用后切换第 2 段编辑，再回第 1 段，确认两个段落分别读取自己的已应用值。
9. 未选择目标时只展示对应空状态；选到有效 TAB 位置后“录入简谱”可用。歌词必须选择可填词位置。
10. 在桌面、720px 与 390px 查看；谱面在内部滚动，面板可完整操作，无页面横向溢出。
