## 2. 视觉与结构

沿用 design-v2 与实际编辑器的蓝白工作台：操作蓝 `#1677ff`、主文字 `#26364a`、辅助文字 `#63748a`、工作区 `#f4f6fa`、面板白 `#ffffff`、删除红 `#ff4d4f`。系统中文字体，正文 14px，辅助信息 12px，控件高约 32px，间距 8／12／16px，圆角 6px。

本轮是对现有工具界面的紧凑调整，不改变谱面排版密度、音乐符号语义或编辑缩放规则。正式编辑器继续沿用 1400px 最小桌面宽度；小视口审稿允许横向滚动。

工具栏顺序：时值与附点 → 常用音符／技巧 → 所有技巧 → 节奏型 → 连音 → 小节 → 和弦。节奏型、连音、小节使用纯图标按钮，鼠标悬停和键盘聚焦展示中文名称。连音使用括号加数字的谱学符号，小节使用边界符号，节奏型使用连梁音符，避免依赖不明含义的通用图标。

浮层同一时刻只打开一个，锚定对应按钮；在视口边缘内缩，过高时内部滚动。Esc、再次点击入口、点击外部可关闭，关闭后焦点返回触发按钮。图标按钮提供可访问名称、展开态；选择按钮同时提供颜色、描边或勾选及 `aria-pressed`。

关闭规则适用于空闲状态。中文输入法组字期间不把 Enter 作为提交／关闭，正在提交时暂时锁定切换和重复操作；未完成的目标选择或数值输入在取消后丢弃，不写入其他位置。已经即时生效的修改通过撤销恢复。

## 3. REQ-044：选区侧栏

“选区”下只保留“音符／小节”两个页签，取消第三个“连音”页签。音符页从上到下：当前对象摘要 → 时值与附点 → 连音 → 音符状态 → 常见节奏型。

时值六项为全音符、二分、四分、八分、十六分、三十二分；附点为无、单、双。使用一行紧凑图标组，中间以分隔线区分时值与附点，保留各自独立选中态。可用条件和混合选区含义沿用原命令；禁用不得表现为已经应用。

连音紧随其后，直接提供与工具栏相同的六种纯图标按钮及删除入口，每排三个，按钮高 34px，底部一句规则提示；名称及禁用原因通过悬停／聚焦读取，避免额外切换页签。只在 TAB 合法连续拍点选区启用；简谱当前不借此新增连音命令，给出明确原因。

常见节奏型直接展示模板，不再要求先点“更多”。按用户最新截图反馈，十二种模板（含四种三十二分细分）全部放在同一网格直接平铺，不单列分区或折叠；工具栏节奏型气泡同步平铺。侧栏仅保留标题、模板网格、简洁前后对照及“应用节奏型”按钮，移除标题旁模板数量／跟随谱层文字、模板上方谱层／拍号／目标范围说明、底部结果说明和模板数量。必要的错误、预览过期提示及标记影响确认保留。侧栏和工具栏节奏型属于同一操作：切换入口时沿用目标、模板和预览，避免出现两个独立草稿。

侧栏已经打开时，工具栏节奏型仍可进入较宽的预览气泡，方便检查多拍对照；两处选中态同步。任何一处提交成功，另一处读取已更新结果；不得重复提交同一个旧预览。节奏型影响确认期间不允许另一入口绕过确认。

严格继承 [REQ-043 v2.1](REQ-043常见节奏型交互设计.md)：

- 跟随谱面活动层与焦点位置，自动归齐完整演奏拍；产品面板不加回谱层选择或范围选择。
- 4/4、3/4 共用十二种拍内模板，6/8 使用五种模板。多拍逐拍套用，不能跨拍借位；跨小节不应用。
- 顺序保留已有音符及休止，不足补待填空位。空位与休止区分；不复制原音、不自动加延音线。
- 技巧或连接标记需移除时，在原区域确认影响后统一应用；歌词和和弦保留。内容超额、跨范围内容或映射失败时阻止并说明。
- 外部选区、谱层、拍号或内容变化使预览过期，须重新预览。应用作为一次可撤销操作。

无选区可浏览模板，应用与音符修改禁用，提示选择谱面位置；不得沿用离开的旧目标。右栏滚动不挤压谱面，反馈在当前操作附近显示。

## 4. REQ-045：所有技巧

气泡标题为“所有技巧”，右上角使用 text 类型的纯删除图标按钮，常态和禁用态无边框、无底色，悬停时仅提供浅红反馈。按实际技巧目录展示全部十六项：

- 音符连接：击弦 H、勾弦 P、上滑音、下滑音、延音线。
- 音高与修饰：推弦、颤音、自然泛音、人工泛音、点弦 T、颤音奏 tr。
- 演奏方向与范围：扫弦、琶音、拨片方向、手掌闷音 P.M.、Let Ring。

每项为图标加中文名按钮，不使用 select；删除“新增技巧：选择全部 16 类…”入口及原底部全宽添加／删除按钮。

按最新截图反馈，技巧区改为三列紧凑横排按钮（图标在左、名称在右），高 36px、间距 6px，分组标题及间距收紧，面板内边距 14px。正常态高度约 386px。删除底部操作说明和禁用原因说明两段常驻文案；名称与具体禁用原因仍可悬停／聚焦读取。多技巧对象的点选控件及实际操作所需参数区保留，不作为常驻提示展示。

点击可确定的技巧直接应用，保持气泡打开以便继续操作。需要关系目标的技巧，点击后提示选择同弦目标音符，完成选择即应用；需要音高、方向、辅助品位等参数的技巧，使用就近小控件，选择值即应用，取消不留下半成品。不能为满足“点击即应用”而默选关系目标或丢失参数能力。

已有技巧仍可从谱面选中并就近修改参数。参数区明确显示正在编辑的对象及作用范围；类型格默认新增，同类型已选对象可进入参数修改。更换已有对象类型须有明确的“更换类型”操作态，再从同一组十六类按钮选择，不以点击另一类型偷偷覆盖原对象，也不恢复旧下拉框。

推弦半音／全音、上下方向等离散选项点击即提交；辅助品位等数字字段只在 Enter 或失焦时提交完整合法值（辅助品位为 0～24 整数），输入中的中间值不提交。非法值就近解释并保留输入。参数操作绑定开始编辑时的目标及文档版本；目标变化先取消旧预备操作并说明，提交期间阻止重复修改，避免把旧参数写入新选区。

禁用原因应贴近对应项目，悬停／聚焦都能读取。无选区、休止、跨小节、目标音不合法等情况按技巧自己的条件判断，不以全体统一可用代替。

删除提案：右上角按钮仅在能唯一定位一项已选技巧时启用，删除当前技巧对象；选区含多项但未指定对象时先提示选择，不隐式清空全部技巧。成功提示技巧名并提供撤销。此范围需随整稿确认。

后续产品实现需删除被替代的旧入口与专用选择流程，而不是仅以 CSS 隐藏；共享参数控件及其他仍在使用的技巧命令保留。

## 5. REQ-046：连音

气泡保留标题“连音工具”，按用户最新截图反馈，六种按钮仅显示连音图标，去掉“x 连音”等名称标签。六项沿用实际比例：二连音 2:3、三连音 3:2、四连音 4:3、五连音 5:4、五连音 5:3、六连音 6:4。五连音两种在图标内分别显示 5:4、5:3，其他图标显示实际数量。名称与完整比例保留在悬停提示及可访问名称中；禁用原因可聚焦读取。侧栏同步采用相同纯图标排布。

图标使用实际括号和数字，避免用普通上下标文本代替谱学符号。删除连音组保留为紧凑操作。

按后续反馈，气泡宽度收至 300px，六种图标按每排三个、两排排列；按钮高 34px、间距 6px，内边距 14px。图标维持 38×24px 可读尺寸，下方保留删除按钮及一句规则提示。

应用条件：TAB 同小节连续拍点，所选实际拍点数量恰好等于比例的 actual 值；因此 5:4 和 5:3 都要求连续五个拍点。不是根据拍号分子或六根弦推算可用性。

底部只保留一句“同小节内，连续拍点数须与连音数字一致。”，不再显示已选数量及删除前置条件的多行说明。无选区、简谱层、跨小节及数量不符的具体原因收进对应禁用按钮的悬停／聚焦提示；删除只在可定位已有连音组时启用，禁用原因同样就近提示。

“连音比例与选区详情”入口及对应专用功能从本轮新界面移除，不再从气泡跳转到另一表单。侧栏沿用同一组动作和状态。

## 6. REQ-047：小节工具

小节入口位于连音之后、和弦之前。气泡头部并列“小节工具”及“第 x 小节”，不再重复占用一整块目标提示。

主体分两区。按用户最新截图反馈，标题下直接显示六类小节线及“谱首反复”图标，下方直接放三个小节操作。移除“小节线与反复”标题、当前边界名称、右侧边界说明、“小节操作／当前小节”标题及底部插入位置说明。侧栏复用同组图标及精简操作。

三个小节操作使用浅灰整体底座、三列等宽横排，按最新反馈改为图标在左、名称在右的紧凑按钮，高 36px，图标 18px；整体底座高 44px，以细竖线区分操作，收紧上下分区留白。新增用蓝色突出，复制保持正文色，删除用红色图标识别；删除悬停时使用浅红反馈。插入位置仅保留在按钮悬停提示中，侧栏复用相同样式。

三个图标加名称按钮：

1. 新增小节：在当前小节后插入空白小节，延续当前适用拍号。
2. 复制当前小节：原内容保留，副本紧跟当前小节后；不把连续范围隐式当作复制来源。
3. 删除当前小节：使用红色删除操作，区内展示目标和内容影响，确认后删除；取消不改谱。仅剩一个小节时禁用，说明须至少保留一个。

以焦点所在小节为当前小节，即使存在跨小节选区，也不对全范围新增、复制或删除。当前目标在气泡标题可见，避免误操作。

顶部一排提供单小节线、双小节线、终止线、开始反复线、结束反复线、双向反复线及“谱首反复”七个图标按钮，底部各有简短名称；“谱首反复”前以细竖线区分独立开关。前六项修改当前小节右边界，具体目标通过悬停提示说明；点击即时应用并保持面板打开。侧栏共用同样外观、选中态与约束。

小节新增、复制或删除成功后，标题、谱面小节数量、当前焦点及侧栏一起更新，避免气泡继续指向已经删除或改号的旧位置。撤销同时恢复内容、边界、数量及有效焦点。

末小节右边界没有下一小节，开始反复及双向反复禁用；另外四项允许。“谱首反复”图标只在第一小节启用，作用于全谱左侧首边界，以 `aria-pressed` 和选中样式表示开关，可与六类右边界图标独立选中。取消单独整行的开关及说明文字，必要原因改为悬停／聚焦提示。

气泡不保留范围复制、小节属性跳转、六类小节线跳转、段落标记等旧入口。小节设置的其他已有能力仍可通过侧栏“小节”页操作；本需求不授权删除整个设置系统。

## 7. 设计确认与复核边界
