# REQ-043 · 常见节奏型交互设计

版本：v2.1，按截图反馈压缩预览并扩充模板；已实施，2026-11-18 用户验收通过，已完成。[PRD](REQ-043常见节奏型PRD.md) · [可点击稿](../prototypes/req043/index.html) · [产品实现与验证](../records/REQ-043产品实现与验证.md)。

## 1. 入口和视觉

“节奏型”原位替换“拍点”，顺序 **小节 → 节奏型 → 连音**，沿用文字＋下拉箭头。旧拍点工具不混入新面板，不额外新增入口。

沿用现有编辑器：蓝色 `#1677ff`、正文 `#26364a`、辅助文字 `#63748a`、白面板、浅灰工作区；系统中文字体，正文 14px、辅助 12px，控件高约 32px，间距 8／12／16px，卡片圆角 6px。模板用正常符干、连梁和附点表示真实时值。

浮层锚定入口，桌面建议宽 680～760px，边缘自动内缩，内容过高时内部滚动、底部按钮始终可见。产品仍以至少 1400px 桌面为基线，窄屏布局仅用于审稿。

## 2. 面板简化

正常态只保留：

1. 标题“节奏型”和关闭按钮。
2. 一行只读目标：“简谱 · 第 1 小节第 1 拍 · 4/4”。6/8 补充“每拍＝附点四分”，TAB 标明“全部六弦”。
3. 全宽模板卡片：4/4、3/4 十二张，分“常用”八张和“三十二分细分”四张；6/8 五张。桌面四列；中文名、真实节奏图、选中勾选即可。新增小切分、十六＋附点八分及成对的三十二分细分，具体时值见 PRD §5。
4. 模板下方紧凑“当前 → 应用后”单层并排对照，正常态对照区目标不超过 170px，去掉原右侧高大的上下卡片。待填位置用虚线框，已有休止用 `0` 或 TAB 休止符，音符／品位只读原有内容。
5. 一句结果：“保留 1 个音，新增 2 个空位”。多拍注明逐拍套用；没有问题时不展示校验成功横条。
6. 取消、应用节奏型。

移除 v1 的双谱、谱层选择、当前拍／整小节范围按钮、搜索框、细分格与重复说明。用户在谱面选择目标，面板跟随当前活动层和目标拍；不用在面板再次配置。

窄屏审稿使用两列模板；前后对照可保持并排或改紧凑上下布局，按可读空间调整。正文独立滚动，不能把应用按钮挤出浮层。三十二分用三层连梁／减时线，预览时值标为 `1/32`，不混同十六分。

## 3. 自动范围

点中一个音符或短选区：取焦点所在完整演奏拍。连续选区达到一拍：取首尾涉及的全部完整拍，向外归齐拍边界。只读范围与谱面高亮必须同步，范围以拍为单位，不以程序 Beat 数量或弦数计算。

整小节由谱面整小节选区自然形成，多拍逐拍独立应用。跨小节暂不应用，提示改选同小节；无活动简谱／TAB 目标时可浏览模板，提示先选择位置，不能使用旧残留目标。

外部选区、当前谱层、文档或拍号在预览后变化，原预览过期并禁用应用，显示“选区已变化，请重新预览”。重新预览读取最新目标；拍号变化导致模板不兼容时要求重新选择，不拉伸旧模板。

## 4. 三条主要路径

### 4.1 音符不足，补空位

点中四分音符 `1` → 打开节奏型 → 默认预览“前八后十六” → 当前为一个音，结果为 `1（八分）＋空（十六分）＋空（十六分）` → 应用 → 原音保留一次，新建两个待填位置。

两个八分音符 `1、3` 同样得到 `1、3、空`。不复制原音来填空，不给新增位置加 Tie，不把空位变成休止。空白／混合空位使用同一规则，不单独增加操作模式。

### 4.2 多拍重复

同小节选择两拍 → 显示“第 1～2 拍” → 每拍各套一份模板，分别保留各拍自己的内容，不跨拍合并计数。预览按拍分段，指出每拍的保留与新增结果；一拍超额则整次禁用，并明确问题所在拍。

### 4.3 有标记时确认

选中含技巧／延音连接的拍 → 正常预览结果，同时出现“将移除 2 项标记：击弦、延音线” → 点击应用 → 同一个浮层显示紧凑确认区，保留效果预览：

> 将移除 2 项标记：击弦、延音线。保留原音符，按节奏型调整。

按钮变为“返回预览”“确认调整”。不弹浏览器确认框，不打开第二个大弹窗。返回只退出确认；取消、Esc、关闭退出整次操作；均不改谱。确认才提交，取消后不能留下半次标记清除。

模板变化或重新预览必须清除已确认状态。失败可在同一目标版本重试；目标过期后先重新核对，再确认。歌词与和弦作为内容保留，不出现在默认“移除技巧／标记”的清单内。

## 5. 边界和反馈

- **数量不足**：正常可用，以空位补齐。结果逐拍说明新增数，无警告。
- **明确休止**：保留其类型和顺序，新增位置仍为空位；休止与空位视觉明确区分。
- **每拍内容超额**：阻止，例“第 1 拍有 4 个内容，模板仅有 3 个位置”，不让其他拍借位。
- **跨范围内容／不完整连音组**：提示扩大范围，不能截断范围外音符、休止或带内容空位；连音组完整进入范围才可确认移除。Tie 相连的多个原拍点各自保留，只清除连接，不合并成一个音。
- **歌词／和弦**：跟随原内容保留；无法一一映射时指出具体内容并阻止，不能按演奏标记一并删除。
- **跨小节／无当前拍／不支持拍号**：显示实际原因，应用禁用，允许继续浏览。
- **成功**：关闭浮层，回焦入口，保留应用范围高亮；状态提示模板、谱层、范围及撤销。
- **失败**：保留模板和预览，用一条就近错误提示，可重试。
- **无变化**：提示“当前已是此节奏型”，不增加历史；若需要移除标记，仍属于变化且必须确认。

## 6. 焦点与原型边界

模板用原生按钮，选中态包含勾选和 `aria-pressed`，键盘能操作；打开后聚焦选中卡片，确认时聚焦确认区首个操作。关闭、成功、取消后回焦入口。错误有文字和 `role=alert`，成功为 `role=status`。提交期间锁定重复操作与谱面数字／删除快捷键。

框外“样例／拍号／目标范围／活动谱层”只用于载入评审场景；会重置页面内样例，不能被理解成产品内拍号或谱层编辑。真实外部变化由“预览过期”场景演示。

原型内存数据只演示顺序映射、空位、逐拍应用、标记确认及撤销，不证明生产命令、真实锚点、复杂连音、保存、补音或导出已实现。未来产品按 PRD A01～A16 验收，本轮记录仅覆盖独立原型可观察行为。
