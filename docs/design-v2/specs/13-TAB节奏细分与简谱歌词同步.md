# 13 · TAB 节奏细分与简谱、歌词同步

日期：2026-11-09。状态：交互原型先行完成，产品已接入；[实施与验证见方案 §11](../../mvp/v8/20261109_TAB节奏细分与简谱歌词占位同步修复方案.md#11-实施记录与验证)。依据：[确认方案 §3、§4.5、§10](../../mvp/v8/20261109_TAB节奏细分与简谱歌词占位同步修复方案.md)。[打开独立交互原型](../prototypes/rhythm-sync/index.html)。本说明补充专项操作，不替代既有编辑台与草稿约定。

## 入口与历史

- **按所选 TAB 节奏细分简谱**：选择已改好的同小节连续 TAB 范围，从节奏操作区进入。不能依赖点击缺失的简谱空框。多根弦上的同一 Beat 只计一个区间。成功新增一条历史；此前独立 TAB 修改保留其原历史。
- **TAB 拆分并同步**：仅对单个有效 Beat 精确等分，统一预览 TAB 和简谱影响。复用 TAB 拆分的音符复制、持续音 tie 和技巧迁移；简谱侧只保留首段音高与内容，不复制 TAB 音高、不新增简谱 tie。两侧全部成功后一次提交、一次撤销。简谱已更细或为真空窗时，仍可提交有效的 TAB 拆分。
- 普通 TAB 时值修改仍保持声部独立。本次不增加“沿用 TAB 节奏”的批量录入入口、选项或占位开关。

## 预览、应用与反馈

入口只生成预览，使用一个“应用细分”动作。展示小节与拍内范围、各项实际节奏、原事件缩短数、新空位数、原音与歌词保留位置和记号影响；界面不要求用户阅读内部身份与版本字段。

- A：第一拍四分 → 原音八分＋八分空位。首音、原内容与两段歌词留在前半拍，新后半拍无音、无词。
- B：第一拍两个八分 → 原首音十六分＋十六分空位＋原第二个八分。第二个八分位置、身份、音高与歌词保持原样。
- 取消保留原谱、原 TAB 选择、历史；预览不能消耗持久化 ID 或写文档。
- 应用成功保留 TAB 范围，返回时间最早的新空位；不自动打开歌词编辑器，也不抢走其他有效草稿输入焦点。没有新空位时保留当前目标。再次事后细分没有新增边界，提示“所选范围已按当前 TAB 节奏细分”，不写入、不增加历史。
- 预览期间更换目标、编辑、撤销/重做、切换文档或会话后，提示“谱面或选择已变化，请重新检查细分结果”，保留可恢复输入与选择信息，禁用旧确认。重新检查必须显式发起，不能自动换目标应用。版本保护同时覆盖文档、状态与会话，不能仅比较 revision。
- 切穿原音提示“所选范围切穿已有简谱，请扩大到完整音符后重试”。组合入口不得自动扩大 TAB Beat，改用事后完整范围细分。
- 无有效/不连续/跨小节目标提示“请选择同一小节内连续的 TAB 拍点”；不可精确时值、连音、需要拆分的休止或延续，以及受影响 tie/slur 提示“此范围暂不支持同步细分”，说明对象。未定义迁移规则的关系直接阻止，不能靠确认弹窗放行。
- 最终校验失败提示“未应用细分，请重新检查目标范围”；TAB、简谱、歌词与历史均不产生部分提交。失败、过期、取消、重复确认均零写入。

## 空位、补音与歌词

已有 notes 或持久化 gap 均需显式细分；首段保留原 eventId、全部 items ID 与全部 verse，新增尾段使用新 gap ID。只填歌词的 gap 不能当作真实空窗。无事件的真实空窗随 TAB 边界自动派生两行入口，仅显示不写文档。

简谱和每个可编辑歌词段均命中新 gap，不回退到前一音或前一字。补音采用保留事件身份的内容更新，继承 gap 自身时值；即使上次偏好是四分，B 的新位置补音仍为十六分。先填词再补音或先补音再填词都锚定同一 eventId。多个已保存位置逐项补音保留各自时值，不能用统一模板重建事件。

编辑态 gap 显示虚线输入提示；它不是 `0` 或 `-`。成品、打印和导出不画虚线，不凭空生成音符或减时线，时间间隔仍参与布局。补齐 B 后应为十六分、十六分、八分：第一层线跨三音，第二层只跨前两音。原型以每个音的下划线提示时值，精确共享减时线几何留待真实布局验收。

连续歌词旧预览依赖整个实际映射范围的轨道、小节、段号、模式和有序 eventId/tick/endTick。即使首身份与文字不变，只要细分改变中间位置，也须废弃旧映射、保留已输入文字并重新规划；单点歌词继续锚定存活事件并重算区间与版本。

## 现有模板

继续使用统一、自定义、前八后十六、前十六后八模板，预览明确实际时值、数量、作用范围与剩余位置。输入超过可写位置整批拒绝，不截断、不重复最后一个时值。五个统一十六分仍保存为五个十六分，不能静默转成混合节奏。原型的模板区独立演示现有节奏结果，不向细分后的已保存位置覆盖写入，也不增加节奏来源。

## 原型核对路径与边界

1. 默认 A 事后入口：预览 → 取消，历史为零；重新预览 → 应用，新增一个八分 gap、历史一条；点击其歌词行先填词应用，再点简谱补音，检查两段词与八分时值保留。
2. 切换 B：预览确认第二个八分不变；应用后点击中间空位，补音仍为十六分。再次事后细分无新增历史。
3. 切换组合入口、A：应用后一次撤销同时恢复 TAB 与简谱；重新应用，再拆首个八分，得到 0/240/480 位置且原后半拍 gap 不动。B 组合入口从两个八分开始，拆首个八分。
4. 对已有歌词 gap 重复上述路径；对真空窗查看无需细分即出现的两行派生提示，以及组合拆分仍可提交 TAB 的路径。
5. 预览内模拟过期后旧确认禁用；取消再预览，模拟最终校验失败后点击应用，两层均不变；边界演示区查看四类阻止原因。取消与失败均保留原选择。
6. 查看现有模板：统一模式输入五个数字，预览五个十六分；混合模式输入四个数字，整批拒绝。

原型为无依赖单文件，可直接本地打开。演示条件切换会重置固定样谱；“模拟变化”仅推进演示版本，“边界反馈”使用固定拒绝条件。原型不实现真实编辑会话、跨小节歌词映射、记号迁移、持久化、打印导出及核心验证；这些都须在产品实施后按方案验收矩阵复核，不能用原型结果替代。

本轮已用 Playwright + Chrome 复核 12 组入口 × A/B × 原内容组合，并检查取消/应用/撤销、过期确认禁用、最终校验失败零提交、B 先填词再补音保留身份与十六分时值、重复事后细分无历史、连续两次组合拆分及 375px 页面无横向溢出。浏览器未捕获 `pageerror`。这是原型验证，不代表产品验收。
