这一稿的四个重点

对象与位置常驻；输入后立刻看节拍映射；低频操作按音乐任务展开；底部写清应用范围。气泡和侧栏编辑同一份内容，复杂属性留在侧栏。

仅面向 1440px 及以上桌面窗口，侧栏默认 400px 并排常驻。收起后释放谱面空间；更大窗口增加谱面留白，不改变编辑台结构。原型中的曲谱、校验与写入结果为固定演示。
