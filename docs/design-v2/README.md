# 六线猫：右侧编辑台设计 v2

第一轮讨论稿。仅设计交付，未修改产品实现。

设计基线已确定为 **1440px 及以上桌面视口**。先打开 [1440px 桌面基准稿](desktop.html)，再用 [并排评审板](review.html) 比较侧栏内容，或在 [可点击交互稿](index.html) 体验完整流程。侧栏固定 400px 并排常驻，支持主动收起；更大窗口增加谱面空间。

交互稿上方的演示条共 10 个场景：简谱、歌词、选区、小节、和弦、歌曲、空态、校验错误、导出检查和和弦切换确认；也可直接点击原型里的页签、第一行第 2–3 小节简谱、歌词、和弦、气泡、折叠组、应用与收起按钮。评审板的原草稿位置改为歌曲设置，保护位置展示和弦确认。

## 本轮推荐

四入口保留为「选区 / 简谱与歌词 / 和弦 / 歌曲」；右栏固定提供当前对象和位置、按任务分组的编辑区、明确影响的应用区。以节拍映射预览建立与谱面的联系。简谱、歌词气泡与侧栏共享当前同目标输入；复杂属性在侧栏完成。

歌词、简谱切换目标、页签、段号、模式或结束编辑直接丢弃未应用输入；回到原位置读取已应用值。重复同目标、仅收起侧栏或隐藏气泡且未结束会话时保留输入。和弦及歌曲设置保留离开确认；简谱正文、时值、单个音高继续独立应用，校验与 IME 保护保留。当前未应用输入阻断导出，已离开位置的旧输入不再阻断。第一版跨目标暂存、待处理列表及文字切换确认已删除。

按截图评审，侧栏固定 400px，标题右侧只保留收起按钮，已移除四角展开按钮及宽度切换。建议先讨论四入口名称与归属、气泡与侧栏的职责，以及是否接受把小节段落标记与范围复制移回「选区」。尚未进入产品实现。

范围已收敛为桌面：不再提供窄屏演示、抽屉、底部编辑区或移动端画面。小于 1440px 时只保留桌面画布并允许横向查看，不另做布局适配。评审板中的单栏画框是部件截取，不是产品小窗口方案。
