01 / 从工具栏添加

先选 TAB 拍点，再点击「技巧」右侧的和弦图标。无有效拍点时禁用；已有和弦进入编辑，不重复创建。

02 / 快捷操作只放高频项

名称、六个常用指法、显示方式。改名称不自动改指法，预设会同时替换二者。

03 / 复杂编辑留在侧栏

六弦、横按、起始品位与删除直接在右侧同目标编辑。侧栏已收起时使用「打开编辑台」；错误仍可「前往修正」。

04 / 同一个应用范围

名称、指法、显示方式一次应用。底部仅保留右对齐的应用按钮；标题 × 退出并丢弃未应用输入，收起侧栏保留会话。

这里的指法图和提交结果为设计演示；实际实现继续使用既有和弦校验与图形布局。
