## 2. 工具交互与边界

工具栏休止与技巧区域统一使用等宽符号按钮，不显示中文按钮标签或分组文字。H/P/S 是技巧本身的记谱符号，保留字母；S 提示“滑音”。SVG 与字母居中对齐，按钮热区及选中态不随文字移除而缩小。每个按钮保留准确的 `aria-label`；鼠标 hover 与键盘 focus 显示同一名称提示，Escape、移开或点击后关闭。触屏不要求悬停才能完成操作，技巧菜单展开后继续显示完整名称；参数面板、历史及侧栏保留文字说明。

休止影响整拍全部弦，不取决于框选了几根弦。设置休止会清空该拍音符；取消后得到空拍，恢复原音符须撤销。混合选区按钮不高亮，提示“包含休止与普通拍，点击统一设为休止”。无目标时禁用，并说明原因。

H/P 快捷没有额外用户参数，限定同弦选择，已有合法起音和同弦下一音时可直接添加；无目标、多弦选区或音高关系不符时不能生成技巧。滑音和琶音快捷打开参数面板，先选择方向，再应用；此方向待选不改变更多技巧原有流程。

下扫和上扫快捷按钮已明确方向，点击后直接应用，不再打开扫弦方向窗口；两者各有名称提示，当前方向独立高亮，重复点同一方向为 no-op。同拍已有扫弦或琶音时，只替换该目标拍的对应技巧，作为一次可撤销编辑；不能误更新其他目标上的已选技巧。从更多技巧选择“扫弦”时，仍使用原有参数窗口，不改其操作方式。

方向按产品现有 TAB 映射：低音弦位于视觉下方，下扫由低音弦侧指向高音弦侧（箭头向上），上扫反向（箭头向下）。本次方案复核已校正原型按钮和谱面示意，名称、提交值及箭头保持一致；不是按英文 down/up 猜屏幕方向。完全相同方向及范围才是 no-op，范围变化仍需更新；正式实施复用 `UpdateTechnique` 保留 ID，并修复 core 字段顺序影响判等的问题，详见技术方案。

扫弦和琶音范围沿用当前同拍多弦选区，不能隐式扩成全弦。原型选区固定为第 1–6 弦，仅模拟方向、历史和休止显示。

简谱焦点激活时，TAB 休止与吉他技巧入口暂停，不操作残留的 TAB 选区。时值、附点仍跟随当前谱层。仅展开菜单、历史、属性抽屉或切换尺寸不提交文档、不清草稿。

草稿以 v2 当前规则为准：上述保留只适用于未结束编辑会话的呈现变化；和弦、歌词、简谱实际离开目标／页签／模式等时直接丢弃未应用输入，settings 保留离开确认。更多技巧保留产品原有默认值与参数流程；原型的方向待选仅为交互演示，不把它推广成旧窗口改造要求。

在休止拍添加扫弦／琶音时，同拍休止符按既有修复规则隐藏；删除技巧后恢复。这条规则与本次 UI 设计兼容，不将视觉隐藏解释为数据丢失。

## 3. 历史与反馈

历史默认收起。展开后最新操作在上，当前节点有文字标记，已撤销记录标明“已撤销”。点击“影响详情”只展开内容，既不改选区也不回退文档。工具栏与历史内的撤销／重做使用同一能力、同一保护。

真正修改文档的提交才记历史；失败、取消、no-op、普通剪贴板复制不记。撤销后新增真实编辑会截断重做分支。历史与现有上限 100 条保持一致；切换文档清空，不保存到谱文件或浏览器存储。当前代码只有文档快照，操作名、目标及影响元数据需要后续补充。

方案复核补充：裁掉最早记录后，起点标为“更早状态”，不能承诺回到最初导入状态；分叉或裁切删除条目时同步清理其详情与反馈链接。撤销后的详情可查，须标明“已撤销”，不恢复历史选区、滚动或草稿。

有附带影响的提交显示 4 秒可关闭提示，提供“查看影响”直达对应历史详情。无附带影响时历史安静更新。复制遗漏使用独立的短时反馈和详情，不伪造历史。移除的是提交后的全局黄条，粘贴预览及必要的提交前影响确认继续保留。

4 秒计时在反馈被聚焦或悬停时暂停，用户已打开的详情不会自动关闭。复制详情不显示“本次编辑／可撤销”；复制失败不得重新弹出旧遗漏提示。这些为正式实施合同，原型仅展示主要交互。

## 4. 视觉基线与适配

视觉取向是“谱面占主位，工具按乐谱操作分组”。继续使用白纸、浅灰蓝工作区及蓝色选中态；不新增大标题、装饰性卡片或持续动画。颜色基线为主色 `#2458E8`、选中底 `#EDF3FF`、正文 `#202B3A`、次文 `#5D6B7E`、边线 `#DCE3ED`、工作区 `#EEF2F7`，纸面为白色。字体沿用中文系统字体栈；产品通用控件继续映射 Ant Design。原型的符号为 SVG 示意，落地时复用项目音乐资源并补充休止／技巧资产，不依赖平台 emoji。

字号与间距沿用现有 px 基线。常规符号按钮热区高度参考 36px，粗指针设备参考 44px；主操作不随窗口按比例缩小。细边框使用 1 CSS px，不能把 CSS px 当设备物理像素。

| 容器可用宽度 | 布局 |
| --- | --- |
| ≥1600px | 历史展开占独立列，右侧编辑台并列，中央谱面弹性填充 |
| 1200–1600px | 右栏保持，历史从工作区左边浮层打开，不挤压中间宽度 |
| 960–1200px | 右栏默认收起，按需抽屉；两侧面板互斥打开 |
| <960px | 工具分两行，时值组内部可滚动，休止固定可达；附点及结构等放“更多”；一次展开一个侧面板 |

历史轨宽 `40px`，主体 `272px`，小窗口受剩余宽度限制。正式实施以宿主可用宽度 W 为同一测量来源，右栏目标为 `clamp(352px, 0.24 * W, 384px)`，不能在嵌入场景直接用 `24vw`。当前产品 400px 右栏缩窄时，全部页签和参数内容须一并验证；窄模式面板不超过工作区。面板从工具栏下展开，列表／表单内部滚动，关闭入口可达。

本轮只处理工具与面板布局，不改根字号和全局主题单位。此前原型的字体放大检查保留为设计探索记录，不列为本轮单位迁移或全局字号专项验收。

谱面提供“适合宽度／100%”：正式实施固定 780px 纸面基线及逻辑单位显示倍率，不随断点改为 800px；默认适合宽度，按完整纸面／超宽 SVG 包围盒最多缩放至 1，100% 在窄画布中独立横向查看。同时维护缩放后占位、浮层重定位与当前可见页位置。界面尺寸、谱面显示缩放、音乐布局、A4 mm 与 PNG 像素各有边界，不通过界面调整改变谱的节奏或导出分辨率。谱面命中与浮层须沿同一变换矩阵，打印隔离须覆盖工作区外的 portal；原型的示意谱不替代这些几何验收。

## 6. 原型核对与限制

已在本机 Chrome 的独立原型中检查 1920、1440、1280、1024、768、375 CSS px，以及 1440×650 低高度：页面无横向溢出；休止和更多入口可达；历史展开、参数选择、撤销／重做与分叉演示通过；控制台无错误。另检查简谱焦点下禁用 TAB 快捷，以及页面 root 字号 200% 时工具收纳。

详见 [原型核对记录](prototype-validation.json) 与 [可复用核对脚本](validate-prototype.cjs)。复跑时从仓库根目录启动静态 HTTP 服务，脚本默认访问 `127.0.0.1:4178`；需已有 Playwright 和 Chrome，`PLAYWRIGHT_MODULE` 可指定本机模块路径，`PROTOTYPE_URL` 可改服务地址。

原型只模拟本轮交互，使用演示谱与演示历史，不接领域命令或持久化。H/P 完整音高校验、音乐时值重排、所有低频菜单、导入导出、草稿协调、模态焦点圈定及读屏全流程留待正式实施。非本轮演示入口会明确显示保留入口说明。原型为了便于看见操作会显示普通成功反馈；产品按第 3 节只对附带影响作额外反馈。

尚未进行浏览器原生 200% 缩放、系统默认字体 200%、真实 IME 和多浏览器的产品验收；页面 root 字号截图不能替代这些检查。谱面为交互示意，不作为音乐排版几何验收依据。

## 7. 本轮技能依据与自检

已使用本机 `frontend-design` 与 `ui-ux-pro-max` 的 SKILL.md。前者用于先确定视觉、布局与 token，再制作和复查原型；本轮按用户参考保留蓝白工具型界面，将视觉注意力留给谱面。后者用于目标平台、渐进收纳、断点与可达性核对，不套用原生 App 的 pt/dp 规则。
