## 建议审查顺序

1. **首页 · REQ-017。** 查看欢迎语、曲谱编辑器和吉他进阶入口；编辑器使用 `/editor`。首页支持窄屏，编辑器沿用 1400px 最小桌面宽度。
2. **连续选区 · REQ-018。** 在数字或歌词上拖选，或 Shift 点击终点；可跨小节、跨行，不能混选。简谱 `1+3` 为一个事件，歌词限定当前段。输入较短内容后应用，剩余位置留空；超范围时禁止应用。试用清空、撤销、Shift 左右扩选和 Esc 折叠，再切换第二段歌词检查独立性。
3. **和弦气泡与侧栏 · REQ-019、020、029、030。** 点击谱面和弦打开气泡，两处共享草稿。检查紧凑指法预览、名称旁应用、更多菜单推荐、更多配置入口、显示方式单选，以及标签末尾直接删除。
4. **和弦库 · REQ-021～023。** 只保留“全部和弦／我的指法”；按调性浏览，卡片含图与名称，列表滚动时右侧详情固定。选用只回填草稿，应用后才写入示例谱面。
5. **自定义指法 · REQ-024～028。** 检查单行工具区、右侧预览、header 最新错误。点击品格放按点，选中按点后输入 `1`～`4`、`T`、`0` 指定或取消手指；同指重复不报冲突。横按与按点共用“按弦手指”，默认未指定。完成只回填草稿，取消不回填。
