# 整小节节奏型与小节编号

飞书「需求」子表第 56、57 行的交互稿，待确认。直接打开 [可点击原型](index.html)。

## REQ-045 整小节节奏型

- 工具栏气泡和选区侧栏使用同一组「拍内」「整小节」切换，两个入口共享当前模板和预览。拍内沿用原流程，整小节以当前焦点小节与活动谱层为目标。
- 每条整小节模板独占一行，左侧名称、右侧等宽逐拍排布。拍内模板在气泡用三列，在侧栏或窄屏用两列。4/4 包含「交替分解」（前八后十六、四个十六、前八后十六、四个十六），3/4 和 6/8 各有适配预设。预览逐拍分隔，并排显示当前与应用后。
- 应用继承逐拍保留音符与休止、不足补空位、超额或跨界保护、受影响标记确认及一次撤销。原型使用固定谱例演示切换、预览、影响确认和撤销。

## REQ-046 小节编号

- 优先在每小节右上方显示 11px 灰色数字。当前小节的编号使用编辑器蓝色。编号在编辑器叠加层绘制，依据现有和弦、技巧和拍号边界选择同小节内的空位，保留现有音乐元素布局。换行后编号连续。
- 编号随曲谱顺序更新。提案仅在编辑界面显示编号，导出的图片和打印谱保持洁净。侧栏沿用现有位置提示。

原型以桌面音乐编辑工作区为基准，复核了窄屏换行、按钮可读性、可见焦点和 Esc 返回工具栏。设计使用 `ui-ux-pro-max` 与 `frontend-design` 的界面复核指导。
