# REQ-081 · 曲谱速度设计稿

这是 `REQ-081` 的可点击交互原型，按仓库约定以 1440px 桌面视口为设计基线。

## 预览

从仓库根目录启动静态服务：

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4178/docs/design-v2/prototypes/req081/`。

## 设计范围

- 「歌曲」侧栏增加「曲谱速度」字段，空值表示未设置。
- 歌曲侧栏沿用「整首歌曲 → 曲谱信息 / 演奏设置」结构，曲谱速度与变调夹各自独立应用。
- 设置后在第一小节上方显示 `♩ = BPM`。
- 试听默认读取曲谱速度，临时调速只影响当前试听会话。
- 「恢复曲谱速度」回到已保存的曲谱速度，未设置时回到 90 BPM。
- 试听气泡突出「播放当前曲谱」和「临时调速试听」，保留曲谱速度、临时调速、滑杆和恢复入口。

原型顶部的状态按钮用于切换评审场景，不代表最终产品需要保留该工具条。
