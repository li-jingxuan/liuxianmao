## 本稿已覆盖

本期新建弹窗 v1.3 已替代旧 v1.1 / v1.2：宽 560px，曲名独占第一行，编谱作者与调性双列第二行，拍号与调弦双列第三行。内容区横向留白 28px、行列间距 20px、标签 13px / 字重 500、输入控件与取消 / 创建按钮 40px、标题 20px、圆角 12px；白色底部操作区轻分隔，焦点使用蓝色边框与 2px 低透明度光圈。采用清爽蓝白表单，仅保留字段与操作，不含正文说明、帮助按钮或结果摘要。

- 首页聚焦新建与原生 JSON 导入，不展示云端曲库或虚构最近文件；保留指向既有“吉他进阶”原型的入口。
- 新建调性按大调 / 小调分组，每组 12 项：大调 C、G、D、A、E、B、F♯、D♭、A♭、E♭、B♭、F；小调 A、E、B、F♯、C♯、G♯、D♯、B♭、F、C、G、D。默认 C 大调，展示升降号，模型保留所选拼写（如 `F#`、`F#m`）。新建固定大调主音记 1、小调主音记 6，音高由调性推导，无独立音高或主音记法输入。
- 新建默认 4/4、标准调弦、4 空小节，空位仅以浅色虚线待填框表示，不自动填入休止符。**没有速度 / BPM 字段**。曲名输入初始为空，以“未命名曲谱”为占位，最多 128 字，提交空曲名使用该默认名；作者可选、单行最多 64 字，留空不显示谱面作者行。中文输入法组合期间按 Enter 不提交；确认设置即构成需要留存的新文档。
- 文件选择与拖拽、预览、错误和重试。新建先填设置、导入先预览，最终替换前再保护当前曲谱。取消新建或文件预览不会改变原文档状态。
- 编辑器“文件”下拉覆盖新建、导入及返回首页；主“导出”下拉直接选择 JSON、PNG 图片、打印。修改音符与新增小节移至顶部评审工具，谱面首音符仍可点击演示修改。撤销 / 重做、历史浮层、四个面板页签、侧栏开关、75–175% 缩放均可操作；音乐输入工具仅作视觉展示，以禁用及 title 区分，不表示已实现完整编辑能力。默认“歌曲”页签含紧凑信息及可编辑曲名草稿，无大块教程。
- JSON 是同步序列化与下载交接的设计演示，不显示图片式进度。紧凑弹窗包含“导出可编辑曲谱”、文件名、必要用途与“导出 JSON”。PNG 保留 ready → generating → generated / download 两阶段，生成中可取消，取消回 ready，关闭终止生成；生成成功后才显示下载入口，失败可重试。范围 / 页码 / 已应用文档内容变化均使旧结果过期。全部多页下载 ZIP，当前页 / 单页下载 PNG。打印沿用同一三列预览，入口模拟、不真调用。样例 12 小节，演示为 2 页，每行严格六根弦。
- 编谱作者、数字1音高与最终调性摘要保留在文档模型及相应谱头、歌曲信息、PNG / 打印预览和导入候选中；JSON 弹窗精简为文件名与用途。作者文本经过安全转义，示例作者留空，不编造真实署名。
- 新建即“待导出 JSON”。有效导入文件作为可恢复基线，未编辑为“与导入文件一致”，可以直接离开；编辑后重新标记待导出。
- 普通 JSON 导出成功交接后显示“JSON已导出”，tooltip 明确“当前版本已发起 JSON 下载，请确认文件已下载”，支持再次导出。PNG / ZIP / 打印不改变 JSON 基线。
- 未导出保护宽约 480px，标题“离开前导出曲谱？”，包含曲名及当前动作，操作为继续编辑 / 不导出并继续 / 导出 JSON，默认安全焦点在“继续编辑”。下载交接后可在状态旁“重新下载”，用户明确点击“已下载，继续”才执行原意图；取消或失败不离开、不清除待导出状态和原意图。关闭保护也留在当前谱，无大图标、绿色确认卡或技术说明。“吉他进阶”同页导航同样经过草稿 / JSON 两层保护；修饰键打开新标签保持普通链接行为。
- 活动草稿独立于文档是否已导出；导出及应用内离开前显式处理，可返回歌曲面板应用或放弃草稿。处理后**停在编辑器，重新点击原操作**，不自动执行延迟跳转或导出。已提交文档干净但有活动草稿时仍会提示。刷新 / 关闭标签页对待导出内容与活动草稿使用浏览器原生离开提醒。
- 原生 `<dialog>`、可见键盘焦点、焦点圈定、Esc 关闭、关闭后焦点恢复，字段均有 label；格式页签支持方向键 / Home / End，文件菜单支持方向键导航。

## 已同步的源码边界

产品协议 `lxm-tab-score` 当前 v8，接受 `.json` / `.lxm.json`，兼容 v4–v7 升级，最大 10 MiB，单轨至少 1 小节。默认导出名为 `曲名.lxm.json`，清理非法字符并截取 80 字。PNG 复用既有 A4、300 DPI、2480 × 3508、白底、多页 ZIP 流程；ZIP 内页名为 `曲名_001.png`，现有预算为 100 页 / 200 MiB。本稿展示这些口径，**不重写产品协议解析、迁移、渲染或预算判断**。

已核对的原生字段含义：`score.arranger` 是可选的单行编谱作者（最多 64 字）；`score.keySignature` 是数字1音高；`score.meta['lxm:tonality']` v1 表示 `{tonic, mode, minorTonicDegree: 1 | 6}`。本期新建固定大调记 1、小调记 6：大调音高等于主音音级，小调音高为 `(主音音级 + 3) % 12`，按 C / Db / D / Eb / E / F / Gb / G / Ab / A / Bb / B 归一化。例如 F♯ 大调对应 `numberedKey: "Gb"`，F♯ 小调对应 `numberedKey: "A"`、`minorTonicDegree: 6`。独立模型的 `key` 保留所选调性拼写，`numberedKey` 存规范音高，作者、音高与调性继续传入编辑器和导出预览。导入旧演示文件仍保留小调记 1，不改写为记 6。本原型只演示上述关系，不实现原生字段映射或产品协议。

**现有产品已有导航草稿保护，处理草稿后需重新点击，不自动续跳；尚无本稿提出的 JSON 导出基线保护。** 歌曲 info / capo / signature 的部分现有输出路径会先 `discardSong`，是现状例外；本提案改为显式处理，属于新增的待评审行为变更，不能视为已有能力。JSON 原流程为同步 serialize + 发起下载；PNG 既有 ready / generating / generated、下载、取消返回 ready 和关闭终止流程在本稿保留。本稿不拦截浏览器 Ctrl/Cmd + P。产品保持最小 1400px 桌面，本审稿页另外提供窄屏重排，不能视为移动端产品需求。

## 演示限制与检查方法

所有状态仅存在页面内存，刷新即重置，没有云端保存或本地自动保存。**所有下载、图片生成与打印均模拟**，不会生成文件、不会调用打印机，也不会声称文件已写入设备。顶部评审工具分别选择图片生成与任务交接的成功 / 取消 / 失败；modal 内底部独立灰色 `review-strip` 同步这两个选择，以避免原生 modal 使外层顶部工具 inert。此条为评审工具，与产品内容区分开；JSON / guard 仅显示任务交接选择。长错误放在操作附近，不挤顶栏。

文件选择 / 拖拽真实读取所选文件，但仅识别 [sample-score.demo.json](./sample-score.demo.json) 的独立演示结构，带 `REQ-048-DEMO-NOT-FOR-PRODUCT` 标记。**该文件不是产品原生 JSON，不可导入产品**。关闭、切换候选或重新选择后，异步读取的旧结果不会重新弹窗。可直接用“载入有效文件”审查成功路径，使用“载入错误文件”或选择非法 JSON 审查错误路径。没有把产品 v4–v7 判为不支持的设计要求，实际协议兼容性仍由现有产品导入器负责。

演示读取校验作者类型、单行与 64 字限制、12 项规范数字1音高，以及 `key` 与大小调记法的音级一致性，允许调性等音拼写（如 `F#` 与 `Gb`）；小调记法省略时按 6 验证，大调不接受小调记法字段。旧版演示 C 大调样例省略这些可选字段时仍可读取，归一化为作者空字符串、数字1音高 C；这只兼容本目录旧演示样例，不推断真实产品旧文件。可将样例改为 `numberedKey: "A" / key: "F#m" / minorTonicDegree: 6` 验证新建 F♯ 小调，再改为 `numberedKey: "Gb" / key: "F#m" / minorTonicDegree: 1` 验证旧记 1；同音级的大调组合不接受错误的小调音高关系，不一致组合应显示演示结构错误。

推荐依次检查：首页新建 → 编辑 → 导出取消 / 失败 → 返回首页保护 → 发起下载 → 确认后继续；首页导入有效样例 → 不编辑直接返回 → 再导入并修改 → PNG / 打印后依然待导出；“未应用表单”场景中先返回处理，再尝试离开。

谱面为手绘 SVG，分页按每页 8 小节简化，不是正式排版结果。修改音符和新增小节用于验证文件状态，不表示完整编辑能力。标准调弦是本稿唯一选项。设计继承蓝白 AntD 风格：`#1677ff` / `#26364a` / `#63748a` / `#f4f6fa`，系统中文字体，不引入远程资源。
