## 评审方式

先看 REQ-044 默认侧栏，再使用原型顶部的需求入口查看技巧、连音和小节气泡。顶部场景工具用于验证无选区、连续拍点、已有技巧／连音、首尾小节等状态，属于审稿辅助。所有应用只修改本页内存样例，可撤销。

重点确认：时值与附点一行、连音不另设页签、节奏型常驻侧栏；技巧点击即应用及复杂参数流程；六种连音名称与禁用提示；新增／复制／删除当前小节与小节线布局。

建议按以下路径试用：

1. 默认连续拍选区，查看侧栏布局并切换时值、附点；应用一次节奏型，再撤销。
2. 打开所有技巧，查看十六类按钮；切换“已有技巧”场景体验单项删除，切换“同拍多弦”查看扫弦／琶音方向。
3. 打开连音，切换实际拍点数 2～6，核对可用类型；在“已有连音”场景删除并撤销。
4. 打开小节工具，分别查看首小节、末小节、仅剩一小节的禁用差异；新增、复制或删除后核对当前小节和撤销。
5. 切换无选区、跨小节或简谱场景，查看相应提示；用 Esc 关闭气泡并核对焦点返回入口。
