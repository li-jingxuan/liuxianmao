## 画面与审查路径

1. **两处入口**：快捷弹窗和侧栏“我的常用”都有“更多 ⌄”。选 Bm 等非快捷项后，按钮仍叫“更多”，当前名称与指法由上方展示；短屏允许快捷项换行，“更多”保持可达。“我的常用”是用户自己的快捷配置，不伪装成本调推荐，也不会随调性静默改写。
2. **更多下拉**：顶部明确显示当前曲谱的已确认调性与简谱基准，默认只列本调三和弦与七和弦，小调另列和声小调补充。输入搜索时改标“搜索结果 · 全部和弦”，不把搜索出的借用和弦称为调内和弦。原“切换调性”改为“设置调性”，进入歌曲设置，应用后才改变曲谱事实。
3. **和弦库与配置**：默认跟随当前曲谱。选择其他主音、大小调或点“浏览其他调”后，显示“临时浏览 X 调 · 曲谱仍为 Y 调”，可一键跟随曲谱；再次打开默认跟随，不记住上次浏览调冒充当前曲谱。“全部和弦”按类型过滤。选 G 可切换开放与 3 品横按；“选用此指法”回填草稿，取消不改父草稿。配置页可添加、移除、排序，最多六项，保存后两处同步。
4. **自定义指法**：点品格设置按弦，点弦顶切换空弦/禁奏。可留空手指，也可选择手指后放按点。“横按”模式依次点同品两个端点，自动同步覆盖区按弦事实；冲突操作拒绝并保留原值。精细表单折叠收纳，作为图形操作的替代路径。
5. **加载与配置故障**：补充状态稿可切换首次加载、失败重试、保留旧版本、引用已移除、非标准调弦；模拟保存失败、跨标签冲突、坏记录隔离、未知配置版本及导入替换/取消。曲谱信息整组冲突需要显式核对，只改标题不能清冲突。此稿只模拟状态，不发送真实 HTTP、不解析文件、不写 storage。
6. **近期行为对齐**：审查控件可切已有/新增和弦、TAB `-` 续音拍、独立简谱或无目标。已有和弦清空名称后提示应用删除，新增空名禁用；工具栏沿用删除图标，未应用父草稿阻止直接删除。父名称 Enter 应用，custom 名称 Enter 只回填，两者不穿透。
7. **工作区与预览**：保持当前最小 1400px 桌面，小窗口横滚；侧栏从页签开始，纯图标收起再开保留父草稿。Modal 按可视高度滚动，底部完成可达。custom 并列谱图缩小示意，可读预览与编辑目标不跟着缩小；图中 ×、TAB x 与 TAB - 语义各自独立。
8. **全局显示偏好**：审查控件可模拟未指定/开启/隐藏指法图。侧栏区分“和弦保存方式”和全局覆盖提示；全局隐藏保留编辑预览，开启但缺图仍仅名称。偏好切换不改草稿快照；背景谱面为静态示意，不据此验证真实布局。

“完成编辑”只回填草稿，“应用和弦”才代表写入谱面。单改名称保留指法；选预置替换名称与指法并保留显示方式。筛选大小调不改变歌曲调号。

## 曲谱调性来源与状态

标记处始终读取**当前曲谱已应用的调性**，不读库筛选、不读用户偏好、不看当前正在编辑的和弦名，也不读尚未应用的歌曲草稿。

现有 `keySignature` 只表达简谱数字 1 的音高。`1=C` 可能用于 C 大调，也可能用于主音记 6 的 A 小调，因此不能默认成 C 大调。建议通过 `score.meta` 的版本化可选扩展保存主音、大小调和小调主音记法，保留谱 schema v8。歌曲设置会在一次应用中同步调性及对应简谱基准，取消不变，撤销一起恢复；已有音符与和弦不自动转调。

- 已确认：显示“曲谱 G 大调”“本调推荐 · 1=G”，推荐随已应用的曲谱更新。
- A 小调主音记 6：显示“曲谱 A 小调”“本调推荐 · 1=C · 6=A”；主音记 1 则显示 `1=A`。两种记法均明确保存，不能相互猜测。
- 旧谱只有 `1=G`：显示“曲谱 1=G · 大小调未确认”，暂停本调推荐；可设置调性、搜索全部和弦或使用我的常用。
- 未设基准与调性：显示“曲谱调性未设置”。不生成默认 C 大调。
- 简谱基准与已存调性不一致：显示“曲谱调性信息冲突”，暂停本调推荐，提供修正入口。
- 扩展数据无效或版本不支持：分别显示“曲谱调性资料无效”“曲谱调性版本暂不支持”，不能当成已确认调性；打开未知版本设置不会预先认可为 v1，正式实现保留原始 namespace。

清除调性先进入设置草稿，应用才生效，取消保留原值。主音和推荐保留调性拼写，简谱数字 1 映射到现有 12 值；例如 Db 小调主音记 6 保存 `1=E · 6=Db`，不向既有枚举写入 Fb。

原型顶栏“审查样谱”可切换上述示例。它用于模拟读取不同谱文档，属于评审控件，产品不会增加此下拉。实际产品接入、文件载入、撤销/重做、未知元数据保留及目标失效校验按技术方案实施。

## 预置与配置建议

完整产品目标为 **12 根音音级 × 16 常用性质 = 192 个和弦身份**，每项至少一套经过结构、音程、最低音与演奏性审核的指法；热门和弦提供 2–3 套。16 类为大三、小三、属七、大七、小七、减三、减七、半减七、增三、sus2、sus4、add9、6、m6、9、m9。异名同音归一计数，显示保留调性正确拼写。大小调推荐另外列出自然调内和弦；小调补充和声小调常用属和弦。

常用栏配置和“我的指法”建议保存于当前浏览器，支持独立 JSON 导入导出；和弦库更新不追改已保存谱面。标准调弦系统指法与非标准调弦自定义图分开校验。具体契约见技术方案。

系统预置库按最新讨论改为**项目内 JSON + 同源 HTTP 加载**：文件纳入仓库，放 `apps/website/public/assets/chords/`，由现有网站静态服务提供；本轮不接第三方存储。加载中/失败时只影响依赖系统库的选用，提供重试，已保存指法、自定义编辑及独立收藏仍可使用。原型仍用页面内示例，真实 HTTP 接入与版本校验列入实施方案。

## 原型限制

- 页面只包含部分示例指法；缺图的下拉候选明确禁用，完整库可查看详情但不能选用。192 项及热门多指法属于后续数据交付，不能把名称数量当作指法覆盖数量。
- 配置、收藏与“应用”只影响当前原型页面；刷新会重置，没有真实谱文件写入或持久化。“我的指法”同名版本已按页面内 id 分别选用；正式产品按稳定 UUID 管理。收藏显式保存独立生效，之后取消自定义也不撤回收藏。
- 原型未接入真实会话、目标版本、调弦或输出闸门；IME 与 cooling 只有简化页面守卫，未做真实输入法验收；Modal 焦点圈定为原型实现。正式实现需补齐现有 guard 的 cooling/内层 popup 优先缺口，复用协调器与 Modal 宿主。
- 图形编辑提供按点、横按、名称及窗口的局部撤销/重做、精细表单和最后有效图预览；名称单行且最多 32 字符，同品横按重叠被拒绝。它仍是简化校验，完整统一核心规则、键盘网格方向导航、输入事务 IME、精确错误定位、横按修改与全部边界需按方案实现，不将绿色示例提示视为正式校验已交付。
- 原型的谱面是背景示意，不用于评审谱面渲染；歌曲调性用单独评审弹层简化呈现，正式产品接入现有歌曲信息组与专用暂停/恢复流程。故障稿已经模拟导入导出入口、调弦不匹配、未知配置及调性版本，导出仅是标明用途的 txt 审查示例；真实 JSON 导入导出、文件选择和持久化未实现。
