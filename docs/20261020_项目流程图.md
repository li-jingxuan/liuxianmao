## 关键边界

- `EditorStore` 保存文档快照历史；选区、滚动位置、输入草稿等属于临时 UI 状态，不进入历史快照。
- 所有领域编辑通过 `applyScoreCommand` 产生新文档，成功后才推进历史；失败只更新错误提示。
- 文档替换统一经过 `loadDocument` 校验，成功后通过新的会话版本清理旧输入和异步任务。
- 布局层消费不可变文档快照，负责把节奏、技巧和数字谱结构转换成可渲染的曲谱视图。
