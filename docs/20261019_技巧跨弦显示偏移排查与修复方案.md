# 技巧跨弦显示偏移排查与修复方案

日期：2026-10-19。下述局部修复已实施，推弦保留原布局。

**最终修复说明：** 本文记录最初的局部修复，仅覆盖简化谱例。完整紧凑谱面、多弦和多技巧的原因与最终实现见[密集谱面击弦标签与弧线定位方案](./20261019_密集谱面击弦标签与弧线定位方案.md)，现已实现并通过完整回归；下文保留历史分析，不代表最终避让策略。

## 复现与原因

4/4 小节的第 2 拍拆成两个八分音符，第一弦 0→1 品、第四弦 1→2 品。命令传入第四弦两颗音符的 ID，保存结果也正确指向第四弦；但紧凑布局将击弦的 `lane` 设为 4，整体向上移动 48 个逻辑单位，弧线出现在第一弦上方。

问题位于 `packages/lxm-editor/src/layout/technique-layout.ts` 的 `assignLanes`，不在音符选区或命令绑定。算法将弧线和 H 标签合并成一个矩形，再额外扩大碰撞范围。该矩形包含实际没有图元的空白，碰到第一弦数字后将整个技巧不断上移。

单变量探针结果：合并矩形报告碰撞；分开检查弧线、含白色描边的 H 标签时，两者均不与第一弦数字相交；再次增加 2 个单位额外留白时又报告碰撞。品位与标签的边界本身已经包含白色描边。

## 局部修复方案

本次改动限于延音线、击弦和勾弦对品位文字的避让判断，属于局部修复：

1. 保留合并矩形作为快速初筛，以及技巧之间原有的碰撞规则。
2. 初筛发现与品位相交后，分别检查实际弧线范围及各标签范围。范围包含线宽与白色描边，不再重复增加品位避让留白。
3. 只在实际图元范围相交时整体上移；保留真实拥挤场景的避让能力。
4. 不改变技巧的音符引用、音符间距、跨行规则、历史或文档格式。

风险集中在避让判断过松导致遮字，因此回归需同时验证用户谱例不再上移、真实文字碰撞仍会避让、编辑与成品布局一致、技巧仍能被命中。其他技巧维持既有避让规则。

## 其他技巧核查

以下为同一双弦短音谱例的单独技巧对照；下降技巧调整第四弦为 2→1，同音延音线调整为 1→1，确保命令合法。单音技巧以第四弦第二颗音符为目标。该结果不代表所有谱例下均无风险。

| 技巧                         | 修复前结果               | 判定                                                       |
| ---------------------------- | ------------------------ | ---------------------------------------------------------- |
| 击弦、勾弦                   | lane 4，整体到第一弦上方 | 同类问题，本次修复                                         |
| 延音线                       | lane 0，留在目标弦附近   | 同样使用弧线分支，本次一并收敛判断                         |
| 上滑音、下滑音               | 固定在目标弦             | 不走该向上避让分支                                         |
| 推弦                         | lane 4，整体到第一弦上方 | 也有显示关联变弱的问题，标签、箭头需单独评估；本次保留现状 |
| 颤音、人工泛音、点弦、颤音奏 | lane 0                   | 本谱例未复现；这些类型仍有向上避让机制                     |
| 自然泛音                     | 原位替代品位数字         | 不走该向上避让分支                                         |
| 扫弦、琶音                   | 固定覆盖所选弦范围       | 不走该向上避让分支                                         |
| 拨片方向                     | 多音 Beat 被领域规则拒绝 | 本实现仅支持恰好一颗音符的 Beat                            |
| P.M.、Let Ring               | 正常显示在 staff 上方    | 整拍区间记号，属于预期位置                                 |

以上成功命令保存的 Note ID / Beat ID 均保持原目标，未发现自动改绑到第一弦的行为。

## 弧线垂直净空

将 `packages/lxm-editor/src/layout/layout-constants.ts` 中的 `LXM_TECHNIQUE_CURVE_FRET_GAP_Y` 从 2 调整为 0。0 表示弧线外缘贴近品位白色描边上缘，仍计入弧线半线宽；并不是让弧线穿过数字墨迹。增大该常量可将弧线抬高。

应用位置是 `technique-layout.ts` 的 `createNaturalSegmentLayout` 中 `curveY` 的计算。常量旁已增加中文调节说明。
