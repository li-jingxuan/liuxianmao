# UI 编辑器外壳重构实施验收

日期：2026-10-15。实施分支：`codex/ui`。验收提交：`0b17ba7`。状态：第一切片通过。

## 1. 验收范围

本次只验收编辑工作区，不包含曲谱管理、新建曲谱、曲谱库保存、IndexedDB、业务路由和离开保护。

验收对象包括：

- 编辑器根布局与 Ant Design 全局主题。
- 顶部编辑工具的通用控件迁移。
- 谱面视口与属性侧栏的布局关系。
- 属性侧栏四栏目：选区、段落、和弦、歌曲。
- 歌词/简谱/和弦/歌曲设置草稿在栏目切换中的保护行为。
- 现有音乐编辑命令、文件导入导出和图片输出回归。

## 2. 已完成内容

### 2.1 编辑器外壳

- 根布局新增 `AppProviders`，通过 `ConfigProvider` 统一中文 locale、品牌色、正文色、边框、圆角和控件高度。
- 顶栏撤销、重做、图片导出和和弦图显示开关使用 Ant Design Button/Switch 与官方 Icons。
- 属性侧栏一级导航从原有三页签改为四栏目：`选区`、`段落`、`和弦`、`歌曲`。
- 新增“当前选区”只读面板，展示当前选区是否已定位和当前焦点信息；该面板不写入音乐历史。
- 编辑工作区增加容器查询断点：较窄宽度下侧栏转为上下分区，谱面和侧栏保持独立滚动。

### 2.2 业务行为保持

- 一级 Tabs 使用受控 `activeKey`；切换先经过现有 `request` 草稿保护，未应用草稿不会被直接丢弃。
- 歌曲设置和选区都映射到 `score` 业务目标，但歌曲表单存在未应用修改时，切换到选区仍会出现处理草稿确认，不会被同一 `kind` 短路绕过。
- 段落栏目继续承载歌词和独立简谱子模式；简谱切换不建立或迁移 TAB 选区。
- 未修改 `@liuxianmao/lxm-editor` 的领域命令、布局算法、简谱模型和导出分页逻辑。

## 4. 实际页面验收

使用本地开发服务 `http://127.0.0.1:3100/` 完成以下烟测：

1. 首页编辑器正常渲染，谱面、顶部工具和属性侧栏同时可见。
2. 默认进入“歌曲”栏目，歌曲设置表单可见。
3. 点击“选区”后显示当前选区空态，不改变谱面内容。
4. 点击“段落”后显示歌词/简谱子页签和添加歌词行、添加简谱行入口。
5. 修改歌曲名称但不应用，点击“选区”会显示“当前草稿尚未应用”确认区。
6. 选择“继续编辑”后仍停留在歌曲表单，草稿没有被清除。
7. 选择“放弃并切换”后进入选区栏目，说明草稿保护和栏目切换顺序生效。
8. 页面截图确认谱面视口与侧栏没有互相覆盖，侧栏长内容可以独立滚动。
