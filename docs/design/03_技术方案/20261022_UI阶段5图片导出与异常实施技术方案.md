## 1. 目标与范围

阶段 5 将现有 A4 图片输出能力迁移为受控 Ant Design Modal，补齐页面缩略图、输出范围、生成进度/取消、成功下载、预览失效与失败恢复，并将“输出前检查全部草稿和 IME”的布尔闸门补成可定位、可返回处理的 S02 输出闸门。

必须保留的既有能力：

- 预览和 PNG 共用 `presentation` 用途的 layout/scene，编辑 SVG 不参与截图。
- Bravura 字体加载、真实文字度量、A4 分页、单页 PNG、多页 STORE ZIP、300 DPI `pHYs`。
- 字体变化、文档/会话替换、取消和迟到结果失效逻辑。
- 页码、页缩略图、单页/全部页生成、下载和失败重试。
- 输出不改变曲谱保存状态，不写入撤销历史。

不在本阶段：PDF/打印排版、曲谱库保存、领域 layout/分页算法重写、原生 JSON 文件导入/导出改造、阶段 6 的 Edge/Firefox/Safari 矩阵和真实系统 IME 人工签字。阶段 6 的 S6-D 仍负责 100 小节长谱、多页输出的最终环境验收。

## 4. 阶段契约

### 4.1 输出快照与会话有效性

打开图片预览时捕获：

```ts
interface ImageExportSnapshot {
  version: EditorSessionVersion;
  document: ILXMDocument;
  density: ILXMLayoutDensity;
  showChordDiagrams: boolean;
}
```

- 只有 `isOutputBlocked()` 为 false 才创建快照并打开 Modal。快照创建后，预览的 layout、分页、字体度量和 PNG 都消费同一份快照，不读取后续背景编辑状态或视图偏好。
- `version` 必须用 `captureEditorVersion(session.getState())` 捕获，包含 `document`、`stateVersion`、`sessionId`、`sessionVersion`，不能用 `documentRevision` 或 `document` 引用代替完整版本。
- 打开期间订阅 session：`document`、`stateVersion`、`sessionId`、`sessionVersion` 任一变化，立即取消准备/生成、撤销 Blob URL、关闭 Modal。普通命令、撤销/重做和外部替换都按此处理。
- 异步 prepare/generate 的每个 late callback 必须先比较任务 token 和 `sameEditorVersion(captureEditorVersion(getState()), snapshot.version)`；不匹配直接丢弃，不 setState、不发布 URL、不写错误到新会话。
- 会话已被替换时只关闭，不把“预览已失效”写进新会话的状态栏。
- 字体变化是快照内容之外的失效条件：首次 prepare 成功后再监听 `document.fonts` 的 `loadingdone/loadingerror`；触发后取消任务、清除 prepared/download，进入 `stale`，等待用户点“重新准备预览”。首次 prepare 期间仍以 `document.fonts.ready`/超时为准，不用字体事件打断正常加载。

### 4.2 输出闸门、草稿和 IME（S02）

图片导出前必须复用 `isOutputBlocked()`，不另写草稿判断。该布尔值当前覆盖：活动 Modal、草稿协调器 `inspect().pending`、品位草稿、`MusicTextController` 的 IME composing、pending、numbered 输入、当前/暂存简谱、设置草稿和歌词/和弦未应用修改。

| 情况 | 行为 | 不允许 |
| --- | --- | --- |
| 无阻断 | 捕获快照，打开 `ImageExportModal` | 不得在打开后再补做“自动应用草稿” |
| 有已登记草稿 | 打开 `OutputBlockedModal`，按 `label` + `location` 列出待处理项和错误；每项“返回编辑”；“放弃全部草稿”需二次确认 | 自动逐项 apply；把缓存当已应用；静默丢弃 |
| 正在 IME 组合 | 提示先完成组合输入；“放弃全部”被协调器拒绝时原样显示原因 | 在 composition 期间提交、切目标或关闭输入框 |
| 只有非记录阻断（如 pending 导航、输入中但未 dirty） | 显示通用“请先完成当前输入”，提供关闭返回编辑 | 伪造草稿条目或绕过阻断 |
| 已有其他 Modal 打开 | 保持现有提示，不叠加第二个 Modal | 抢占当前 Modal 的焦点或 drafts 锁 |

S02 动作契约：

- “返回编辑”：先关闭 `OutputBlockedModal`，在退出动画结束后调用 `drafts.request({ type: "focus", id })`。返回失败（stale/blocked）时在状态栏说明“请从原编辑入口定位”，不猜测邻近目标。
- “放弃全部草稿”：第一次调用 `drafts.request({ type: "discardAll" })` 获取 `confirmation` token 和 ID 列表；必须在 UI 中明确显示数量和范围，用户再次确认后才以同一 token 调用。token 过期、草稿变化或 busy 时重新 inspect，不能复用旧确认。
- 放弃成功后只关闭提示，**不自动重新打开图片预览**；用户重新点击“导出图片”，重新经过闸门和快照。这样“放弃草稿”和“输出”始终是两个明确动作。
- 本阶段只把 S02 接到图片导出；`ScoreFileControls` 维持现有阻断文案和文件流程，后续可复用同一 presenter，但不得在本阶段顺带改变文件导入/导出语义。

### 4.3 预览 Modal 与页面检查

- 使用 Ant Design 6.4.4 `Modal`，`footer={null}`、`closable={false}`、`mask={{ closable: false }}`；标题区提供“A4 图片预览”、副标题“纵向 · 300 DPI · 白底 PNG”和明确的“关闭预览”按钮。
- 桌面三栏：
  - 左：`页面 · 共 N 页` 缩略图列表；当前 inspected page 有可见选中态和 `aria-current="page"`；点击只切换 inspected page。
  - 中：当前页的 `ScorePresentationPage`，白底、A4 比例、可滚动；不出现编辑空位、hover、焦点、选区、输入框或工具栏。
  - 右：`输出设置`、输出范围、分辨率/格式说明、主/次动作、进度、成功/失败提示和“预览采用当前已提交内容，未应用的草稿不会进入输出”的说明。
- 缩略图与主预览消费同一 `PreparedScoreImages.pages`。缩略图不是第二套 layout；不得根据缩略图尺寸推算音乐坐标。
- 输出范围：
  - 选项为“全部 N 页”和“当前第 M 页”；选择具体页时同步 inspected page，保证预览与输出目标一致。
  - 主按钮按范围显示“生成全部图片”/“生成第 M 页图片”；“仅生成当前页”是当前页范围的快捷入口，最终都调用同一 `generate(range)`。
  - 范围为全部时，单纯切换 inspected page 不清除已生成的全量下载；范围为当前页且 inspected page 变化时，清除已生成 URL 并要求重新生成。
  - 生成中锁定范围选择和生成按钮，避免把进度/结果归到另一范围；关闭仍可用，等同取消。
- `pages.length > MAX_IMAGE_PAGES` 时预览仍可浏览，禁用“全部”生成并说明“超过 100 页，请按页生成/下载”；单页生成仍可用。`exportScoreImages` 的 100 页/200 MiB 上限继续作为最终防线。
- 窄窗口先做基本可用：宽度不足时缩略图转为上方横向条或收起，设置栏移到预览下方；650px 高时三块区域各自滚动。完整的 07 响应式、200% 缩放和多浏览器证据归阶段 6。

### 4.4 输出状态机

| 状态 | 进入条件 | 可见状态 | 允许动作 | 退出 |
| --- | --- | --- | --- | --- |
| `preparing` | Modal 打开或重新准备 | “正在准备字体和分页…”；生成按钮禁用 | 关闭（abort） | `ready` / `failed` / `stale` |
| `ready` | prepare 成功，页数据可用 | 缩略图、当前页、范围、生成按钮可用 | 切页、改范围、生成、关闭 | `generating` / `stale` / `preparing` |
| `generating` | 单页/全部页任务开始 | 进度文本、进度条、“取消生成”；范围锁定 | 取消、关闭 | `ready`（取消）/ `generated`（成功）/ `failed` / `stale` |
| `generated` | 编码成功且 URL 已创建 | 成功摘要、文件名、下载主按钮、重新生成 | 下载、重新生成、切页（见 4.3）、关闭 | `generating` / `ready`（范围变化）/ `stale` |
| `failed` | prepare/生成失败且可分类 | 错误 Alert、对应重试/返回编辑动作 | 重试、返回编辑、关闭 | `preparing` / `generating` / closed |
| `stale` | 字体变化、版本/会话失效 | “预览已失效”及原因；无下载 | 重新准备（仅字体失效且会话仍有效）、关闭 | `preparing` / closed |

- `cancelling` 不作为独立可见状态：取消后立即清空进度和任务，回到 `ready` 或直接关闭。
- 状态与任务 token 绑定。旧任务的 `then/catch/finally` 只能清理自己的 controller，不能覆盖新任务的进度、错误或 URL。
- 进度只在当前任务且 Modal 仍打开时更新；`onProgress` 的第 0 页显示为“正在生成第 1 / N 页”，不出现“第 0 页”。

### 4.5 生成、取消和迟到结果

- 全部页按页串行编码，任何时刻最多持有一个 2480×3508 Canvas；单页同样走 `encodeScorePage`。
- 开始生成前再次检查 `isCurrent()`；不复用已失效的 prepared 快照。
- 取消生成：abort 当前 controller，清空进度，保持 prepared 页数据和当前 inspected page，撤销未完成的临时结果，不创建下载 URL；用户可再次生成。
- 生成中关闭/按 Esc：先取消再关闭；关闭后恢复触发按钮焦点。输出可重新生成，不需要二次确认，也不得让旧任务继续占用 Canvas 或发布 URL。
- 取消或会话替换后，迟到 `progress`、编码结果、ZIP 结果一律丢弃；不得出现迟到下载、迟到错误或旧 Blob URL 泄漏。
- 成功时才 `URL.createObjectURL`；同一时刻只保留一个输出 URL。重新生成、范围变化、失效、关闭、组件卸载都先 `revokeObjectURL`。
- 下载按钮只消费已创建的 URL 和文件名；点击下载不修改 document、dirty、保存基线或撤销历史，也不承诺浏览器一定写入磁盘。
- 多页 ZIP 的条目顺序必须与 `pages` 顺序一致；文件名继续使用 `imageBasename/pageImageName`，不得把长标题或路径字符原样写入文件。

### 4.6 错误分类与恢复

在 `image-export-controller.ts` 增加可判别错误（保留现有中文消息和测试正则）：

```ts
type ImageExportErrorCode =
  | "font-unavailable"
  | "font-timeout"
  | "text-measure"
  | "layout-empty"
  | "layout-geometry"
  | "layout-header-overflow"
  | "layout-system-too-wide"
  | "layout-system-too-tall"
  | "layout-first-page-overflow"
  | "encode-failed"
  | "encode-timeout"
  | "zip-too-many-pages"
  | "zip-too-large"
  | "zip-failed";
```

| 错误 | 触发 | UI 与动作 |
| --- | --- | --- |
| `font-unavailable` / `font-timeout` | 字体未加载或 10s 超时 | 红色 Alert“音乐字体加载失败/字体准备超时”；“重新准备预览”重新走字体加载与度量 |
| `text-measure` | 文字度量非有限/空尺寸 | 红色 Alert；允许重新准备；不生成估算图 |
| `layout-*` | 空谱、非法几何、标题溢出、谱行超宽/超高、首页溢出 | 橙色警告，显示核心诊断消息和具体小节；“返回编辑器调整内容后再试”，不提供无意义重试 |
| `encode-failed` / `encode-timeout` | Canvas toBlob 失败或 15s 超时 | 红色 Alert；保留 prepared 预览；“重试生成”只重跑编码 |
| `zip-too-many-pages` / `zip-too-large` | 全部页超过 100 页或累计超过 200 MiB | 橙色说明；保留预览并引导按页生成/下载；不发布部分 ZIP |
| `zip-failed` | fflate 回调错误 | 红色 Alert；可重试生成；不发布部分 ZIP |
| stale（非 controller 抛出） | 字体变化、版本/会话失效 | `stale` 状态；字体变化可重新准备，版本/会话失效关闭 |
| AbortError | 用户取消/关闭 | 不显示错误；清空进度，回到 ready 或关闭 |

- 错误消息必须来自 controller 的真实失败原因，UI 不根据输入内容自行推断“超宽”等诊断。
- 重新准备必须使用同一打开快照重新测量字体和分页；若当前会话已变化则不再重试，直接关闭。
- 失败时不得保留旧的下载 URL 或“下载”按钮；部分 ZIP chunks、Canvas、listener 和 controller 全部释放。

### 4.7 焦点、键盘和可访问性

- Modal 打开后焦点落在“关闭预览”按钮；缩略图、范围 Select、主/次按钮和下载按钮均按 DOM 顺序可 Tab 到达。
- 复用 `EditorModalHost` 的 Tab 首尾循环规则和 Escape 语义：Tab 从最后控件回到第一个，Shift+Tab 反向；Escape 在非 IME 组合输入时关闭。生成中 Escape 等同取消并关闭，不写文档。
- Modal 通过 portal 覆盖编辑区；背景编辑快捷键、SVG 命中、工具菜单和草稿输入在 Modal 打开期间全部隔离。不得让 Escape 先被背景歌词/简谱输入截获。
- 关闭后焦点回到“导出图片”触发按钮；触发按钮已移除时回退谱面 SVG。焦点恢复在退出动画结束后执行，不能把焦点送回已卸载节点。
- 进度 `role="status"`、错误 `role="alert"`；缩略图按钮有“第 N 页”可访问名称和 `aria-current`；Select 有“输出范围”标签；说明文字与按钮不重复暴露。
- `@media print` 隐藏图片 Modal；打印仍由现有 `ScorePrintLayer` 负责。
- 1024/768/650px 的布局只要求不遮挡关闭、范围、进度、取消和下载；逐尺寸截图与键盘路径在阶段 6 补全。

## 7. 风险与处理

- **原生 dialog 迁移到 AntD Modal 后焦点/快捷键分叉**：复用 `EditorModalHost` 的 Tab 循环、Escape 和焦点恢复规则；IME composition 期间 Escape 不清空草稿、不关闭表单。迁移后用键盘路径逐项验收。
- **100 页缩略图和 SVG 预览性能**：缩略图复用 presentation scene，但必须限制同时渲染量（滚动容器 + `content-visibility` 或窗口化）；生成始终串行单 Canvas，禁止同时持有整谱高分辨率画布。100 小节长谱的最终性能验收归阶段 6 S6-D。
- **迟到结果和 Blob URL 泄漏**：所有异步结果绑定任务 token + 完整会话版本；关闭、取消、重试、范围变化、组件卸载统一调用 abort/revoke；每次生成只保留一个 URL。
- **S02 变成自动应用/自动输出**：协调器只提供 focus/discard，不提供批量 apply；放弃全部后必须让用户重新发起导出；确认 token 过期必须重新 inspect。
- **错误分类与设计稿不一致**：UI 只映射 controller 错误码；超宽/超高显示核心诊断和小节，字体失败显示重新准备；不要用固定文案掩盖真实原因。
- **快照与当前文档混淆**：Modal 打开后禁止重新读取 `document`/`density` 重排；版本变化直接失效，不做“边预览边更新”的半实时状态。
- **范围切换导致旧下载误用**：范围或当前页目标变化时撤销 URL 并要求重新生成；下载按钮必须与文件名/范围一致。
- **阶段边界蔓延**：本阶段不改 core layout/分页、PDF、保存/曲谱库、文件导入升级、真实 IME 和多浏览器矩阵；发现领域缺陷先给复现和 core 测试，单独立项。

### 7.1 方案审查补充（2026-10-22）

审查代码后补充以下实施决定，均不扩大第 1 节范围：

1. **错误码落地方式**：在 `image-export-controller.ts` 新增 `ImageExportError extends Error`（`code` 为 4.6 的联合类型）和 `toImageExportError(error)` 归一化函数。现有中文消息逐字保留，避免破坏已有测试正则；只有准备/编码/ZIP 的真实抛出点改成带码错误，未知异常统一回落 `encode-failed` 的通用消息，不猜测原因。`页码不存在`归入 `layout-geometry`。
2. **草稿 `location`**：`EditorDraftRecord.location?: string` 为可选呈现字段，不参与版本、确认 token 或协调行为。`MusicTextSidebar` 按 `draft.target`/`numberedTarget` 的 measure/beat 生成“第 N 小节 · 第 M 拍”；暂存简谱写“暂存目标 · 第 N 小节”；品位草稿写“第 N 小节 · 第 M 拍 · 第 X 弦”；歌曲设置写“歌曲设置”。无法解析位置时留空，由 UI 只显示 label，不伪造坐标。
3. **键盘守卫提取**：把 `EditorModalHost` 的 Tab 首尾循环与 Escape 分支提取为 `EditorModalGuard`，两个 Modal 共用。图片 Modal 以 `keyboard={false}`、`mask={{ closable: false }}` 接管关闭；生成中 Escape/关闭先 abort 再退出。背景编辑器已通过 `closest('dialog,[role=dialog]')` 跳过快捷键，不新增第二套全局监听。
4. **输出快照 owner**：`EditorShell` 持有 `ImageExportSnapshot | null`，替换现有布尔值；打开时用 `captureEditorVersion(session.getState())` 捕获，订阅 session 时用 `sameEditorVersion` 比较，任一文档版本变化立即置空（取消/关闭/撤销 Blob URL 由 Modal 卸载清理）。`density`/`showChordDiagrams` 只在打开瞬间读取，此后 Modal 不读 React 视图状态。
5. **Modal 打开与焦点**：Modal 以 `afterOpenChange(true)` 把焦点放到“关闭预览”，卸载时若原触发按钮仍连接则恢复焦点，否则回退谱面 SVG。范围 Select 与缩略图按钮保持 DOM 顺序；缩略图使用 `aria-current="page"`。
6. **生成进度语义**：单页路径显式回调 `onProgress(1)`；UI 显示 `Math.max(1, progress)`，不出现“第 0 页”。取消只在任务 token 仍匹配时把状态改回 `ready`，避免旧任务的 finally 覆盖新任务。
7. **范围与下载一致性**：默认 `all`；切到具体页时同步 inspected page。范围为 `all` 时切缩略图保留全量下载；范围为具体页且 inspected page 改变时清空下载并回到 `ready`。超过 `MAX_IMAGE_PAGES` 时 UI 禁用“全部”选项，但仍保留 controller 的 `zip-too-many-pages` 防线。
8. **测试挂载策略**：纯逻辑（错误码、快照版本、草稿 location）进 Vitest；S02 与图片 Modal 的交互用 Chrome 脚本走真实按钮/DOM，不直接访问 store。浏览器 fixture 继续使用 `apps/website/...` 之外的 `artifacts/ui-phase5-20261022/`，不复用阶段 3 截图作为本阶段证据。

### 7.2 实施回填（2026-10-22）

S5-A～E 已按本文落地，Chrome 逐画面验收通过，验收记录见[阶段 5 实施验收](../04_实施验收/20261022_UI阶段5图片导出与异常实施验收.md)。实施中补充三条决定：

1. **S02 确认态只由关闭路径清理**：`OutputBlockedModal` 的 `afterOpenChange(true)` 只负责聚焦首个“返回编辑”，不再重置 confirmation/message。否则用户在入场动画结束前点击“放弃全部草稿”，确认 token 会被动画回调清空，二次确认按钮消失。
2. **超宽 fixture 使用合法 48/4 单小节**：长标题只会按 A4 宽度折行，不能可靠触发页高溢出；改为 48 拍单小节（拍号 48/4）后，layout 返回 `system-too-wide`，UI 显示“谱行超过 A4 宽度（第 N 小节）”。该场景与 06-04 的“超出 A4 宽度”一致，同时保留 `header-overflow`/`system-too-tall` 的 controller 映射。
3. **布局失败标题缩短**：310px 设置栏中“超出 A4 页面范围，无法生成”会发生难看的拆行，Alert 标题固定为“超出 A4 页面范围”；完整诊断、小节和“请调整内容后重试”仍由 controller 消息显示，不改变错误分类。

验收截图、报告和复跑命令见[阶段 5 实施验收](../04_实施验收/20261022_UI阶段5图片导出与异常实施验收.md)。
