当前可复用的深 Module 与 Interface：

- `MusicTextSidebar` 是唯一的文字编辑 owner，负责目标切换、草稿保护、协调器登记和最终提交；新视图只能通过受控 props 与具名事件接入。
- `NumberedEditor` 暴露 `snapshot / applyGroup / discard / focus`，继续作为简谱草稿和命令规划的唯一 Interface；不得在视图层再建一套 FormStore。
- `ChordEditor` 接收受控 `ChordDraft`，预览继续消费真实 `layoutChordDiagram`，不能用静态图替代。
- `editor-draft-coordinator` 只协调 owner，不保存音乐内容，也不批量自动应用草稿。

## 3. S3-A：状态和提交契约

### 3.1 目标与 key

- 歌词目标：`trackId/measureId/beatId/verse`。
- 和弦目标：`trackId/measureId/beatId`。
- 简谱目标：事件使用 `eventId/itemId`，空位使用 `tick/endTick`；`numberedDraftKey` 不回退到 TAB `beatId`。
- 每组 draft 都绑定 `sessionId/sessionVersion/documentRevision/targetKey`。同一目标的普通重渲染不刷新基线；文档对象或目标身份变化才使请求失效。

### 3.2 分组基线

- 歌词：`text + lyricMode + allowOverwrite`。
- 简谱：`content / rhythm / itemPitch` 三组分别比较 dirty；应用某组只更新该组基线。
- 和弦：名称、显示模式、指法图、横按数组作为一个 chord draft；预设只写入 draft，应用时生成一次 `SetChordSymbol`。
- no-op 不产生历史；非法值不清空 draft；取消只恢复当前目标的初始快照。

### 3.3 最终状态

所有 owner 的 `apply` 必须返回可区分的 `applied / noop / blocked / pending / stale`。保护导航只在 `applied` 后执行；`pending`、取消、失败、过期都保留输入并释放执行锁。协调器调用必须复用同一 owner Interface，不能把 Promise 当 boolean。

## 4. S3-B：歌词与内容行

- 新增 `LyricFormView` 纯呈现 Module：不读取 store、不执行命令、不拥有 draft；父级传入目标、模式、预览行、校验、焦点 ref 和具名事件。
- 单拍歌词保留 Enter“应用并下一拍”、Shift+Enter“仅应用”；连续歌词以真实 `planLyricSequence` 行为展示跨小节、休止、跳过、覆盖和谱尾错误。
- `addParagraph` 只打开真实目标，首次应用才写入；优先目标轨道，系统布局未就绪时保留目标小节，四段已满时给出可行动提示。
- 无目标时不制造假 Beat、休止或持久化“显示行”；简谱入口继续使用真实独立时间窗。

## 5. S3-C：独立简谱

- 保持 `NumberedEditor` 的稳定 owner 和 `snapshot`；模式、范围、模板、比例、自定义时值、itemDraft 全部进入 A/B 暂存。
- `numbered-preview` 只解释核心候选，不重新计算时值；范围预览按 tick 对齐，分别显示新增、修改、同值、删除、释放和覆盖。
- 内容、时值、item 音高只能单组应用；有记号影响时必须进入同一确认终态，确认成功后一次命令、一次历史和一次焦点迁移。
- 应用内容后不清除未提交的时值或 item 草稿；只在对应 group 成功后更新对应基线。

## 6. S3-D：和弦

- 基础区：名称、预设、显示模式；指法区：六弦编辑和真实 SVG 预览；高级区：起始品位和横按。
- 预设使用深拷贝；`InputNumber` 清空保留 `NaN` 非法中间值；非法指法不生成误导性预览，也不能提交。
- 清除指法保留名称，取消不写文档；删除标记使用独立删除命令；非标准调弦禁用预设但允许自定义。
- 折叠只改变呈现，不卸载或重置 draft；宽窄断点不改变 owner、目标和焦点。

## 8. 第一轮实施回填

本轮已落地：

- 新增 `LyricFormView.tsx`，将歌词字段、连续歌词预览、规则说明和内容行按钮抽为纯呈现 Module；目标、草稿、校验和提交仍由 `MusicTextSidebar` 唯一持有。
- `MusicTextSidebar` 为歌词/和弦草稿固定进入目标时的 `EditorSessionVersion`，为简谱暂存目标维护独立版本表；普通重渲染和其他分组成功提交不会刷新这些基线。
- `NumberedEditor` 增加成功应用/取消回调，简谱 owner 只推进实际目标的版本，避免协调器把其他分组草稿误判为当前版本。
- 外部文档替换会清理对应版本表；放弃暂存草稿会同步清理版本，防止旧目标回归后误用旧基线。
