# 编辑区现有表单控件 Ant Design 迁移方案

日期：2026-10-16。分支：`codex/ui`。基于 `27c42a0` 和当前工作区已有改动。用户已明确要求本批直接迁移现有控件、对照设计并清理旧样式；本方案补充主方案的组件适配契约，不另起业务重构。

## 范围与视觉依据

本批迁移歌词、和弦、独立简谱属性表单，以及已有小节/拍点/技巧工具浮层、导入确认和图片预览内的基础控件。歌曲设置已使用 Ant Design，统一沿用主题 token。原生隐藏文件 input 保留浏览器文件选择职责。

对照 `04-01` 歌词单拍、`04-02` 连续填词、`04-06` 和弦预设与六弦指法、`04-07` 横按、`04-10` 独立简谱稿；沿用既有区域、分组、提示和作用范围，不删减现有音乐能力。侧栏宽度为用户最新指定的 440px，歌词头部两列，和弦指法预览在六弦表格上方。

## 组件与状态契约

| 原控件 | 目标组件 | 适配要求 |
| --- | --- | --- |
| 文本/多行输入 | Input / Input.TextArea | 受控草稿保持在原 owner；回调取实际 DOM input/textarea，保留焦点恢复、Enter、IME 和草稿登记 |
| 单选下拉 | Select + options | onChange 直接取值；保留禁用候选、只读拍号、空值和原类型；不通过伪事件兼容；覆盖时长候选去除相同 value |
| 数字输入 | InputNumber | 清空映射为非法草稿 NaN，显示为空并交原整数校验；changeOnBlur=false，避免失焦自动钳制成合法数据；禁止无效技巧提交 |
| 覆盖确认 | Checkbox | 复用原 checked/确认逻辑，不扩大覆盖权限 |
| 普通/主要/危险动作 | Button | type、danger 使用组件契约；取消/应用/删除仍调用原入口，和弦主操作由主题提供白字蓝底 |
| 段落子栏目 | Segmented | 受控切换继续经 request 闸门；方向键/Home/End 与焦点恢复保留；导航不激活音乐文本输入 |
| 字段标签 | Form.Item | 只做布局，不加 name/initialValues 或第二份 FormStore；显式 htmlFor/id；表单间距与标签色使用全局 Form token |

Select 的方向键、Enter、Esc 不上交侧栏退出逻辑。根编辑器识别 combobox/listbox/下拉浮层，避免触发谱面历史快捷键。所有业务命令、撤销事务、简谱独立时间窗和 A→B 缓存沿用现有实现。

## 清理与验证

删除已无调用方的原生按钮、输入框、select、textarea、checkbox 皮肤，以及 primary/chordPrimary/danger/link/icon 补丁。保留布局、滚动、分区、谱面、提示和响应式样式；文件导入和图片预览删除对 Ant Design 按钮的后代覆盖。不得借本批修改核心音乐布局。

验证包括 TypeScript、ESLint、Ant Design 用法检查、全量 Vitest、生产构建；浏览器检查真实 Select、非法数值、主按钮颜色、草稿保护、歌词快捷键、简谱缓存和窄窗口。真实操作系统中文 IME 仍需人工复核，不把程序填字视作已完成 IME 验收。

## 设计差异留痕

- `UI-D04` 延续：独立简谱保留音组内容、当前事件时值、单音符音高三个动作，以及自定义时值、技巧与复制粘贴；PNG 的单一“应用简谱”不足以覆盖这些领域动作。
- `UI-D09`：本批单拍歌词继续使用单行 Input，设计稿中较高的文本框不作为多行输入承诺；现有单行校验及 Enter/Shift+Enter 语义优先，连续歌词和简谱使用 TextArea。
- 440px 侧栏为用户本轮明确修订，覆盖旧稿的宽度基线。
