# 设计复审与落地契约

日期：2026-10-13。范围：复审与修订 PNG 设计、定义实施接口和验收条件；本轮没有修改产品代码，也没有实现持久化层。

## 1. 结论

原 45 张稿的主要视觉方向可保留，但“入口覆盖完整”和“业务可以落地”不能只凭页面数量判定。复审发现已有功能入口遗漏、非法示例、保存基线未定义、持久化未选型以及小字对比度不足。

本轮已修订原稿并新增 13 张关键状态，现为 **58 张界面/状态稿，7 个分类**。索引及分类总览同步更新。现有编辑能力可在保持领域模型不变的前提下重组；新建、保存、管理必须新增宿主业务层，不能只给按钮挂空回调。

**可以进入实现方案审查，不能宣称已经验证了运行时完整行为。** PNG 验证覆盖编码、尺寸、布局及代表状态；持久化、键盘、输入法、并发写入和真实缩放仍必须在实现中验证。

## 3. 新增业务层：可落地的首版建议

### 3.1 持久化边界

本轮建议：**同浏览器、同应用来源的本地曲谱库**，使用 IndexedDB 的事务保存完整曲谱与列表元数据，存储访问封装为接口。此为落地建议而非已经实现或用户已审批的技术选型；正式实施前按照 AGENTS.md 审查。

- 本地库不等于永久备份；清理浏览器数据、换浏览器或换设备不会自动出现曲谱。产品说明须准确，不使用“已同步”。
- 页面 reload 后可重新列出、打开已保存曲谱；不能依赖仅在内存中的 Zustand store 或写一条 localStorage 标记。
- 若后续选择已有宿主的远端保存接口，替换 Repository 适配器并更新“本地曲谱库”文案；不要同时混用两份权威存储。
- 一次保存同时提交音乐文档和列表可检索元数据。缩略图缓存可随后生成，缩略图失败不把已经成功保存的音乐判为失败。
- 写入失败、额度不足、存储不可用归入明确错误码；UI 保留当前内容并提供重试，不改用无法重开的假保存。

### 3.2 数据契约

| 数据 | 所有者 | 规则 |
| --- | --- | --- |
| `document: ILXMDocument` | 领域模型/存储快照 | `schema: lxm-tab-score`、当前 schemaVersion 7，至少一小节的单轨六线谱 |
| `libraryId` | 业务库 | 独立 UUID，定位持久化记录；不是 store 的 sessionId |
| `storeVersion` | Repository | 每次写入递增，作为原子条件写入版本；不使用可随撤销重做回退的 documentRevision |
| `score.id` | 乐谱文档 | 新作品/完整副本生成新 score.id；副本内轨道、拍点和技巧引用保持自洽 |
| 歌名/作者/调性/拍号/小节数 | 曲谱文档派生 | 显示信息从已提交文档派生，库索引在保存事务内更新，避免两份标题漂移 |
| 分类 | 业务库 | 首版固定枚举：指弹练习、歌曲编配、节奏练习、未分类；默认未分类 |
| 收藏、createdAt、updatedAt、lastOpenedAt | 业务库 | 收藏不改音乐历史；打开仅更新 lastOpenedAt，不伪造内容修改时间 |
| `savedContentSnapshot` | 保存控制器 | 记录最近一次成功持久化的内容快照；不是“点过保存”的布尔值 |
| `sessionId/sessionVersion` | 编辑会话 | 用于忽略晚到的异步回调，不持久化到音乐文档 |
| 密度、指法图显示、面板页签、选区、剪贴板、历史 | UI/会话 | 不保存进音乐 JSON；视图偏好可另存，不影响曲谱 dirty |

Repository 建议接口：`list(query)`、`get(libraryId)`、`create(document, category)`、`save(libraryId, expectedStoreVersion, snapshot)`、`rename(...)`、`duplicate(libraryId)`、`remove(libraryId, expectedStoreVersion)`、`setFavorite(...)`。读写统一返回结构化成功/错误结果。

同名策略在本轮设计中定为：同一分类内规范化后重名拒绝，不用名称定位记录。副本自动追加“（副本）”“（副本 2）”并在写入时检查；名称规则和名称唯一性属于新增产品规则，核心本身允许空标题。

### 3.3 保存状态与导航

| 状态 | 顶栏/动作 | 允许的后续行为 |
| --- | --- | --- |
| 新曲谱未持久化 | 尚未保存 | 首次保存；内容为空也需要有效业务名称 |
| 内容与保存基线一致 | 已保存 | 无修改时保存无操作；可以直接离开 |
| 内容与保存基线不同 | 有未保存的修改 | 保存或离开保护；撤销回到基线可恢复“已保存” |
| 正在写入 | 正在保存 | 禁止重复提交；模态锁定会话编辑与导航，不堆叠多次离开请求 |
| 保存失败 | 保存失败，可重试 | 保留当前会话和原保存基线；不执行待处理导航 |
| 库版本变化 | 版本冲突 | 保留当前内容；继续编辑或另存为副本，不强制覆盖另一窗口 |

dirty 判断比较规范化的持久化内容（排除 documentRevision、视图和业务时间戳），不以历史深度或 stateVersion 判断。新增保存控制器与领域 history 分离，保存成功不重置撤销历史；重新打开作品才建立新会话和空历史。

保存时捕获 `(sessionId, sessionVersion, libraryId, expectedStoreVersion, contentSnapshot)`；写入完成时只更新相应请求的基线。旧会话的回调不能改变新打开作品的标题、状态或执行跳转。

保护顺序统一：

1. 正在中文输入组合时，不提交、不切目标；保留原生输入焦点。
2. 处理表单未应用草稿：应用并继续 / 放弃草稿并继续 / 继续编辑；应用失败停留原处。
3. 处理文档未保存：保存并继续 / 放弃修改 / 继续编辑；保存失败取消本次导航。
4. 目标作品先完成 loader 校验，再 `replaceDocument` 或装配新 `EditorSession`。替换失败不丢当前会话。

浏览器刷新/关闭采用原生 `beforeunload` 提醒；不承诺能在卸载阶段完成异步保存，也不展示自定义三选项弹窗。应用内返回/新建/打开另一曲谱使用自己的保护流程。

### 3.4 新建与管理

- 新建工厂必须新生成实体 ID，并按选定拍号创建完整合法休止拍，调用 `loadEditorDocument` 校验后装配会话。初始小节数 1–100 是建议的产品限制，不冒充核心硬上限。
- 歌名业务要求非空，核心上限 128 Unicode 字符；作者可空，上限 64；不允许换行/控制字符；调性使用现有常量；拍号只允许 2/4、3/4、4/4、6/8；Capo 0–12 整数。
- 筛选先做名称/作者规范化检索，再叠加分类、调性、收藏/最近条件；空库、无搜索结果、加载失败互不混淆。排序规则与稳定次序必须明确，不能单纯从 PNG 复制“12 首”。
- 管理打开按钮与双击卡片进入同一路径；菜单按钮点击不冒泡触发打开；复制/删除成功刷新列表，失败保留行；删除确认显示对象，删除操作不属于音乐撤销。
- 删除首版按确认后从库移除设计，不承诺回收站。若要可恢复删除，必须另补存储状态、回收站和恢复入口，不能只改成“可撤销”文案。
- 打开旧版本不自动迁移。核心有显式 4/5/6 升级函数，首版 UI 未设计升级流程，应只读报告并保留原数据。

## 4. 已有编辑能力与 UI 映射

| 设计入口 | 现有代码契约 | 提交/状态规则 |
| --- | --- | --- |
| 数字品位 / x / 删除 | `SetNote`、`SetNotesInRect`、`RemoveNotesInRect` | 单格/矩形按稳定 ID；1/2 前缀等待 600ms；非法输入不写入 |
| 时值 / 附点 | `SetBeatRhythm` | 单拍；多拍禁用；0/1/2 附点有完整入口 |
| 休止 / 取消休止 | `SetBeatKindRange` | 清除整拍音符；恢复类型不复原旧音符，旧内容用撤销 |
| 新增/删除小节 | `InsertMeasure`、`RemoveMeasure` | 新增继承相关拍号；最后一个小节不可删 |
| 小节复用 | `CopyMeasure`、`CopyMeasureRange` | 稳定来源/目标 ID；展示跨边界技巧遗漏；含所有弦和文本 |
| 拆分/合并 | `SplitBeat`、`MergeBeats` | 单拍等分；合并限同小节合法休止/Tie持续音；非法组合拒绝 |
| 拍点复用 | `copyBeats`、`planBeatPaste`、`PasteBeats` | 内容和确认 key 与预览同源；目标/文档/剪贴板变化使预览失效 |
| 拍号 / 小节线 | `SetTimeSignature`、`SetBarlineBoundary` | 基础拍号 untilNextChange；局部范围说明明确；六类边界完整 |
| 连音 | `resolveTupletSelection`、`SetTuplet`、`RemoveTuplet` | 6 比例，同小节连续同值；删除只对已有组可用 |
| 16 类技巧 | `AddTechnique`、`UpdateTechnique`、`RemoveTechnique` | 类型决定参数；已有音符、同弦关系、弦范围、拍范围各自校验 |
| 歌词/简谱 | 现有单拍/连续命令及 planner | 预览计数来自 planner；无效批次不产生部分写入；简谱唯一行 |
| 和弦 | `SetChordSymbol`、`RemoveChordSymbol` | 清图仅 diagram=null；名称、指法与跨度一起校验 |
| 歌曲/段落字段 | `SetNotationInfo`、`SetCapo`、`SetSectionLabel` | 分组草稿仍保留；段落字段只存储，不恢复已移除的谱面标签 |
| 视图/历史 | density、showChordDiagrams、undo/redo | 视图不进音乐历史；输入框历史与谱面历史按已有规则协调 |
| 导出 | `prepareScoreImages`、`encodeScorePage`、`exportScoreImages` | 输出应用后的不可变快照；使用正式 scene/layout，非截图或重新画音乐 |
| 新建/保存/管理 | 当前尚无完整业务实现 | 必须实现工厂、Repository、保存控制器和路由保护 |

实现时保留 `packages/lxm-editor` 作为模型、验证、排版与命令边界。不得为了画稿将数组下标当稳定身份，不在按钮里重做时值运算或手工移动 SVG 音乐元素。

## 5. 界面与交互细节

- React 使用函数组件/Hooks、TypeScript 与 ES6+；领域规划保持纯函数。关键命令、保存状态与异步请求隔离增加中文注释。
- 建议壳组件按 DocumentHeader、NotationToolbar、ScoreViewport、Inspector、StatusBar、LibraryView 与通用确认/导出弹窗划分；会话仍通过现有 context 注入，不增加多份全局曲谱状态。
- 1440/1280 常规窗口保留右栏；低高度靠内容区滚动与固定动作条；1024 采用上下分区；768 把小节/拍点/连音/技巧收纳到更多工具。以容器可用宽度而非设备型号决定断点。
- 工作区和属性区需要 `min-width:0`、`min-height:0` 和独立 overflow。分区上下布局不能用浮动弹层覆盖目标拍。PNG 中视觉位置不是 CSS 绝对坐标规格。
- 行数长的对应预览保留表头、统计和操作底栏；点击预览行时只切 inspected target，不误写文档；真实 glyph 命中和高亮保持同步。
- 工具 hover 显示名称与作用范围，键盘焦点有清晰轮廓；禁用原因通过可聚焦说明/父容器提示展示，不仅依赖 disabled 按钮事件。
- 危险操作使用文字与颜色共同表达；选中、覆盖、错误和跳过都有文案，不能仅有色块。
- 长歌名在顶栏/列表省略并可查看全名；表单显示完整值。标题换行后按真实字体布局；新建/保存名称校验必须按 Unicode 字符计数，不截断用户输入。
- 对话框使用 modal 焦点约束，Esc 取消，关闭后返回触发入口；busy 写入时不允许 Esc 绕过保护。受保护背景也不能被全局快捷键修改。
- Cmd/Ctrl+S 接入宿主保存路径；继续保留当前 undo/redo/数字快捷键语义；有表单草稿时先走草稿保护，不直接序列化半截输入。
- 调弦设置、缩放、播放、云同步、备份导入导出仍未加入首版实施；已有非标准调弦文档可查看/编辑且预设限制提示清晰，不新增隐含自动转置。

## 6. 实施顺序与验收门槛

1. **冻结技术方案**：本地库或已有宿主适配器、同名策略、删除策略、数据契约、创建限额与路由保护经过审查。此为真正实施前的必要条件，不把设计复审当成编码授权。
2. **业务闭环先行**：合法空谱工厂 → 原子保存 → 列表 → 重新打开 → 保存基线 → 错误/冲突/导航保护；最少用一首同时含 TAB、技巧、歌词、简谱、和弦的文档验证重开保真。
3. **重组编辑壳**：分组工具、属性页签、现有草稿保护及焦点；逐项迁移能力，不同时修改领域模型。
4. **交互完善**：连续预览、和弦高级操作、完整技巧参数、禁用说明、反馈与导出分阶段。
5. **窗口与键盘验收**：1440×900、1280×800、1024×768、768×900、650px 高、200% 缩放、中文输入法及长谱。

必须验证的实际场景：

- 保存 → 重新加载页面 → 从管理打开，音乐数据、文本与技巧一致；存储失败保留内容且不显示已保存。
- 保存后编辑 → 撤销回到保存内容 → dirty 消失；再走新分支不能因 revision 相同被误判已保存。
- 保存进行中不可重复提交；旧会话晚到结果不更新新作品；两个窗口写同一条记录按 storeVersion 检出冲突。
- 未应用草稿与未保存作品连续保护，取消任何一级都停止导航；输入法候选阶段 Enter 不写入曲谱。
- 空谱合法、初始数量与拍号正确；列表搜索/筛选/收藏与最近时间一致；改名/复制不破坏实体引用。
- 最后一小节删除、多拍时值、无音符技巧、非法合并、跨边界粘贴、谱尾连续输入、指法超限、连音非法均明确拒绝。
- 导出编辑与预览一致，单页/多页输出正确；关闭/取消/字体变化不会留下可下载的旧快照。
