# UI 基础协调层实施验收

文档分类：04_实施验收 · [返回 UI 设计与重构总纲](../README.md)

日期：2026-10-16。实施分支：`codex/ui`。状态：基础首批通过，工作区改动尚未提交。

## 1. 对应方案与复审结论

依据 [严格按稿重构技术方案](../03_技术方案/20261015_UI编辑工作区严格按稿重构技术方案.md) 第 18–22 节实施。复审修正了异步动作返回、全量丢弃确认、成功提交的版本判定、runtime 生命周期、歌曲表单分组和弹层焦点契约，修订后通过并开工。

本批交付是实施准备中的基础协调层及真实入口接入；阶段 1 的完整工作台骨架、顶栏组织和 Ant Design 歌曲表单仍待实施。

## 2. 已完成范围

| 内容 | 实现 | 保留约束 |
| --- | --- | --- |
| 会话 runtime | `EditorSessionRuntime` 与 `EditorShell` 共用 session key，内部惰性创建协调器和弹层控制器 | 普通侧栏切换、响应式重排不重建；替换曲谱时整体重建 |
| 草稿协调器 | 注册、汇总、定位、单项应用/丢弃、全量丢弃确认 token、实际数量、异步互斥和过期处理 | 草稿内容仍属于原表单；没有自动应用全部或静默清空入口 |
| 草稿接入 | 品位、歌曲设置、歌词、当前及暂存简谱、和弦、拍点粘贴预览 | 简谱按 event/item/time window 的 key 独立登记；品位沿用 600ms 自动提交路径 |
| 输出检查 | JSON 导入/导出、A4 图片入口共用协调器检查，并保留现有即时检查 | 覆盖输入法、暂存草稿、粘贴预览及 effect 登记前的短暂窗口 |
| 统一弹层宿主 | 首先接入快捷键帮助与公共结构影响确认 | 忙碌时禁用取消和重复确认；待确认时版本变化失效；成功提交不误判过期 |
| 焦点与快捷键 | 关闭动画后恢复触发焦点，触发元素移除时回退谱面；活动 Modal 隔离背景编辑快捷键 | 其他原生 dialog 的历史快捷键也不向背景冒泡执行 |
| 状态带 | 显示位置、选区格数、品位输入、待处理草稿数量及组合输入状态 | 不写入领域历史；原有错误、影响和布局提示继续显示 |

本批没有修改 `@liuxianmao/lxm-editor` 的领域命令、音乐模型、布局与图片编码算法。

## 4. 实际页面烟测

使用隔离的无头 Chrome 访问本地生产预览，已验证：

1. 修改歌曲名称后，状态带显示一处草稿；图片输出被阻断。
2. 打开帮助弹层、发送历史快捷键、关闭弹层，原输入保留，焦点回到帮助按钮。
3. 在 1024/768 宽度下，歌曲表单值和草稿登记保持。
4. 合成 compositionstart/compositionend 事件能进入和释放输入法保护。
5. 切换栏目仍出现原有“应用/放弃/继续编辑”保护；继续编辑保留输入，放弃后解除草稿阻断。
6. 歌曲信息应用、撤销和重做与表单及草稿清理一致。
7. 点击两个真实简谱目标，分别输入 A/B 草稿，再返回 A 能恢复；状态带正确汇总两处，768 宽度仍保留，图片输出被阻断。

烟测没有出现页面运行时异常。
