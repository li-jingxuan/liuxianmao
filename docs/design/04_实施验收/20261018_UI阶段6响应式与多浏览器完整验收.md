## 4. 本轮发现并修复

| 等级 | 问题                                                                                         | 修复                                                                     |
| ---- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| P1   | 图片 Modal 按 Esc 后焦点停在 `body`：StrictMode 模拟卸载提前触发还原并置位，真正关闭时被跳过 | 卸载后延后判定，仅在无新对话框接管时还原；帧级时间线验证焦点回到触发按钮 |
| P2   | ≤900 堆叠布局工作区与设置栏双层滚动，200% 下生成按钮被裁切约 4px                             | 堆叠时设置栏使用自然高度，工作区单一滚动，并断言按钮完整位于滚动视口     |
| 测试 | 200% 用例遗留悬置草稿，被阶段 5 S02 闸门正确阻断                                             | 导出前显式放弃草稿，并新增 200% S02 检查                                 |
| 证据 | 1024 被描述为堆叠，实际为三栏                                                                | 更正检查项与截图命名，仅 ≤900 视口堆叠                                   |
