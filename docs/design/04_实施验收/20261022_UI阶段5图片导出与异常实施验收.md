## 验收中发现并修复的问题

1. **S02 确认按钮被入场动画重置**：`afterOpenChange(true)` 在用户快速点击“放弃全部草稿”后会清空确认态，导致二次确认按钮消失。已改为只在 `close()` 时清理确认/错误状态，入场完成只负责聚焦；Chrome 脚本覆盖了快速点击路径。
2. **超宽 fixture 不触发诊断**：长标题只会折行，不会超过 A4 页高；改为合法拍号 48/4 的 48 拍单小节，稳定触发 `layout-system-too-wide`，与设计“超出 A4 宽度”一致。
3. **失败 Alert 标题换行**：310px 设置栏中“超出 A4 页面范围，无法生成”会把“生成”拆行；标题缩短为“超出 A4 页面范围”，完整原因仍由 description 和 controller 消息提供。
4. **S02 断言范围**：背景编辑面板仍显示未应用文本，验收断言改用 dialog 作用域，避免把“Modal 不展示草稿正文”误测成“整页不存在该文本”。

以上修改均未改变 core layout/分页、PNG/ZIP 算法或文档写入语义。
