最终按组调用为 `applyGroup(group, isCurrent?) -> Promise<NumberedPropertyApplyResult>`；保护导航调用 `apply(isCurrent?)`。终态为 `applied/noop/cancelled/blocked/stale`。导航入口先要求零组或恰好一组待处理；多组不自动连续提交。零组结束编辑不制造音乐命令，单组仅成功/no-op 后执行原待导航一次，因此无需用“内容 apply 成功”推断其他组也已处理。

所有写操作共用提交入口，包括拆合、删除、记号、连音移除和粘贴。当前其他分组与暂存草稿先对核心候选检查依赖；冲突先阻断，提供恢复当前分组或返回暂存草稿入口。暂存草稿采用保守的小节依赖，均匀连续内容追加其实际跨越的小节及相关记号；可能阻断同小节内彼此相邻的编辑，这是有意保护，未复制音乐规划算法。

协调器通过同一 owner 的 `inputKey` 和完整版本识别实际输入，不以普通 effect 重登记使确认过期；仍保留登记实例清理和真实输入/版本检查。确认期间只保留一份活动模态，原生 dialog 独立处理 Esc 和双向 Tab，底层保护区不可达。
