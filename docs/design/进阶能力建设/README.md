## 核心流程

1. 吉他进阶入口 → 学习路径 → 模块详情 → 理论小节 → 练习。
2. 理论学习 → 查看谱例 → 完成本节 → 进入练习。
3. 练习选择 → 提交答案 → 正确/错误反馈 → 解析 → 重新练习或下一题。
4. 四个模块完成 → 综合考试 → 暂存或提交 → 成绩与模块分数 → 错题复习。
5. 所有完成状态和考试记录写入当前浏览器；刷新后恢复，不承诺云端同步。

## 落地边界

- MVP 只做选择、排序、谱面/指板识别等非音频题型；不设计麦克风录音和自动演奏识别状态。
- 理论页的谱例复用现有 `packages/lxm-editor` 只读谱面能力，学习模块不修改曲谱 schema。
- 题目答案、评分、错题归类和进度状态由独立学习模块管理，不写入曲谱文档。
- 练习答错后允许继续；错误状态提供解析和复习入口，不阻塞学习路径。
- 考试满分 100 分，80 分及格；结果页同时展示最近一次成绩和最好成绩。
- 本地持久化异常必须显示可恢复提示，不能伪装成“没有学习记录”。

## 视觉与制作

- 常规设计尺寸 1440×900，输出 2880×1800，沿用现有 2 倍 PNG 交付方式。
- 视觉基线沿用现有 `#F4F6FA` 页面底色、白色内容区、蓝色主操作、绿色成功、红色错误和琥珀色提醒。
- 中文使用 Hiragino Sans GB，英文数字使用 Arial；控件沿用 Ant Design 6.4.4 语义和图标。
- 页面使用完整内容区和局部卡片，避免把整页套成多层浮卡；主要操作固定在内容流末端或窄窗口底部。
- 交互状态通过文字、图标和颜色共同表达，不能只靠颜色区分正确、错误、锁定和完成。

## 验证

制作脚本会生成全部设计 PNG、分类总览、封面总览、视觉规范和 `manifest.json`。验证报告只覆盖 PNG 编码/尺寸、索引和指定颜色对比度；真实 React 控件、键盘操作、本地存储恢复和响应式行为仍需实现阶段验收。
