# UI 编辑器外壳重构实施方案

日期：2026-10-15。实施分支：`codex/ui`。状态：开始实施。

## 1. 目标与边界

本轮目标是把现有编辑器从“原生控件拼接的功能壳”迁移为可持续扩展的 Ant Design 工作台，同时保持已经通过测试的音乐领域命令、独立简谱模型、草稿保护、文件导入导出和图片输出行为不变。

本轮包含：

- 在根布局注入 `ConfigProvider` 与中文 locale，统一品牌色、正文颜色、控件高度和圆角。
- 将属性侧栏重组为四个稳定入口：选区、段落、和弦、歌曲。
- 段落入口继续承载歌词和简谱两个子模式；歌曲入口承载原有谱面设置表单。
- 迁移属性入口的 Tabs、图标和主要按钮到 Ant Design，保留业务草稿闸门和受控切换。
- 统一顶栏的撤销/重做、文件、导出等明确操作的按钮语义和可访问名称。
- 补充窄窗口下的 flex 约束、独立滚动和焦点样式。

本轮不包含：

- 曲谱库、IndexedDB、保存基线、同名冲突和跨窗口冲突。
- 新建/管理页面路由及离开保护。
- `@liuxianmao/lxm-editor` 领域命令、布局几何、简谱事件模型和导出分页算法。
- 把所有音乐专用控件强行替换成通用 Ant Design 图标；谱面符号和现有音乐资产继续使用领域资源。

## 2. 当前代码与设计差距

当前 `EditorShell` 已经具备完整的编辑能力，但通用控件主要是原生 `button`、`select`、`input` 和 `dialog`。设计复审要求使用 Ant Design 的主题、Tabs、Button、Form/Select，并且 Tabs 切换必须先经过草稿保护，不能让 `onChange` 直接改变业务目标。

当前 `MusicTextSidebar` 内部已经有可复用的请求闸门 `request`，它负责处理歌词/简谱草稿、和弦草稿和谱面设置草稿。因此本轮只增加 UI 表示层的 `propertyTab`，不改写现有 `SidebarAction` 和草稿状态机。

## 3. 实施设计

### 3.1 全局主题

新增客户端 `AppProviders`：

- `ConfigProvider` 使用 `zh_CN`。
- `colorPrimary: #285BE0`。
- 正文 `#202838`，辅助文字 `#626E82`。
- 布局背景 `#F4F6FA`，容器白色，边框 `#D9D9D9`。
- `borderRadius: 6`，控件高度采用 32，紧凑工具保留 24。
- `App` 作为后续反馈消息、通知和 Modal 的统一上下文入口。

### 3.2 四栏目映射

| 设计栏目 | 内部业务目标 | 说明 |
| --- | --- | --- |
| 选区 | 当前 TAB 选区、焦点位置、操作提示 | 只展示/引导，不新增领域命令；已有顶栏命令仍是实际操作入口 |
| 段落 | `lyric` / `numbered` | 保留歌词与独立简谱子页签、连续输入和草稿恢复 |
| 和弦 | `chord` | 保留和弦名称、指法图和横按编辑 |
| 歌曲 | `score` | 承载原有歌曲信息、基础拍号和排版设置表单 |

`propertyTab` 只决定侧栏的一级显示内容；内部 `kind` 继续使用现有四种业务目标，避免在 UI 重构中改变草稿目标身份。

### 3.3 切换与草稿保护

- 一级 Tabs 为受控组件，`activeKey` 从 `propertyTab` 派生。
- 点击一级栏目时先调用现有 `request`；只有返回 `true` 才提交 `propertyTab`。
- 切换到段落时沿用当前歌词/简谱子模式；切回和弦或歌曲时不清除未激活栏目中的合法暂存草稿。
- 选区栏目使用当前选择和焦点信息作为只读面板，不把展示状态写入历史。
- `pending`、输入法组合态和正在提交的音乐文本仍由现有控制器处理，Modal/Tabs 不绕过保护。

### 3.4 顶栏迁移策略

本轮先迁移无领域歧义的撤销、重做、文件导入/导出、图片导出和基础显示偏好控件；节奏、拍点、技巧、简谱和连音组工具保留现有音乐图标与禁用规则，后续逐组迁移。这样可以验证主题和布局，不会因为一次性替换大量按钮而丢失键盘语义或测试选择器。

## 4. 验收条件

- `pnpm --dir apps/website type-check` 通过。
- `pnpm --dir apps/website lint` 通过。
- 现有网站测试全部通过，且不改变领域命令测试结果。
- 属性侧栏默认显示“歌曲”，可以切换到“选区/段落/和弦”。
- 在歌词或简谱存在未应用草稿时，切换一级栏目仍由现有保护流程决定；取消保护不会改变当前栏目。
- 简谱切换不建立或迁移 TAB 选区；选区栏目只显示 TAB 选区状态。
- 1440 宽和 1024/768 宽下侧栏、谱面视口均可达，长表单和长谱各自滚动，不能覆盖顶栏。
- 现有文件导入、导出、图片预览和音乐编辑快捷键保持可用。

## 5. 后续切片

完成本轮外壳后，再单独提交曲谱库与保存控制器技术方案，冻结 IndexedDB 数据契约、`storeVersion`、名称策略、复制/删除规则和全量草稿接口，之后才实现管理、新建、保存和离开保护闭环。
