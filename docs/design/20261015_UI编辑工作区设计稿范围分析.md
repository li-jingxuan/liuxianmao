## 3. 画面范围与实现域

### 3.1 编辑工作台：9 张

对应目录：`03_编辑工作台/`。

- 默认态：编辑器顶栏、A4 纸张、谱面视口、属性侧栏和底部状态。
- 单格输入：两位品位输入草稿、超时提交、输入中反馈。
- 范围选择：多弦多拍的选区边界、混合值、作用范围和禁用状态。
- 未应用草稿保护：应用、放弃、继续编辑，且保持原目标焦点。
- 歌曲设置：歌曲信息、基础拍号、Capo、段落标记、小节复用。
- 视图与排版：紧凑/舒适排版、和弦图显示、编辑/成品视图边界。
- 快捷键帮助：受控 Modal、焦点约束和编辑快捷键说明。
- 休止/恢复/删除/附点完整入口：即时工具与作用范围提示。
- TAB 对齐与选区细节：字形居中、符干、连梁、悬停、焦点、范围端点和命中。

实现重点：先完成外壳骨架和工具分组，再校准谱面与侧栏的真实布局；不能用 PNG 固定坐标替代核心 layout 和命中结果。

### 3.2 歌词、简谱、和弦：11 张

对应目录：`04_歌词简谱与和弦/`。

- 歌词：单拍编辑、连续填词预览、谱尾错误。
- 简谱：单拍多音、连续录入、覆盖保护、独立音高/时值/技巧属性。
- 和弦：预设与六弦指法、横按、高级操作和错误状态。
- 内容行：添加歌词/简谱行、无目标空态。
- 视觉规范：简谱常用符号、拍号、连梁、八度点、升降号和连线。

实现重点：歌词仍锚定 TAB Beat；简谱锚定独立 event/item/时间窗；和弦保留指法图与横按编辑。三者不能合并成一个模糊的“文本属性表单”。

### 3.3 技巧与小节结构：12 张

对应目录：`05_技巧与小节结构/`。

- 小节属性与范围复制。
- 拍点覆盖/粘贴预览。
- 连音组比例和禁用条件。
- 16 类技巧选择器。
- 推弦半音/全音属性。
- 编辑影响反馈与撤销。
- 关系技巧目标音符。
- 范围技巧起止与语义。
- 小节工具展开与段落字段。
- 拍点结构菜单与可用条件。
- 六类小节线及谱尾禁用。
- 技巧方向与辅助品位参数。

实现重点：命令规划、预览、影响确认和撤销必须继续由核心领域层决定；UI 只负责选择目标、展示计划和提交确认，不能在 React 层复制音乐规则。

### 3.4 图片导出与异常：4 张

对应目录：`06_图片导出与异常/`。

- A4 多页图片预览。
- 图片生成进度与取消。
- 图片生成成功与下载。
- 字体未就绪或谱面超宽导致的导出失败。

实现重点：编辑视图使用 `purpose: editing`，预览/PNG 使用 `purpose: presentation`；选区、悬停、焦点、空位框和编辑提示不能进入成品。

### 3.5 窄窗口适配：4 张

对应目录：`07_窄窗口适配/`。

- 1280：谱面与属性并列。
- 1024：底部属性分区。
- 650px 高：独立滚动与固定动作。
- 768：更多工具与底部编辑。

实现重点：分区 flex/grid、独立 overflow、稳定表单实例和可达的弹层/下拉/键盘焦点；不能用卸载面板或绝对定位模拟设计稿。

## 4. 全局视觉约束

以 Ant Design 6.4.4 为实际实现基线：

| Token | 值 |
| --- | --- |
| 主操作 | `#285BE0` |
| 正文 | `#202838` |
| 次级文字 | `#626E82` |
| 工作区背景 | `#F4F6FA` |
| 容器背景 | `#FFFFFF` |
| 边框 | `#D9D9D9` |
| 成功/警告/危险 | `#19734F` / `#92600C` / `#BC3547` |
| 通用控件高 | 24 / 32 / 40 |
| 通用圆角 | 6；面板/Modal 最多 8 |

字体和间距以视觉规范为基准。通用按钮、Tabs、Form、Select、InputNumber、Segmented、Alert、Modal 使用 Ant Design；音符、休止、附点、连音、TAB、技巧线和指法图继续使用项目音乐资产和核心谱面 scene。

## 5. 当前代码覆盖度判断

当前 `0b17ba7` 已完成第一阶段外壳：主题 Provider、四栏目 Tabs、选区面板、部分通用按钮/Switch、基础窄窗口断点和草稿切换保护。

但与 40 张目标画面相比，仍有以下明显差距：

- 顶栏仍是高密度平铺工具，尚未按设计稿完成分组、收纳和作用范围反馈。
- 歌曲设置、歌词、简谱、和弦表单大部分仍是原生控件，尚未逐项按 Ant Design 表单样式落地。
- 结构影响确认、快捷键帮助、文件确认等仍未统一为设计稿中的 Modal/Alert 状态。
- 技巧、拍点、连音组和小节结构的设计状态尚未逐画面对齐。
- 图片导出预览、生成进度、成功下载和失败态尚未按设计稿完整重构。
- 1024/768/650px 场景当前只有基础断点，尚未完成设计稿要求的工具收纳、底部动作固定和焦点可达验收。
- 谱面本身的字形居中、TAB 对齐、简谱记号净空和编辑/成品差异必须继续消费核心 layout，不能用 CSS 外壳掩盖差距。

## 6. 建议实施顺序

1. **编辑工作台骨架**：按默认态、歌曲设置、视图排版、选区细节冻结页面结构和视觉 token。
2. **顶栏工具分组**：节奏/休止、小节/拍点、连音、技巧、文件/导出分组，并补齐 Tooltip、禁用原因和键盘焦点。
3. **属性表单**：歌曲设置 → 歌词 → 简谱 → 和弦，逐个迁移 Ant Design Form 控件，保留稳定草稿 owner。
4. **结构与技巧状态**：小节、拍点、连音、技巧选择器/属性、影响确认和撤销。
5. **图片导出与异常**：A4 预览、进度、取消、下载、失败恢复。
6. **响应式和真实验收**：1280/1024/768、650px 高、200% 缩放、中文 IME、长谱和多页 PNG。

每一阶段都要同时对照对应 PNG、`implementation-review.json`、最新复审规则和现有测试；不以“页面能渲染”替代行为验收。

## 7. 本次分析的决策

本次暂不改产品代码。下一步实施前需要先审查本分析范围和顺序；确认后从“编辑工作台骨架 + 顶栏工具分组”开始，严格按 `03_编辑工作台` 的 9 张画面对照实现。
