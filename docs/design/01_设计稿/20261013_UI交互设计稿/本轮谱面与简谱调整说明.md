## 谱面展示

- 六线谱不显示小节序号。编辑器状态栏、属性面板及操作预览仍可标识当前位置，帮助定位。
- 仅在六线谱首小节及拍号发生变化的小节开头显示竖排拍号：分子在上，分母在下。普通小节不重复展示；简谱行不展示拍号。
- 拍号占用独立的前导空间，六线谱音符避让；缩小或导出时保留这一规则。

- 谱内文字（品位、拍号、歌词、简谱、和弦名称及记号文字）不铺白底块，只使用沿字形的细白色描边；页面纸张底色和控件容器不属于文字底块。

## 独立简谱编辑

简谱与 TAB 共用全曲小节与拍号规则，但简谱行不绘制拍号；拥有独立的音符、时值与技巧。简谱音符不要求与 TAB 音符一一对应；编辑简谱时值或技巧，不改变 TAB 内容。

- 点击简谱音符进入独立属性面板，编辑音高、八度、升降、时值与附点。
- 已有事件的连续均匀录入按已有事件序列改内容并保留原时值，可跨小节；新增/模板按当前小节时间范围与成员时值创建，显示简谱自身位置。两种操作不能统称为“每项默认时值”；覆盖默认关闭。
- 连音组、同音延音与圆滑连线作用于简谱自身的选区。不同音高不能应用同音延音；不适用操作在菜单中禁用并提示原因。
- 连梁根据简谱时值与分组展示，减时线与连梁不影响 TAB 的节奏线。音高点、升降号、附点及连线应分别留出空间。
- 简谱行及其上方记号区不显示 H/P 等 TAB 专用技巧字母，不沿用 TAB 的技巧关联线；仅显示简谱自身的常用记号。
- 连音组使用类似 `|___|` 的括号形标记，两个竖端向上且尽量短，组数字在括号上方居中。正常谱面端高 3px、放大的符号规范示例端高 5px（均为设计逻辑尺寸），与时值连梁区分。
- 空选区、非法输入、超出可写范围时保留草稿，显示字段提示并禁用应用。删除、替换或应用后提供撤销入口。
- 简谱 A → B 暂存/恢复草稿并提示返回编辑，不建立 TAB 选区；切其他编辑类型/模式经过保护，IME 组合期间保持原目标。全量暂存草稿处理后才能保存/输出/离开。
- 缩短时值释放空位，不补休止；延长覆盖完整后续事件，部分事件/连音组拒绝。记号删除/迁移先显示影响，确认与内容一起提交；旧文档候选不得继续使用。
- 编辑使用 editing，成品使用 presentation；有限编辑空位与命中保持同源，成品不预留纯编辑空行或输入框。原图的端高、间隙是视觉示意，正式几何由布局算法决定。

## 常用记号

符号参考稿覆盖四分、八分、十六分、二分、附点、时值连梁、高低八度点、升降号、三连音、延音增时线、同音延音连线、圆滑连线、单/双小节线、终止线和反复线。最终显示应避免记号与谱线、相邻音符和歌词碰撞。

通用按钮、菜单、表单、选择器、页签与提示沿用 Ant Design；音乐符号使用专用谱面图形，不用通用 UI 图标替代。

## 六线谱对齐与选取细节

- 品位按字形实际墨迹范围居中，单、双位数字与闷音 `x` 共用弦线交点中心；符干和连梁端点沿同一水平中心轴，不按固定字符偏移摆放。
- 六线谱符干从下方连梁基线向上伸入 TAB，靠近该拍最下方品位数字的下缘，而不是停在最下方弦线之外。按实际字形高度，在白描边之外保留 2px 间隙（设计逻辑尺寸）；同拍多音以最下方音符为准。不同拍的符干长度随数字位置变化，连梁基线保持一致。歌词按对应时间列居中，拍号上下数字也沿统一中心轴摆放。
- 窄谱面与导出预览适当展开时间列，保证数字与歌词的最小字形间距，不机械压缩为重叠文字。
- TAB 专用技巧与简谱记号分开显示；本轮示例移除原先位于简谱上方的 H 及其横线。
- 单格选中只描绘细蓝色轮廓，并改变原数字颜色；不再叠画另一个数字，也不使用不透明底块。双位数字的选中框随字形宽度扩展。
- 范围选区使用薄蓝叠层、细轮廓与小端点柄，仅覆盖所选 TAB 弦和时间列；保留当前活动格，不覆盖简谱或歌词。示例范围与属性面板的“3 拍 · 12 格”一致。
- 范围内品位不一致时，属性面板显示“混合值”，输入后才统一设置；休止操作提示所选拍点的完整作用范围。
- 悬停提示弱于选中，不显示强边框与控制柄；键盘移动沿当前格定位。指针按最近弦与时间列命中，命中范围以相邻位置中点为界，避免邻格重叠。
- 导出不展示选区、悬停、焦点和端点柄，只保留音乐内容及文字描边。
