## 字段与行为约束

- 录入方式只使用实际名称“连续录入”“单音组编辑”。当前简谱事件支持“新增时间范围”及已有事件；位置从“第1拍”表示，不再使用“1/0”。
- 节奏模板包含：自选时值、前八后十六、前十六后八、三连音（八分）、自定义成员时值、自选节奏连音。自定义模板按输入项显示“第 N 音时值”及附点；自选节奏连音增加“连音比例”。未展示的下拉选项以此规格为准。
- 保留实际公共字段：简谱时值、时值附点、录入起点、覆盖时长。单音组文本与连续文本共用该组字段；不添加独立“八度”“升降”下拉或“默认时值”字段。
- 输入提示沿用实际语法：空格分先后音，`+` 同时发音，`'` 高音、`.` 低音、`n` 还原。单音组只接受一个输入项，同时多音写作 `1+3+5`。
- “允许覆盖此时间范围的简谱”默认不勾选；预览按实际输出音乐内容与时值的文本呈现，取消原稿虚构的逐项表格。已有事件连续改内容保留原时值；模板新增按窗口校验，不承诺每项强制改成默认时值。
- 文本应用为内联“删除简谱 / 取消 / 应用”。无已有事件时删除禁用；无有效操作或校验失败时应用禁用。
- 选中已有事件时才显示“简谱时值与技巧”：应用当前音符时值、等分持续音、起始音符、单音符音高、升音/降音/还原、低一八度/高一八度、应用单音符音高、连接终点、添加延音线/添加连音线/切换延长记号。
- 未选择连接终点时两个连线添加按钮禁用。范围操作保留复制简谱范围、覆盖简谱、插入简谱、合并至终点；已有连音组或记号时保留移除简谱连音组、更新记号端点、删除记号。图 10 将对象存在时的入口合并作设计示例，不表示这些对象在浏览器初始示例中同时存在。
- 无目标、无有效文本、窗口或模板时长不合法时按实际条件给出提示，不为了展示行或属性创建虚假音符、休止或 TAB Beat。帮助与稿件修订不更改产品行为。

## 制作与核对

本批修改 3 张既有简谱稿，新增 3 张简谱状态稿；全包共 65 张画面、75 张评审 PNG。图 04 使用 1440×1220，加高展示完整录入表单；图 10 使用 1440×1000，图 15 使用 1440×1080，其余本批画面 1440×900，均为 2 倍输出。源文件按完整面板内容裁取不同滚动位置，避免字段越出容器。

在 `制作源文件/` 中执行：

```sh
python3 -B render_designs.py --category 04_歌词简谱与和弦
python3 -B audit_delivery.py
```

核对对象为 PNG 编码、尺寸、清单覆盖、设计参考链接、配色与视觉布局；本次不修改产品代码，不新增运行时功能验收结论。
