# 段落简谱表单紧凑布局说明

日期：2026-10-19。用户已在聊天中确认按字段重要程度调整。本文是“段落 → 简谱”的最新布局依据，替代上一批实界对齐稿中的逐字段单列排布；功能字段与音乐语义继续依据实际编辑器。

范围起初为六张简谱设计稿；2026-10-19 追加技巧工具栏与范围复用展开态迭代，涉及 10、16 两张画面及索引。既有应用代码不在本批修改范围。

## 排序与默认状态

| 优先级 | 区域 | 排布及默认状态 |
| --- | --- | --- |
| 1 | 定位 | 当前简谱事件与录入方式同行两列；小节位置继续在状态栏显示 |
| 2 | 内容 | 单音组/连续简谱输入占满宽度，默认两行；下方只留一行速记提示，完整说明通过标签右侧问号查看 |
| 3 | 节奏 | 节奏模板占一行，简谱时值与时值附点同行；条件字段随模板出现 |
| 4 | 录入范围 | 已有事件默认收起，标题显示起点和当前范围摘要；新增时间范围默认展开起点、覆盖时长两列 |
| 5 | 预览与提交 | 先预览/校验，再覆盖勾选，最后为删除、取消、应用；动作紧随表单内容，不固定到整个侧栏底部 |
| 6 | 高频技巧 | 选中简谱音符后，在顶端工具栏直接提供延音线、连音线、延长记号快捷入口；工具栏无选区或正在编辑未提交草稿时禁用 |
| 7 | 高级操作 | “音符技巧”“范围复用”默认收起，各自按需展开；单纯开关不应用或清空草稿 |

两个添加内容行按钮与歌词/简谱切换栏保留上一批简谱稿位置。已有事件和新增窗口共用紧凑骨架；无目标时只保留禁用的事件提示、可用的录入方式与建立窗口说明，不展示虚假音乐属性。

## 紧凑规则

- 侧栏宽 440px，水平内边距 20px；控件高 32px。两列间距 8px，同组字段间距以 12px 为基准，分组间距以 20px 为基准。输入框高 56px，内容增加时按需要滚动或增高。
- 常规单音组和连续录入恢复 1440×900 的标准窗口，高频输入与提交在同一首屏；低频区域以收起标题显示，展开后侧栏可独立滚动。
- 自定义成员采用“音序｜时值｜附点”三列表格，每个输入项一行；不再把每项时值和附点各占一个全宽行。
- 选择自选节奏连音时，模板后显示连音比例；模板或窗口不合法时以错误区域替换成功预览，“应用”禁用，输入与取消入口保留。
- 长目标、范围摘要或选项超出单行时省略；完整目标和数值须在聚焦/悬停或展开区域可读。普通说明不堆叠成常驻大提示块。

## 独立操作与展开态

- 文本的“应用”、当前音符时值应用、单音符音高应用继续分别提交，收纳布局不改变命令范围。主表单时值字段旁的问号须说明：已有事件的时值变更需在音符技巧中独立应用。
- 音符技巧按时值调整、单音符音高、连接与已有记号排列。时值显示当前选择摘要和独立应用按钮；起始音符与单音符音高同行；升音/降音/还原/低一八度/高一八度同排，下方紧接“应用单音符音高”。
- 连接终点下方同排放置添加延音线、添加连音线、切换延长记号。无终点时两个连线按钮禁用；已有记号的更新/删除紧随该记号。工具栏快捷操作遵循相同目标限制，支持直达高频动作；延音线需同音目标，连音线需可连接目标。
- 范围复用展开态按两层组织：第一行并列复制、覆盖、插入等作用范围操作；第二层放合并至终点与移除连音组，并按当前对象/选区显示或禁用。覆盖与插入按钮附近保留作用范围摘要，避免误把单事件与整段范围混淆。
- 展开/收起状态属于界面状态，不写入曲谱。切换目标和模板后的原有草稿、校验与覆盖规则继续保留。问号入口应支持键盘聚焦、Enter/Space 打开和 Esc 收起；收起后回到入口。
