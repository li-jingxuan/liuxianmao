# 歌词简谱编辑入口调整说明

日期：2026-10-19。范围：仅设计 PNG、制作源文件和设计索引。本次布局方案已在聊天中确认，不涉及产品代码修改或运行时验收。

## 添加内容行

- 常规“段落”面板在歌词/简谱切换栏下方增加一行次级按钮：“＋ 添加歌词行”“＋ 添加简谱行”。按钮等宽，高 32px，间距 8px；两种模式下顺序一致。
- 常规歌词单拍、连续填词、谱尾错误、简谱单拍、连续录入及独立简谱属性稿统一使用该入口。预览表格与输入区相应收紧间距，底部提交动作保持可见。
- 无目标时允许先进入编辑区域。歌词仍定位 TAB 拍点；简谱定位自己的音符或空白位置。首次应用才写入内容，不创建占位音乐数据。
- 歌词满 4 段时“添加歌词行”禁用，说明引导编辑已有段号。简谱只有一行，已有时复用并切换到该行，不重复创建；见 [内容行状态稿](04_歌词简谱与和弦/08_添加内容行与无目标状态.png)。
- 1280px 并列布局沿用相同位置；1024px、768px 底部布局将按钮放在表单上方，低高度稿保留入口与固定动作栏，长预览在内容区滚动。

## 连续填词规则

- 仅在连续填词状态的“连续歌词”标签右侧放置 `QuestionCircleOutlined`，图标 14px，点击/聚焦区域 24px；距标签 8px。
- 悬停提示“连续填词规则”；鼠标点击或键盘 Enter/Space 打开 Popover，打开时图标高亮。保留输入框下方的一行速记提示。
- 常规侧栏浮层朝左、向谱面侧展开，不遮挡输入框、对应预览与提交按钮；窄窗口按可见空间调整方向，宽度不超出视口。
- 浮层展示空格分拍、休止拍占位、独立 `_` 跳过、同拍英文短句、覆盖选项和谱尾整批拒绝规则；文案沿用现有歌词行为。
- 点击关闭图标、外部区域或 Esc 收起，草稿与目标保持，焦点回到入口；打开/关闭帮助不触发应用。
- 新增 [12_歌词_连续填词规则浮层](04_歌词简谱与和弦/12_歌词_连续填词规则浮层.png)。这是静态展开状态设计，键盘与浮层行为须在正式实现中验证。

## 制作与核对

本批完成时共 62 张界面/状态稿、72 张评审 PNG；后续[段落简谱实界对齐](20261019_段落简谱设计稿与实际界面对齐说明.md)新增 3 张状态，当前总数为 65 张画面、75 张评审 PNG。新增稿和本轮修改均维护在 `manifest.json` 与 `implementation-review.json`，分类总览和封面同步。

制作命令（在 `制作源文件/` 目录执行，Python 环境需提供 Pillow）：

```sh
python3 -B render_designs.py --category 04_歌词简谱与和弦 --category 07_窄窗口适配
python3 -B audit_delivery.py
```

定向重绘只输出指定分类与全局封面，清单保留全部画面。PNG 编码、尺寸与索引由核对脚本检查；正文对比度继续使用原有颜色 token。
