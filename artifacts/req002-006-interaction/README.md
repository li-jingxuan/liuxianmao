## 交互与验收

完整确认范围见 [REQ-002—006 交互设计确认稿](../../docs/mvp/v8/REQ-002-006交互设计确认稿.md)。

- 默认 125% 单音符选区；画布右下缩放控件横排（减号／百分比／加号），四档菜单向上展开，滚动和 SVG 选区同步。
- 缩放控件采用约 118×34px 的紧凑尺寸，收紧按钮宽度、容器内边距及箭头间距。
- 底部评审区切换未选择、音符、多拍、小节、连音；成员数 2—6 和非法条件独立切换，不修改已应用分组。
- 时值、附点、音符状态即时生效；休止影响整拍。小节段落标记显式应用，六种右边界即时生效，末小节禁用开始/双向反复。
- 六种连音比例全部可见，按成员数、连续性、时值和附点校验；选择后显式应用，删除仅移除分组。
- 连音按钮、摘要与应用反馈优先显示中文名称；仅两种五连音保留比例区分，悬停或聚焦解释节奏比例。谱面括号标记显示数字，例如三连音显示 3。
- 撤销 / ⌘或 Ctrl+Z 恢复完整修改前状态；Esc 清除选区。所有按钮有焦点样式和可访问名称。

浏览器定位：`#zoom-minus`、`#zoom-toggle`、`#zoom-plus`、`[data-zoom]`；`[data-review]`；`[data-duration]`、`[data-dots]`、`[data-state]`；`#measure-select`、`#section-label`、`#apply-label`、`[data-bar]`；`#review-members`、`#review-condition`、`[data-ratio]`、`#apply-tuplet`、`#delete-tuplet`；`#undo`、`#locate`、`#canvas-scroll`。

## 范围边界

这是设计验收原型：9 个示例小节，休止、时值和分组以演示数据呈现，无播放、持久化、完整乐理排版或生产编辑器能力。评审区的非法条件用于展示校验状态，不向谱面写入非法数据。撤销以每次显式修改为单位恢复谱面、编辑上下文和待应用值。
